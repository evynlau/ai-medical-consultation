# 周围神经病

## 概述
周围神经病(PN)是**周围神经系统**(脑神经、脊神经根、神经丛、神经干、末梢)的损害,病因广泛:代谢(糖尿病)、免疫(Guillain-Barré、CIDP、MMN)、遗传(CMT)、感染(麻风、HIV)、中毒(药物、工业毒物)、营养缺乏(B 族)、肿瘤、副肿瘤。临床表现为**感觉、运动、自主神经**受损,常呈**远端对称性**分布(「手套袜套样」)。

## 分类
### 按分布
- **单神经病(mononeuropathy)**:腕管、肘管、腓总神经麻痹
- **多发性单神经病(mononeuritis multiplex)**:糖尿病、ANCA 相关、结节病、麻风
- **多发性神经病(polyneuropathy)**:对称、远端重

### 按神经纤维
- **大纤维**:**位置觉、振动觉、本体觉**、反射消失
- **小纤维**:**疼痛、烧灼、感觉异常**、温度觉减退(神经电生理正常!)
- **自主神经**:血压、膀胱、肠道
- **运动**:无力、萎缩

## 临床评估
### 病史要点
- 起病(急性/亚急性/慢性进行性)
- 分布(对称/不对称、近/远端)
- 感觉异常种类(麻木/疼痛/烧灼)
- 自主神经症状(体位性低血压、胃轻瘫、膀胱)
- 家族史、毒物、用药、血糖、感染、营养

### 体格
- **足部溃疡、关节变形(Charcot)**
- 叩击:远端肌肉肥大
- **踝反射早期消失**
- 步态、感觉图、Romberg、肌力

## 主要疾病

### 1. 糖尿病周围神经病(DPN)
- **最常见**(60-70% 糖尿病)
- **远端对称性感觉运动多神经病**(DSPN):最常见
- **小纤维性**:疼痛、灼痛、电击,夜间重,普瑞巴林、加巴喷丁、度洛西汀、TCAs、阿片类(避免)
- **大纤维性**:位置觉差、步态不稳、跌倒
- **自主神经**:体位性低血压、胃轻瘫、便秘/腹泻、神经原性膀胱、勃起功能障碍
- **治疗**:**严格控糖**(HbA1c < 7%)、对症

### 2. 慢性炎症性脱髓鞘性多发神经根神经病(CIDP)
- **慢性进展 / 阶梯 / 复发**性(> 8 周)
- 临床:**近端 + 远端无力、感觉异常、反射消失**
- 变异:**纯感觉型、MADSAM(不对称)**
- **电生理**:脱髓鞘(传导阻滞、远端潜伏期延长、时间离散)
- **CSF**:蛋白-细胞分离
- **治疗**:
  - **一线**:**糖皮质激素**(0.8-1 mg/kg)、**IVIG**(2 g/kg)、**PE** 同样有效
  - **维持**:硫唑嘌呤、吗替麦考酚酯、环孢素
  - **生物制剂**:**利妥昔单抗**、**来那度胺**
- **预后**:多数可缓解,15% 进展为依赖

### 3. 多灶性运动神经病(MMN)
- **纯运动、不对称、上肢重**
- **传导阻滞**(运动神经)
- **GM1-Ab** 阳性
- **治疗**:**IVIG**(首选,2 g/kg)维持

### 4. 遗传性(Charcot-Marie-Tooth, CMT)
- 儿童期起病、远端肌萎缩(「鹤腿」「爪形手」)、高弓足
- **CMT1A**(PMP22 重复):脱髓鞘,神经传导慢
- **治疗**:康复、矫形器,无特异性药物

### 5. 中毒性
- **化疗**:**奥沙利铂**(急性冷诱感觉异常)、**顺铂**(剂量累积)、**紫杉醇**、**长春碱**、**硼替佐米**
- **抗 HIV**:**司他夫定**(乳酸中毒、感觉神经病)
- **抗结核**:**异烟肼**(维生素 B6 拮抗)
- **金属**:**铅**(运动轴索、腕下垂)、**砷、铊**
- **工业**:**正己烷**(胶水)、**丙烯酰胺**
- **酒精致**:营养性 + 酒精本身

### 6. 营养性
- **维生素 B1(硫胺素)缺乏**:脚气病(运动 + 感觉 + 心脏)
- **维生素 B6 缺乏 / 中毒**:感觉神经病
- **维生素 B12 缺乏**:亚急性联合变性

### 7. 副肿瘤性
- **感觉神经元神经病**(抗 Hu):肺癌、消化道癌
- **自主神经病**:抗 CRMP5
- **Lambert-Eaton**(抗 VGCC):近端无力、自主神经

### 8. 单神经卡压
- **腕管综合征(CTS)**:正中神经,**大鱼际萎缩、拇指-小指对掌困难、Tinel、Phalen**
- **肘管综合征**:尺神经,**爪形手**
- **腓总神经麻痹**:足下垂
- **治疗**:**腕部夹板、NSAIDs、激素局部注射**;严重:**手术松解**

## 辅助检查
### 必查
- **血糖 / HbA1c、OGTT**
- **肝肾、电解质、TSH**
- **B12、叶酸、VitD**
- **血常规、电泳**(副蛋白血症)
- **ANA、ENA、ANCA**(血管炎)
- **HIV、梅毒、HBV/HCV**
- **免疫固定电泳**(POEMS)

### 选查
- **CSF**:CIDP、GBS 蛋白-细胞分离
- **抗体**:GM1、GD1a、抗 Hu、抗 MAG
- **影像**:**增强 MRI 神经根**(炎症、肿瘤)
- **皮肤活检**(表皮神经纤维密度):小纤维神经病
- **腓肠神经活检**:疑难时

## 治疗原则
- **病因治疗**:控糖、戒酒、脱离毒物、补充维生素
- **免疫调节**:CIDP、MMN、血管炎
- **疼痛管理**:**普瑞巴林 150-600 mg/d**、**度洛西汀 60-120 mg/d**、**加巴喷丁**、**阿米替林**(老年人慎用)
- **康复**:理疗、夹板、矫形器、防止跌倒
- **自主神经**:体位性低血压(米多君、屈昔多巴、补液)

## 注意事项
- **血糖未控制**是 DPN 主因,**严格控糖可预防、延缓**
- **维生素 B6 中毒**:大剂量 1-2 g/d 即可致神经病
- **顺铂、奥沙利铂**:化疗前告知神经毒性
- **CIDP 与 GBS 鉴别**:> 8 周进展、阶梯病程、近端+远端、激素有效
- **副蛋白血症**:50 岁以上 PN 必查电泳;MGUS 神经病
- **POEMS 综合征**:多发神经病、脏器肿大、内分泌病、M 蛋白、皮肤改变
- **家族史阳性、畸形足**:CMT 可能性大
- **皮肤活检**:**小纤维神经病唯一确诊手段**(NCV 正常)
- **阿片类**应避免用于慢性神经痛
