# 皮肤软组织感染

## 概述
皮肤软组织感染(SSTI)是临床最常见的感染之一,涵盖**毛囊炎、脓疱疮、丹毒、蜂窝织炎、坏死性筋膜炎、皮肤脓肿、糖尿病足感染、手术部位感染**等。**2014 IDSA 分类**为非复杂(uncomplicated)和复杂(complicated),后者需警惕外科处理。

## 分类(IDSA 2014)

### 1. 浅表非复杂
- **脓疱疮**(Impetigo)
- **毛囊炎**
- **疖、痈**(Furuncle / Carbuncle)
- **脓肿**(可切开)

### 2. 复杂性
- **蜂窝织炎**(Cellulitis)
- **丹毒**(Erysipelas,表浅)
- **坏死性筋膜炎**(NF,外科急症)
- **肌坏死**(气性坏疽)
- **糖尿病足感染**

### 3. 特殊
- **动物咬伤**(猫、狗、人咬伤)
- **术后 SSI**
- **脓疱病**(Molluscum 周围)
- **真菌**(孢子丝菌、皮肤癣)

## 常见病原
- **金黄色葡萄球菌**(S. aureus) — 最常见,**MRSA 流行**
- **A 组链球菌**(GAS, 化脓性链球菌)
- **化脓性链球菌**(蜂窝织炎、丹毒、NF)
- **革兰阴性**(糖尿病、动物咬伤)
- **厌氧菌**(咬伤、糖尿病、NF)
- **铜绿假单胞**(中耳炎、外耳炎、热浴毛囊炎)

## 临床表现

### 蜂窝织炎
- 局部红、肿、热、痛
- 边缘不清
- 全身:发热、寒战、淋巴结炎
- 反复:排查静脉功能不全

### 丹毒
- **浅表淋巴管**
- **边缘清楚、隆起**(与蜂窝织炎区别)
- 好发:面部、小腿
- 高热、寒战

### 坏死性筋膜炎(NF)
- **外科急症**、病死率高
- **疼痛与体征不平行**(早期剧痛,体征轻)
- 皮肤:红→紫→大疱、坏死
- 全身中毒
- **多菌协同**(I 型)、**GAS**(II 型)

### 脓肿
- 局部红、肿、痛、**波动感**
- 引流(切开/穿刺)

## 诊断
- **临床**(主要)
- **实验室**:WBC、CRP、PCT
- **血培养**(全身、NF)
- **脓液培养**(引流时)
- **影像**:
  - **超声**(脓肿、深部)
  - **CT/MRI**(深部、坏死)
- **快速抗原**(链球菌)
- **MRSA 筛查**(鼻)

## 治疗

### 脓疱疮、毛囊炎、浅表
- 局部:莫匹罗星、夫西地酸、复方多粘菌素
- 系统:克林霉素、SMZ-TMP(局灶)

### 蜂窝织炎/丹毒
- **轻-中度**:
  - **头孢唑啉**、**头孢氨苄**、**头孢呋辛**
  - **克林霉素** 300 mg qid
  - **阿莫西林克拉维酸**
  - **MSSA**:苯唑西林、头孢唑啉
  - **MRSA**:**SMZ-TMP、多西环素、利奈唑胺**
- **中-重度**:
  - **静脉**(头孢唑啉、头孢曲松、苯唑西林)
  - **MRSA**:**万古霉素、利奈唑胺、达托霉素**
- 抬高患肢
- 疗程:**5-10 d**(症状缓解后 3 d)

### 脓肿
- **切开引流(核心)**
- 培养(脓液)
- 抗菌:扩散性、蜂窝织炎、复发、特殊部位
- 单纯脓肿:可单引流

### 坏死性筋膜炎
- **急诊手术**(核心、不可延误)
- **广谱经验**:
  - **碳青霉烯**(亚胺培南、美罗培南) + **万古霉素** + **克林霉素**(抗毒素)
  - 或 **哌拉西林他唑巴坦** + **万古** + **克林霉素**
- 覆盖:GAS、GAS、肠杆菌、厌氧、MRSA
- **克林霉素**(抑制毒素)
- 多次清创(24-48 h)
- ICU 支持、液体复苏
- **IVIG**(GAS 严重,争议)

### 糖尿病足
- 多菌、需外科评估
- **轻度**:**阿莫西林克拉维酸、克林霉素 + 氟喹诺酮**、**TMP-SMX**
- **中-重度**:**碳青霉烯**、**哌拉西林他唑巴坦** + **万古/利奈唑胺**
- **覆盖厌氧**:甲硝唑、克林霉素
- **骨穿 + 影像** + 骨活检 → 骨髓炎
- 引流、清创
- **糖化血红蛋白 7% 以下**
- 病原:金葡、链球菌、肠杆菌、厌氧

### 动物咬伤(猫、狗)
- 伤口清洁、清创
- 破伤风、狂犬病
- **不缝合**(咬伤)
- 抗菌:早期
  - **阿莫西林克拉维酸**(覆盖多杀巴斯德、犬咬 CO2、链球菌、葡萄球菌、厌氧)
  - 头孢呋辛 + 甲硝唑
  - 厌氧:Bacteroides、Capnocytophaga

### 术后 SSI
- 引流 + 培养
- 经验:头孢唑啉/头孢呋辛,严重时碳青霉烯
- 病原:金葡、肠杆菌

## 特殊 SSTI
- **MRSA 社区**(CA-MRSA):皮肤、化脓、坏死
  - SMZ-TMP、多西、克林、万古
- **A 组链球菌**:严重(猩红热、坏死)、接触隔离
- **孢子丝菌病**:碘化钾、伊曲康唑
- **铜绿假单胞**(热点):热浴、伤口:氟喹诺酮

## 预防
- 创面清洁
- 糖尿病、静脉、淋巴水肿管理
- **金葡菌去定植**(复发性):莫匹罗星鼻、氯己定
- 皮肤屏障(湿润、避免外伤)
- 疫苗(链球菌,研发中)

## 注意事项
- **NF 早识别**(剧痛与体征不平行)**早手术**
- **脓肿**先引流(抗菌仅辅助)
- **蜂窝织炎**与丹毒区别(淋巴管)
- **中重度**经验覆盖 MRSA + 链球菌
- **克林霉素** 抑毒(GAS、葡萄球菌)
- **糖尿病足** 多学科(血管、伤口、骨科)
- **预防**金葡去定植
- **咬伤**不缝合 + 抗菌 + 狂犬
- **坏死性**:不延误手术
