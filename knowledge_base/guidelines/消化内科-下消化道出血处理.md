# 下消化道出血处理

## 概述
下消化道出血(LGIB)指 Treitz 韧带以远的小肠、结肠、直肠出血。年发病率约 20-30/10万,大多为自限性,严重出血(需输血)占 20% 左右。80% 出血可自行停止,病死率 2-4%。常见病因:憩室病、痔疮、肛裂、结直肠癌、息肉、炎症性肠病、缺血性结肠炎、血管畸形(AVM)、放射性肠炎、感染性结肠炎等。

## 病因(按部位)
- **小肠**(5-10%):肿瘤、Meckel 憩室、Dieulafoy、AVM、IBD、缺血、NASID 肠病
- **结肠**(> 90% 出血):
  - 老年:憩室病(最常见)、AVM、缺血性结肠炎
  - 中年:IBD、感染、息肉
  - 青年:IBD、痔疮、肛裂、息肉
- **肛门直肠**:痔疮(最常见)、肛裂、直肠癌
- **系统**:凝血病、血管炎

## 临床表现
- **便血**:鲜红(低位)、暗红(高位)、果酱样
- **黑便**:出血部位高(小肠、升结肠)
- **循环障碍**:心悸、苍白、晕厥
- **伴随**:腹痛、发热、消瘦、便条变细

## 严重度评估
- **休克指数 SI = HR/SBP**:
  - 0.5:轻度(< 500 mL)
  - 1.0:中度(500-1000)
  - 1.5:重度(> 1000)
- **Oakland 评分**(预测安全出院):年龄、性别、便血史、HR、收缩压、Hb

## 诊断
- **结肠镜**:首诊首选(出血后 24 h 内最佳)
  - 出血量大、肠腔准备差者影响观察
- **CTA(增强 CT)**:
  - 大出血、血流动力学不稳
  - 0.3-0.5 mL/min 以上可显示
  - 阳性后行 DSA 治疗
- **DSA / 介入**:
  - 0.5-1.0 mL/min 出血可见造影剂外溢
  - 同时可栓塞止血
- **核素扫描(⁹⁹ᵐTc-RBC)**:
  - 0.1 mL/min 灵敏度高
  - 间歇性出血
- **小肠镜 / 胶囊内镜**:小肠出血
- **上消化道检查**:必要时排除

## 治疗

### 一、复苏
- 同 UGIB
- 双通路补液、备血
- 输血阈值:Hb < 70 g/L 启动
- 纠正凝血、抗凝桥接

### 二、药物
- **停用抗凝、抗血小板**(评估血栓风险后)
- **NSAID 相关**:停药
- **生长抑素、奥曲肽**:小肠 / 憩室出血可能有益
- **氨基己酸 / 氨甲环酸**:辅助,谨慎(血栓风险)
- **沙利度胺**:AVM 长期治疗

### 三、内镜
- **结肠镜**:
  - 出血部位 90% + 来自结肠,首选
  - 充分肠道准备(PEG)
  - 治疗:注射肾上腺素、热凝、钛夹、套扎
  - **憩室出血**:钛夹、肾上腺素 + 热凝
  - **AVM / 放射性**:APC
  - **息肉出血**:圈套、钛夹
- **小肠镜**:球囊辅助小肠镜(DBE) / 单气囊

### 四、介入
- **DSA 栓塞**:
  - 内镜失败 / 不可及、严重大出血
  - **超选择性微弹簧圈 / 明胶海绵**
  - 注意肠道缺血风险(小肠比结肠敏感)
- **TIPS**:门脉高压 EGVB 罕见致 LGIB,少数门脉高压性结肠病需此治疗

### 五、手术
- 适应证:大出血内镜 + 介入失败、肿瘤、肠坏死、狭窄
- 术中内镜定位
- 切除范围宁少勿多(小肠尽量保留)

## 注意事项
- 黑便不仅限上消化道,小肠 / 升结肠出血也可
- 30% 患者出血反复,需多次评估
- 自限性为主,但老年人、心脏病者预后差
- 痔疮出血一般量少(便后滴血)
- NSAID 相关小肠溃疡增加
- 缺血性结肠炎常以腹痛 + 血便为特征,左半结肠多见,处理以禁食、抗生素、补液为主,坏死需手术
