# 慢性咳嗽病因诊断流程

## 概述
咳嗽是临床最常见症状,**慢性咳嗽**指 > 8 周,以咳嗽为主要或唯一症状、胸部影像正常。我国慢性咳嗽专科门诊中前 3 位病因:**咳嗽变异性哮喘(CVA)、上气道咳嗽综合征(UACS,鼻后滴流)、嗜酸粒细胞性支气管炎(EB)**。

## 慢性咳嗽解剖分布
咳嗽反射弧:
- **咳嗽感受器**:鼻窦、咽、喉、气管、支气管、外耳道、胸膜、心包膜、膈肌、胃
- **传入神经**:迷走、三叉、舌咽
- **咳嗽中枢**:延髓
- **传出神经**:迷走、膈、肋间、喉返
- **效应器**:呼吸肌、喉

## 病因分类
### 1. 呼吸系统
- **CVA**(哮喘特殊类型)
- **UACS**(鼻后滴流,鼻炎 / 鼻窦炎)
- **EB**(嗜酸粒细胞性支气管炎)
- 变应性咳嗽
- 支气管结核
- 早期 IPF
- 支气管肺癌
- 气管支气管软化
- 支气管异物
- 纵隔肿瘤
- 胸膜疾病

### 2. 消化系统
- **胃食管反流病(GERD)**
- 食管动力障碍
- 贲门失弛缓

### 3. 心血管
- 心衰(肺淤血)
- 心包炎
- 二尖瓣狭窄
- 主动脉瘤
- 血管紧张素转换酶抑制剂(ACEI)
- **ARB** 也可(较少)

### 4. 神经 / 心理
- 习惯性 / 心因性咳嗽
- 抽动障碍(儿童)
- 中枢性

### 5. 感染后
- 上感后咳嗽(亚急性,3-8 周)

## 临床评估

### 详细病史(关键)
- 咳嗽特点:干 / 湿、阵发 / 持续、昼夜规律
- 诱因:冷空气、说话、运动、进食、卧位
- 伴随:反流症状、鼻塞、流涕、喘息、咽痒
- 用药史(尤其 ACEI)
- 吸烟、环境
- 既往:哮喘、过敏、鼻窦炎、GERD
- 职业暴露

### 体格检查
- **鼻**:鼻甲肥大、鼻中隔、鼻息肉
- 咽:鼻后滴流、淋巴滤泡
- 喉:杓状软骨、鹅卵石样
- 胸:啰音、哮鸣音
- 心:杂音、心律
- 腹:反流征

## 诊断流程

### 第一步:基础评估
- **胸片**(或 HRCT)
  - 正常 + 病史无特殊提示 → 进入第二步
  - 异常:针对性检查
- 戒烟、环境改善、停 ACEI(4 周)

### 第二步:经验性治疗
**「解剖学」方案**(中华医学会推荐,Irwin 流程):
- **CVA 优先**:诱导痰 EOS + 支气管激发试验阳性
  - 治疗:低剂量 ICS + LTRA,2-4 周
- **UACS**:
  - 病史:鼻塞 / 流涕 / 咽部滴流感
  - 治疗:鼻用糖皮质激素 + 抗组胺,2-4 周
- **EB**:诱导痰 EOS ≥ 3% 但无气道高反应
  - 治疗:ICS,2-4 周
- **GERD**:
  - 病史:反流 / 烧心
  - 治疗:PPI + 促动力,8 周

### 第三步:辅助检查
- 诱导痰细胞分类
- 肺功能 + 支气管激发试验
- FeNO(嗜酸气道炎症)
- 鼻咽镜 / 鼻窦 CT
- 24h 食管 pH 监测
- 胸部 CT(胸片无异常,咳嗽顽固)
- 支气管镜(可疑肿瘤、结核、异物)

## 各病因治疗

### CVA
- **ICS**:低剂量布地奈德 / 氟替卡松
- 联合 LTRA(孟鲁司特)
- 联合支气管扩张剂(必要时)
- 部分演变为典型哮喘

### UACS
- 鼻用 ICS(布地奈德鼻喷)
- 抗组胺(西替利嗪、氯雷他定)
- 减充血剂(短期)
- 生理盐水鼻腔冲洗
- 慢性鼻窦炎:延长治疗 / 手术

### EB
- ICS(诊断性治疗有效)
- 一般不需 LTRA

### GERD 咳嗽
- **PPI**(奥美拉唑、雷贝拉唑)8 周
- 促动力(莫沙必利、伊托必利)
- 饮食:避免咖啡、酒精、油腻、巧克力
- 减重、抬高床头
- 难治:抗反流手术(腹腔镜 Nissen 胃底折叠)

### 感染后咳嗽
- 3-8 周自限
- 对症:复方甘草片、苏黄止咳、抗组胺
- 顽固:ICS / LTRA

### 药物性(ACEI)
- 停 ACEI,4 周
- 换 ARB(部分人仍咳)

### 心理性 / 习惯性
- 排除器质性
- 言语疗法、行为治疗
- 多见于青少年

## 难治性咳嗽
- 多病因:同时治疗 CVA + UACS + GERD
- 神经调节剂:
  - 加巴喷丁、普瑞巴林(成人)
  - 阿米替林(老年 / 顽固)
- 言语病理治疗(SLP)
- 咳嗽抑制训练

## 注意事项
- **不要**一上来就「消炎、止咳」盲目治疗
- **儿童慢性咳嗽**:常见 UACS、CVA、心因性、迁延细菌性支气管炎
- **老年人**:肿瘤、ACEI、GERD 常见
- 「上感后咳嗽」常误认为感染,反复抗生素
- 戒烟、改善环境是基础
- **咳嗽晕厥**:阵发性咳嗽 → 颅压↑、静脉回流↓ → 晕厥
- 心理评估不可忽视
- 长期咳嗽生活质量差:焦虑、抑郁

## 何时紧急评估
- 痰中带血
- 进行性加重
- 体重下降
- 声音嘶哑(尤其吸烟者)
- 吞咽困难
- 胸痛
- 抗炎无效
