# 老年共病管理

## 概述
共病(Multimorbidity)指个体同时存在**2 种或以上慢性疾病**。我国老年人 60 岁以上 60%+ 共病,80+ 80%+。共病是**功能下降、失能、死亡**的独立风险因素。**老年共病管理**以**患者为中心**、**优先级、循证**为核心。

## 流行病学
- 60-69 岁:50% 共病
- 70-79 岁:65% 共病
- 80+:80% 共病
- 5+ 慢病:1/3+
- 常见共病组合:高血压 + 糖尿病 + 冠心病 + 卒中 + 慢阻肺 + 骨松 + 抑郁

## 评估

### 1. 共病评估
- **Charlson 共病指数(CCI)**
- **累计疾病数**
- **疾病相互作用**(协同)
- **疾病负担**(QoL)

### 2. 功能评估
- ADL、IADL
- CGA(综合)

### 3. 治疗负担
- **多药**(polypharmacy, ≥ 5)
- **过度医疗**
- **患者依从性**

### 4. 预后评估
- **衰弱**(Frailty)
- **预期寿命**(ePrognosis)
- **MORT**(住院死亡风险)

## 管理原则

### 1. 患者为中心
- **关注患者优先级**(可能与医师不同)
- **共同决策**(shared decision making)
- **目标导向**(生活质量、功能、独立)

### 2. 优先级
- 危险疾病**优先**:急性、不稳定、致死致残高
- **患者偏好**重要
- 治疗获益 vs 风险

### 3. 循证医学的局限
- RCT 多**排除老年、共病**
- **指南**单一疾病,**不适用**多病
- **循证 + 经验 + 患者意愿**

### 4. 合理用药
- **Beers 标准**(2019)
- **STOPP/START**(2014)
- **STOPPFrail**(临终)
- **去处方化**(Deprescribing)

### 5. 多学科
- 全科 + 老年科 + 专科
- 协调、避免重复、专科对抗治疗

### 6. 自我管理
- 患者教育、共病管理
- 自我监测(血压、血糖)

## 常见共病管理

### 心血管共病
- 高血压 + 糖尿病 + 冠心病
- **降压 + 降糖 + 他汀 + 抗血小板**
- **目标个体化**(老年)
  - 血压:< 150/90(80+ 起始),< 140/90(可耐受)
  - 糖化:7.5-8.5%(> 80 岁、虚弱)
  - LDL:适度(个体化)

### 糖尿病 + 肾衰
- 二甲双胍(剂量调整)
- SGLT2i(心肾保护)
- GLP-1RA(肥胖、ASCVD)
- **低血糖风险**:避免格列类

### 骨松 + 跌倒
- **钙 + Vit D + 抗骨吸**(双膦、地舒)
- 跌倒预防(运动、家居)

### 认知 + 共病
- 痴呆 + 高血压、糖尿病、房颤
- 治疗高血压、糖尿病(中-晚期可能降)
- **抗血小板**:权衡出血
- **不推荐他汀**(晚期)

### 慢阻肺 + 心衰
- 短效支气管扩张 + 抗心衰
- 避免 β 阻滞剂
- **利尿** 注意电解质

### 抑郁 + 焦虑 + 失眠
- SSRI/SNRI(慎药相互作用)
- **苯二氮卓**:短程、避免长期
- **CBT**

## 跨疾病注意事项
- **蛋白尿**(降压、降糖、抗血小板)
- **心肾综合征**(心衰 + CKD)
- **衰弱**(运动、营养)
- **多重用药**:精简

## 治疗冲突
- 糖尿病指南:严格降糖 → 老年增加低血糖
- 高血压指南:严格降压 → 老年低血压、跌倒
- **循证 → 个体化**

## 团队管理
- 老年医学科医师(主导)
- 多个亚专科
- 全科医生
- 药师
- 护士
- 康复
- 心理

## 注意事项
- **多病并存 ≠ 多病同治**
- **优先危及生命、影响功能的疾病**
- **不照搬单一指南**
- **治疗负担 + 患者意愿**
- **去处方化**:定期精简
- **多学科协作**减少重复
- **关注**衰弱、失能、社会
- **共同决策**
- **远期目标**:功能、生活质量 > 单纯延寿
