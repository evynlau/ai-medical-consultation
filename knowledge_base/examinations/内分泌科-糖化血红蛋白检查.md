# 糖化血红蛋白检查

## 概述
糖化血红蛋白(HbA1c)是红细胞中血红蛋白与葡萄糖非酶促结合的产物,浓度反映过去 2-3 个月(红细胞半衰期 120 天)的平均血糖水平。2010 年 ADA 将其纳入糖尿病诊断标准,与 DCCT/UKPDS 推导的平均血糖(ADAG)对应关系明确。

## 原理与检测
- 糖基化不可逆,与血糖浓度持续时间相关
- 60% 反映过去 1 月、30% 中间 1-2 月
- 检测方法:
  - **HPLC**(高效液相):金标准,NGSP 认证
  - 免疫法、酶法
  - 床旁 POC:NGSP 认证方可
- 报告:NGSP % 或 IFCC mmol/mol(eAG)
  - 换算:NGSP = 0.0915 × IFCC + 2.15

## 参考与诊断

### 正常参考
| 人群 | HbA1c |
|---|---|
| 正常 | 4.0-5.6% |
| 高危(Prediabetes) | 5.7-6.4% |
| **糖尿病** | **≥ 6.5%** |

### 糖尿病诊断标准(任一)
- 空腹血糖 ≥ 7.0 mmol/L
- OGTT 2h ≥ 11.1
- 随机 ≥ 11.1 + 症状
- **HbA1c ≥ 6.5%**(无干扰情况下)

### 平均血糖估算
| HbA1c | eAG(mmol/L) |
|---|---|
| 6% | 7.0 |
| 7% | 8.6 |
| 8% | 10.2 |
| 9% | 11.8 |
| 10% | 13.4 |
| 11% | 14.9 |
| 12% | 16.5 |

## 治疗目标
| 人群 | 目标 |
|---|---|
| 一般成人 | < 7.0% |
| 严格(年轻、新诊断、CV 风险低) | < 6.5% |
| 宽松(老年、低血糖高危、长病程) | 7.5-8.0% |
| 妊娠(孕前、T1DM) | < 6.5% |
| 终末期、严重合并症 | < 8.5% |
| TIR 70-180 mg/dL | > 70% |

## 临床应用

### 1. 糖尿病诊断
- 无需空腹、变异性小
- ≥ 6.5% 重复确认(无典型症状)

### 2. 治疗监测
- 每 3 月复查 1 次
- 治疗达标、方案稳定:6 月 1 次
- 治疗调整:每 1-3 月
- **目标** < 7% 是 DCCT/UKPDS 推导的获益阈值

### 3. 治疗决策
- HbA1c 9% 强烈建议联合
- 2-3 月评估疗效
- 持续 > 9% 需强化

### 4. 筛查
- 45 岁以上、超重 + 危险因素:每 3 年
- 妊娠:GDM 不推荐(可能漏诊),监测用
- SGLT2、HIV 治疗
- 移植后、HIV、囊性纤维化

## 干扰因素

### 假性升高
- 缺铁性贫血
- B12、叶酸缺乏
- 脾切除、纯合 HbF、高海拔
- 慢性酒精、肾功能不全(早期)
- 铅中毒、阿司匹林大剂量
- 高胆红素

### 假性降低
- 急性失血、溶血性贫血
- 慢性肾衰
- 维生素 C、E 大剂量
- 妊娠中后期(红细胞周转快)
- 血红蛋白病(HbS、HbC、HbF、HbE)
- 促红细胞生成素、铁剂
- HIV 治疗(部分药物)

### 影响红细胞寿命
- 出血、输血
- 缺铁治疗中
- 化疗
- EPO

## 特殊场景
- **GDM**:诊断仍用 OGTT,HbA1c 用于已诊断糖尿病
- **T1DM**:CGM 时代 GMI(Glucose Management Indicator)反映估算 HbA1c
- **T2DM 缓解**:HbA1c < 6.5%、停药 3 月以上
- **围手术期**:血糖 7.8-10 mmol/L
- **CKD**:贫血、ESA 影响 HbA1c
- **肝病**:GSP(糖化白蛋白)反映 2-3 周血糖
- **血液透析**:AGP(1,5-AG)反映短期

## 糖化白蛋白(GA)
- 反映 2-3 周血糖
- 急性应激、初发糖尿病、监测
- GA/HbA1c 比值
- 参考:11-16%
- 受甲状腺、白蛋白影响

## 注意事项
- 床旁 POC 需 NGSP 认证
- 实验室 NGSP 认证
- 报告含 NGSP/IFCC 双值便于统一
- 同一患者同一方法
- 急性疾病、应激不可作诊断
- 与 TIR 互为补充:CGM 时代
- 严格个体化:年龄、病程、并发症、低血糖
- HbA1c 不能代替 SMBG/CGM,尤其 T1DM、胰岛素治疗
