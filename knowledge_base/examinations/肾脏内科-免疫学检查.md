# 免疫学检查

## 概述
肾脏疾病中,免疫学检查是鉴别原发 / 继发性肾小球病、监测活动度、指导治疗的核心工具。包括 ANA、ENA、ANCA、抗 GBM、抗 dsDNA、补体、抗 PLA2R 等。

## 抗核抗体(ANA)

### 检测方法
- **间接免疫荧光(IIF)**:**金标准**,以 Hep-2 细胞为底物
- **滴度** ≥ 1:80 阳性(成人)
- **核型**:
  - 均质型:抗 dsDNA、抗组蛋白(SLE)
  - 周边型:抗 dsDNA(SLE 活动)
  - 斑点型:抗 ENA
  - 核仁型:硬皮病(抗 Scl-70、抗 PM-Scl)
  - 着丝点型:局限型 SSc(CREST)

### 临床意义
- **SLE**:95%+ 阳性
- **其他**:干燥综合征、SSc、MCTD、DM、RA、药物狼疮
- 健康人也可低滴度阳性(< 1:160)

## 抗 ENA 抗体谱

### 主要靶抗原
- **抗 SSA(Ro)**:
  - SLE(40%)、pSS(70%)、新生儿狼疮、SCLE
- **抗 SSB(La)**:
  - pSS(40%)、SLE
- **抗 Sm**:
  - SLE 特异(10-30%)
- **抗 RNP**:
  - MCTD(100%)、SLE
- **抗 Scl-70(拓扑异构酶)**:
  - 弥漫型 SSc
- **抗 Jo-1(组氨酰 tRNA 合成酶)**:
  - 多发性肌炎、皮肌炎(20-30%)
- **抗 Mi-2**:皮肌炎
- **抗 MDA5**:临床无肌病皮肌炎(ADM)

### 检测
- **免疫印迹 / 免疫斑点**:多个抗原同时检测
- **ELISA / CLIA**:定量

## 抗中性粒细胞胞浆抗体(ANCA)

### IIF 分型
- **c-ANCA**(胞浆型):抗 PR3
  - **GPA(肉芽肿性多血管炎、Wegener)** 70%+
- **p-ANCA**(核周型):抗 MPO
  - **MPA(显微镜下多血管炎)**、**EGPA**(部分)
  - UC、自身免疫性肝病
- **a-ANCA**(非典型):不特异

### 检测
- **IIF 筛查** → **抗原特异性 ELISA 确认**(PR3、MPO)
- MPO-ANCA、PR3-ANCA 阳性才特异

### 临床意义
- 急进性肾炎、新月体肾炎
- 系统性血管炎(GPA、MPA、EGPA)
- 监测:滴度与疾病活动相关(部分患者)

## 抗肾小球基底膜(抗 GBM)抗体
- **IIF**(人 / 灵长类肾) 或 **ELISA**(α3 链 NC1)
- **Goodpasture 综合征**:**肺出血 + RPGN**
- **急进性肾炎 II 型**
- 阳性提示预后差,**早期血浆置换 + 免疫抑制**
- 监测:3-6 月,阴转可停强化

## 抗磷脂抗体
- **抗心磷脂(ACL)**、**抗 β₂-GP1**、**狼疮抗凝物(LA)**
- **抗磷脂综合征(APS)**:
  - 血栓(动脉、静脉)、病理妊娠、血小板 ↓
  - SLE 中 30-40% 阳性
- 肾脏:**APS 肾病**(血栓性微血管病)
- 监测:持续 12 周阳性才有意义

## 抗 dsDNA
- **Farr 法**(放射免疫)、**CLIFT**(免疫荧光)、**ELISA**
- **SLE 特异**(特异度 > 95%)
- **滴度与活动度平行**(尤其 LN)
- 监测:SLEDAI、抗 dsDNA、C3/C4

## 抗 PLA2R(磷脂酶 A2 受体)
- **原发性膜性肾病**(特异度 > 95%)
- 70% 患者阳性
- **ELISA / IIFT**
- 滴度与疾病活动、蛋白尿平行
- 缓解:抗体消失 + 蛋白尿 ↓
- 复发:再现(可早于蛋白尿)

## 其他特异性抗体

### 肾脏病相关
- **抗 THSD7A**:少数 MN(< 5%)
- **抗 C1q**:LN 活动相关
- **抗 α-烯醇化酶**:M 蛋白相关肾病
- **抗 H-factor**:C3 肾病、aHUS
- **抗 SOD1**:Pauci-immune GN

### 系统性
- **类风湿因子(RF)**、**抗 CCP**:RA(肾脏相对少见)
- **抗 RNP / Sm / SSA**:SLE
- **抗 Jo-1 / Mi-2 / MDA5 / TIF1-γ**:肌炎

## 实验室方法

| 方法 | 应用 |
|---|---|
| **IIF**(金标准) | ANA、ANCA、抗 GBM |
| **ELISA** | 定量、特异抗原 |
| **CLIA / CMIA** | 自动化定量 |
| **免疫印迹 / 斑点** | ENA 多抗原筛查 |
| **流式** | 抗血小板、抗中性粒 |

## 适应证
- 肾活检同时查免疫荧光
- 不明原因肾小球病(血尿、蛋白尿、肾功能 ↓)
- 系统性疾病累及肾(发热、皮疹、关节、多系统)
- 移植肾功能障碍
- 治疗监测

## 注意事项

### 假阳性 / 假阴性
- **ANA 低滴度**:5-10% 健康人,尤其老年女性
- **MPO / PR3 低滴度**:UC、感染(结核)、药物(丙硫)
- **ANA 阴性 SLE**:罕见(抗 SSA 单阳、抗 Jo-1 等)
- **抗 GBM 假阳**:糖尿病、淀粉样变(非特异染色)

### 检测时机
- 急性期、活动期采血
- 治疗稳定期监测(3-6 月)
- 避免溶血、脂血标本

### 结果解读
- 必须**结合临床**
- 滴度变化更重要(单次阴性 / 阳性不绝对)
- 不同方法学结果不可直接比较
