# 原发性胆汁性胆管炎

## 概述
肝内小胆管慢性非化脓性炎症，AMA抗体阳性，表现为黄疸和皮肤瘙痒。本病严重程度不一，早期可无明显症状，晚期可累及多系统甚至危及生命。

## 分类
- 按病因分：原发性/继发性
- 按受累范围分：局限性/系统性
- 按病程分：急性/慢性
- 按活动性分：活动期/缓解期

## 危险因素
- 遗传因素
- 感染
- 内分泌因素
- 环境因素
- 药物
- 紫外线
- 吸烟
- 免疫功能异常

## 常见症状
- 关节痛、关节炎
- 发热
- 皮疹
- 乏力
- 口腔溃疡
- 光过敏
- 雷诺现象
- 淋巴结肿大
- 脏器受累表现

## 并发症
- 肾功能衰竭
- 心血管并发症
- 肺部受累
- 神经系统损害
- 血液系统异常
- 感染
- 恶性肿瘤
- 多器官功能衰竭

## 治疗原则
- 非甾体抗炎药
- 糖皮质激素
- 免疫抑制剂
- 生物制剂
- 血浆置换
- 对症支持治疗
- 定期随访监测

## 何时就医
- 症状加重
- 新发皮疹
- 尿量减少
- 呼吸困难
- 神经系统症状
- 高热不退
- 常规治疗无效

## 预防
- 避免诱因
- 预防感染
- 规律作息
- 健康生活方式
- 定期复查
- 遵医嘱用药
- 避免日晒
- 情绪管理
