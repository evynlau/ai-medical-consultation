# 新生儿科-新生儿寒冷损伤综合征

## 概述
新生儿寒冷损伤综合征(neonatal cold injury syndrome)又称**新生儿硬肿症**(neonatal scleredema),指新生儿期由**寒冷、损伤、感染、早产**等因素致低体温、皮肤与皮下脂肪硬化水肿、多脏器功能损伤的综合征。多见于寒冷季节早产儿、低出生体重儿,我国农村、边远地区仍有发生,严重者死亡率高(25-50%)。

## 病因
- **冷暴露**:保暖不当(尤其冬春)、转运
- **体温调节差**:
  - 体表面积大(相对)、皮下脂肪薄
  - 棕色脂肪少(尤其早产儿)
  - 战栗反应弱
- **疾病因素**:
  - 感染(败血症、肺炎、脑膜炎)
  - 窒息、产伤
  - 喂养不足、热量不够
  - 早产、低出生体重
  - 母体疾病(糖尿病、感染)

## 发病机制
- 寒冷 → 散热 > 产热 → 低体温
- 棕色脂肪产热耗竭 → 体温不升
- 周围血管收缩 → 循环障碍、组织缺氧
- 微循环障碍 → DIC
- 皮下脂肪凝固、细胞变性
- 严重低体温 → 呼吸暂停、肾衰、心律失常

## 临床表现
### 「五低一硬」
- **低体温**:核心温度 < 35°C(肛温)
- **少吃、少动、少哭**
- **心率慢**(< 100)、**呼吸暂停**
- **硬肿**:
  - **皮脂硬化**:皮肤、皮下脂肪硬化
  - **水肿**:
  - 先小腿 → 大腿外侧 → 臀 → 面颊 → 上肢 → 全身
  - 硬、肿、冷、暗红
  - 指压无明显凹陷
- **多脏器损害**:
  - 循环:低血压、DIC、休克
  - 肺:肺出血(死亡主因之一)
  - 脑:意识障碍、惊厥
  - 肾:急性肾衰
  - 消化:腹胀、便血、NEC
  - 心:心衰、心肌损害

## 硬肿范围评估
- **轻度**:< 20%
- **中度**:20-50%
- **重度**:> 50%

## 低体温分度
- **轻度**:35-32°C
- **中度**:32-28°C
- **重度**:< 28°C

## 诊断
- **病史**:寒冷、季节、围产、喂养
- **体征**:低体温、硬肿、器官功能损害
- **实验室**:
  - **血气**:代谢性酸中毒、低氧
  - **血糖**:常低
  - **凝血**:PT/APTT 延长、D-二聚体 ↑、血小板 ↓
  - **肾功**:Cr、BUN ↑
  - **心肌酶**:CK、CK-MB、LDH
  - **电解质**:高钾、低钙
  - **血常规**
  - 感染筛查:CRP、血培养

## 治疗
### 复温
**核心**:逐渐复温,避免复温性休克。
- **轻-中度(肛温 > 30°C)**:
  - 预热暖箱至 30°C,逐渐 1°C/h 升温
  - 6-12 h 达正常
- **重度(肛温 < 30°C)**:
  - **外加温** + **内加温**:
    - **红外线 / 暖箱**:逐步升温
    - 温热水浴(初始 39-40°C,10-20 min,后置暖箱)
    - **热辐射抢救台**
- **复温速度**:**0.5-1°C/h**
- **监测**:肛温、心率、呼吸、血压、血糖、电解质

### 支持
- **热量与液体**:
  - 热量:50-60 kcal/kg/d → 100-120(逐步)
  - 液体:60-80 mL/kg/d
  - **葡萄糖**:6-8 mg/kg/min
- **纠正代谢**:
  - 酸中毒:NaHCO₃
  - 低血糖
  - 电解质
- **抗休克**:
  - 扩容:0.9% NaCl 10-20 mL/kg
  - 多巴胺
- **抗感染**:
  - 经验抗生素(广谱,氨苄西林 + 头孢)
  - 血培养后调整
- **抗凝**:
  - 肝素、DIC 处理
  - **低分子肝素**(争议)
- **脏器支持**:
  - 肺出血:正压通气、肾上腺素、凝血
  - 肾衰:呋塞米、CRRT
  - 心衰:西地兰、多巴酚丁胺
- **糖皮质激素**(短期、小剂量)
- **维生素 E**(抗氧化)

## 注意事项
- **保暖**是预防核心
- **复温过快**可致休克、惊厥、颅内出血
- **核心温度(肛温)**为标准
- **肺出血**是死亡主因
- **早识别 DIC**、**感染**
- **早产儿**、**VLBW** 高发
- **输血、FFP**纠正凝血障碍
- **多学科**:NICU、营养、康复
- **保暖环境**:产房 25-26°C、暖箱中性温度
- **出生后 6 h 内低体温** → 高死亡风险
