# 非酒精性脂肪性肝病

## 概述
非酒精性脂肪性肝病(NAFLD)是与代谢紊乱密切相关的脂肪在肝细胞内过度沉积的临床病理综合征,排除过量饮酒等明确肝损因素。全球患病率约 25%,我国成人约 20-30%。新命名建议:代谢相关脂肪性肝病(MAFLD)或代谢功能障碍相关脂肪性肝病(MASLD,2023)。可从单纯性脂肪肝(NAFL)进展为脂肪性肝炎(NASH/MASH)、肝纤维化、肝硬化、肝癌,现已成终末期肝病、肝移植的主要原因之一。

## 命名变迁
- **NAFLD**(传统命名,2020 前)
- **MAFLD**(2020 国际共识,强调代谢功能障碍)
- **MASLD**(2023 AASLD/EASL/ALEH 新命名,代谢功能障碍相关脂肪性肝病)

## 诊断标准(MASLD,2023)
- **脂肪肝**(影像 / 血生物标志物 / 组织学)
- 满足以下 ≥ 1 项代谢心血管标准(无需排除其他肝病):
  - BMI ≥ 23(亚洲) / 25(欧美)
  - 腰围 ≥ 90/88 cm(亚裔男/女)
  - 空腹血糖 ≥ 5.6 mmol/L 或 2h 血糖 ≥ 7.8 或 HbA1c ≥ 5.7%
  - 血压 ≥ 130/85 或降压药治疗
  - TG ≥ 1.7 或降脂药治疗
  - HDL-C < 1.0(男)/1.3(女) 或降脂药

## 分型
- **NAFL(单纯性脂肪肝)**:脂肪变性,无炎症
- **NASH/MASH(脂肪性肝炎)**:脂肪变性 + 气球样变 + 炎症
- **肝纤维化**:
  - F0:无
  - F1:门管纤维化
  - F2:门管-桥接
  - F3:桥接纤维化
  - F4:肝硬化
- **HCC**:可发生于无肝硬化的 NASH

## 临床表现
- **多无明显症状**,体检发现
- 乏力、右上腹不适、肝区胀痛
- 体征:肝大、脾大、肥胖、痤疮(亚临床甲状腺减退可并存)
- 合并代谢综合征表现:腹型肥胖、高血压、血脂异常、糖尿病

## 诊断与评估

### 实验室
- 肝功(ALT/AST 多轻中度 ↑,AST/ALT < 1,NASH 后期可 > 1)
- GGT 升高
- 血脂、血糖、尿酸、HOMA-IR
- 排除:HBV/HCV、自身免疫性肝病、Wilson 病、药物性、酒精性

### 影像
- **腹部超声**:首选筛查(肝实质弥漫高回声,远场衰减)
- **CT**:肝 CT 值 < 40 HU,肝/脾 CT 比 < 1
- **MRI / MRS / PDFF**:定量最准确
- **FibroScan(TE 瞬时弹性成像)**:
  - **CAP(受控衰减参数)**:定量脂肪变 ≥ 248 dB/m
  - **LSM(肝硬度)**:F2 ≥ 7.0 kPa、F3 ≥ 9.0、F4 ≥ 11.0-13.0(需结合病因)
- **FibroMeter、NAFLD Fibrosis Score(NFS)、FIB-4、APRI**:
  - 用于初筛,排除晚期纤维化

### 肝活检
- 诊断 NASH 和分期的金标准
- 适用:诊断不明、需鉴别、临床试验、新药评估
- **SAF / NAS 评分**:脂肪、炎症、气球样变、纤维化
- **MASH 替代终点**:脂肪变性 + 炎症 + 气球样变(无纤维化恶化)

## 治疗

### 一、改变生活方式(基石)
- **减重**:
  - 体重下降 ≥ 7% 改善 NASH
  - ≥ 10% 改善纤维化
  - 每周减 0.5-1 kg
- **饮食**:
  - 热量限制 500-1000 kcal/d
  - **地中海饮食**(首选)
  - 减少精制糖、含糖饮料、饱和脂肪
  - 增加膳食纤维、不饱和脂肪酸
- **运动**:
  - 中等强度有氧 ≥ 150 min/周(快走、游泳、骑车)
  - 联合抗阻训练
- **戒酒**:严格限制(< 20 g/d,男)

### 二、药物治疗
- **维生素 E(α-生育酚)**:800 IU/d(无糖尿病 NASH)
- **吡格列酮(pioglitazone)**:NASH(伴 / 不伴糖尿病),注意水肿、体重
- **GLP-1 受体激动剂**:
  - **司美格鲁肽(2.4 mg/wk)**:改善 NASH + 纤维化
  - 利拉鲁肽(1.8 mg/d)
- **SGLT2 抑制剂**:恩格列净、达格列净(2 型糖尿病 + NAFLD)
- **二甲双胍**:改善血糖,无组织学证据,不作 NASH 特异性
- **奥贝胆酸(OCA)**、**FGF21 类似物**、**FXR 激动剂**:尚在评估 / 上市
- **Resmetirom(MASH 伴 F2-F3)**:2024 FDA 批准,甲状腺激素受体 β 选择性激动剂
- **护肝药**:多烯磷脂酰胆碱、水飞蓟素、甘草酸制剂、还原型谷胱甘肽
  - 用于 ALT 升高、辅助

### 三、代谢合并症管理
- 糖尿病、高血压、血脂异常(他汀安全,中度肝酶升高不忌)
- 减重手术:BMI ≥ 35 + 代谢综合征,或 NASH 合并糖尿病 BMI 30-35
  - 改善纤维化,减少 HCC
  - 袖状胃、胃旁路

### 四、终末期管理
- 肝硬化筛查:HCC(超声 + AFP 每 6 月)、胃镜(曲张静脉)
- 肝移植:失代偿、严重纤维化 + 代谢并发症

## 注意事项
- MASLD 患者心血管病为主要死因(占 50%+)
- 全因管理:代谢、心血管、肝脏
- 中药 / 补品多对肝有损害,谨慎
- 避免有毒环境、肝毒性药物
- 减肥速度过快可诱发脂肪性肝炎加重
