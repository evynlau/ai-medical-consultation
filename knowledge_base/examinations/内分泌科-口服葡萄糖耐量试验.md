# 口服葡萄糖耐量试验

## 概述
口服葡萄糖耐量试验(OGTT)是评估机体葡萄糖代谢能力的标准方法,测定空腹及口服 75 g 葡萄糖后 2h(必要时 30、60、120 min)血糖与胰岛素水平。用于糖尿病(尤其是空腹血糖正常、糖耐量异常)诊断、糖代谢状态评估、胰岛功能评价。

## 适应证
- 糖尿病可疑、空腹血糖 < 7.0 但伴风险因素
- 空腹血糖受损(IFG)、糖耐量减低(IGT)诊断
- 妊娠期糖尿病(GDM)筛查(75 g 或 100 g)
- 评估胰岛 β 细胞功能(胰岛素、C 肽释放)
- 反应性低血糖评估
- 糖尿病分型参考

## 准备
- **检查前 3 d 每日碳水 ≥ 150 g**
- **禁食 8-12 h**(可饮白水)
- 停用影响糖代谢药(糖皮质激素、噻嗪、β 阻滞剂、避孕药)
- 避免前 1 日剧烈运动、饮酒
- 空腹抽血后口服 75 g 无水葡萄糖 + 300 ml 水 5 min 内饮完
- 服糖后 30、60、120 min(常规仅 0 和 120)采静脉血
- 测血糖、胰岛素、C 肽
- 试验期间静坐、禁烟、禁食

## 正常参考与判读

### 75 g OGTT 切点(成人)
| 时点 | 静脉血浆血糖(mmol/L) |
|---|---|
| 空腹 | < 6.1 |
| 0.5 h | < 11.1 |
| 1 h | < 11.1 |
| 2 h | < 7.8 |

### 糖代谢状态分级(成人非妊娠)
| 状态 | FPG | OGTT 2h |
|---|---|---|
| 正常 | < 6.1 | < 7.8 |
| **IFG** | 6.1-6.9 | < 7.8 |
| **IGT** | < 7.0 | 7.8-11.0 |
| **DM** | ≥ 7.0 | ≥ 11.1 |

### 妊娠期糖尿病(75 g, 中国/ADA 标准)
任意一项异常:
- FPG ≥ 5.1
- 1h ≥ 10.0
- 2h ≥ 8.5
孕 24-28 周筛查。

### 胰岛功能
- 胰岛素/C 肽基础 + 餐后 30、60、120、180 min
- 早相分泌:30 min 峰值 5-10 倍
- 高峰延迟:胰岛素抵抗
- C 肽反映内源 β 细胞
- 曲线评估:分泌时相、峰值、面积

## 异常解读
- **IGT/IFG**:糖尿病前期
- **2h > 11.1 + FPG < 7.0**:单纯餐后高血糖
- **胰岛素抵抗**(HOMA-IR = FPG × FIns/22.5 > 2.5)
- **胰岛 β 细胞功能**:HOMA-β、I30/G30、处置指数
- **反应性低血糖**:服糖后 3-5h 血糖 < 3.0,胰岛素高

## 注意事项
- 试验中如有不适(出汗、心悸)立即测血糖
- 严重糖尿病已确诊可不做
- **儿童**:1.75 g/kg(最大 75 g)
- 妊娠剧吐、胃肠术后、甲状腺功能亢进影响结果
- 标本及时送检,氟化钠管抗凝
- 床旁血糖仪初筛,确诊需静脉血浆
- 不能耐受口服:静脉葡萄糖耐量试验(IVGTT)
- **HbA1c 反映 3 月平均血糖,与 OGTT 互补**
