# 1 型糖尿病管理

## 概述
1 型糖尿病(T1DM)是 T 细胞介导的自身免疫性胰岛 β 细胞破坏,导致绝对胰岛素缺乏。占糖尿病 5-10%,多见于儿童和青少年,也可成年起病(LADA)。必须依赖外源胰岛素治疗,急性并发症为 DKA,慢性并发症包括视网膜、肾脏、神经病变。

## 诊断标准
- **典型**:「三多一少」、DKA 起病、胰岛素依赖
- **血糖**:FPG ≥ 7.0 或 OGTT 2h ≥ 11.1 mmol/L,HbA1c ≥ 6.5%
- **自身抗体**(支持诊断):
  - 谷氨酸脱羧酶抗体(GADA)
  - 胰岛细胞抗体(ICA)
  - 胰岛素自身抗体(IAA)
  - 锌转运体 8 抗体(ZnT8A)
- **C 肽**:空腹 < 0.3 nmol/L,刺激后 < 0.6 nmol/L(提示绝对缺乏)
- **鉴别**:T2DM、MODY、胰腺外分泌病、药物性

## 治疗目标
- **HbA1c** < 7%(儿童可 < 7.5%,低龄 < 8%)
- **空腹/餐前**:4-7 mmol/L
- **餐后 2h**:5-10 mmol/L
- **睡前**:6-10 mmol/L
- 避免低血糖(< 4 mmol/L)、DKA

## 治疗

### 1. 胰岛素治疗(核心)
**基础-餐时方案**:
- 基础(甘精/地特/德谷):50% 总剂量
- 餐时(门冬/赖脯/谷赖):50%,按 1/6、2/6、3/6 分配三餐

**剂量调整**:
- 起始 0.5-1 U/kg/d
- 餐前大剂量:500/碳水系数(g) + 1500/胰岛素敏感系数
- 每 2-3 天调整 10-20%

**特殊方案**:
- **CSII(胰岛素泵)**:MDI 控制不佳、黎明现象、备孕
- **混合闭环(HCL)**:AID 系统,T1DM 优选

### 2. 持续葡萄糖监测(CGM)
- 实时 CGM(rtCGM)或扫描式(isCGM)
- 关键指标:**TIR(70-180 mg/dL) > 70%**,TAR < 25%,TBR < 4%,严重低血糖 < 1%
- 葡萄糖管理指标(GMI)反映估算 HbA1c

### 3. 营养
- 碳水化合物计数(CHO counting)
- 蛋白质、脂肪可影响餐后血糖
- 不限制水果蔬菜

### 4. 运动
- 血糖 < 5.6 mmol/L 运动前补充碳水
- 警惕运动后迟发低血糖(4-12h)
- 泵使用者可临时降低基础率

### 5. 心理与社会支持
- 儿童青少年家庭参与
- 学校血糖管理
- 糖尿病教育、社交支持

## 急性并发症
- **DKA**:见 DKA 指南
- **严重低血糖**:胰高血糖素 0.5-1 mg 肌注/鼻腔
- **蜜月期**:部分缓解期,胰岛素减量

## 慢性并发症筛查(诊断 5 年后或青春期后)
- 眼底、UACR、eGFR、足部、神经
- 血压、血脂、戒烟
- 自身免疫筛查:甲状腺、肾上腺、乳糜泻

## 注意事项
- 感染、手术、创伤可诱发 DKA
- 妊娠期严格控制(HbA1c < 6.5% 孕前)
- 旅行携带胰岛素、医生证明
- **SMBG + CGM** 联合
- 教育是 T1DM 管理核心
