# 非霍奇金淋巴瘤

## 概述
非霍奇金淋巴瘤(NHL)是起源于 B / T / NK 细胞的异质性淋巴组织恶性肿瘤,占淋巴瘤 90%。我国年发病率约 5-7/10 万。最常见为**弥漫大 B 细胞淋巴瘤(DLBCL)**(30-40%)、滤泡淋巴瘤(FL)、套细胞淋巴瘤(MCL)、边缘区淋巴瘤(MALT)、T 细胞淋巴瘤。

## 分类(WHO 2016/2022)

### B 细胞 NHL
- **弥漫大 B 细胞淋巴瘤(DLBCL)**:最常见
- **滤泡淋巴瘤(FL)**
- **套细胞淋巴瘤(MCL)**
- **边缘区淋巴瘤(MALT / 脾 / 淋巴结)**
- **伯基特淋巴瘤(BL)**
- **慢性淋巴细胞白血病 / 小淋巴细胞淋巴瘤(CLL/SLL)**
- **淋巴浆细胞淋巴瘤(LPL)/ WM**
- **原发中枢神经系统淋巴瘤(PCNSL)**
- **原发纵隔大 B 细胞淋巴瘤(PMBCL)**

### T/NK 细胞 NHL
- **外周 T 细胞淋巴瘤(PTCL, NOS)**
- **血管免疫母细胞 T 细胞淋巴瘤(AITL)**
- **间变性大细胞淋巴瘤(ALCL)**
- **鼻型 NK/T 细胞淋巴瘤**
- **蕈样霉菌病 / Sézary(MF / SS)**
- **成人 T 细胞白血病 / 淋巴瘤(ATLL)**

## 临床表现

### 一般
- **无痛性淋巴结肿大**(60-70%)
  - 颈、腋、腹股沟
  - 进行性、多发
- **B 症状**(30%):发热 > 38°C、夜汗、消瘦 > 6 月
- 乏力、瘙痒

### 结外(40%)
- **胃肠道**:最常见(胃 MALT、回盲)
- **韦氏环**(鼻咽、扁桃体)
- **皮肤**:MF / SS、原发皮肤 B
- **骨**:原发骨淋巴瘤(罕见)
- **CNS**(PCNSL)
- **睾丸**(老年 DLBCL)
- **其他**:乳腺、甲状腺、眼眶

### 特殊类型
- **DLBCL**:迅速进展、巨大肿块
- **FL**:惰性、无痛性、复发-缓解
- **MCL**:中等侵袭性(常见多发)
- **MALT**:惰性、慢性炎症(幽门螺杆菌)
- **NK/T**:鼻部破坏、坏死、EBV
- **Burkitt**:儿童 / 青年、生长迅速

## 实验室

### 病理(诊断金标准)
- **淋巴结 / 结外活检**(完整切除优先)
- 形态学 + 免疫组化(IHC)
- **流式细胞术**(新鲜组织)
- **FISH**、**PCR**(克隆性、病毒)
- 二代测序(部分)

### 主要免疫标记
- **B 细胞**:CD19、CD20、CD22、CD79a、PAX5
- **T 细胞**:CD2、CD3、CD5、CD7、CD4、CD8
- **生发中心(GCB)**:CD10、BCL6、MUM1(分型)
- **Ki-67**:增殖指数(高级别)
- **MYC、BCL2、BCL6**:双打击 / 三打击淋巴瘤

### 分型(以 DLBCL 为例)
- **生发中心(GCB)**(预后好)
- **活化 B 细胞(ABC)**(预后差)
- **双打击**(MYC + BCL2/BCL6)(预后差)

### 影像 / 分期
- **PET-CT**:**金标准**(分期、再分期、疗效)
- **CT**(颈、胸、腹、盆)
- **MRI**(CNS、骨)
- **超声**(浅表、浅表淋巴结)

### 分期(Ann Arbor)
- Ⅰ:单淋巴结区(IE 单结外)
- Ⅱ:同侧横膈 ≥ 2 区(IIE + 结外)
- Ⅲ:横膈两侧(III / IIIE)
- Ⅳ:广泛结外(骨髓、肝、骨髓)

**「A/B」**:B = 有 B 症状(发热 > 38°C、夜汗、消瘦 6 月 > 10%)

### 其他
- 血常规、肝肾、LDH、β2-MG
- **尿酸**(肿瘤溶解)
- **骨髓活检**(分期、淋巴瘤骨髓浸润)
- **CNS 检查**(高危、HIV)
- 病毒(HBV、HCV、HIV、EBV)
- **心电图、超声**(化疗前)
- **腰穿**(高危、CNS)

### 预后指标
- **国际预后指数(IPI)**(DLBCL):
  - 年龄 > 60
  - 分期 Ⅲ/Ⅳ
  - ECOG ≥ 2
  - LDH ↑
  - 结外 ≥ 2 处
- 4 年生存:
  - 0-1 分:94%
  - 2:79%
  - 3:55%
  - 4-5:59%
- **aaIPI**(年龄调整):< 60
- **R-IPI**(利妥昔时代)

## 治疗

### 总体策略
- 按**类型、分期、预后**分层
- 化疗 ± 免疫治疗 + 放疗(局限)
- **复发 / 难治**:挽救化疗、HSCT、CAR-T

### 1. DLBCL(**最常见**)

#### 一线
- **R-CHOP** × 6-8 周期(利妥昔单抗 + CHOP):
  - 环磷酰胺、阿霉素、长春新碱、泼尼松
  - 60-70% 治愈
- 高危(双打击):
  - **DA-EPOCH-R**(强化)
- 局限(Ⅰ-Ⅱ,无不良):
  - R-CHOP × 3-4 + 放疗
- **Pola-R-CHP**(Polatuzumab):
  - 替代 R-CHOP(新标准,POLARIX)

#### 复发 / 难治
- **R-ICE / R-DHAP**(挽救)
- **ASCT**(敏感复发)
- **CAR-T**:
  - **Axicabtagene ciloleucel**
  - **Tisagenlecleucel**
  - **Lisocabtagene maraleucel**
- **CD20 双抗**(Mosunetuzumab、Epcoritamab)
- **Pola-BR**(Pola + 苯达莫司汀 + 利妥昔)
- **Tafasitamab + 来那度胺**
- 临床试验

### 2. FL(滤泡淋巴瘤)
- 惰性、缓慢
- **局限**(Ⅰ-Ⅱ):**放疗**(可选治愈)
- **进展 / 晚期**:
  - **R-CHOP × 6**
  - 或 **R-CVP**、**R-bendamustine**
  - 维持:利妥昔单抗(每 2 月 × 2 年)
- **复发**:
  - 重复免疫化疗
  - **Idelalisib**(PI3K 抑制剂)
  - **Copanlisib**
  - **来那度胺 + 利妥昔**
  - **Mosunetuzumab**(双抗)

### 3. MCL(套细胞)
- 中度侵袭性
- **年轻**:
  - **R-CHOP / R-DHAP / R-CHOP + R-DHAP**
  - + 高剂量阿糖胞苷
  - + ASCT 巩固
  - **R 维持**(每 2 月)
- **老年 / 脆弱**:
  - **R-CHOP** 或 **VR-CAP**(硼替佐米)
  - 或 **BR**
- **复发**:
  - **BTK 抑制剂**(Ibrutinib、Acalabrutinib、Zanubrutinib)
  - 联合利妥昔
  - **来那度胺** + R
  - **CAR-T**(Brexucabtagene autoleucel)
  - ASCT

### 4. MALT(边缘区)
- **胃 MALT**(HP 阳性):
  - **HP 根除**(三联 / 四联疗法)
  - 70% 缓解
- **HP(-) / 抗 HP 失败**:
  - **放疗**(局限)
  - 或 **R-单药**
  - **R-CHOP**(播散)

### 5. Burkitt(伯基特)
- **高侵袭**、生长迅速
- **CODOX-M / IVAC**(Lymphomes Malins B)
- **Hyper-CVAD + R**
- **DA-EPOCH-R**(低危)
- **CNS 预防**(鞘注)
- **高剂量 + 巩固**
- 老年:减量 R-CHOP

### 6. T 细胞 NHL
- **PTCL(NOS / AITL)**:
  - **CHOP**(标准)
  - **CHOEP**(E = 依托泊苷)(年轻)
  - **Brentuximab vedotin**(CD30+):ALCL、AITL
  - **复发**:HDAC 抑制剂、HSCT
- **鼻 NK/T**:
  - **「SMILE」**(地塞米松、甲氨蝶呤、异环磷酰胺、L-天冬酰胺、依托泊苷)
  - **P-GEMOX**(培门冬酶)
  - 早期:放疗 + L-ASP

### 7. PCNSL
- **大剂量 MTX**(基础)
- + 阿糖胞苷 / 利妥昔
- 全脑放疗(部分)
- **来那度胺**(维持)
- **复发**:再诱导、自体移植、CAR-T

## 支持治疗

### 输血
- RBC(< 60)、血小板(< 10)

### 感染
- 免疫化疗:预防(PCP、HSV、念珠菌)
- IVIG(低 Ig)
- **HBV**(CD20 单抗):预防抗病毒

### 肿瘤溶解综合征
- 高白细胞、巨大肿块
- 水化、别嘌醇、拉布立酶

### CNS 预防
- 高危:DLBCL(睾丸、乳腺、骨、CNS、CNS 症状)、Burkitt、淋巴母细胞
- 鞘注(MTX / Ara-C)

### 生育
- 年轻:生育力保存
- HSCT:卵巢 / 睾丸保护

## 注意事项

### 监测
- 体检、影像(CT / PET)
- **PET**(中期 / 末次,2 年内)
- 复发:症状、新发淋巴结
- 长期:继发肿瘤

### 化疗注意
- **阿霉素**:心脏(累积)
- **长春新碱**:神经
- **CHOP**:老年人支持

### 利妥昔 / 双抗
- **HBV 筛查 / 抗病毒**
- 输注反应(预处理)
- 进行性多灶性白质脑病(PML,罕见)

### HSCT
- ASCT(敏感复发)
- 异基因(反复失败、CLL、某些 T)

### CAR-T
- CRS / ICANS
- 专病中心

### 长期
- 继发肿瘤(化疗、放疗)
- 心脏(阿霉素、放疗)
- 心理

### 预后
- DLBCL 5 年 OS 60-70%
- FL 10 年 OS 80%
- MCL 中位 5-7 年
- NK/T 差异大
- 总体改善(新药、CAR-T)
