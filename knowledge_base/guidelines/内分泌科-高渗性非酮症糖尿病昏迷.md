# 高渗性非酮症糖尿病昏迷

## 概述
高渗性高血糖状态(HHS),曾称「高渗性非酮症糖尿病昏迷(HONK)」,以严重高血糖(> 33.3 mmol/L)、高渗透压、无明显酮症酸中毒为特征,伴进行性意识障碍。常见于老年人 T2DM,死亡率高达 10-20%。

## 诱因
- 感染(肺炎、UTI、脓毒症,最常见)
- 急性心脑血管事件、心梗、卒中
- 漏服降糖药/胰岛素
- 糖皮质激素、利尿剂、免疫抑制剂
- 胃肠出血、胰腺炎、外伤、烧伤
- 饮水不足(独居老人)

## 临床表现
- 起病隐匿,数天-数周
- 严重多尿、脱水、体重下降
- 神经:**进行性意识障碍、定向力下降、局灶体征、癫痫、昏迷**
- 血流动力学:低血压、心动过速、休克
- 无明显 Kussmaul 呼吸、酮味

## 诊断标准
- **血糖** > 33.3 mmol/L(常 44-100)
- **有效血浆渗透压** > 320 mOsm/L
  - 2 × Na⁺ + 血糖 + 尿素氮(mmol/L)
- **pH** > 7.30 或 HCO₃⁻ > 18 mmol/L
- **血酮** 阴性/弱阳性,β-羟丁酸 < 3 mmol/L
- **阴离子间隙** 正常或轻度升高
- 阴离子间隙正常 + 高渗 → HHS 典型
- 阴离子间隙升高 + 高渗 → 混合 DKA/HHS

## 鉴别
- 脑卒中(局灶体征突出)
- DKA(酮症酸中毒 + 渗透压 < 320)
- 颅内感染、肿瘤
- 低血糖昏迷

## 治疗

### 1. 补液(最关键)
- **失水量估算**:可达 8-12 L
- **首选 0.9% 生理盐水**:
  - 第 1 小时:1-1.5 L
  - 第 2-4 小时:1 L/h
  - 后续 250-500 ml/h
  - 24 h 入量 8-10 L(心肾评估)
- 渗透压下降速度 < 3 mOsm/L/h(防脑水肿)
- 血糖 < 16.7 mmol/L 改 5% 葡萄糖 + 胰岛素

### 2. 胰岛素
- 起始时间:**补液 1 h 后**血糖仍 > 16.7 再启动
- 剂量:0.05-0.1 U/kg/h(较 DKA 谨慎,防低渗)
- 血糖下降速度 3-5 mmol/L/h
- **当血糖 ≤ 16.7** 减量至 0.02-0.05 U/kg/h
- 渗透压正常后过渡皮下胰岛素

### 3. 纠正电解质
- 钾:补液同时补 K⁺(目标 4-5 mmol/L)
  - < 3.3 暂缓胰岛素
  - 3.3-5.3 每升 20-40 mmol
- 钠:限制过快下降(防脑水肿),校正钠速度 < 10 mmol/L/24h
- 磷、镁:低时补充

### 4. 诱因
- 抗感染
- 心衰、肾衰评估
- 抗凝预防 VTE(老年卧床)

## 监测
- 血糖:q1h
- 电解质、肾功能、渗透压:q2-4h
- 血气、乳酸
- 出入量、CVP、神志
- 计算校正钠、渗透压

## 注意事项
- **脑水肿**:渗透压骤降、钠下降过快 → 甘露醇
- **低血糖、低血钾**:胰岛素过量
- **溶血性高钾**:补液后仍高,警惕
- 老年人心肾差,补液不宜过快
- 神志恢复时间可达 24-48 h,需耐心
- 后续 T2DM 长期管理,避免诱因复发
- 出院后家庭支持、独居监护
