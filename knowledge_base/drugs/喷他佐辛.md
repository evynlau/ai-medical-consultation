# 喷他佐辛

### 喷他佐辛
*## 基本信息*## 
- 分类：阿片受体激动-拮抗剂
- 常见商品名：镇痛新、喷他佐辛片
- 上市时间：1960年代
- 处方/OTC状态：处方药
*## 适应症*## 
- 中度至重度疼痛
- 术后疼痛
- 癌痛（主要用于替代吗啡）
*## 药理作用*## 
- μ阿片受体部分激动剂
- κ阿片受体激动剂
- 对呼吸抑制作用较弱，依赖性低于吗啡
*## 用法用量*## 
- 成人：50mg/次，3-4次/日，最大日剂量150mg
- 肌注：50mg/次，必要时重复
- 老年人：起始剂量25mg
*## 不良反应*## 
- 恶心、呕吐（较吗啡常见）
- 头晕、嗜睡
- 心悸、血压升高
- 长期使用可产生耐受性和依赖性
*## 注意事项*## 
- ⚠️ 可引起血压升高，高血压患者慎用
- ⚠️ 有药物滥用史者慎用
- ⚠️ 呼吸功能不全者慎用
- ⚠️ 不应用于已对阿片类产生依赖的患者（可能诱发戒断症状）
*## 禁忌*## 
- 对喷他佐辛过敏者
- 正在使用或14天内使用过单胺氧化酶抑制剂者
- 严重肝功能不全者
*## 相互作用*## 
- 单胺氧化酶抑制剂：严重不良反应风险
- 苯二氮䓬类：增加中枢抑制
- 酒精：增强中枢抑制作用
*## 临床应用要点*## 
- 成瘾性低于吗啡，但仍具有滥用潜力
- 可用于术后镇痛和癌痛治疗
- 长期使用后停药应逐渐减量
