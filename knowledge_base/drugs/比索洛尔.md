# 比索洛尔

#### 比索洛尔
*## 基本信息*## 
- 分类：β1受体选择性拮抗剂（β-blocker）
- 常见商品名：康欣、Zebeta
- 上市时间：1980年代末
- 处方/OTC状态：处方药
*## 适应症*## 
- 高血压
- 慢性稳定性心绞痛
- 慢性左室收缩功能不全（心衰）
*## 药理作用*## 
- 高度选择性β1受体阻断剂
- 半衰期较长（约10小时）
- 无内在拟交感活性
*## 用法用量*## 
- 成人：5mg/次，1次/日，最大剂量10mg/日
- 心力衰竭：起始1.25mg/日，渐增至目标剂量
*## 不良反应*## 
- 头晕、疲劳
- 心动过缓
- 四肢冰冷
*## 注意事项*## 
- ⚠️ 支气管哮喘患者慎用
- ⚠️ 长期停药应逐步减量
- ⚠️ 糖尿病患者注意低血糖症状可能被掩盖
*## 禁忌*## 
- 二至三度房室传导阻滞
- 心源性休克
- 明显心动过缓
- 严重支气管哮喘
*## 临床应用要点*## 
- 心脏选择性高，对支气管影响较小
- 半衰期较长，每日一次给药
- 是慢性心衰长期治疗的重要药物
