# 短暂性脑缺血发作

## 概述
短暂性脑缺血发作(TIA)是由于脑、脊髓或视网膜局灶性缺血导致的**短暂神经功能缺损发作**,且无急性梗死证据。传统定义以 24 h 为限;**新定义**以**组织学损伤**为标准——**无梗死**即为 TIA。我国 TIA 患病率高,90 d 卒中风险 10-15%,尤其 48 h 内最高,故 TIA 是**卒中急症**,需紧急评估与干预。

## 病因与机制
- **动脉粥样硬化**(最主要):大动脉、颅内动脉
- **心源性栓塞**:房颤、卵圆孔未闭(PFO)、瓣膜病
- **小血管病变**:腔隙性 TIA
- **血流动力学**:低灌注(锁骨下盗血)
- **动脉夹层**:颈动脉、椎动脉

## 临床表现(按血管供血区)
### 颈内动脉系统
- 单眼一过性黑矇(同侧)
- 偏身感觉、运动障碍
- 失语(优势半球)
- 同向偏盲

### 椎-基底动脉系统
- 眩晕、复视、构音障碍、吞咽困难
- 交叉性感觉/运动障碍
- 跌倒发作(drop attack)
- 一过性意识丧失
- 短暂全面遗忘症(TGA)

## 危险分层(ABCD²)
| 字母 | 含义 | 分数 |
|---|---|---|
| **A** | 年龄 ≥ 60 岁 | 1 |
| **B** | 血压 SBP ≥ 140 / DBP ≥ 90 | 1 |
| **C** | 临床特征:偏侧无力 | 2 |
| | 言语障碍不伴无力 | 1 |
| | 其他 | 0 |
| **D** | 持续 ≥ 60 min | 2 |
| | 10-59 min | 1 |
| | < 10 min | 0 |
| **D** | 糖尿病 | 1 |

**评分**:
- **0-3 分**:低危(2 d 卒中风险 1.0%)
- **4-5 分**:中危(2 d 风险 4.1%)
- **6-7 分**:高危(2 d 风险 8.1%)

**≥ 4 分**建议住院观察,完善检查。

## 诊断与评估
- **病史**:发作时间、症状、持续时间最关键
- **头颅 MRI + DWI**:敏感显示急性小梗死(发现梗死者按卒中处理)
- **头颅 CT**:排除出血
- **血管评估**:**CTA / MRA** 颈动脉、颅内动脉;**DSA** 必要时
- **心脏评估**:心电图、**24 h 动态心电图**(发现阵发房颤)、心脏超声
- **血液**:血糖、血脂、肝肾功能、凝血、血常规
- **颈动脉超声、IMT 评估**
- **PFO 筛查**(隐源性 TIA)

## 急性期治疗
- **立即启动二级预防**(不需等待 24 h)
- **抗血小板**:
  - **非心源性**:
    - **轻型卒中 / 高危 TIA**(ABCD² ≥ 4):**阿司匹林 100 mg + 氯吡格雷 75 mg 双抗 21 d**,后单抗
    - 一般 TIA:单抗(阿司匹林 100 mg 或氯吡格雷 75 mg)
  - **CHANCE 研究**(中国)、**POINT 研究**支持 21 d 双抗
- **他汀**:**高强度**(阿托伐他汀 40-80 mg),LDL-C < 1.8 mmol/L
- **血压**:平稳控制(二级预防目标 < 130/80)
- **血糖**:**HbA1c < 7%**
- **房颤**:启动抗凝(见卒中)
- **颈动脉狭窄**:
  - **症状性 70-99%**:**颈动脉内膜剥脱术(CEA)** 或**颈动脉支架(CAS)**
  - **50-69%**:男性、近期症状可获益
  - **< 50%**:药物
- **生活方式**:戒烟、限酒、减重、运动

## 长期管理
- 定期随访神经科、心内科、内分泌科
- 监测血压、血脂、血糖、肝功、肌酶
- 警惕出血转化(尤其双抗期间)
- **抗凝时**机:房颤 TIA 急性期,影像无出血、面积小,可 1-2 周内启动
- **教育**:识别卒中先兆(Fast 原则)

## 注意事项
- TIA 是**卒中预警**,必须**紧急评估**(48 h 内门诊 / 住院)
- **ABCD² ≥ 4**、DWI 阳性、颅内动脉狭窄 → 高危
- **TIA 合并房颤**:**抗凝优于双抗**(ACTIVE-W 试验)
- **「小卒中」**并不轻,NIHSS ≤ 3 也应按卒中流程
- 颈动脉支架(CAS)围术期需双抗
- **青年 TIA** 需警惕**动脉夹层**(外伤、按摩、剧烈活动史)、PFO、抗磷脂综合征
- 反复同侧颈内动脉系统 TIA + 颈动脉狭窄,优先 CEA
- 戒烟、限酒、健康饮食是降低复发的基础
