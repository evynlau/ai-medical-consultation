# 检验科-C反应蛋白

## 概述
C反应蛋白（C-reactive protein，CRP）是一种由肝细胞合成的急性时相反应蛋白，属于正五聚蛋白家族（pentraxins）。其名称源于早期发现能与肺炎球菌细胞壁C多糖发生沉淀反应。CRP的合成受白细胞介素-6（IL-6）、肿瘤坏死因子-α（TNF-α）等炎性细胞因子调控，在感染、创伤、炎症、组织坏死等应激状态下迅速升高，可达正常水平的数百倍。CRP是临床上最敏感的急性时相反应标志物之一，主要用于感染性疾病、自身免疫性疾病、肿瘤及组织损伤的辅助诊断、病情监测和疗效评估。

## 检查方法
- **标本采集**：静脉采血2-3ml，注入含促凝剂或分离胶的真空采血管中，室温静置30-60分钟待其充分凝固后，离心分离血清进行检测。
- **标本类型**：血清（首选）、血浆（肝素抗凝血浆可用，但部分方法需注意干扰）。
- **检测方法**：
  - **免疫比浊法（Turbidimetric immunoassay）**：CRP与抗CRP抗体结合形成免疫复合物，产生浊度变化，通过光密度测定定量。该方法操作简便、自动化程度高，是临床常规检测的主要方法。
  - **化学发光免疫分析法（CLIA）**：采用双抗体夹心原理，灵敏度高于免疫比浊法，适用于低浓度CRP检测（超敏CRP）。
  - **酶联免疫吸附法（ELISA）**：主要用于科研，临床少用。
  - **胶体金免疫层析法**：快速筛查方法，适用于床旁检测（POCT），灵敏度相对较低。
- **结果报告**：以mg/L表示。

## 正常参考值
- **常规CRP**：<10mg/L（部分标准为<8mg/L或<5mg/L）
- **超敏CRP（hs-CRP）**：<3mg/L（用于心血管疾病风险评估）
- **新生儿**：<2mg/L（脐带血水平较低）
- **妊娠期**：可轻度升高，但一般<20mg/L
- **儿童**：参考值同成人

## 临床意义
### CRP增高的常见原因
- **细菌感染**：尤其是侵袭性细菌感染（如肺炎、脑膜炎、败血症），CRP常显著升高（>50mg/L甚至>100mg/L）。
- **病毒感染**：轻度至中度升高（通常<40mg/L），但病毒性脑膜炎、传染性单核细胞增多症等也可明显升高。
- **真菌感染**：系统性真菌感染（如曲霉病、念珠菌血症）可显著升高。
- **组织损伤与坏死**：手术、创伤、心肌梗死（CRP在胸痛后4-6小时升高，峰值在48-72小时）、烧伤、胰腺炎等。
- **自身免疫性疾病**：类风湿关节炎（活动期）、系统性红斑狼疮（尤其伴浆膜炎时）、系统性血管炎、炎性肠病等。
- **肿瘤性疾病**：淋巴瘤、白血病、实体瘤（尤其是伴坏死或转移时），可作为辅助指标。
- **其他**：风湿热、痛风急性发作、慢性阻塞性肺疾病急性加重（AECOPD）等。

### CRP动态变化的临床价值
- **感染类型鉴别**：细菌感染时CRP通常显著升高（>50mg/L），病毒感染多为轻度升高（<20-40mg/L），但两者有重叠，需结合临床。
- **疗效监测**：抗生素治疗有效时，CRP在24-48小时内开始下降；若无变化提示可能存在耐药或并发症。
- **病情评估**：AECOPD、急性胰腺炎等疾病，CRP水平与病情严重程度相关。
- **术后监测**：手术后48-72小时CRP升高，若术后第3-5天仍持续升高或再次升高，提示可能存在感染并发症。
- **川崎病**：是冠脉动脉瘤发生的危险因素评估指标之一。

### 超敏CRP（hs-CRP）的临床应用
- **心血管疾病风险评估**：hs-CRP<1mg/L为低风险，1-3mg/L为中风险，>3mg/L为高风险。结合血脂、血压等综合评估。
- **代谢综合征**：与胰岛素抵抗、2型糖尿病风险相关。
- **预测新发糖尿病**：独立预测因子之一。

## 注意事项
- **个体差异**：部分健康老年人可呈轻度升高，解读需结合临床。
- **妊娠影响**：妊娠晚期可生理性升高至10-30mg/L。
- **药物影响**：肾上腺皮质激素、非甾体抗炎药（NSAIDs）、他汀类降脂药可降低CRP水平。
- **检测方法选择**：不同检测系统间存在差异，动态监测应使用同一系统或注意方法学差异。
- **窗口期**：CRP在炎症刺激后4-6小时开始升高，达峰时间约48小时，评估急性感染需注意采血时机。
- **结果解读**：CRP为非特异性指标，必须结合临床表现综合判断，不可作为单一诊断依据。
- **连续监测**：危重患者建议每12-24小时复查一次，以评估治疗反应和病情演变。
- **与其他指标联合**：CRP+降钙素原（PCT）+血常规联合检测可提高感染性疾病的诊断效能。
