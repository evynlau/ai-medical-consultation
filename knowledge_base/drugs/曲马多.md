# 曲马多

### 曲马多
*## 基本信息*## 
- 分类：阿片类镇痛药（中枢性镇痛药）
- 常见商品名：屈他维林、曲马多缓释片
- 上市时间：1970年代
- 处方/OTC状态：处方药（部分复方制剂为OTC）
*## 适应症*## 
- 中度至重度疼痛
- 癌痛、术后疼痛、创伤性疼痛
- 骨关节炎、类风湿性关节炎等慢性疼痛
*## 药理作用*## 
- 激动μ阿片受体（弱效）
- 抑制5-羟色胺和去甲肾上腺素再摄取
- 两重机制协同增强镇痛效果
*## 用法用量*## 
- 成人：50-100mg/次，4-6小时一次，最大日剂量400mg
- 缓释片：100mg/次，12小时一次
- 老年人：起始剂量50mg，根据需要调整
- 肝功能不全：每日最大剂量减半
*## 不良反应*## 
- 恶心、呕吐、便秘、头晕
- 出汗、口干
- 罕见：癫痫发作（高剂量时）、呼吸抑制
*## 注意事项*## 
- ⚠️ 严禁与单胺氧化酶抑制剂合用（至少停药14天）
- ⚠️ 长期使用可产生耐受性和依赖性
- ⚠️ 癫痫患者慎用
- ⚠️ 肝肾功能不全者调整剂量
*## 禁忌*## 
- 对曲马多过敏者
- 正在使用或14天内使用过单胺氧化酶抑制剂者
- 癫痫患者
- 急性酒精、镇静剂或阿片类药物中毒者
*## 相互作用*## 
- 单胺氧化酶抑制剂：严重不良反应风险（5-HT综合征）
- 选择性5-HT再摄取抑制剂：增加癫痫和5-HT综合征风险
- 阿片受体拮抗剂：降低镇痛效果，可能诱发戒断症状
*## 临床应用要点*## 
- 不适用于急性轻中度疼痛（如头痛、牙痛）的首选
- 应从最低有效剂量开始使用
- 停药时应逐渐减量，避免戒断症状
