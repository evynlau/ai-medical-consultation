# 食管癌诊治

## 概述
食管癌是我国第 5 大恶性肿瘤,年新发约 32 万,死亡约 30 万,病理以**鳞状细胞癌(ESCC)占 90% 以上**(与西方以腺癌为主不同)。发病地域性强(豫、冀、苏、晋、川北)。早期症状隐匿,5 年生存率约 30%。

## 危险因素
- 吸烟、酗酒(尤其烈性酒)
- 腌制、霉变食物(亚硝胺)、过烫饮食(> 65°C)
- 微量元素缺乏(锌、硒)、维生素缺乏
- 食管反流、巴雷特食管(腺癌主因)
- 食管腐蚀性损伤、贲门失弛缓症
- HPV、口腔卫生差

## 筛查
- **高发区**40-69 岁:每 5 年内镜 + 碘染色
- 高危人群(症状、家族史):机会性筛查
- **早期食管癌**定义:局限于黏膜层及黏膜下层,无淋巴结转移

## 病理
- **鳞状细胞癌(ESCC)**:90%+(东亚、东非、东欧)
- **腺癌(EAC)**:西方主流,我国 < 10%
- 少见:神经内分泌癌、腺鳞癌、未分化癌、肉瘤样癌
- **WHO**分型高/中/低分化
- **分子**:ESCC 高 TP53 突变;HER2 在腺癌可阳性;PD-L1 CPS 表达较常见;NTRK 罕见
- 免疫组化:HER2、PD-L1、MMR/MSI(部分)

## 分期
- TNM 第 8 版
- **部位**分颈段、上胸段、中胸段、下胸段(影响手术入路)
- 鳞癌对放疗较敏感

## 诊断
- **胃镜 + 碘染色(Lugol 液) + 活检**(金标准)
- **超声内镜(EUS)**:评估 T、N 分期
- **胸腹增强 CT**:分期、远处转移
- **PET-CT**:局部晚期/转移性评估
- **颈部超声/超声内镜** 颈部淋巴结
- 钡餐:补充食管动力学、狭窄
- 标志物:SCC(鳞癌)、CEA、CA19-9

## 治疗

### 早期(0-Ⅰ 期、高度异型增生、T1a)
- **内镜黏膜切除(EMR)/ 黏膜下剥离(ESD)**
- 黏膜内癌、表浅癌是适应证
- 黏膜下浸润 ≥ 200 μm(SM2)、低分化、淋巴血管侵犯:补做外科

### 进展期(可手术 cT1b-2 N0、部分 cT3)
- **新辅助化疗 + 手术**(CROSS 方案:**紫杉醇 + 卡铂** × 4 + 放疗 41.4 Gy)
- 或 **新辅助化疗**(**S-1 + 顺铂**,JCOG1109)
- **手术**:
  - 颈段/上胸段:三切口(McKeown)
  - 中下段:Ivor-Lewis(右胸 + 上腹)
  - 二野淋巴结清扫
- 术后辅助化疗(病理 N+、R1):紫杉醇 + 5-FU 或 S-1

### 局部晚期(不可手术)
- **根治性同步放化疗**(50-50.4 Gy + 化疗:紫杉醇 + 卡铂/5-FU + 顺铂/FP)
- 后续评估能否转化手术
- 维持化疗/免疫巩固

### 转移性/复发
- **一线**:
  - 鳞癌、PD-L1 CPS ≥ 10:**帕博利珠单抗 + 化疗**(FP,KEYNOTE-590)
  - 全人群(ESCC):**纳武利尤单抗 + 化疗**(FP,CheckMate-648)
  - 腺癌:PD-L1 阳性 + 化疗 ± 帕博利珠
- **二线**:紫杉醇 + 雷莫西尤单抗(RAINBOW-Asia);单药紫杉/多西他赛/伊立替康
- **HER2+ 腺癌**:曲妥珠单抗 + 化疗
- **MSI-H/dMMR**:免疫单药
- **NTRK**:拉罗替尼
- **免疫单药**:纳武利尤、帕博利珠、卡瑞利珠(中国)、信迪利(中国)

## 对症支持
- **吞咽困难**:放疗/支架/胃造瘘
- **营养**:鼻饲、空肠造瘘
- **食管瘘**(气道、胸腔):支架封堵、抗感染
- **疼痛**:三阶梯镇痛
- **声音嘶哑**(喉返神经侵犯):考虑激光/手术

## 注意事项
- 食管癌全程营养评估和干预
- 戒烟、戒酒、不吃过烫食物
- 放疗期间监测放射性食管炎、骨髓抑制
- 免疫治疗前查**PD-L1 CPS**
- 多学科(MDT)决策
- 定期随访前 2 年每 3 月
