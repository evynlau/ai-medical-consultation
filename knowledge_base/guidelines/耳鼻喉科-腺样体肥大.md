# 腺样体肥大

## 概述
腺样体(增殖体)是位于鼻咽顶后壁的淋巴组织,儿童期生理性肥大,青春期后退化。腺样体肥大(AH)是儿童常见病,发病率约 10-30%,3-7 岁高发,致鼻塞、打鼾、分泌性中耳炎,影响生长发育与面容。

## 病因
- 生理性肥大(3-7 岁)
- 反复上呼吸道感染、过敏性鼻炎
- EB 病毒、慢性鼻窦炎
- 空气污染、被动吸烟
- 胃食管反流
- 免疫因素

## 临床表现
### 鼻部症状
- 鼻塞、张口呼吸
- 流脓涕、鼻音重
- 「腺样体面容」:颌面发育异常、上颌前突、硬腭高拱、牙列不齐、上唇短厚

### 耳部症状
- 分泌性中耳炎(OME)、听力下降
- 急性中耳炎反复发作

### 咽、喉、下呼吸道
- 睡眠打鼾
- **儿童阻塞性睡眠呼吸暂停综合征(OSA)**
- 慢性咳嗽、反复支气管炎

### 全身影响
- **生长发育迟缓**(生长激素分泌不足)
- **神经认知**:注意力不集中、多动、学习困难
- **行为问题**:易怒、情绪障碍
- **遗尿**
- **心血管**:肺心病(罕见,重度)

## 诊断
- **病史**:睡眠打鼾、张口呼吸、夜惊、憋气
- **电子鼻咽镜**(金标准):评估腺样体大小,堵塞后鼻孔比例
  - **腺样体 - 鼻咽腔比值(A/N)**
- **鼻咽部侧位 X 线**(传统):
  - A/N 比 < 0.60 正常
  - 0.61-0.70 中度肥大
  - > 0.70 病理性肥大
- **PSG 多导睡眠监测**(术前评估):
  - 轻度 AHI 1-5/h
  - 中度 5-10/h
  - 重度 > 10/h
- **声导抗**:B 型 / C 型曲线提示 OME
- **纯音测听**(可配合者)
- **颅面评估**:腺样体面容

## 治疗

### 保守治疗
- **适应**:轻度症状、A/N < 0.7、无 OSA
- **鼻用糖皮质激素**:莫米松 / 氟替卡松 2-3 月
- **孟鲁司特**(尤其伴 AR)
- **抗生素**:急性感染期
- **鼻盐水冲洗**

### 手术治疗
- **腺样体切除术**(Adenoidectomy)
- **适应证**:
  - 中重度 OSA(AHI > 5)
  - 反复 / 慢性分泌性中耳炎
  - 慢性鼻窦炎、药物无效
  - 颌面发育异常
  - 生长发育迟缓
- **手术方式**:
  - **传统腺样体刮除术**(Beckman 刀)
  - **内镜下腺样体切除**:可视化、彻底、低残留
  - **低温等离子**:出血少
  - **电动切割器**(microdebrider)
- **同期手术**:
  - 鼓膜切开 + 置管(OME)
  - 扁桃体切除(伴扁桃体肥大)
  - 鼻窦手术

### 围术期
- 全身麻醉,经口插管
- 术后出血风险(1-3%)
- 流质 / 半流质 2 周

## 注意事项
- **3 岁以下**腺样体切除需严格权衡(免疫功能)
- 腺样体面容一旦形成,**部分不可逆**
- 早期手术可改善颌面发育
- 术后仍有打鼾可能(合并鼻炎、舌根肥大)
- 术后 OSA 残留需 CPAP 或其他手术
- **儿童 OSA 神经认知损害**需及时干预
- 术后 1 周复查
- 注意术后出血(罕见但严重)
