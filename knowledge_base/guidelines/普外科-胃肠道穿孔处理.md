# 胃肠道穿孔处理

## 概述
胃肠道穿孔是普外科常见急腹症,起病急、进展快,需早期识别与手术干预。常见病因包括消化性溃疡、外伤、肿瘤、医源性及缺血性病变。弥漫性腹膜炎、脓毒症、休克是主要死亡原因。

## 病因
- **上消化道**:
  - 消化性溃疡(胃、十二指肠)最常见
  - 胃癌穿孔
  - 异物、外伤、医源性(内镜、支架)
- **下消化道**:
  - 阑尾穿孔(详见急性阑尾炎)
  - 结直肠癌穿孔、憩室穿孔
  - 炎症性肠病、肠扭转、绞窄性肠梗阻
  - 缺血性肠病、医源性损伤

## 临床表现
- 突发剧烈腹痛(「刀割样」),继而弥漫全腹
- 板状腹(腹膜炎体征)
- 肝浊音界缩小或消失
- 休克表现:心率快、血压低、烦躁
- 恶心、呕吐、停止排气排便
- **体征**:全腹压痛、反跳痛、肌紧张,肠鸣音消失

## 辅助检查
- **立位腹平片**:膈下游离气体(80% 溃疡穿孔阳性)
- **腹部 CT**(首选):明确穿孔部位、积液、脓肿,敏感度 > 95%
- **诊断性腹腔穿刺**:抽到脓性液、胆汁、肠液
- **血常规/血气/乳酸**:评估感染、休克
- **淀粉酶**:鉴别急性胰腺炎

## 处理原则
- 禁食、胃肠减压、静脉补液、抗休克
- 广谱抗生素(覆盖革兰阴性 + 厌氧):三代头孢 + 甲硝唑 / 哌拉西林他唑巴坦
- 纠正水电解质紊乱、抑酸(质子泵抑制剂)
- 多学科会诊(MDT):普外科、麻醉科、ICU

## 手术方式

### 胃十二指肠溃疡穿孔
- **单纯穿孔修补 + 活检**:污染重、情况差、年龄大
- **胃大部切除(Billroth Ⅰ/Ⅱ)**:耐受好、同时处理溃疡
- **腹腔镜修补**:创伤小,越来越多采用
- 术后根除幽门螺杆菌(术后 4-6 周复查)

### 胃癌穿孔
- 条件允许:**根治性胃切除 + D2 淋巴结清扫**
- 条件差:穿孔修补 + 活检,二期根治
- 预后差,5 年生存率 < 30%

### 小肠穿孔
- 楔形切除 / 肠段切除 + 吻合
- 外伤所致需全面探查,防漏诊多发伤

### 结直肠穿孔
- 右半结肠:右半结肠切除 + 吻合 / 末端回肠造口
- 左半结肠:Hartmann 手术(切除 + 造口,二期还纳)
- 乙状结肠:穿孔修补 + 近端造口 / Hartmann
- 直肠:乙状结肠双腔造口 + 骶前引流

## 术后管理
- ICU 监测,持续胃肠减压
- 抗生素 5-7 d,根据培养调整
- 营养支持:肠外 → 早期肠内
- **并发症**:
  - 吻合口漏(3-15%)
  - 腹腔感染、脓肿
  - 短肠综合征(广泛切除)
  - 肠粘连、肠梗阻

## 注意事项
- 老年、糖尿病、激素使用者症状不典型
- 不可一味追求微创,生命体征不稳者首选开腹
- 胃穿孔均应活检,排除癌
- 术后随访 1 个月、3 个月、6 个月,排查肿瘤
