# 抗生素合理使用

## 概述
抗生素合理使用(AMS,Antimicrobial Stewardship)是优化抗菌药使用、延缓耐药、改善预后、降低费用的核心策略。**多学科(MDT)管理** + **分级管理** + **监测反馈**是关键。

## 核心原则
- **Right Drug, Right Dose, Right Duration, Right Route**(4R)
- 经验 → 目标治疗
- 避免滥用、不足、过长
- 关注**PK/PD**

## 分级管理(我国 2012, 2022 调整)
- **非限制级**:一线、安全、广谱低(青霉素、一代头孢、SMZ-TMP)
- **限制级**:深部、特殊(碳青霉烯前药、二代头孢、氟喹诺酮)
- **特殊级**:多学科审批(碳青霉烯、万古、达托、利奈唑胺、替加、棘白、多粘)

## 经验 → 目标(降阶梯)

### 流程
1. **正确诊断**(感染、部位)
2. **预测病原**(本院药敏)
3. **取样**(血培养、其他)
4. **经验广谱 + 早用**
5. **48-72 h 评估** + **培养**
6. **降阶** → 目标治疗
7. **疗程** 足量、足程

## PK/PD 优化

### β 内酰胺
- **时间依赖性**(T > MIC)
- **延长输注**(3-4 h)、持续输注(美罗培南、哌拉西林)
- 给药频次 q6-8h(高剂量)
- 监测血药(部分)

### 氟喹诺酮、糖肽、氨基糖
- **浓度依赖**
- **AUC/MIC**、**Cmax/MIC**
- 大剂量 qd(氨基糖)

### 利奈唑胺、替加环素
- **AUC/MIC**
- q12h,qd

### 优化策略
- **高剂量、足次数、延长输注**(β 内酰胺)
- **负荷剂量**(危重)
- **肾功能调整**(肌酐清除率)
- **儿童/老年/肥胖/妊娠/肝衰**:调整
- **TDM(治疗药物监测)**:
  - 万古霉素(谷浓度 15-20 mg/L)
  - 氨基糖
  - 替考拉宁
  - 部分抗真菌(伏立康唑、伊曲康唑)

## 经验选择要点

### 部位
- **呼吸道**:肺炎链球菌、支原体、军团、流感、金葡、革兰阴性
- **泌尿**:肠杆菌、肠球菌
- **腹腔**:混合(肠杆菌 + 厌氧)
- **皮肤**:金葡、链球菌
- **血流**:金葡、革兰阴性

### 场所
- **社区**:敏感肠杆菌
- **医院**:MDRO 风险
- **ICU**:ESBL、CRE、铜绿、MRSA
- **长期照护**:MDRO
- **海外旅游**:耐药肠杆菌

### 宿主
- 免疫抑制:扩大覆盖
- 肝、肾:调整
- 妊娠:避免致畸
- 儿童:限制氟喹诺酮、四环素

## 特定感染疗程
| 感染 | 疗程 |
|---|---|
| 链咽、AOM | 10 d |
| 单纯膀胱炎 | 3-5 d |
| 肾盂肾炎 | 7-14 d |
| CAP(链球) | 5-7 d(退热后 3 d) |
| HAP/VAP | 7 d(短) |
| 腹腔(已引流) | 4-7 d |
| 蜂窝织炎 | 5-10 d |
| **菌血症 S. aureus** | ≥ 14 d |
| 心内膜炎 | 4-6 周 |
| 骨髓炎 | 4-6 周 |
| 念珠菌血 | 14 d |

## 多学科管理(AMS 团队)
- **感染病科**(主导)
- **临床药学**
- **微生物**(本院耐药谱)
- **信息**(数据)
- **临床科室**(具体)

## 监测指标
- **DDDs**(每日每千患者日 DDD 数):抗菌药使用强度
- **DOT**(Days of Therapy)
- **菌检送检率**(经验用抗菌前)
- **特殊级使用量**
- **抗菌药使用率**
- **耐药率**(MRSA、CRE、CR-AB)
- **PCT、CRP** 指导

## 干预措施
- **审批**(特殊级)
- **审核 + 反馈**(实时)
- **前瞻性审核**(24-48 h)
- **降阶梯建议**
- **短程方案**
- **IV → PO 转换**
- **TDM 监测**
- **教育**(继续医学)
- **指南**、**路径**

## 注意事项
- **不滥用**:70-80% 抗菌药用于上呼吸道(多病毒)
- **不预防**(无指征)
- **早经验、48-72 h 降阶**
- **PK/PD 优化**
- **疗程** 不可过长(短程)
- **IV → PO 序贯**(快、费用低)
- **重视 TDM**(万古、氨基糖、伊曲康唑)
- **关注相互作用**(P450 抑制/诱导)
- **过敏史**明确
- **妊娠、哺乳** 安全用药
- **监测耐药** 趋势
- **患者教育**:不自行购药
