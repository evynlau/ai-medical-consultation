# 耳鸣诊治

## 概述
耳鸣是缺乏外部声源情况下耳内或颅内的声音感觉,我国成人耳鸣发生率约 10-15%,> 65 岁达 30%。慢性严重耳鸣影响睡眠、情绪、生活质量,部分导致焦虑、抑郁。

## 分类

### 按性质
- **主观性耳鸣**(最常见,95%):仅患者感知
- **客观性耳鸣**(5%):检查者可听到
  - 血管性:动静脉瘘、动脉瘤、颈静脉球瘤
  - 肌源性:腭肌阵挛
  - 颞下颌关节

### 按病程
- 急性(< 3 月)
- 慢性(> 3 月,亚急性 3-6 月)

### 按部位
- **耳源性**(耳蜗 / 蜗后):
  - 突发性聋、梅尼埃病
  - 噪声性聋、老年性聋
  - 听神经瘤
- **全身性**:
  - 高血压、动脉硬化
  - 甲亢、甲减
  - 糖尿病
  - 贫血、维生素 B12 缺乏
  - 颈静脉球瘤、动脉瘤

## 病因
- **听力损失**(最常见诱因):耳蜗毛细胞损伤、听觉剥夺 → 神经可塑性代偿
- **耳部疾病**:中耳炎、耳硬化症、耵聍栓塞
- **噪声暴露**:急性声损伤(演唱会)、慢性工业噪声
- **药物耳毒性**:氨基糖苷类、顺铂、袢利尿剂、阿司匹林(大剂量)
- **颅脑外伤、颈椎病**
- **颞下颌关节紊乱**(TMJ)
- **心理因素**:压力、焦虑、抑郁
- **饮食**:咖啡因、酒精、烟草、味精

## 临床表现
- **声音感受**:蝉鸣、嗡嗡、嘶嘶、铃声、搏动性(血管性)
- **单侧 / 双侧**
- **急性 / 慢性、波动 / 持续**
- **伴随症状**:听力下降、眩晕、耳闷
- **影响**:睡眠、注意力、情绪

## 诊断

### 病史
- 起病、性质、部位、强度、波动
- 听力、眩晕、耳闷
- 噪声暴露史、用药史
- 心理状态

### 体格检查
- **耳镜**:耵聍、鼓膜、中耳积液
- **颞下颌关节、颈部**
- **听诊**:耳周、眼眶、颈部(搏动性)
- **血压**(基础)

### 听力学
- **纯音测听**
- **声导抗**
- **耳鸣匹配**:频率、强度
- **最小掩蔽级(MML)**
- **残余抑制**

### 影像
- **颞骨 CT**:中耳病变
- **MRI**(内听道 + 桥小脑角):**排除听神经瘤**(单侧耳鸣 + 听力下降)
- **MRA / CTA / 颈静脉超声**(搏动性)

### 实验室
- 血常规、血糖、血脂
- 甲功
- 维生素 B12
- 自身免疫病

### 评估量表
- **THI**(耳鸣致残量表)
- **VAS**(视觉模拟评分)
- **HADS**(焦虑抑郁)

## 治疗

### 病因治疗(关键)
- **耵聍取出**(立竿见影)
- **中耳疾病处理**
- **停用耳毒性药物**
- **控制血压、血糖、血脂**
- **治疗 TMJ、颈椎病**
- **听神经瘤**手术
- **血管性**:动脉瘤、瘘管介入

### 对症治疗
#### 急性耳鸣(同突发性聋处理)
- 糖皮质激素
- 改善微循环

#### 慢性耳鸣
**目前无特效治疗,目标是适应、缓解**
- **声治疗**(基础):
  - 白噪音、自然声音(雨、海浪)
  - 助听器(伴听力下降)
  - 耳鸣掩蔽器
  - **耳鸣习服治疗(TRT)**
- **认知行为治疗(CBT)**:
  - **一线推荐**
  - 改变对耳鸣的错误认知
- **药物治疗**:
  - 抗焦虑抑郁:SSRIs(SER 严重时)
  - 抗癫痫:利多卡因静推(短暂)、卡马西平(争议)
  - 银杏叶提取物
  - **不推荐**长期镇静药
- **神经刺激**:
  - **重复经颅磁刺激(rTMS)**
  - **迷走神经刺激 + 声音**(2017 报道)
- **耳蜗植入**(伴重度聋)

### 患者教育
- **避免噪声**(加重)
- **避免咖啡因、酒精、烟草**
- **规律作息、减压**
- **声环境**:不完全寂静,加背景声
- **心理咨询**
- **耳鸣互助小组**

## 注意事项
- **单侧耳鸣 + 听力下降**:警惕听神经瘤,需 MRI
- **搏动性耳鸣**:警惕血管病变
- 慢性耳鸣**难以治愈,目标是适应**
- 焦虑抑郁与耳鸣相互加重,需共病管理
- **避免大剂量阿司匹林**(耳鸣副作用)
- 助听器对伴听力下降者常有效
- 慎用「偏方」与未经证实疗法
- **睡眠卫生**对慢性耳鸣极重要
- TRT、CBT 需 6-18 月,需坚持
