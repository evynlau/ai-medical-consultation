# 抗中性粒细胞胞浆抗体

## 概述
抗中性粒细胞胞浆抗体(ANCA)是靶向中性粒细胞胞浆抗原(主要为蛋白酶 3、PR3;髓过氧化物酶、MPO)的自身抗体,是**ANCA 相关血管炎(AAV)** 的诊断与监测核心标志物。

## 检测方法

### 1. 间接免疫荧光(IIF)
- **底物**:乙醇固定中性粒细胞
- **金标准筛查**
- **两种核型**:
  - **c-ANCA**(胞浆型):均匀胞浆染色
    - 主要对应 **PR3-ANCA**
  - **p-ANCA**(核周型):核周染色
    - 主要对应 **MPO-ANCA**
  - **a-ANCA**(非典型):不规则、不特异
- **报告**:滴度(1:20、1:40 等)

### 2. 抗原特异性 ELISA / CLIA
- **确诊**:
  - **抗 PR3**
  - **抗 MPO**
- 定量、可监测
- 推荐:**IIF + ELISA 联合**

### 3. 第三代检测
- **化学发光 / 多重微球**
- 同时检测 PR3 + MPO
- 自动化、定量

### 4. 新型抗原
- **抗弹性蛋白酶、抗 cathepsin G、抗 lactoferrin、抗 BPI**:
  - 「非典型 ANCA」,与药物(丙硫脲)、UC、自身免疫性肝病相关

## 临床意义

### 三型 AAV 对应

| 疾病 | ANCA | 敏感度 | 特异度 |
|---|---|---|---|
| **GPA**(肉芽肿多血管炎) | **PR3-ANCA**(70-80%) | 高 | 高 |
| **MPA**(显微镜下多血管炎) | **MPO-ANCA**(70%) | 高 | 高 |
| **EGPA**(嗜酸性肉芽肿多血管炎) | **MPO-ANCA**(40%) | 中 | 中 |

### 1. GPA
- **PR3-ANCA**:**特异性 > 95%**
- 累及:上呼吸道(鼻窦)、肺(结节、空洞)、肾(RPGN)
- **滴度与活动**平行

### 2. MPA
- **MPO-ANCA**
- 累及:肾、肺(DAH)、皮肤、神经
- 多神经炎突出
- 部分 ANCA 阴性(10-30%)

### 3. EGPA
- MPO-ANCA(40%)
- 哮喘 + 嗜酸粒细胞 ↑ + 血管炎
- ANCA(+) 多累及肾、神经
- ANCA(-) 多累及心、肺(预后差)

### 4. 药物诱导 AAV
- **丙硫氧嘧啶**(甲状腺)、肼苯哒嗪、米诺环素、柳氮磺吡啶
- MPO-ANCA 多见
- 停药 + 免疫抑制

### 5. 非典型 ANCA
- UC、克罗恩病、原发性硬化性胆管炎
- 自身免疫性肝病
- RA、SLE(罕见)

## 适应证
- 寡免疫 RPGN(急进性肾炎)
- 不明原因肺出血、结节、空洞
- 多发性单神经炎
- 可触性紫癜
- 鼻窦、口腔、眼眶累及(眼炎、突眼)
- 多系统症状伴 ANCA(+) 史

## 标本采集
- **血清**(无抗凝)
- 室温 / 4°C 短期稳定
- 避免溶血、脂血
- 治疗前采血(阳性率高)

## 报告解读

### IIF + ELISA 联合
- **c-ANCA + PR3(+)** → **GPA**
- **p-ANCA + MPO(+)** → **MPA**(或 EGPA)
- **IIF (+) + ELISA (-)** → 非典型 ANCA(UC、Crohn、药物)
- **IIF (-) + ELISA (+)** → 早期 AAV(治疗中仍可)
- **双 (+)** → 注意交叉反应

### 滴度
- 高滴度:活动、未治、复发
- 低滴度:缓解期、治疗后
- **滴度变化与活动不完全一致**

## 临床应用

### 1. 诊断
- **AAV 高度特异**
- 2022 ACR/EULAR 分类标准:ANCA 评分

### 2. 疾病活动评估
- PR3-ANCA + AAV:滴度与活动相关(60-70%)
- MPO-ANCA:相关性弱
- **临床 + BVAS + ANCA**(综合判断)

### 3. 复发预测
- **ANCA 转阳**(尤其 PR3):复发风险 50% / 6-12 月
- **维持治疗**策略参考
- 但**单 ANCA 不能预测**

### 4. 治疗反应
- 缓解后滴度持续阳:可考虑延长免疫抑制
- 阴转后:可减量(谨慎)

### 5. 鉴别
- 感染(结核、IE)、肿瘤(淋巴瘤)、药物(丙硫)
- 心内膜炎、HIV、HCV(冷球蛋白)

## 注意事项

### 假阳性
- 感染:细菌(IE、结核)、病毒(EBV、HIV)、真菌
- 慢性病:Crohn、UC、PBC、SLE(罕见)
- 健康人罕见(< 1%)

### 假阴性
- **治疗中**:免疫抑制可抑制滴度
- **局限型**:局限 GPA(如鼻)可阴性
- **疾病晚期**:活动可阴性

### 滴度与临床
- 滴度 ↑ → 复发风险 ↑(不必然复发)
- 滴度正常 → 不能排除活动
- **临床 + BVAS + 影像**(综合)

### 特殊人群
- **儿童**:c-ANCA / PR3 罕见
- **妊娠**:不影响监测,但活动可变化
- **透析**:持续滴度

### 复查
- 活动期:1-3 月 1 次
- 维持期:3-6 月 1 次
- 复发期:每 1-3 月

### 实验室质控
- IIF:主观、操作者依赖
- 推荐:**IIF 筛查 + 特异 ELISA 确认**
- 自动化 CLIA 更稳定

### AAV 分类标准(2022 ACR/EULAR)
- ANCA 评分:7 项
- PR3(+):5 分
- MPO(+):-1 分
- 综合 ≥ 5 分(分类为 AAV)
