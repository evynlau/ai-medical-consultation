# 肌电图与神经传导

## 概述
肌电图(EMG)与神经传导(NCV)是评估**周围神经、神经肌肉接头、肌肉**功能的核心神经电生理检查。通过**针电极记录肌肉电活动**、**表面电极记录神经传导**,鉴别神经源性、肌源性、神经肌肉接头及中枢性病变。

## 适应证
- **周围神经病**:糖尿病、CIDP、GBS、遗传(Charcot-Marie-Tooth)、卡压
- **肌萎缩侧索硬化(ALS)**
- **神经根病、神经丛病**(颈椎、腰椎)
- **单神经病**(腕管、肘管、腓总神经)
- **多发性单神经病**(血管炎、麻风)
- **肌病**:炎性肌病、肌营养不良、代谢性
- **神经肌肉接头病**:**重症肌无力(MG)**、**Lambert-Eaton 综合征(LEMS)**
- **肉毒毒素注射定位**
- **术中神经监测**

## 禁忌证
- **绝对**:出血倾向(PT > 15 s、INR > 1.5、PLT < 50×10⁹/L);植入除颤器 / 心脏起搏器(注意)
- **相对**:
  - **抗凝**:肝素、华法林、DOAC 慎做针 EMG
  - **局部感染**:避免穿刺
  - **淋巴水肿**:可致感染、影响
  - **不能配合**

## 准备
- **停用新斯的明**(影响重复电刺激):停 12-24 h
- **体温**:**> 32°C**(温度低影响传导)
- **皮肤清洁**
- **知情同意**

## 检查项目

### 1. 神经传导速度(NCV)
- **运动神经传导(MCV)**:刺激神经,**记录肌肉 CMAP**(复合肌肉动作电位)
  - **末端潜伏期(DL)**
  - **传导速度(CV)**
  - **波幅(mV)**
- **感觉神经传导(SCV)**:**顺行 / 逆行**;**SNAP**(感觉神经动作电位,**μV 级**)

#### 正常值(参考)
| 神经 | MCV(m/s) | SCV(m/s) | 远端潜伏期(ms) |
|---|---|---|---|
| **正中神经** | ≥ 50 | ≥ 50 | < 4.5(运动) |
| **尺神经** | ≥ 50 | ≥ 50 | < 3.5 |
| **腓总神经** | ≥ 40 | ≥ 40 | < 5.5 |
| **胫神经** | ≥ 40 | ≥ 40 | < 5.5 |
| **腓肠神经** | - | ≥ 40 | - |

#### 异常
- **脱髓鞘**:
  - **CV 减慢**(< 正常下限 30%)
  - **DL 延长**
  - **传导阻滞**(近端 / 远端 CMAP 下降 > 30%)
  - **时间离散**(波形离散)
- **轴索损害**:
  - **CMAP / SNAP 波幅下降**
  - **CV 轻度减慢**
  - **DL 正常 / 轻度延长**

### 2. 针电极 EMG
- **插入活动**:正常 < 300 ms
  - **延长**:**失神经**(新近)
  - **减少 / 消失**:**纤维化、脂肪浸润**
- **自发电位**:
  - **纤颤电位(fibrillation)**:**新近失神经**(7-14 d 后出现)
  - **正锐波(PWS)**:**失神经早期**
  - **束颤(fasciculation)**:**LMN、良性**
  - **肌强直放电**:**强直性肌营养不良、非萎缩性肌强直**
  - **肌强直样放电**:MC、酸性麦芽糖酶缺乏
  - **复合重复放电(CRD)**:**慢性**
- **运动单位电位(MUP)**:
  - **时程、波幅、相位、稳定性**
  - **神经源性**:**时程↑、波幅↑、多相波↑、募集差**
  - **肌源性**:**时程↓、波幅↓、多相波↑、早募集(full)**
  - **MU 募集**:早 = 肌源;差 = 神经源

### 3. 重复神经电刺激(RNS)
- **刺激频率**:**2-3 Hz(低频) / 20-50 Hz(高频)**
- **测量**:CMAP 衰减 / 递增
- **重症肌无力**:
  - **低频 2-3 Hz 第 4-5 波 / 第 1 波 CMAP 下降 > 10-15%**:阳性
  - 服新斯的明后消失
- **LEMS**:
  - 低频衰减
  - **高频递增 > 60-100%**:**特征**
- **肉毒中毒**:高频递增小
- **肌强直**:**高频递减**

### 4. 单纤维 EMG(SFEMG)
- **最敏感**:**NMJ 异常**诊断
- **Jitter(颤抖)**:> 50 μs 异常(95% 上限)
- **MG**:敏感度 > 95%(眼肌型 90%)
- **LEMS**:也异常
- **新斯的明后 Jitter 改善**

### 5. F 波、H 反射
- **F 波**:**运动神经近端**:**神经根病、GBS**(早于临床表现)
- **H 反射**:**S1 神经根**(电生理跟腱反射)

## 临床应用

### 1. 腕管综合征(CTS)
- **正中神经**:
  - **DL > 4.5 ms** 异常
  - **跨腕 SCV 减慢**(最敏感)
  - **APB(拇短展肌)CMAP 降低**
- **针 EMG**:APB 失神经(重度)

### 2. 尺神经病
- **肘段 CV 减慢**:**肘管综合征**
- **ADQ(小指展肌)失神经**

### 3. 糖尿病周围神经病
- **远端对称性感觉运动神经病**
- **SCV 减慢(SNAP 降低)** + 轻度 MCV 减慢
- **足部感觉神经先受累**

### 4. CIDP
- **脱髓鞘为主**:
  - **CV 减慢**(< 70% LLN)
  - **DL 延长**(< 130% ULN)
  - **传导阻滞**、**F 波延迟 / 消失**、**时间离散**
  - **感觉、运动均受累**
- **AAN 电生理诊断标准**:**符合 4/7**(CV 减慢、DL 延长、CB、TD、F 波、末端 CMAP 负相面积 / 远端异常)

### 5. ALS(肌萎缩侧索硬化)
- **广泛神经源性损害**:
  - 多个区域(脑干、颈、胸、腰骶)肌萎缩
  - **慢性 + 活动性**(纤颤、束颤)
  - **MCV、SCV 正常**(无感觉受累!)
- 排除:**感觉神经受累、显著 LMN 单区域、影像解释的局灶性**

### 6. 重症肌无力
- **RNS 低频递减**(近端肌,**三角肌、斜方肌**敏感)
- **SFEMG Jitter 升高**
- **MCV、SCV 正常**、**针 EMG 正常**

### 7. Lambert-Eaton 综合征
- **RNS 高频递增** > 60-100%
- **CMAP 起始波幅低**(远端 + 近端)
- **SFEMG Jitter 升高**

### 8. 肌病
- **炎性肌病**:**多灶性肌源性改变 + 纤颤**(活动期)
- **肌营养不良**:**肌源性,无纤颤**(静止期)
- **MCV、SCV 正常**
- **肌强直样放电**:**强直性肌营养不良**

### 9. 神经根病(颈、腰)
- **EMG 失神经**(椎旁肌:多根;肢体肌:对应肌节)
- **神经根刺激征阳性**:**F 波、H 反射**
- **NCV 大多正常**

## 注意事项
- **EMG 检查前 24 h**:**停抗胆碱能**(腾喜龙、新斯的明)——影响 RNS
- **抗凝**:肝素 24 h、华法林 INR < 1.5、PLT > 50;新斯的明 24 h
- **体温维持 > 32°C**:**低体温**使 CV 假性减慢
- **评估者经验**:**神经科电生理医师**
- **针 EMG**:可致肌痛、皮下血肿
- **报告单描述**:**详细描述**、**对比正常值**、**结论 + 鉴别**
- **不诊断为神经源 / 肌源**:**需结合临床**
- **注射肌电图**(triggered EMG):肉毒毒素定位
- **神经根病早期(< 2-3 周)**:**EMG 阴性**(瓦勒变性未完成)
- **小纤维神经病**:**NCV 正常**,需**皮肤活检**(表皮神经纤维密度)
