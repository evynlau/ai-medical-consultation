# 急性心包炎

## 概述
急性心包炎是心包膜的急性炎症性疾病，可由感染、自身免疫、肿瘤、代谢疾病、物理因素等多种病因引起。临床表现为胸痛、心包摩擦感和心电图ST段改变。急性心包炎大多数为特发性或病毒性，预后较好，但少数可演变为缩窄性心包炎或出现心脏压塞。

## 分类
- 按病因分类:
  - 感染性心包炎:
    - 病毒性(柯萨奇病毒、腺病毒最常见)
    - 细菌性(结核性最常见)
    - 真菌性
    - 寄生虫性
  - 非感染性心包炎:
    - 自身免疫性(SLE、类风湿关节炎)
    - 肿瘤性(原发性或转移性)
    - 代谢性(尿毒症、痛风)
    - 物理性(外伤、放射性)
    - 药物性(普卡胺、异烟肼)
  - 特发性心包炎(病因不明)
- 按表现形式:
  - 经典急性心包炎
  - 复发性心包炎
  - 心脏压塞型
  - 缩窄性心包炎型

## 危险因素
- 病毒感染(上呼吸道感染最常见)
- 细菌感染(结核病)
- 自身免疫性疾病
- 恶性肿瘤(晚期)
- 尿毒症(透析患者)
- 胸部外伤
- 心脏手术(心包切开术后综合征)
- 放射治疗(胸部肿瘤)
- 某些药物(普鲁卡因胺、肼苯达嗪)
- 免疫功能低下(HIV感染)

## 常见症状
- 胸痛(最具特征性):
  - 位于胸骨后或心前区
  - 可放射至左肩、颈部
  - 随呼吸、体位变化(深吸气、平卧加重，坐位前倾减轻)
  - 性质:锐痛、刀割样痛、压榨样痛
- 心包摩擦感(体检发现):
  - 三相摩擦音(心房收缩、心室收缩、心室舒张)
  - 随体位变化
- 发热(多为低热，感染性可高热)
- 乏力
- 咳嗽
- 呼吸困难(严重时)
- 全身症状(根据病因)

## 并发症
- 心脏压塞(最严重并发症):
  - 静脉压升高、颈静脉怒张
  - 动脉压下降、脉压差缩小
  - 心音遥远
  - Beck三联征
  - Kussmaul征
- 复发性心包炎(10-30%患者)
- 缩窄性心包炎(部分结核性或特发性)
- 心包积液(常合并)
- 心肌炎(炎症累及心肌)
- 心包切开术后综合征(心脏手术后2-4周)

## 治疗原则
- 病因治疗(最重要):
  - 病毒性/特发性:对症治疗
  - 结核性:规范抗结核治疗
  - 细菌性:抗感染治疗
  - 自身免疫性:糖皮质激素或免疫抑制剂
  - 肿瘤性:原发肿瘤治疗
  - 尿毒症性:加强透析
- 对症治疗:
  - 镇痛:非甾体抗炎药(NSAIDs)首选
    - 阿司匹林(650-1000mg，每6-8小时)
    - 布洛芬(400-800mg，每6-8小时)
    - 吲哚美辛
  - 秋水仙碱(减少复发，0.5-1mg/天)
  - 糖皮质激素(顽固性或激素依赖性复发)
- 并发症处理:
  - 心脏压塞:紧急心包穿刺引流
  - 大量积液:心包穿刺抽液
- 复发性心包炎治疗:
  - NSAIDs+秋水仙碱(一线)
  - 糖皮质激素(短期使用)
  - 难治性考虑心包切除术

## 何时就医
- 剧烈胸痛(尤其随呼吸加重)
- 胸痛伴发热
- 呼吸困难
- 既往心包炎病史出现症状复发
- 诊断不明确需鉴别其他疾病
- 口服NSAIDs效果不佳
- 出现心脏压塞征象(颈静脉怒张、血压下降)
- 严重胸痛伴出汗、恶心(需排除心梗)

## 预防
- 积极治疗原发疾病
- 病毒感染后注意休息
- 避免心包外伤
- 胸部放疗控制剂量
- 透析患者充分透析
- 自身免疫病规范治疗
- 复发性心包炎患者长期秋水仙碱预防
- 定期复查，早期发现并发症
