# 外科感染与抗生素

## 概述
外科感染是细菌、真菌等病原体入侵组织引发的局部或全身炎症反应,涵盖浅表软组织感染、腹腔感染、复杂性皮肤软组织感染(cSSTI)、手术部位感染(SSI)、脓毒症等。合理使用抗生素是治疗核心,但需结合外科引流、清创、营养等综合措施。

## 常见外科感染

### 浅表感染
- **疖、痈、蜂窝织炎、丹毒、淋巴管炎**
- 主要病原:金黄色葡萄球菌(金葡菌,含 MRSA)、链球菌

### 腹腔感染
- **原发性腹膜炎**:自发性(肝硬化腹水)、儿童
- **继发性腹膜炎**:阑尾穿孔、溃疡穿孔、肠瘘
  - 病原:大肠杆菌、肺炎克雷伯菌、肠球菌、脆弱类杆菌
- **腹腔脓肿**:膈下、肠间、盆腔
- **胆道感染**:胆管炎(胆道梗阻基础上)
- **胰腺坏死感染**

### 复杂性皮肤软组织感染(cSSTI)
- 深部软组织感染、外伤感染、糖尿病足感染
- 病原:金葡菌、链球菌、革兰阴性菌、厌氧菌(混合)

### 手术部位感染(SSI)
- 浅表、深部、器官/腔隙
- 发生率:清洁手术 < 5%,清洁-污染 5-15%,污染 15-30%

## 诊断
- 局部:红、肿、热、痛、功能障碍
- 全身:发热、寒战、心率快、WBC ↑、PCT ↑、CRP ↑
- **影像**:超声、CT、MRI 评估深部感染、脓肿
- **病原学**:
  - 血培养(高热、寒战、抗生素前)
  - 脓液、胆汁、腹腔液培养 + 药敏
  - 组织活检(免疫抑制、罕见病原)

## 抗生素应用原则

### 经验性治疗
- 覆盖最可能病原、避免滥用
- 结合部位、感染类型、当地流行病学、既往抗生素、药敏
- 严重感染:广谱、足量、降阶梯

### 目标性治疗
- 培养 + 药敏后选择窄谱、低毒、经济的药物
- 口服序贯:病情稳定后,生物利用度高的药物口服

### 常用方案

| 感染类型 | 一线方案 |
|---|---|
| 皮肤软组织(非 MRSA 风险) | 头孢唑啉、苯唑西林、氨苄西林舒巴坦 |
| 皮肤软组织(MRSA 风险) | 万古霉素、利奈唑胺、达托霉素 |
| 社区获得性腹腔感染 | 头孢曲松 + 甲硝唑;哌拉西林他唑巴坦 |
| 医院获得性 / 重度腹腔 | 碳青霉烯、哌拉西林他唑巴坦 ± 抗真菌 |
| 胆道感染 | 头孢曲松 / 哌拉西林他唑巴坦;重症加抗厌氧 |
| 复杂性尿路 | 头孢曲松、哌拉西林他唑巴坦 |
| 脓毒症 | 1 h 内经验性广谱,目标治疗后调整 |

### 特殊抗生素
- **万古霉素**:MRSA 首选,谷浓度监测(15-20 mg/L)
- **利奈唑胺**:MRSA、皮肤软组织、肺部,骨髓抑制
- **达托霉素**:金葡菌菌血症、复杂皮肤感染
- **碳青霉烯**(亚胺培南、美罗培南):重度、ESBL 阳性、混合感染,避免滥用防耐药
- **替加环素**:复杂腹腔、皮肤,血药浓度低、不用于菌血症
- **抗真菌**(氟康唑、棘白菌素):念珠菌、腹腔真菌感染

## 围术期预防

### 适应证
- 清洁-污染、污染手术
- 涉及植入物、假体的清洁手术
- 高危患者(免疫低下、糖尿病)

### 时机
- 切皮前 30-60 min 给药
- 手术 > 3 h 或失血 > 1500 mL 追加
- 术后 24 h 停药(心脏手术可延至 48 h)

### 药物选择
- **头孢唑啉**(1-2 g):大多数手术
- **头孢呋辛**(1.5 g):心脏、骨科
- **万古霉素**:MRSA 高发机构、既往 MRSA 感染
- **头孢曲松 + 甲硝唑**:结直肠
- **莫西沙星** β 内酰胺过敏者

## 外科引流原则
- 感染灶「有脓必引」
- 引流物选择:烟卷、双套管(主动冲洗吸引)
- 术后拔管指征:引流液 < 10-20 mL/d、清亮、无感染迹象

## 注意事项
- 抗菌药物管理(AMS):多学科协作
- **降阶梯**:48-72 h 培养 + 临床反应调整
- 长期使用监测:C.diff 肠炎、真菌二重感染
- **耐药菌**:CRKP、CRE、MRSA、VRE 隔离、接触预防
- 破伤风预防(外伤、动物咬伤、烧伤):被动 + 主动免疫
