# 兰索拉唑

#### 兰索拉唑
*## 基本信息*## 
- 分类：质子泵抑制剂（PPI）
- 常见商品名：达克卢、 Prevacid
- 上市时间：1990年代初
- 处方/OTC状态：处方药（部分OTC）
*## 适应症*## 
- 胃溃疡、十二指肠溃疡
- 反流性食管炎
- Zollinger-Ellison综合征
*## 药理作用*## 
- 抑制H+/K+-ATP酶（质子泵），阻断胃酸分泌最后步骤
-抑酸作用强而持久
*## 用法用量*## 
- 成人：15mg/次，1次/日，餐前服用
- 严重反流性食管炎：30mg/次，1次/日
*## 不良反应*## 
- 腹泻、便秘
- 头痛、头晕
- 长期使用可能增加骨折、维生素B12缺乏风险
*## 注意事项*## 
- ⚠️ 应于餐前30分钟服用
- ⚠️ 长期使用（>1年）需评估必要性
- ⚠️ 肝功能不全者减量使用
*## 禁忌*## 
- 对奥美拉唑等苯并咪唑类过敏者（交叉反应）
*## 临床应用要点*## 
- 抑酸作用强于H2受体拮抗剂
- 半衰期短（1小时），需早晨餐前服用
- 适用于需要强效抑酸的患者
