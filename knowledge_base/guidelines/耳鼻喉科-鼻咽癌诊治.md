# 鼻咽癌诊治

## 概述
鼻咽癌(NPC)是起源于鼻咽部黏膜上皮的恶性肿瘤,我国南方(广东、广西、福建)、东南亚高发,与 EB 病毒感染、遗传易感、饮食(咸鱼)、环境密切相关。年发病率约 2-30/10 万(地区差异极大),男性多见,40-60 岁高峰。

## 病因
- **EB 病毒(EBV)**:几乎所有非角化型 NPC 携带 EBV
- **遗传**:家族聚集,HLA 相关
- **饮食**:咸鱼、腌制食品(含亚硝胺)
- **环境**:镍、甲醛、农药、吸烟
- **慢性炎症**

## 病理(WHO 分类)
- **角化型鳞癌**(WHO I):预后差
- **非角化型癌**(WHO II):分化型
- **未分化型非角化癌**(WHO III):放疗敏感、预后好(我国多见)

## 临床表现
- **早期症状**(易忽视):
  - **回缩性血涕**(吸鼻后吐痰带血)
  - 单侧耳鸣、听力下降(咽鼓管阻塞)
  - 颈部无痛性肿块(淋巴结转移,60% 首诊)
- **进展期**:
  - 鼻塞
  - 头痛(颅神经受侵)
  - 复视、视力下降(III、IV、VI 颅神经)
  - 张口困难(翼外肌、颞下窝受侵)
  - 面部麻木(V 颅神经)
  - 声嘶、吞咽困难(IX-XII 颅神经)

## 诊断
- **电子鼻咽镜**:**金标准**,可见菜花样 / 结节 / 溃疡
- **颈部超声**:淋巴结评估
- **MRI**(首选):明确肿瘤范围、颅底、咽旁、淋巴结
- **CT**:骨破坏评估
- **PET-CT**:分期、远处转移(尤其 N3、M1)
- **病理活检**(确诊):鼻咽镜下活检
- **EB 病毒检测**:
  - **血浆 EBV DNA**(定量):诊断、监测、预后
  - VCA-IgA、EA-IgA:筛查

## 分期(UICC/AJCC 第 8 版)
- **T**:原发肿瘤大小与侵犯范围
- **N**:淋巴结(鼻咽癌 N 分期特殊,根据部位与大小)
- **M**:远处转移
- **TNM 综合分期**(I-IV 期)

## 治疗

### 治疗原则
- **首选放疗**(对放射敏感)
- 早期(I-II 期):单纯放疗
- 中晚期(III-IV 期):**同步放化疗**(CCRT)+ 诱导化疗 / 辅助化疗
- 复发 / 转移:化疗、免疫治疗、靶向

### 放射治疗(根治手段)
- **IMRT(调强放疗)**:标准技术
  - 鼻咽 + 咽旁 + 颈部淋巴引流区
  - 总剂量 66-70 Gy / 30-35 次
  - 保护脑干、脊髓、视神经、腮腺
- **螺旋断层放疗(HT)**、**质子治疗**:精准

### 化学治疗
- **同步化疗**:顺铂 100 mg/m² q3w × 2-3 周期(标准)
  - 或每周 40 mg/m²
  - 不耐受者:卡铂、奈达铂
- **诱导化疗**(T4、N3):
  - TPF(多西他赛 + 顺铂 + 5-FU)
  - TP(多西他赛 + 顺铂)
  - GP(吉西他滨 + 顺铂,GP 方案近年标准)
- **辅助化疗**:顺铂 + 5-FU(疗效有限)
- **复发 / 转移**:吉西他滨 + 顺铂、卡培他滨、紫杉醇

### 免疫治疗(新进展)
- **PD-1 单抗**:帕博利珠单抗、替雷利珠单抗、卡瑞利珠单抗、特瑞普利单抗
  - 复发 / 转移、含铂化疗失败后
  - 联合 GP 一线(2023 ASCO 报道)
- **靶向**:尼妥珠单抗(抗 EGFR)、西妥昔单抗

### 手术治疗(选择)
- 残留 / 复发挽救手术:鼻内镜下 NPC 切除
- 颈部淋巴结清扫(放疗后残留)

### 对症支持
- 营养支持(经口困难者鼻饲、胃造瘘)
- 口腔护理(防放射性黏膜炎)
- 镇痛
- 心理支持

## 注意事项
- **EBV DNA** 是治疗监测、复发预警重要指标
- 放疗**急性反应**:口腔黏膜炎、皮肤反应、口干、味觉减退
- 放疗**晚期反应**:口干(永久性)、听力下降、颞叶坏死、颅神经损伤、放射性龋齿、甲状腺功能减退、垂体功能减退
- 治疗后 2 年内每 3 月复查,5 年内每 6 月,之后每年
- 复查项目:鼻咽镜、MRI、EBV DNA、胸部 CT、肝胆 B 超
- **口腔卫生**终生维护
- 家族史(一、二级亲属)需 EBV 筛查
- 高发区 30-69 岁可考虑 EBV + 鼻咽镜筛查
- 戒烟酒、避免腌制食品
