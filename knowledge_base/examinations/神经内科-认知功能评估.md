# 认知功能评估

## 概述
认知功能评估是**痴呆、MCI(轻度认知损害)、其他认知障碍**(脑外伤、MS、精神疾病)的**核心诊断工具**。涵盖**筛查量表、综合神经心理、专项功能**(记忆、语言、执行、视空间)、**日常与社会功能评估**,结合影像、实验室、生物学标志物。早期识别可干预,延缓进展。

## 适应证
- **痴呆(MCI、AD、VaD、FTD、DLB、PDD)**
- **认知主诉**(本人或家属)
- **脑卒中后认知**
- **MS、PD 认知减退**
- **脑外伤、TBI**
- **手术前后评估**(心脏、神经外科)
- **法医、劳动能力鉴定**
- **疗效评估**(AED、药物副作用)

## 主要量表分类
1. **筛查量表**:MMSE、MoCA、AD8、mini-Cog
2. **综合认知**:MoCA 完整版、ADAS-cog
3. **分项评估**:
   - 记忆:HVLT、CVLT、逻辑记忆(WMS)
   - 执行:TMT、Stroop、WCST
   - 语言:BNT、语义流畅性、动物流畅性
   - 视空间:Rey-O 复杂图、画钟
   - 注意力:数字广度、符号数字
4. **功能**:**ADL、IADL、FACS**
5. **精神行为**:**NPI、CMAI、CDR**
6. **总体分级**:**CDR、GDS(FAST)**

## 1. 筛查量表

### MMSE(简易精神状态量表)
- **满分 30**、**时间 5-10 min**
- 评估:**定向、记忆、计算、语言、视空间、注意力**
- **文盲 ≤ 17**、**小学 ≤ 20**、**中学 ≤ 22**、**大学 ≤ 23** 提示认知障碍
- **缺点**:**顶叶、MCI 不敏感**;受文化程度、教育影响
- **MCI 检出率低**(< 20%)

### MoCA(蒙特利尔认知评估)
- **满分 30**、**时间 10-15 min**
- **比 MMSE 敏感**:**筛查 MCI 优先**
- 评估:**视空间/执行(连线、复制立方体、画钟)、命名、记忆(5 词)、注意力(数字、敲击、连减)、语言(复述、流畅性)、抽象、延迟回忆、定向**
- **< 26 分**:**认知障碍**(教育年限 ≤ 12 年加 1 分)
- **版本**:MoCA-BLIND(视盲版)、MoCA-BASIC(低文化)

### AD8(知情者问卷)
- 8 项、**3 min**、**敏感度 80%+**
- 包含:**判断力、兴趣、重复、学会新事物 / 使用器具、忘事、健忘发作、沟通、个性**
- ≥ 2 项:**提示痴呆**

### Mini-Cog
- **3 项词回忆 + 画钟**(计时 / 指向)
- 5 min,文盲可用
- **> 5 min 不能正确画钟 + 回忆 ≤ 2 词**:**阳性**

## 2. 总体分级量表

### CDR(临床痴呆分级)
| CDR | 描述 |
|---|---|
| **0** | 无痴呆 |
| **0.5** | **MCI / 可疑痴呆** |
| **1** | 轻度(记忆 + IADL 受损) |
| **2** | 中度(IADL 受损加重) |
| **3** | 重度(全面失能) |

### GDS / FAST(整体衰退量表)
- 7 级:1(无)→ 7(严重)
- 用于 AD 分期

## 3. 综合神经心理评估

### 记忆
- **韦氏记忆量表(WMS-IV)**:逻辑记忆、视觉再现
- **CVLT / HVLT**(词语学习测验):10-15 词,5 次,评估编码、储存、再认
- **Rey 听觉词语学习测验(RAVLT)**
- **延迟回忆敏感**:**AD 早期** —— 信息保留差

### 执行功能
- **连线测验 A / B(TMT-A / B)**:A 数 1-25;B 1-13,A 1-M:**切换、灵活性**
- **Stroop 试验**:词色不一致抑制
- **威斯康星卡片(WCST)**:分类切换
- **FrSBe**(额叶行为)

### 语言
- **Boston 命名测验(BNT)**:60 张图,**30 min**
- **流畅性**:**动物 / 1 min**(> 18 正常)、**音首**(FAS)
  - **AD 语义流畅性差**;**额颞叶变性**音首差
- **失语筛查**:WEST、Token、Token Test

### 视空间
- **画钟试验(CDT)**:10 分
  - **计分:Cacho、TUHELP 等**
- **Rey-O 复杂图**(临摹 + 延迟)
- **Benton 视觉保持**

### 注意力
- **数字广度(顺/逆)**:5-9 / 3-7
- **符号数字模式(SDMT)**:90 s 转换

## 4. 行为精神评估

### NPI(神经精神量表)
- **12 项**:妄想、幻觉、激越、抑郁、焦虑、欣快、冷漠、去抑制、易激惹、异常运动行为、睡眠、饮食
- **评分:频率 × 严重度**

### CMAI(激越行为量表)
- 29 项、护理员评分

### GDS-15 / PHQ-9(老年抑郁)
- 排除**假性痴呆**(抑郁伪装痴呆)
- **抑郁性假性痴呆**:**DST(数字符号)差,延迟回忆好**

## 5. 日常与社会功能

### ADL(基本日常活动)
- 6 项:吃饭、穿衣、移动、洗澡、二便、控便
- **躯体疾病**也下降

### IADL(工具性日常活动)
- 8 项:**购物、家务、理财、用药、电话、交通、洗衣、备餐**
- **MCI 早期受损**

### FAQ(功能活动问卷)(知情者)
- **MCI 早期信号**

## 6. 临床应用

### AD 评估流程
1. **主诉 + 病史 + 知情者**
2. **筛查**:MMSE + MoCA + AD8
3. **综合**:ADAS-cog / 神经心理全套
4. **影像**:MRI / CT(海马萎缩、颞角扩大)
5. **实验室**:排除(甲减、B12、肝肾、梅毒、HIV)
6. **生物标志物**:
   - **CSF Aβ42↓、tau ↑、p-tau↑**
   - **PET Aβ**、**PET tau**
   - **血液 p-tau217、p-tau181、GFAP**
7. **基因**(家族性 / 早发):APP、PSEN1、PSEN2、ApoE

### VaD 评估
- **Hachinski 缺血评分(HIS)**:**> 7**:AD;**< 4**:VaD
- **NINDS-AIREN** 标准
- **影像**:白质高信号(WML)、腔隙、关键部位梗死

### FTD(额颞叶痴呆)
- **执行 / 行为 / 语言**:主导
- **MMSE 早期正常**、**MoCA 异常**
- **功能 MRI**:额 / 颞叶萎缩
- **基因**:MAPT、GRN、C9ORF72

### DLB(路易体痴呆)
- **核心**:波动性认知、视幻觉、REM 睡眠行为障碍、帕金森综合征
- **MoCA + UPDRS**
- **MIBG 心肌显像**、DAT-SPECT

### PD 认知(PDD / PD-MCI)
- **MoCA、Mattis DRS**
- 多个领域:**注意力、执行、视空间、记忆(再认差)**

## 7. 评估要点

### 文化与教育
- **教育调整**:MMSE 教育年限 ≤ 12 年加 2 分(部分版本)
- **MoCA 11 年以下教育 + 1**
- **文化程度盲点**:**画钟**、**命名**(低文化人陌生)

### 知情者报告
- 客观性高,**鉴别抑郁与痴呆**
- **AD8、FAQ、IQCODE**

### 床旁评估
- 5 min 方案:
  1. **三词登记 + 画钟**
  2. **3 min 回忆 + 画钟评分**
  3. **定向、命名、复述**

## 注意事项
- **量表辅助临床诊断**,**不替代**
- **环境安静、舒适**、避免患者疲劳
- **MCI**:MMSE 25-27、MoCA 19-25
- **教育校正**:**未校正易误诊**
- **情绪评估必做**:**抑郁伪装**
- **失语患者**:**认知不能全靠量表**
- **盲 / 聋 / 严重失能**:**MoCA-BLIND、视触**
- **重复评估条件一致**:同一时间、环境、评分员
- **随访间隔**:**6-12 月**(MCI)、**3-6 月**(中度)
- **症状量表**:**家属 + 患者分别评估**
- **决策能力评估**:金融、医疗、驾驶、遗嘱(神经心理 + 精神科)
- **早期识别 + 综合干预** = 最佳策略
