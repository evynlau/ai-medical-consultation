# 左氨氯地平

#### 左氨氯地平
*## 基本信息*## 
- 分类：二氢吡啶类钙通道阻滞剂（CCB）
- 常见商品名：络活喜、安内真
- 上市时间：2000年代
- 处方/OTC状态：处方药
*## 适应症*## 
- 高血压
- 慢性稳定性心绞痛
*## 药理作用*## 
- 氨氯地平的左旋异构体，抑制钙离子内流
- 降压效果与氨氯地平相当，但副作用可能更少
- 作用时间长（半衰期30-50小时）
*## 用法用量*## 
- 成人：2.5-5mg/次，1次/日
- 老年人及肝功能不全：起始剂量2.5mg/日
- 最大剂量5mg/日
*## 不良反应*## 
- 头痛、水肿（外周性）
- 面红、心悸
- 眩晕、乏力
- 牙龈增生（少见）
*## 注意事项*## 
- ⚠️ 肝功能不全者减量使用
- ⚠️ 心力衰竭患者慎用
- ⚠️ 可能引起牙龈增生，注意口腔卫生
*## 禁忌*## 
- 对二氢吡啶类过敏者
- 严重低血压
- 心源性休克
*## 相互作用*## 
- 葡萄柚汁：可能升高血药浓度
- 环孢素、他克莫司：升高其血药浓度
- CYP3A4抑制剂（如酮康唑）：升高本品血药浓度
*## 临床应用要点*## 
- 半衰期长，每日一次给药，降压平稳
- 对代谢无不良影响，适用于糖尿病患者
- 可与ACEI/ARB、噻嗪类利尿剂联合使用
