# 视力检查

## 概述
视力(visual acuity)是衡量眼睛分辨最小物像的能力,是眼科最基本的视功能检查。包括远视力与近视力,是筛查、诊断、随访的核心指标。标准化的检查方法是获得可靠结果的前提。

## 检查方法

### 远视力
- **视力表**:
  - **国际标准对数视力表**(5 分制,我国常用)
  - **Snellen 视力表**(6/6、20/20 系统)
  - **LogMAR 视力表**(ETDRS,科研金标准)
- **检查距离**:
  - 标准对数表:5 m
  - Snellen:6 m(20 ft)
- **照明**:标准照明 200-500 lux
- **步骤**:
  1. 双眼分别检查(遮盖板,勿压迫眼球)
  2. 先查右眼后左眼
  3. 从大视标开始,逐行辨认
  4. 记录能辨认最小一行

### 近视力
- **标准近视力表**:Yeager 近视力表、Jaeger 近视力表
- **检查距离**:30-40 cm(标准近表),自身阅读距离
- 评估阅读能力、老视

### 儿童视力评估
- **选择性注视(Selective Looking)**:
  - Teller 卡:婴儿
  - Cardiff 卡:1-3 岁
- **图形视力表**:
  - Allen 卡、Lighthouse、Lea Symbols:2-5 岁
- **HOTV 视力表**:3-5 岁
- **E 字视标 / Snellen**:5 岁+

## 记录方法

### 小数记录(常用)
- 0.1、0.2、0.3 ... 1.0、1.2、1.5
- < 0.1:指数(FC / CF)、手动(HM)、光感(LP)、无光感(NLP)
- 光定位

### 5 分记录(对数)
- 5.0 = 1.0(标准视力)
- 4.0 = 0.1
- 3.0 = 指数
- 2.0 = 手动
- 1.0 = 光感
- 0 = 无光感

### LogMAR
- 0 = 1.0
- 0.3 = 0.5
- 1.0 = 0.1
- 临床研究中常引用

## 评估意义

### 正常参考值
- **成人**:远视力 ≥ 1.0(对数 5.0)
- **儿童**:3 岁 0.5+、4 岁 0.6+、5 岁 0.7+、6 岁及以上 1.0
- **矫正视力**:屈光不正戴镜后 ≥ 1.0

### 临床应用
- **< 0.05**:法医学盲
- **< 0.3**:明显视力损害
- **0.3-0.8**:轻度下降
- **≥ 1.0**:正常

### 异常意义
- **< 0.8 / 不及格**:视力低下,需进一步检查
- **矫正视力 < 0.8**:屈光不正、弱视、眼病
- **矫正视力 < 0.3**:中重度视功能损害

## 检查流程

### 成人
1. 病史询问
2. 远视力(裸眼)
3. 显然验光 / 显然验光 → 矫正视力
4. 必要时散瞳验光
5. 近视力

### 儿童(关键筛查)
1. 3 岁起每年检查 1 次
2. 屈光 + 眼位 + 眼底
3. 睫状肌麻痹验光(< 12 岁必做)

## 注意事项
- **环境光线**稳定,反光镜、视力表避免眩光
- **遮盖板**严密,勿让患者偷看
- **鼓励但勿提示**
- **眯眼**会提高视力(测量误差)
- **测量距离**精确,小于 5 m 用镜面反光
- **散瞳**后无法立即验光测远视力
- 特殊人群:婴幼儿、智力低下、伪盲(雾视法、视觉电生理)
- **主观误差**:对数视力表比 Snellen 更稳定
- 国际盲与低视力标准(WHO):
  - 盲:最佳矫正视力 < 0.05
  - 低视力:0.05-0.3
