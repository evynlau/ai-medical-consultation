# 慢性阻塞性肺疾病管理

## 概述
慢性阻塞性肺疾病(COPD)是以持续性气流受限为特征的可以预防和治疗的疾病,其气流受限多呈进行性发展,与气道和肺组织对香烟烟雾等有害气体或颗粒的慢性炎症反应有关。我国 > 40 岁人群 COPD 患病率 13.7%,> 60 岁超 27%。

## 危险因素
- **吸烟**(最重要):主动 + 被动
- 职业粉尘和化学物质
- 室内外空气污染
- 生物燃料烟雾
- 反复下呼吸道感染
- α1-抗胰蛋白酶缺乏(< 1%)
- 肺发育不良
- 哮喘控制不佳

## 临床表现
- **慢性咳嗽**:首发症状,晨起明显
- **咳痰**:白色黏液或浆液性,急性加重时黄脓
- **气短 / 呼吸困难**:进行性加重,标志性症状
- **喘息 / 胸闷**
- **体征**:
  - 视诊:胸廓前后径增大(桶状胸)、肋间隙增宽
  - 触诊:语颤减弱
  - 叩诊:过清音、心浊音界缩小、肝浊音界下降
  - 听诊:呼吸音减弱、呼气延长、湿啰音 / 干啰音

## 诊断金标准
- **肺功能**:吸入支气管扩张剂后 **FEV₁/FVC < 0.7**
- 必备:排除其他疾病(哮喘、支扩、TB)

## 分期与严重度
### GOLD 1-4 级(气流受限)
| 级别 | FEV₁ % 预计值 |
|---|---|
| GOLD 1 轻度 | ≥ 80 |
| GOLD 2 中度 | 50-79 |
| GOLD 3 重度 | 30-49 |
| GOLD 4 极重度 | < 30 |

### GOLD A-D 综合评估
- **症状评分**:mMRC 0-1 / CAT < 10 为少症状
- **急性加重风险**:≤ 1 次(无住院)为低风险
| 风险 | 症状少 | 症状多 |
|---|---|---|
| 低风险 | **A 组** | **B 组** |
| 高风险 | **C 组** | **D 组** |

## 急性加重(AECOPD)
- 急性发生的症状恶化,需要额外治疗
- 表现:呼吸困难加重、痰量增加、脓痰 →「Anthonisen 标准」
- 严重度:轻(仅 SABA)、中(SABA + 抗生素 / 激素)、重(住院 / ICU)
- **住院指征**:严重呼吸困难、急性心衰、新发心律失常、意识改变、需无创通气

## 稳定期治疗

### 戒烟 + 疫苗 + 康复
- **戒烟**:任何阶段都必要,减缓 FEV₁ 下降
- **疫苗**:
  - 流感疫苗(年度)
  - 肺炎球菌疫苗(PCV13 + PPSV23)
  - 新冠疫苗
  - 百日咳疫苗
- **肺康复**:运动训练 + 教育 + 心理

### 药物治疗(基于 ABCD 分组)
| 组 | 首选 |
|---|---|
| **A** | 短效支气管扩张剂(SABA 或 SAMA)按需 |
| **B** | 长效支气管扩张剂(LABA 或 LAMA) |
| **C** | LAMA(优先 LABA+LAMA 也可) |
| **D** | LAMA + LABA + ICS(血嗜酸 ≥ 300);三联,或加罗氟司特 / 大环内酯 |

**常用药物**:
- **SABA**:沙丁胺醇、特布他林
- **SAMA**:异丙托溴铵
- **LABA**:沙美特罗、福莫特罗、茚达特罗、奥达特罗
- **LAMA**:噻托溴铵、格隆溴铵、乌美溴铵
- **ICS**:布地奈德、氟替卡松
- **三联(ICS/LABA/LAMA)**:Trelegy Ellipta、Breztri
- **PDE4 抑制剂**:罗氟司特(慢性支气管炎型、FEV₁ < 50%)
- **大环内酯**:阿奇霉素长期(减少急性加重)

### 急性加重期治疗
- **SABA + SAMA** 雾化(短期)
- **全身糖皮质激素**:
  - 泼尼松 30-40 mg/d × 5 d
  - 或甲强龙 40 mg/d × 5 d
  - 或相当剂量
- **抗生素**:
  - 指征:Anthonisen Ⅰ-Ⅱ 型(脓痰 + 呼吸困难 / 痰量增加)
  - 门诊:阿莫西林克拉维酸 / 多西环素 / 大环内酯
  - 住院:头孢曲松 / 左氧氟沙星
  - 高风险(铜绿假单胞菌):抗假单胞 β 内酰胺
- **氧疗**:低氧者 SpO₂ 88-92%
- **无创通气(NIV)**:pH 7.25-7.35 + 高碳酸血症 → 首选
- **有创通气**:NIV 失败、严重酸中毒、意识障碍
- **监测**:血气、电解质、痰液

## 长期家庭氧疗
- 适应:PaO₂ ≤ 55 mmHg(静息),或 ≤ 60 + 肺心病/红细胞增多
- 时间:> 15 h/d
- 流量:1-3 L/min
- 设备:制氧机
- 戒烟同时是基本

## 注意事项
- 戒烟是唯一能改变 COPD 自然病程的措施
- **疫苗接种很重要**(降低急性加重和死亡)
- **急性加重后**功能常难恢复基线,要积极预防
- 心血管合并症是 COPD 主要死因(50%+)
- 长期口服激素:**不推荐**(增加感染、骨松、肌少)
- ICS 治疗:血嗜酸高 + 频繁加重者获益;肺炎风险增加(注意)
- 营养支持(高蛋白)、心理支持
