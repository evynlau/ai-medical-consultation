# ERCP检查与治疗

## 概述
内镜逆行胰胆管造影(ERCP)是在十二指肠镜下经十二指肠乳头插管,注射对比剂显示胰管、胆管,进行诊断与治疗的技术。1970 年代以来逐步从单纯诊断发展为以治疗为主(胆管取石、支架置入、引流、活检)。ERCP 是消化内镜中操作难度、并发症风险最高的技术之一,需严格把握适应证。

## 适应证

### 治疗性(主要)
- **胆总管结石**取石(EST + 网篮 / 球囊)
- **良恶性胆管狭窄**支架置入
  - 胰头癌、胆管癌、转移
  - 手术损伤、PSC
- **急性胆管炎**减压引流
- **梗阻性黄疸**引流减黄(术前 / 姑息)
- **胆瘘**支架封堵
- **奥迪括约肌功能障碍**(ODDI)
- **慢性胰腺炎胰管狭窄 / 结石**
- **胰管破裂**(胰腺外伤、胰腺炎)支架
- **鼻胆管引流(ENBD)**:短期引流、冲洗、造影
- **乳头括约肌切开(EST)**
- **壶腹周围肿瘤**活检、电切
- **胰腺假性囊肿**引流(ETCD)

### 诊断性(逐步被替代)
- 原因不明胆管扩张
- 胆道术后评估
- 自身免疫性胰腺炎
- 胆管癌、IPMN
- **注意**:单纯诊断性 ERCP 应由 MRCP、EUS 替代

## 禁忌证

### 绝对
- 食管、幽门、十二指肠球部严重狭窄无法进镜
- 严重心肺功能不全
- 凝血功能严重障碍(INR > 1.5、PLT < 50 × 10⁹/L)
- 急性胰腺炎(非胆源性)
- 胆管炎未控制、休克

### 相对
- 妊娠早期(可推迟)
- 急性胰腺炎
- 上消化道术后(Roux-en-Y 等)插管困难
- 胆总管十二指肠瘘
- 碘过敏(换非离子型、预防用药)

## 术前准备

### 评估
- 病史、过敏史、用药史
- 心肺功能、凝血、肝功、淀粉酶
- 影像:MRCP / CT / 超声
- HBV / HCV、HIV(医患防护)
- 抗凝药:阿司匹林可不停(诊断性);治疗性停 5-7 d;华法林停 5 d;NOAC 停 1-2 d
- 禁食 6-8 h

### 操作前
- 知情同意
- 静脉通路
- 镇静 / 麻醉:丙泊酚(无痛 ERCP)、咪达唑仑 + 哌替啶
- 预防性抗生素:胆管炎、胆囊炎、胆道梗阻、免疫抑制
- 预防 PEP(ERCP 术后胰腺炎):直肠 NSAIDs(吲哚美辛 / 双氯芬酸)100 mg 肛塞、PD 支架、乳酸林格液 1 L 静滴

## 操作步骤
1. 十二指肠镜进至降部,找主乳头
2. 乳头插管(选择性胆管 / 胰管)
3. 注射对比剂造影
4. 留图、动态评估
5. 完成治疗(切开、取石、支架)
6. 撤镜

## 主要治疗

### 1. 内镜下括约肌切开(EST)
- 拉式或推式
- 切开长度取决于结石大小、憩室情况
- 「**预切开(Precut)**」:插管困难时
- 电流:混合 / 纯切,电凝减少出血

### 2. 胆管取石
- **网篮 / 球囊**
- 小结石(< 1 cm):直接取出
- 大结石(> 1.5 cm):机械碎石(BML)、液电 / 激光碎石
- 难取:**鼻胆管引流 / 胆管支架**(临时)
- 大量结石:多步治疗

### 3. 胆管支架
- **塑料支架**:
  - 7-10 Fr 圣诞树 / 猪尾
  - 临时 / 短期(1-3 月更换)
  - 良恶性狭窄、胆瘘
- **金属支架**:
  - 全覆膜、自膨式(SEMS)
  - 不可切除恶性胆管梗阻
  - 良性狭窄(短程)
  - 生存期 > 6 月优于塑料

### 4. 鼻胆管引流(ENBD)
- 一端经乳头置入胆管、另一端经鼻引出
- 急性胆管炎冲洗、引流
- 短期(< 2-4 周)
- 监测引流液性状、量

### 5. 胰管操作
- **胰管括约肌切开**
- **胰管支架**:PD 断裂、慢性胰腺炎、IPMN 减压
- **副乳头切开 / 支架**:胰腺分裂症

## 术后处理
- 监测生命体征、腹部症状
- **淀粉酶、脂肪酶**:术后 4-6 h、24 h
- **白细胞、体温**
- **禁食 24 h**(无 PEP)
- 治疗性:补液、PPI、生长抑素(高危)
- **ENBD**:持续引流,记录量、性质
- **支架**:按时复查 / 更换
- 抗生素:胆管炎、胆囊炎

## 主要并发症

### 1. ERCP 术后胰腺炎(PEP)
- **最常见**(3-10%)
- **危险因素**:
  - 插管困难、多次尝试
  - 胰管注射
  - 预切开
  - 球囊扩张
  - 既往 PEP
  - SOD 患者
- **预防**:
  - 吲哚美辛 / 双氯芬酸 100 mg 直肠
  - 胰管支架
  - 乳酸林格液
  - 导丝辅助插管
- **治疗**:禁食、补液、奥曲肽、生长抑素

### 2. 出血
- 切开部位(1-2%)
- 渗血:肾上腺素注射
- 喷血:钛夹、热凝、球囊压迫
- 介入 / 手术罕见

### 3. 穿孔
- 0.5-1.5%
- **Stapfer 分型**:
  - Ⅰ:十二指肠侧壁
  - Ⅱ:腹膜后(壶腹周围)
  - Ⅲ:胆管、胰管
  - Ⅳ:仅腹膜后气体
- 治疗:
  - Ⅰ:手术
  - Ⅱ-Ⅲ:多数保守(禁食、胃肠减压、抗生素)
  - 大穿孔:手术

### 4. 胆管炎、胆囊炎
- 引流不充分、支架堵塞
- 抗生素、引流 / 更换

### 5. 结石嵌顿(网篮)
- 紧急处理:
  - 碎石(液电 / 激光)
  - Soehendra 螺旋管
  - 紧急手术

### 6. 心肺事件、麻醉相关
- 老年人、心脏病者

## 注意事项
- 操作复杂,需有经验医师
- **单纯诊断性 ERCP 应避免**(用 MRCP / EUS)
- **治疗性 ERCP** 限于有 ERCP 指征者
- **预防 PEP 至关重要**
- **预切开**增加并发症,需由经验医师操作
- **支架移位**及时处理
- **Roux-en-Y 术后**:单气囊小肠镜 / EUS 引导(GE-LAMS)ERCP
- **磁压迫吻合(MAGNAM)**:胃 / 肠与胆管 / 胰管磁性支架
- **全覆膜金属支架**可导致对侧胆管 / 胰管堵塞
- 儿童 ERCP 需要专门仪器与团队
