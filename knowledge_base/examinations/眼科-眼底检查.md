# 眼底检查

## 概述
眼底检查是使用检眼镜、裂隙灯、前置镜等设备观察视网膜、视盘、脉络膜的方法,是诊断眼底病、视神经病及部分全身病的核心检查。包括直接检眼镜、间接检眼镜、裂隙灯前置镜等,适应不同临床场景。

## 检查方法

### 1. 直接检眼镜
- **原理**:单目光学系统,放大 15 倍
- **特点**:正像、放大倍率高、可看视盘细节
- **步骤**:
  1. 暗室
  2. 散瞳(0.5% 复方托吡卡胺)
  3. 检眼镜贴眼前
  4. 从颞侧 15° 找到红光反射
  5. 跟随光斑接近患者,聚焦眼底
- **适应**:门诊筛查、视盘细节
- **缺点**:视野小、立体感差

### 2. 间接检眼镜(双目)
- **原理**:双目头戴 + 物镜(+20D/+28D)
- **特点**:倒像、视野大、立体感强
- **步骤**:
  1. 充分散瞳
  2. 头戴 + 物镜
  3. 压迫巩膜可看周边(巩膜压迫器)
- **适应**:视网膜脱离、周边裂孔、玻璃体视网膜手术
- **优点**:视野广(可达锯齿缘)、能配合巩膜压迫
- **缺点**:放大倍数低(2-5 倍)

### 3. 裂隙灯 + 前置镜
- **常用透镜**:
  - **+78D / +90D**:视野中等,易于使用,眼底后极部
  - **+60D**:视野更小,放大高
  - **三面镜**(Goldmann):前房角、周边视网膜
- **步骤**:
  1. 散瞳
  2. 裂隙灯 + 前置镜
  3. 后极部、视盘、黄斑、视网膜
- **优点**:立体感、细节好、可做 FFA、ICGA
- **缺点**:视野小、需裂隙灯

### 4. 广角眼底成像(欧堡 / Optos)
- **原理**:激光扫描共聚焦
- **优点**:免散瞳、200° 视野
- **缺点**:周边仍有盲区、不能查玻璃体

### 5. 眼底照相
- 散瞳或不散瞳
- 彩色、红光、无赤光
- 远程筛查

## 正常眼底表现

### 视盘
- 橘红色、边界清
- 中央生理凹陷(杯盘比 C/D):正常 0.3-0.4
- 血管出视盘中心

### 黄斑
- 中心凹反光(青少年明显)
- 颜色较深,无血管

### 视网膜
- 橘红色
- 动脉:鲜红、细
- 静脉:暗红、粗
- A:V 约 2:3
- 周边:锯齿缘、睫状体平坦部

## 异常表现

### 视盘异常
- 水肿(视盘炎、颅高压)
- 苍白(视神经萎缩)
- C/D 增大(青光眼)
- 出血、渗出

### 视网膜血管
- 动脉变细、反光增强(高血压)
- 静脉迂曲扩张(静脉阻塞)
- 出血(火焰状、点状)
- 棉絮斑
- 微动脉瘤(DR)
- 新生血管
- 动脉硬化(铜丝、银丝)

### 黄斑
- 水肿
- 出血(玻璃体疣)
- 渗出(硬性、软性)
- 裂孔
- 萎缩

### 全身病线索
- **高血压**:动脉痉挛、AV 交叉压迹、出血
- **糖尿病**:微动脉瘤、出血、硬性渗出、棉絮斑
- **动脉硬化**:铜丝 / 银丝动脉
- **HIV**:CMV 视网膜病变(奶酪番茄)
- **系统性红斑狼疮**:棉絮斑

## 适应证
- 视力下降、视野缺损
- 视物变形、闪光、飞蚊
- 糖尿病、高血压病常规
- 头颅外伤 / 神经科
- 健康体检
- 内科、外科术前

## 注意事项
- **充分散瞳**是检查质量关键
- **闭角型青光眼未手术前谨慎散瞳**(可在表麻下用 1% 毛果芸香碱保护后散瞳)
- 婴幼儿需家长协助、必要时全麻
- 屈光间质混浊(白内障、玻璃体出血)需结合 B 超
- 视网膜脱离高危者(高度近视)需查周边
- 检查后告知:散瞳后 4-6 h 视近模糊、畏光,可戴墨镜
- 缩瞳:0.5% 复方托吡卡胺;**儿童慎用阿托品**(中枢毒性)
