# 格列齐特

#### 格列齐特
*## 基本信息*## 
- 分类：磺酰脲类降糖药（第二代）
- 常见商品名：达美康、 Diamicron
- 上市时间：1970年代
- 处方/OTC状态：处方药
*## 适应症*## 
- 2型糖尿病（饮食和运动控制血糖效果不佳者）
*## 药理作用*## 
- 刺激胰岛素分泌
- 抑制血小板聚集（额外益处）
- 减少血管并发症风险
*## 用法用量*## 
- 成人：80mg/次，2次/日（餐前），最大剂量320mg/日
- 缓释片：30mg/次，1次/日（早餐时）
*## 不良反应*## 
- 低血糖（发生率低于格列本脲）
- 恶心、食欲改变
- 皮疹
*## 注意事项*## 
- ⚠️ 肝肾功能不全者慎用
- ⚠️ 长期用药需监测血糖和血常规
*## 禁忌*## 
- 糖尿病酮症酸中毒、高渗性昏迷
- 严重肝肾功能不全
- 孕妇及哺乳期妇女
*## 临床应用要点*## 
- 具有抗血小板聚集作用，对微血管并发症有益
- 缓释片每日一次给药，依从性好
- 低血糖风险较格列本脲低
