# 心肌炎诊断与处理

## 概述
心肌炎是心肌的炎症性疾病,可由感染(最常见病毒)、自身免疫、药物/毒素引起。临床表现谱极广,从无症状到暴发性心力衰竭、恶性心律失常、猝死。

## 病因
- **病毒**(最常见):柯萨奇 B、腺病毒、流感、EBV、CMV、SARS-CoV-2
- **细菌**:白喉杆菌、葡萄球菌、链球菌
- **其他病原体**:立克次体、支原体、衣原体、真菌、原虫(Chagas)
- **自身免疫**:SLE、巨细胞心肌炎、结节病
- **药物/毒素**:蒽环类、可卡因、蒽环霉素、疫苗(罕见)

## 临床表现谱
| 类型 | 特点 |
|---|---|
| 亚临床型 | 流感样症状时心电图偶然异常 |
| 轻症型 | 胸闷、心悸、肌痛,数周自愈 |
| 心律失常型 | AVB、室速、房颤、晕厥 |
| 心衰型 | 急性心衰、DCM 表型 |
| 暴发性 | 急性循环衰竭、心源性休克,需要机械循环 |
| 猝死型 | 致命性心律失常 |

## 诊断
- **临床**:前驱感染(1-2 周) + 心脏症状
- **实验室**:
  - 心肌酶:cTnI/T 升高(最敏感)
  - ESR、CRP、WBC 升高
  - 病毒血清学 / PCR(咽拭子、血、便)
- **心电图**:
  - 非特异性 ST-T 改变
  - 各种心律失常:窦速、AVB、室早、室速
  - 酷似 STEMI 表现(ST 抬高)
- **心脏超声**:节段性室壁运动异常、LVEF 降低、心包积液
- **心脏 MRI(主要无创诊断方法)**:
  - Lake Louise 标准:T2 强化(水肿)、早期钆强化(EGE)、晚期钆强化(LGE)
  - 2 项及以上阳性,诊断心肌炎
- **心内膜活检(EMB)**:金标准,但有创、敏感性低
  - Dallas 标准:炎症细胞浸润 + 心肌细胞坏死

## 治疗
- **支持治疗**:**目前无特效抗病毒治疗**
- 休息:急性期卧床、限制活动至症状消失 + 实验室正常
- **避免运动**:恢复期(3-6 个月)避免竞技运动(猝死风险)
- 心衰治疗:按常规 HF「四联」,但避免早期大剂量 β 阻滞剂(负性肌力)
- 暴发性:主动脉内球囊反搏(IABP)、ECMO、临时起搏
- 高度 AVB:临时起搏,部分需永久
- 免疫治疗:**仅限**巨细胞心肌炎、自身免疫性心肌炎、SLE
  - 糖皮质激素 + 硫唑嘌呤 / MMF
- 抗病毒:干扰素-α 在肠道病毒心肌炎中可试用
- **不推荐**常规免疫球蛋白(IVIG)(除儿童 Kawasaki 病)

## 暴发性心肌炎
- 短期内出现严重心衰、心源性休克、恶性心律失常
- 病死率高(可达 50-70%),早期识别 + 机械循环救命
- **黄金治疗窗**:72 小时内生命支持
- 「以生命支持为依托的免疫调节治疗」:糖皮质激素 + IVIG + 生命支持
- ECMO 桥接恢复或心脏移植

## 预后
- 多数轻症完全恢复
- 10-20% 进展为 DCM、慢性心衰
- 5% 进展为暴发性
- 复发率约 10-25%
- 心源性猝死:主要在恢复期运动诱发的室颤

## 注意事项
- 任何年轻、不明原因心衰 / 严重心律失常,需考虑心肌炎
- 「上感后胸闷心悸」不要轻视,建议心电图 + cTn
- COVID-19 疫苗相关心肌炎:**罕见**(百万分之一级),多为年轻男性第二针后,绝大多数轻症
- 流感季节注意病毒性心肌炎,**不持续劳累**
