# 晕厥诊断与处理

## 概述
晕厥(Syncope)是一过性全脑低灌注导致的短暂意识丧失(T-LOC),伴姿势张力丧失、自发完全恢复。多由心血管病引起,部分可猝死。**关键**:与癫痫、跌倒、眩晕、癔症鉴别。

## 分类
- **神经介导性反射性晕厥**(占 60%):血管迷走性、情境性(咳嗽、排尿、吞咽)、颈动脉窦性
- **直立性低血压(OH)**(15%):原发 / 继发(药物、容量不足)、POTS
- **心源性晕厥**(15-20%,但猝死风险最高):
  - 心律失常:心动过缓(AVB、SSS)、室速、室颤、长 QT、Brugada
  - 器质性:AS、肥厚型梗阻心肌病、PE、心脏压塞、心肌梗死

## 高危红旗征(立即收住院)
- 劳力性晕厥(提示 AS / HCM / 肺动脉高压)
- 伴胸痛(AMI、PE、夹层)
- 伴心悸(室速、室上速)
- 卧位时发生(心源性)
- 心脏杂音(AS、HCM)
- 心电图异常
- 严重容量不足 / 出血
- 神经定位体征

## 病史询问
- 发作前:体位、活动、情绪、久站、咳嗽、排尿
- 发作时:面色(苍白 = 迷走;发绀 = 心源性)、抽搐(可有短暂强直-阵挛,需与癫痫鉴别)、大小便失禁
- 发作后:恢复时间、意识模糊(短 = 晕厥,长 = 癫痫)
- 既往:心脏病、用药(降压药、利尿剂、α 阻滞剂、硝酸酯)

## 体格检查
- 立卧位血压:收缩压下降 ≥ 20 mmHg 或舒张压 ≥ 10 mmHg 提示 OH
- 颈动脉窦按摩(老年、无颈动脉杂音):按压 5-10 s,出现症状 + 收缩压下降 ≥ 50 mmHg 或停搏 ≥ 3 s = 阳性
- 心脏听诊:AS 杂音、HCM 杂音
- 神经查体:排除脑卒中

## 辅助检查
- **心电图**(必查):缺血、QT 间期、Brugada、AVB
- **24h 动态心电图**:发作不频繁者阳性率 < 20%
- **植入式心电记录仪(ILR)**:不明原因晕厥、发作稀少、怀疑心律失常
- **超声心动图**:结构性心脏病
- **直立倾斜试验**:血管迷走性晕厥诊断 + 分型
- **运动负荷试验**:运动诱发晕厥
- **颈动脉窦按摩**
- **心内电生理检查**:器质性心脏病 + 不明原因晕厥
- **头颅 CT/MRI**:神经系统定位体征

## 治疗原则
- **病因治疗**:
  - 心律失常:起搏器(缓)、ICD(室速/室颤)、导管消融
  - 结构性心脏病:手术
  - OH:停用降压药、补充容量、穿弹力袜、米多君
  - 反射性晕厥:避免诱因、倾斜训练

## 各类型处理

### 血管迷走性晕厥
- 健康年轻人最常见
- 典型前驱:头晕、恶心、苍白、出汗、视物模糊
- 避免诱因(脱水、久站、热环境、情绪)
- 倾斜训练(长期有效)
- 反复发作:β 阻滞剂(美托洛尔)、米多君、氟氢可的松
- 起搏器:**仅** 反复心脏抑制型(> 6 个月、停搏 > 3 s)

### 直立性低血压
- 测量:卧位 5 min → 立位 1 min、3 min
- 措施
  - 缓慢起身(三个半分钟)
  - 充足水分(2-3 L/d)与盐(10-12 g/d)
  - 弹力袜
  - 米多君 2.5-10 mg tid

### 心源性晕厥
- 高危(猝死风险)
- **永久起搏器**:症状性 SSS、高度 AVB
- **ICD**:室速 / 室颤、LVEF < 35%
- 导管消融:室速、室上速
- AS:HCM 手术

## 注意事项
- 老年人、司机、高空作业者心源性晕厥需积极评估
- 不明原因反复晕厥,需 ILR
- 反射性晕厥预后好,无需限制活动(驾驶可适度限制)
- 鉴别诊断:癫痫(强直-阵挛、舌咬伤、Todd 麻痹、EEG 异常)、TIA(无 LOC)、跌倒(无 LOC)、心因性(无血压、心率、EEG 改变)

## 驾驶员评估
- 心源性晕厥
  - 单次 + 已治疗:限制 1-6 月
  - 反复 / 未控制:永久禁止驾驶
- 反射性:通常可驾驶
