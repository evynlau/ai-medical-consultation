# 白塞病

## 概述
白塞病(BD)是以口腔溃疡、生殖器溃疡、眼炎、皮肤损害为特征的全身性血管炎(累及动静脉)。我国患病率约 1-3/10 万(丝绸之路地区更高),青壮年男性多见,男性病情重(眼、血管、神经)。

## 诊断标准

### 2014 国际白塞病评分(ISBD)
**≥ 4 分诊断 BD**:
- 口腔溃疡:2 分
- 生殖器溃疡:2 分
- 眼部损害(前/后葡萄膜炎、视网膜血管炎):2 分
- 皮肤损害(结节红斑、假毛囊炎、丘疹脓疱样):1 分
- 血管损害(浅静脉炎、深静脉血栓、动脉瘤、动脉血栓):1 分
- 神经损害:1 分
- **针刺反应(+)**:**可选**(1 分,但计入)

### 其他标准
- 1990 ISG 标准(应用广)

## 临床表现

### 1. 口腔溃疡(**必发**,98%)
- 多发(3-10 个)
- 边缘清楚、疼痛、底部白色
- 持续 10-14 d,可反复
- 部位:唇、舌、颊、咽、腭

### 2. 生殖器溃疡(60-75%)
- 形态与口腔相似,但更深、瘢痕
- 男:阴囊、阴茎
- 女:外阴、阴道
- **特点:瘢痕愈合**

### 3. 眼部(50-70%)
- **葡萄膜炎**(前、后、全):最严重
- **视网膜血管炎**:出血、渗出
- **玻璃体混浊**
- **黄斑水肿、视神经萎缩**
- **失明风险**(男性更易)

### 4. 皮肤
- **结节红斑**(下肢多)
- **假毛囊炎**(躯干、四肢)
- **丘疹脓疱样**(痤疮样)
- **浅静脉炎**(游走性、压痛)
- **针刺反应**(pathergy):皮肤针刺后 48 h 出现脓疱(诊断特异)

### 5. 关节
- 非侵蚀性寡关节炎(50%)
- 膝、踝、腕多见
- HLA-B27(+) 部分患者(脊柱炎样)

### 6. 血管(关键预后)
- **静脉**(更多):
  - **深静脉血栓(DVT)**:下肢、脑(颅内静脉窦血栓)
  - **浅静脉炎**
  - **血栓贴壁**(血管壁炎症,非真正栓塞)
  - **抗凝无效**(复发率高)
- **动脉**:
  - **动脉瘤**(主动脉、肺动脉):致命
  - **动脉血栓、狭窄**
  - **肺动脉瘤出血**:大咯血

### 7. 神经系统(神经白塞,5-30%)
- **实质型**:
  - 脑干综合征(最多)
  - 脊髓炎
  - 偏瘫、小脑
  - 脑膜脑炎
- **非实质型**:
  - **颅内静脉窦血栓**(CVST):头痛、视乳头水肿
  - 颅高压

### 8. 胃肠道(肠白塞)
- 口腔回肠末端、回盲部溃疡
- 类似克罗恩病
- 腹痛、腹泻、出血、穿孔

## 实验室

### 自身抗体
- **ANA、RF、抗 CCP、抗 ENA**:**(-)**(无特异抗体)
- 抗中性粒细胞抗体(罕见)

### 常规
- 血常规(白细胞 ↑)、ESR、CRP(活动)
- 尿、便常规(便隐血、肠道累及)
- **凝血**(DVT 风险)

### HLA-B51
- 50-80% 阳性(诊断辅助、非特异性)
- 某些亚型预后差

### 影像
- **眼**:眼底荧光造影、OCT
- **血管**:B 超、CTA、MRA
- **神经**:MRI(脑干、脊髓)、MRV(颅内静脉窦)
- **肠道**:内镜、胶囊
- **动脉瘤**:CTA、MRA、PET(诊断监测)

### 针刺试验
- 前臂消毒后用 20 G 针斜刺入皮内
- 48 h 观察:脓疱或红丘疹(+)≥
- **诊断特异性高**(东方 > 西方)
- **活动期阳性率高**

### 病理
- 血管炎:白细胞碎裂性、淋巴细胞性

## 治疗

### 治疗目标
- 缓解炎症、预防复发、保护脏器(眼、血管、神经)
- **诱导 → 维持**

### 1. 一般治疗
- **口腔**:漱口、外用糖皮质激素凝胶
- **生殖器**:清洁、外用激素
- **休息**:避免针刺(避免肌注)
- 戒烟、避冷

### 2. 皮肤黏膜
- **秋水仙碱** 0.5-1 mg bid/d
  - **基础用药**:口腔、生殖器、皮肤(预防)
  - 口腔溃疡 70% 改善
- **氨苯砜(DDS)**:100-150 mg/d(难治)
- **沙利度胺(沙度利胺)**:**口腔溃疡首选**
  - 50-200 mg/d(夜)
  - 注意:致畸(妊娠禁忌)、神经病、深静脉血栓
- **外用**:激素凝胶、他克莫司软膏

### 3. 眼炎(**关键**)
- **局部**:糖皮质激素眼水、散瞳
- **全身**:
  - **硫唑嘌呤(AZA)** 2-3 mg/kg/d(**首选**)
  - **环孢素(CsA)**:2-5 mg/kg/d
  - **吗替麦考酚酯(MMF)**
- **急性发作**:
  - **甲泼尼龙冲击 1 g iv × 3 d**
  - 后泼尼松 1 mg/kg/d 减量
- **难治**:
  - **IFN-α-2a**:有循证
  - **抗 TNF**(英夫利西、阿达木):重症、难治(首选)
  - **托珠单抗**(IL-6R)
  - **利妥昔单抗**

### 4. 血管(关键预后)
#### 静脉血栓
- **免疫抑制为主**(避免单抗凝)
- **激素 + AZA / CsA / CTX**
- **抗凝**(低分子肝素 → 华法林):仍有争议
  - 部分推荐抗凝(动脉瘤无 + 免疫抑制)
  - 动脉瘤存在:抗凝相对禁忌
- **抗 TNF**:难治

#### 动脉(动脉瘤)
- **强化免疫抑制**(CTX + 激素 + 抗 TNF)
- **手术**:动脉瘤风险大
- **大咯血**(肺动脉瘤):紧急手术 / 介入栓塞

### 5. 神经白塞
- **实质型**:
  - 激素冲击 + 免疫抑制剂
  - **MMF / AZA**(维持)
  - 难治:抗 TNF
- **静脉窦血栓**:
  - 抗凝 + 短程激素
  - 免疫抑制剂(防复发)

### 6. 肠道
- **5-ASA**(美沙拉嗪)
- **激素**(急性发作)
- **AZA / MMF**(维持)
- **沙利度胺**:难治溃疡
- **抗 TNF**:穿孔、瘘管、难治

## 治疗策略(EULAR 2018)

| 受累 | 一线 | 二线 |
|---|---|---|
| 黏膜 | 秋水仙碱 | 沙利度胺、氨苯砜 |
| 眼 | AZA + 激素 | 抗 TNF、IFN、CsA |
| 血管 | AZA / CTX + 激素 + 抗凝(动脉瘤无) | 抗 TNF |
| 神经(实质) | AZA / MMF + 激素 | 抗 TNF |
| 神经(血管) | 短程激素 + 抗凝 | AZA / MMF |
| 肠道 | 5-ASA + AZA | 抗 TNF |

## 注意事项

### 监测
- **眼**:每 3 月专科(视力、眼底、OCT)
- **血管**:B 超、影像、CTA
- **神经**:MRI(每 6 月-1 年)
- **炎性指标**:ESR、CRP
- **药物副作用**:定期查血常规、肝肾

### 预后不良因素
- 男、眼炎、神经、动脉瘤、肺动脉瘤
- 进展迅速、复发频繁

### 手术
- 血管手术、动脉瘤修补(风险高,需免疫抑制控制)
- 动脉瘤术前充分抑制
- 介入:肺动脉瘤栓塞(救命)

### 特殊人群
- **儿童**:少见,血管受累为主
- **妊娠**:缓解期考虑,秋水仙碱 + AZA 可用,沙利度胺 / CTX 停
- **眼病致残**:早期诊断、规范治疗

### 预防
- **戒烟**
- **避免加重诱因**:外伤、手术、感染
- **疫苗**(免疫抑制前):灭活

### 抗 TNF 安全性
- 结核筛查、乙肝
- 治疗反应快(眼、神经、血管)
