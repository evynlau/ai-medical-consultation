# 葡萄膜炎

## 概述
葡萄膜炎是一类累及葡萄膜(虹膜、睫状体、脉络膜)、视网膜、玻璃体的炎症性疾病。我国患病率约 0.1%,多发于青壮年,易反复发作,致盲率高(我国致盲眼病第 5-7 位)。明确病因与分型是规范治疗的前提。

## 分类

### 按解剖部位(国际标准, IUSG 2005)
- **前葡萄膜炎**(最常见):虹膜炎、虹膜睫状体炎
- **中间葡萄膜炎**:睫状体平坦部、玻璃体基底部
- **后葡萄膜炎**:脉络膜炎、视网膜血管炎、视神经炎
- **全葡萄膜炎**

### 按病因
- **感染性**:病毒(HSV、VZV、CMV)、弓形虫、梅毒、TB、HIV
- **非感染性**:
  - 自身免疫:HLA-B27 相关(强直性脊柱炎、Reiter、IBD)
  - 白塞病、Vogt-小柳原田病(VKH)
  - 结节病、多发性硬化
  - 幼年特发性关节炎(JIA)
  - 特发性

### 按病程
- 急性(< 3 月)、慢性(> 3 月)、复发性

## 临床表现

### 前葡萄膜炎
- 眼痛、畏光、流泪、视力下降
- 睫状充血、KP(角膜后沉着物)
- Tyndall 现象(房水细胞、闪辉)
- 虹膜后粘连、瞳孔变形、瞳孔膜闭
- 前房积脓(白塞病、淋球菌)
- 眼压波动(升高或降低)

### 中间葡萄膜炎
- 飞蚊症、视物模糊
- 玻璃体雪球样混浊
- 睫状体平坦部雪堤样渗出
- 黄斑囊样水肿(CME)

### 后葡萄膜炎
- 视力下降、飞蚊、闪光
- 玻璃体混浊
- 视网膜水肿、渗出、坏死
- 视网膜血管鞘、白鞘

### 全葡萄膜炎
- VKH:双侧肉芽肿性全葡萄膜炎,渗出性视网膜脱离、白癜风、白发、听力下降、脑膜刺激征

## 诊断
- **病史**:全身病(关节、皮肤、口腔、生殖器溃疡)、反复发作
- **裂隙灯检查**:KP、Tyndall、虹膜、瞳孔、晶体后囊
- **散瞳眼底**:玻璃体、视网膜、视盘
- **FFA / ICGA**:明确渗漏、血管炎、脉络膜病灶
- **OCT**:CME
- **眼部 B 超**:玻璃体混浊、视网膜脱离
- **实验室**(关键):
  - 血常规、CRP、ESR
  - HLA-B27、HLA-DR4/DR15
  - 抗核抗体谱、ANCA
  - 梅毒(RPR/TPPA)、HIV、TB(IGRA/PPD)
  - 弓形虫、HSV/VZV/CMV
- **胸片 / CT**:结节病、TB
- **腰穿**(VKH 鉴别)
- **前房水 / 玻璃体液**(难治):PCR、细胞学

## 治疗

### 病因治疗(关键)
- 感染性:抗病毒(阿昔洛韦)、抗 TB、抗弓形虫
- 白塞病、秋水仙碱、反应停
- VKH、结节病:免疫抑制剂

### 抗炎治疗
#### 糖皮质激素(一线)
- **局部**:醋酸泼尼松龙、复方地塞米松滴眼液,频繁点眼(q1h-qid)
- **球旁注射**:曲安奈德、地塞米松
- **全身**:泼尼松 0.5-1 mg/kg/d,逐渐减量
- **玻璃体腔植入剂**(Ozurdex):CME

#### 睫状肌麻痹剂(关键)
- 阿托品、托吡卡胺:防后粘连、缓解疼痛

#### 免疫抑制剂(节省激素)
- 甲氨蝶呤、硫唑嘌呤、环孢素、他克莫司
- 吗替麦考酚酯
- 生物制剂:阿达木单抗、英夫利西单抗(白塞、JIA)

#### 生物制剂
- **抗 TNF-α**:英夫利西、阿达木
- **抗 IL-6 / IL-17**(难治)

## 注意事项
- 单眼红痛 + 视力下降 + KP + Tyndall 即可诊断
- 警惕**强直性脊柱炎**(腰背痛史、HLA-B27)
- VKH 神经系统症状需鉴别脑膜炎
- **白塞病**:口腔、生殖器溃疡、皮肤、针刺反应
- 长期激素注意骨质疏松、血糖、血压、感染
- 复发率 30-50%,需长期随访
- 慢性 CME 是致盲主因
- 儿童葡萄膜炎警惕 JIA(常无明显红痛)
- 慎用毛果芸香碱(加重炎症)
