# 类风湿关节炎(RA)

## 概述
类风湿关节炎(Rheumatoid Arthritis, RA)是一种以慢性、对称性、多滑膜关节炎和关节外病变为主要表现的全身性自身免疫性疾病。基本病理改变为滑膜炎和血管翳形成,最终导致关节软骨和骨的破坏。

## 流行病学
- 全球患病率约 0.5-1%
- 中国约 0.42%
- 女性多见(男女比 1:3)
- 高发年龄 30-50 岁
- 是致残的重要原因之一

## 病因
- **自身免疫**:T 细胞异常激活,产生自身抗体
- **遗传**:HLA-DR4 阳性者易感
- **感染**:某些细菌、病毒可能触发
- **环境**:吸烟是明确危险因素
- **其他**:女性激素、压力

## 临床表现
### 关节表现
- **晨僵**:晨起关节僵硬 >1 小时(重要特征)
- **对称性多关节炎**:双手、双腕、双膝等
- **掌指关节、近端指间关节**最常受累
- **关节肿胀、压痛、疼痛**
- **关节畸形**:天鹅颈、纽扣花样、尺侧偏斜
- **关节强直、功能障碍**

### 关节外表现
- **皮下结节**(类风湿结节):鹰嘴、跟腱等
- **血管炎**:皮肤、神经、内脏
- **肺部**:间质性肺病、胸膜炎
- **心脏**:心包炎、心肌炎
- **眼部**:干燥性角结膜炎、巩膜炎
- **血液**:贫血、血小板增多
- **干燥综合征**:合并发生

## 辅助检查
### 必查
- **血常规**:轻度贫血、血小板可升高
- **炎症指标**:ESR(血沉)↑、CRP ↑
- **肝肾功能**:评估用药
- **类风湿因子(RF)**:阳性率 70-80%
- **抗 CCP 抗体**:特异性高(95%+),早期诊断

### 选查
- **关节 X 线**:早期软组织肿胀、骨质疏松;晚期关节间隙狭窄、畸形
- **关节 MRI/超声**:早期滑膜炎、骨侵蚀
- **自身抗体谱**:ANA、抗 ENA
- **免疫球蛋白、补体**

## 诊断标准(2010 ACR/EULAR)
| 项目 | 分数 |
|---|---|
| **A. 关节受累(0-5 分)** | |
| 1 个大关节 | 0 |
| 2-10 个大关节 | 1 |
| 1-3 个小关节(伴或不伴大关节) | 2 |
| 4-10 个小关节(伴或不伴大关节) | 3 |
| >10 个关节(至少 1 个小关节) | 5 |
| **B. 血清学(0-3 分)** | |
| RF 和抗 CCP 均阴性 | 0 |
| RF 或抗 CCP 低滴度阳性 | 2 |
| RF 或抗 CCP 高滴度阳性 | 3 |
| **C. 急性期反应物(0-1 分)** | |

## 治疗
### 治疗目标
- 达到疾病缓解或低疾病活动度(DAS28 <2.6 或 <3.2)
- 防止关节破坏和畸形
- 改善生活质量

### 一般治疗
- 急性期:休息、关节制动
- 缓解期:适度锻炼、预防畸形
- 物理治疗、康复训练
- 心理支持

### 药物治疗(DMARDs 为核心)
**传统合成 DMARDs**:
- **甲氨蝶呤**(MTX):一线首选,7.5-15mg/周
- 来氟米特:可单用或联合
- 柳氮磺吡啶、羟氯喹:多联合用

**生物制剂 DMARDs**(传统治疗无效时):
- TNF-α 抑制剂:依那西普、英夫利昔单抗、阿达木单抗
- IL-6 抑制剂:托珠单抗
- T 细胞共刺激调节剂:阿巴西普
- B 细胞清除:利妥昔单抗

**小分子靶向药**:
- JAK 抑制剂:托法替布、巴瑞替尼

**对症治疗**:
- NSAIDs(双氯芬酸、塞来昔布):缓解症状
- 糖皮质激素:小剂量短期桥接,不长期使用

## 自我管理
- 严格遵医嘱服药,不能自行停药(尤其 MTX、生物制剂)
- 定期复查(血常规、肝肾功能、炎症指标)
- 急性期休息,缓解期锻炼
- 防寒防潮,注意关节保暖
- 避免感染(免疫抑制剂使用者)
- 戒烟
- 心理调适,慢性病容易抑郁焦虑

## 何时就医
- 出现多关节肿痛、晨僵 >6 周
- 已确诊者:症状加重、新出现关节外表现
- 用药期间:发热、咽痛(粒细胞缺乏)、严重感染
- **紧急情况**:
  - 高热、严重感染
  - 呼吸困难(间质性肺病)
  - 胸痛(心包炎)
  - 神经症状(脑血管炎)

## 预后
- 早期诊断、达标治疗可显著改善预后
- 不治疗:2 年内 50% 出现关节畸形
- 规范治疗:多数患者可达到缓解
- 致残率:未规范治疗 5-10 年致残率 40-60%
- 死亡原因:心血管、感染、肿瘤(略高于常人)
- 寿命较常人群略缩短(5-10 年)
