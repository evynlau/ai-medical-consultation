# 霍奇金淋巴瘤

## 概述
霍奇金淋巴瘤(HL)是起源于 B 淋巴细胞的淋巴瘤,以**Reed-Sternberg 细胞(R-S 细胞)**为特征。占淋巴瘤 10%,年发病率约 1-3/10 万,青年(20-30 岁)和老年(> 60)双峰分布。**化疗 + 放疗**治愈率 80-90%,预后最好淋巴瘤之一。

## 分类(WHO 2022)

### 经典 HL(cHL,95%)
- **结节硬化型(NS)**:70-80%,青年、女性、纵隔
- **混合细胞型(MC)**:15-20%,常 EBV+、老年
- **淋巴细胞丰富型(LR)**:少见
- **淋巴细胞消减型(LD)**:少见、HIV、侵袭

### 结节性淋巴细胞为主 HL(NLPHL,5%)
- 「LP 细胞」(爆米花样)
- CD20(+)、CD15(-)、CD30(-)
- 病程更惰性、复发晚
- 可转化为 DLBCL

## 临床表现

### 经典(cHL)
- **无痛性淋巴结肿大**(颈、锁骨上,70-80%)
- **纵隔肿块**(NS 型,50%)
  - 咳嗽、胸痛、上腔静脉综合征
- **B 症状**(25-30%):发热 > 38°C、夜汗、消瘦
- **皮肤瘙痒**(15-20%)
- 酒精诱痛(罕见)
- 巨大肿块(> 10 cm 或纵隔比 > 1/3)

### 晚期
- 肝、脾、骨、骨髓浸润
- 淋巴结外(< 5%)

### NLPHL
- 单一部位(颈、腹股沟、腋)
- 进展缓慢
- 复发晚(可多次)
- 转化为 DLBCL(3-5%)

## 实验室

### 病理(必须)
- **淋巴结活检**(完整)
- **R-S 细胞**特征:
  - 大、双核或多核
  - 「猫头鹰眼」核仁
  - **CD15(+)**、**CD30(+)**(膜、高尔基)
  - **CD20(-)**(多数)、**CD45(-)**
  - **PAX5 弱(+)**
- NLPHL:CD20(+)、CD15(-)、CD30(-)、OCT2(+)、BOB1(+)

### 影像 / 分期
- **PET-CT**:**金标准**(分期、再分期、疗效)
- 颈胸腹盆 CT
- **MRI**(必要时)
- 超声(浅表)
- **分期(Ann Arbor)**:
  - Ⅰ:单淋巴结区
  - Ⅱ:同侧横膈 ≥ 2 区
  - Ⅲ:横膈两侧
  - Ⅳ:广泛结外
- **「A/B」**:B 症状
- **「X」**:巨大肿块(> 10 cm 或纵隔 M/T > 0.33)

### 其他
- 血常规、LDH、ESR、β2-MG
- 肝肾、电解质
- **骨髓活检**(晚期、PET 阳性)
- **妊娠试验**(育龄)
- **HBV、HCV、HIV**(化疗前)
- 心电图、超声(蒽环前)
- 肺功能(BV 含博来霉素)

### 预后指标

#### 早期(EORTC / GHSG)
- **不良因素**(任一):
  - **巨大肿块**(MMR > 0.33 或 > 10 cm)
  - **ESR ≥ 50(无 B 症状)或 ≥ 30(有 B 症状)**
  - **受累淋巴结区 ≥ 3**
  - **年龄 ≥ 50**
- **有利因素**:以上均无
- 分层:有利 / 不利

#### 晚期(IPS 7 因子)
- Alb < 40 g/L
- Hb < 105 g/L
- 男
- 年龄 ≥ 45
- Ⅳ 期
- WBC ≥ 15 × 10⁹/L
- 淋巴细胞 < 0.6 × 10⁹/L 或 < 8%

## 治疗

### 治疗策略
- **分层治疗**:早期(有利 / 不利)、晚期
- 化疗 + 放疗(放疗剂量减少)
- **PET 指导**(Deauville 评分)

### 1. 早期 cHL(Ⅰ-Ⅱ)

#### 有利
- **ABVD × 2-4 周期 + IF-RT**(20-30 Gy)
  - 阿霉素、博来霉素、长春花碱、达卡巴嗪
- 治愈率 90%+

#### 不利
- **ABVD × 4-6 + IF-RT**
- 或 **eBEACOPPesc × 2 + ABVD × 2 + RT**
  - 强化方案(部分高危)

### 2. 晚期 cHL(Ⅲ-Ⅳ)

#### 一线
- **ABVD × 6**(标准)
- **eBEACOPPesc × 6**(IPS ≥ 3,年轻)
- **A + AVD**(Brentuximab vedotin + AVD):
  - **ECHELON-1**:优于 ABVD(部分)
  - **BV 替代博来霉素**(肺毒性)

#### 评估
- **中期 PET**(2 周期后):
  - **Deauville 1-3**:继续 ABVD
  - **Deauville 4-5**:升级方案(BEACOPP、ESHAP)
- 末次 PET:
  - 评估疗效(完全 / 部分缓解)

#### 反应评估(Deauville 5-PS)
- **1**:无残留
- **2**:残留 ≤ 纵隔
- **3**:残留 > 纵隔、但 ≤ 肝
- **4**:残留适度 > 肝
- **5**:进展

### 3. NLPHL
- **局限**:**单纯放疗**(30-36 Gy)
- **进展 / 晚期**:
  - **R-CHOP × 4-6**(CD20+)
  - **R-CVP**
  - **R-单药**(部分)
  - 利妥昔维持(部分)

### 4. 复发 / 难治 cHL

#### 敏感复发(缓解 > 1 年)
- **常规化疗**(ABVD、ICE、ESHAP)
- + 放疗

#### 难治 / 早期复发
- **挽救化疗**:
  - **ICE / ESHAP / GVD**(± 利妥昔、± BV)
- **BV-PD**(Brentuximab vedotin + 帕博利珠单抗)
- **移植**:
  - **ASCT**(标准,敏感复发)
  - **异基因 HSCT**(ASCT 后复发)
- **新药**:
  - **Brentuximab vedotin**(BV,抗 CD30)
  - **Nivolumab / Pembrolizumab**(PD-1)
  - **CAR-T**(CD30)
- **临床试验**

### 5. BV(Brentuximab vedotin)
- **抗 CD30 + MMAE**
- 一线 + AVD(替代博来霉素)
- R/R、单药
- **周围神经病**(主要毒性)

### 6. PD-1 抑制剂
- **Nivolumab / Pembrolizumab**
- R/R cHL(尤其 ASCT 后 / BV 后)
- 长期反应

### 7. 支持
- **生育保存**(BEACOPP)
- **HBV 筛查 / 抗病毒**(BV 利妥昔)
- **PML**(罕见,免疫抑制)
- **二膦酸盐**(骨)

## 特殊人群

### 儿童 / 青年(< 18)
- 减少化疗强度(避免长期毒性)
- ABVD

### 老年
- AVD 替代(博来霉素肺毒性)
- 剂量调整

### 妊娠
- ABVD(中孕后可)
- 早期:终止妊娠考虑
- 严密监测

## 注意事项

### 监测
- **PET-CT**(中期 / 末次)
- 之后:CT / 超声
- 长期:复发、继发瘤

### 化疗副作用
- **博来霉素**:肺毒性(> 400 U)
  - 戒烟、监测肺功能
  - **皮肤毒性**
- **阿霉素**:心脏(累积)
- **长春花碱**:神经
- **达卡巴嗪**:恶心、肝

### BEACOPP
- **急性毒性高**(骨髓、生殖)
- **继发白血病 / MDS**
- 年轻、高危

### 放疗
- 剂量减少(20-30 Gy)
- 长期:继发癌(乳腺、肺、心)
- **儿童避免**(影响生长)

### 生育
- BEACOPP / 移植:致生育力↓
- **保存**(精子、卵子)

### 继发瘤
- 长期生存者(年轻):继发白血病、乳腺癌、肺癌
- 随访筛查

### 心理
- 青年、治愈率高
- 长期支持

### 预后
- 早期:5 年 OS 95%+
- 晚期:80-90%
- 复发 / 难治:50%
- BV / PD-1 改善(难治)
- 主要死因:原病进展、继发瘤、心肺
