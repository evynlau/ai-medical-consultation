# 前列腺癌诊治

## 概述
前列腺癌(PCa)在西方男性最常见,我国发病率快速上升,年新发约 13 万,死亡约 5 万。**雄激素依赖性**是治疗关键,大多数进展期治疗围绕雄激素剥夺(ADT)。**PSA 筛查**存在过度诊断争议,需个体化决策。

## 危险因素
- **年龄**(主要)
- 家族史(父/兄)、BRCA1/2 突变(尤其 BRCA2)
- 种族(黑人高发)
- 饮食(高脂、红肉、乳制品)
- 肥胖、吸烟

## 筛查(有争议)
- 充分告知利弊后,**50-69 岁**可选择
- **高危**(家族史、BRCA2 突变、非洲裔):**40-45 岁起**
- **PSA 异常**(> 4 ng/mL)或直肠指诊(DRE)异常:转诊
- 单纯 PSA 升高不诊断,需活检

## 诊断与分期
- **PSA**(总/游离)、PSAD、PHI
- **多参数 MRI**(mpMRI):可指导穿刺(PI-RADS)
- **前列腺穿刺**(经直肠/会阴,超声/MRI 融合):**金标准**
- **病理**:
  - **Gleason 评分**:主 + 次要 = 总分
  - **ISUP 分级组**(1-5 组)
  - **Gleason ≥ 7**(中-高危)
- **分期**:
  - **CT/MRI 腹盆**、骨扫描(PET-CT 更准)
  - **PSMA-PET/CT**(高危初诊、复发检测)

## 风险分组(NCCN/NICE)

| 风险 | 标准 |
|---|---|
| **极低** | T1c、PSA < 10、GS ≤ 6、阳性针 ≤ 3、每针 ≤ 50% |
| **低** | T1-T2a、PSA < 10、GS ≤ 6 |
| **中(有利)** | T2b-T2c、PSA 10-20、GS 3+4=7(1 项) |
| **中(不利)** | T2b-T2c、PSA 10-20、GS 3+4=7(多项) |
| **高** | T3a 或 PSA > 20 或 GS 8 |
| **极高** | T3b-T4 或 GS 9-10 或 > 4 个 GS 8 |

## 治疗

### 局限期

#### 极低/低危
- **主动监测**(Active Surveillance):首选
  - 每 6 月 PSA、1 年活检

#### 中危
- **根治性前列腺切除**(RP) ± 盆腔淋巴结清扫
- 或 **根治性放疗**(EBRT ± 近距离治疗 + ADT 4-6 月)
- **机器人辅助腹腔镜**(RARP):主流

#### 高危/极高危
- **RP + 扩大淋巴结清扫**(高危可选)
- 或 **放疗 + 长程 ADT(2-3 年)** ± **阿比特龙**(STAMPEDE)
- 术后辅助放疗(pT3、GS 8-10、切缘阳性、pN+)
- 阿比特龙在高危可与 ADT 联用

### 局部进展/转移性
- **ADT**(雄激素剥夺):GnRH 激动剂(戈舍瑞林、亮丙瑞林)± 抗雄(氟他胺、比卡鲁胺)
- 联合**阿比特龙 + 泼尼松**(LATITUDE 高级、STAMPEDE)
- 或 **阿帕鲁胺**(TITAN)、**恩扎卢胺**(ARCHES)
- 联合多西他赛(LATITUDE 高级部分)
- **转移性去势敏感(mCSPC)**:
  - 体能好:**ADT + 阿比特龙/阿帕鲁胺/恩扎卢胺/多西他赛**(联合)
  - 低瘤负荷(CHAARTED):可单 ADT
- **转移性去势抵抗(mCRPC)**:
  - **一线**:**阿比特龙**、**恩扎卢胺**
  - **多西他赛** + 泼尼松
  - **Sipuleucel-T**(免疫,Sip-T)
  - **Radium-223**(骨转移、寡骨病)
  - **PARP 抑制剂**(BRCA1/2:奥拉帕利、卢卡帕利)
  - **镭 177-PSMA**(PSMA 阳性、既往多西他赛后)
  - **Pembrolizumab**(MSI-H/dMMR、TMB-H)
  - **Cabazitaxel**(多西他赛后)

## 随访
- 治愈性治疗后:**PSA 监测**每 3-6 月
- **生化复发**定义:RP 后 PSA ≥ 0.2;放疗后 PSA 较最低值升高 ≥ 2 ng/mL
- 必要时影像、PSMA-PET

## 注意事项
- **PSA 解读**需结合年龄、前列腺体积
- Gleason 6(ISUP 1)可主动监测
- **ADT** 关注:骨质疏松、代谢综合征、心血管、性功能丧失
- **家族性/遗传性**应做 BRCA、ATM、MSH2、MSH6 等胚系检测
- 老龄、合并症多者降阶治疗
- 心理支持、性功能康复(术后)
