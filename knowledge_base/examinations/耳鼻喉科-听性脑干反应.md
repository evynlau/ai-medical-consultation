# 听性脑干反应

## 概述
听性脑干反应(ABR)是声音刺激后 10 ms 内记录到的来自听神经和脑干听觉通路的 7 个波(Jewett I-VII),是评估听神经和脑干功能的客观电生理检查,广泛用于听力评估、听神经瘤诊断、新生儿听力筛查。

## 原理
- 短声(click)或短纯音(tone burst)刺激
- 表面电极记录(额 - 乳突 / 耳垂)
- **平均叠加**(1000-2000 次)提取信号
- Ⅰ 波:听神经远端
- Ⅲ 波:桥脑
- Ⅴ 波:脑桥 / 中脑(临床最常用)

## 主要指标

### Ⅴ 波反应阈
- 最接近听阈
- 正常:0-30 dB nHL(成人)
- 婴幼儿:约 35-40 dB nHL
- 与 2-4 kHz 听阈相关性高

### 波间潜伏期(IPL)
- **I-III**:蜗后传导(听神经 → 桥脑)
- **III-V**:脑干内(桥脑 → 中脑)
- **I-V**:全脑干传导时间
  - 正常成人 ≤ 4.4 ms
  - 延长提示蜗后病变(听神经瘤)

### 双耳 V 波潜伏期差(ILD)
- > 0.4 ms 提示传导不对称

### 波幅与波形
- Ⅰ-Ⅴ 波清晰
- V/I 波幅比 < 0.5 提示蜗后

## 检查方法

### 准备
- 安静 / 自然睡眠 / 镇静(婴幼儿)
- 表面电极:额(正)、乳突(负)、额中(地)
- 皮肤阻抗 < 5 kΩ
- 屏蔽环境

### 刺激
- **Click 短声**(0.1 ms):频率范围宽(1-4 kHz),最常用
- **Tone burst**(频率特异性)
- **骨导 ABR**(评估传导性聋)
- **Chirp 刺激**:新型,频率成分同步

### 参数
- 刺激率:11.1-30.1 Hz
- 滤波:100-3000 Hz
- 叠加:1000-2000 次
- 极性:交替(伪迹小)

## 适应证

### 听力评估
- **新生儿听力筛查**(初筛、复筛)
- **婴幼儿听力诊断**(不合作者)
- **伪聋、夸大聋**:客观评估
- **法医鉴定**
- **听力图频率补充**

### 神经诊断
- **听神经瘤**筛查(敏感度 90-95%)
- **脑干病变**:脱髓鞘(Multiple Sclerosis)
- **脑干听觉通路完整性评估**(颅脑手术监护)

### 手术监护
- **听神经瘤手术**:保留听力
- **后颅窝手术**:脑干功能
- **脑死亡评估**(临床辅助)

### 其他
- **新生儿 NICU 听力筛查**
- **听神经病**(AN)评估
- **听觉植入术前评估**(CI、BAHA)

## 结果解读

### 听力评估
- V 波阈值 ≈ 2-4 kHz 听阈
- 反应缺失 = 听力下降 / 聋
- **残余听力评估**:神经纤维瘤术前

### 听神经瘤
- **V 波潜伏期延长**(I-V IPL > 4.4 ms)
- **ILD > 0.4 ms**
- **V/I < 0.5**
- **波形分化差**
- 需结合 MRI(确诊)

### 脑干病变
- **III-V IPL 延长**:桥脑 / 中脑
- **I-III IPL 延长**:听神经
- **波形消失**:严重
- **MS 经典表现**:III-V / I-III 延长

### 听神经病
- **OAE 正常 + ABR 异常**(反常)
- 提示内毛细胞 / 突触 / 神经功能异常

### 听觉植入
- 神经反应遥测(NRT):CI 电诱发 ABR
- 电诱发 ABR(EABR):CI 调试、BAHA

## 临床应用

### 新生儿听力筛查
- **初筛**:出生 48-72 h,OAE + ABR
- **复筛**:未通过者 42 d 内
- **诊断**:3 月内
- **干预**:6 月内
- **NICU 高危儿**:直接 ABR

### 听神经瘤
- 一侧听力下降、单侧耳鸣
- **ABR + MRI**(金标准)诊断

## 注意事项
- **自然睡眠或镇静**(尤其儿童):水合氯醛
- **睡眠状态**影响(深睡 V 波潜伏期延长)
- **体温**:低温延长潜伏期
- **年龄**:婴幼儿 V 波潜伏期延长(神经髓鞘化未完成)
- **电干扰**影响结果
- **电极位置**精确
- **镇静剂监测**(氯丙秦等)
- **与行为测听、声导抗结合**
- **V 波阈值** 不能替代完整听力图
- 高频听力下降可低估

## 特殊 ABR

### 骨导 ABR
- 鉴别传导性聋
- 用于中耳疾病

### Chirp-ABR
- 频率成分同步,振幅大
- 阈值评估更准

### 耳蜗电图(ECochG)
- 近场记录
- 比 ABR 阈值低 10-20 dB
- 评估耳蜗病变(SP/AP 积水)

### ASSR(稳态诱发电位)
- 多频率同时评估
- 客观听力图
