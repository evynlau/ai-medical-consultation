# 黄体酮

#### 黄体酮
*## 基本信息*## 
- 分类：孕激素
- 常见商品名：黄体酮胶囊、注射液
- 上市时间：1940年代
- 处方/OTC状态：处方药
*## 适应症*## 
- 先兆流产、习惯性流产
- 月经不调
- 绝经后激素替代治疗（与雌激素联用）
*## 药理作用*## 
- 使子宫内膜转化为分泌期，维持妊娠
- 抑制子宫收缩
- 调节女性月经周期
*## 用法用量*## 
- 口服：100-200mg/次，2次/日（先兆流产）
- 肌注：10-20mg/次，1次/日
- 静脉注射：需稀释后缓慢推注
*## 不良反应*## 
- 头晕、嗜睡
- 乳房胀痛
- 注射部位疼痛、硬结
*## 注意事项*## 
- ⚠️ 静脉注射需监测血压（可能引起心血管 collapse）
- ⚠️ 肝功能不全者慎用
- ⚠️ 妊娠期使用需医生指导
*## 禁忌*## 
- 原发性乳腺癌或怀疑激素依赖性肿瘤
- 不明原因阴道出血
- 对黄体酮过敏者
*## 临床应用要点*## 
- 黄体支持是辅助生殖技术的重要环节
- 口服生物利用度低，常采用阴道给药
- 肌注易引起局部反应，注意注射技巧
