# 肝细胞癌诊治

## 概述
肝细胞癌(HCC)是全球第 6 大常见癌症、第 3 大癌症死因。我国每年新发 HCC 约 40 万例,占全球 50%+,多继发于乙肝肝硬化。HCC 5 年生存率仅 12%,早期(< 3 cm)5 年生存率可达 70-80%。B 超 + AFP 筛查可显著早期诊断率。治疗从外科切除、肝移植到介入、靶向、免疫综合应用。

## 病因
- 乙肝(我国 80%)、丙肝、酒精性肝硬化
- 代谢相关脂肪性肝病(MAFLD,新命名)
- 黄曲霉毒素 B1(玉米、花生)
- 肝硬化(任何原因)
- 罕见:血色病、α1-抗胰蛋白酶缺乏、Wilson 病

## 筛查与监测
- **高危人群**:乙肝 / 丙肝肝硬化、其他肝硬化
- **方法**:
  - 腹部超声(每 6 月)
  - AFP(每 6 月,常与超声联合)
  - 高危(肝硬化、HBV):超声 + AFP 每 6 月
  - 极高危(肝硬化合并 AFP 持续升高、影像可疑):每 3 月

## 诊断(典型)
- **典型影像即可确诊**(典型「快进快出」):
  - 增强 CT / MRI:动脉期高增强、门脉期 / 延迟期廓清
  - ≥ 1 cm 结节 + 典型强化模式 → 可诊断 HCC
  - 无需活检(针道转移、出血风险)
- **不典型**:
  - 加做普美显(Gd-EOB-DTPA)增强 MRI(肝胆期低信号)
  - EUS、超声造影、DSA
  - 必要时活检(需除外非 HCC 病变)
- **病理分级**:Edmondson-Steiner Ⅰ-Ⅳ 级

## 分期:BCLC(巴塞罗那)
| 分期 | 体能 | 肝功能 | 肿瘤 | 推荐治疗 |
|---|---|---|---|---|
| **0(极早期)** | 0 | Child-Pugh A | 单个 < 2 cm | 切除 / 消融 |
| **A(早期)** | 0 | A-B | 单个 / ≤ 3 个 ≤ 3 cm | 切除 / 移植 / 消融 |
| **B(中期)** | 0 | A-B | 多发、无血管侵犯 | TACE |
| **C(进展期)** | 1-2 | A-B | 血管侵犯 / 肝外 | 靶向 + 免疫 |
| **D(终末期)** | 3-4 | C | 任意 | 最佳支持 |

## 治疗

### 一、外科切除
- **适应证**:
  - 单发、Child A、ICG 15 min 滞留率 < 10-20%
  - 充足残肝体积(肝硬化者 > 40-50%)
- **不能切除**:
  - 多发(> 3)、巨大(> 10 cm)、门脉癌栓
  - Child B/C、门脉高压
- 围术期评估:Child-Pugh、MELD、ALBI 评分、CT 三维重建
- 乙肝者术后抗病毒治疗

### 二、肝移植(米兰标准,经典)
- **单发 ≤ 5 cm / ≤ 3 个结节、最大 ≤ 3 cm**
- **无大血管侵犯、无肝外转移**
- 5 年生存率 70-80%,复发率 < 15%
- 桥接治疗:切除 / 消融 / TACE 等待肝源
- 中国标准、杭州标准等更宽

### 三、局部消融
- **射频(RFA)、微波(MWA)**:3 cm 内最佳
- **适应证**:< 3 cm、≤ 3 个结节、Child A
- **并发症**:出血、气胸、肝脓肿、针道转移
- **不可逆电穿孔(IRE/NanoKnife)**:血管旁病灶
- **无水乙醇注射(PEI)**:小病灶(已被热消融取代)

### 四、TACE(经动脉化疗栓塞)
- **中期 HCC(BCLC B)首选**
- 适应证:多发、不可切除
- 载药微球(deb-TACE)优于传统 cTACE
- 联合靶向/免疫:LEAP-002、EMERALD-1 等研究
- **TACE 抵抗 / 失败**:换用系统治疗
- **TACE + 消融联合**:> 3 cm

### 五、系统治疗
- **一线**:
  - 阿替利珠单抗 + 贝伐珠单抗(IMbrave150)
  - 度伐利尤单抗 + 替西木单抗(HIMALAYA)
  - 多纳非尼、仑伐替尼、索拉非尼(单药)
- **二线**:瑞戈非尼、阿帕替尼、卡博替尼、雷莫芦单抗(AFP > 400)
- **PD-1**:帕博利珠单抗、纳武利尤单抗、卡瑞利珠单抗、信迪利单抗、替雷利珠单抗
- **对症**:止痛、护肝、营养、心理

### 六、放射治疗
- **外照射(SBRT/SABR)**:小 HCC 与消融等效
- **质子重离子**:大型中心
- **内放疗**:钇-90 微球(选择性内放射 SIRT/TARE)
- **门脉癌栓**、下腔静脉癌栓:SBRT 联合

## 注意事项
- 监测:术后 / 治疗后 1-2 月增强 MRI/CT
- 之后每 3-6 月,至少 2 年
- 多学科团队(MDT):外科、介入、肿瘤、放射、病理
- 乙肝再激活:PD-1 + 贝伐有 HBsAg 升高风险
- 注意免疫相关不良反应(irAE)
- 戒烟限酒、营养支持
