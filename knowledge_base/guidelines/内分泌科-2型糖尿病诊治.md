# 2 型糖尿病诊治

## 概述
2 型糖尿病(T2DM)是以胰岛素抵抗伴进行性胰岛 β 细胞功能缺陷为特征的代谢性疾病。占糖尿病 90% 以上,我国成人患病率约 11.6%,肥胖、久坐和家族史是主要危险因素。长期高血糖导致大血管、微血管并发症,显著增加心肾终点事件。

## 诊断标准(2022 CDS / 2023 ADA)
具有典型「三多一少」症状 + 以下任一即可确诊;无症状者需非同日重复确认:
- **空腹血糖(FPG)** ≥ 7.0 mmol/L
- **OGTT 2h 血糖** ≥ 11.1 mmol/L
- **随机血糖** ≥ 11.1 mmol/L
- **HbA1c** ≥ 6.5%

糖代谢状态分级:
| 状态 | FPG(mmol/L) | OGTT 2h(mmol/L) |
|---|---|---|
| 正常 | < 6.1 | < 7.8 |
| 空腹血糖受损 | 6.1-6.9 | < 7.8 |
| 糖耐量减低 | < 7.0 | 7.8-11.0 |
| 糖尿病 | ≥ 7.0 | ≥ 11.1 |

## 综合控制目标(因人而异)
- **HbA1c**:一般 < 7%;年轻、新诊断、预期寿命长可 < 6.5%;老年/低血糖高危可放宽至 7.5-8.0%
- **血压**: < 130/80 mmHg
- **LDL-C**:极高危 < 1.4 mmol/L,高危 < 1.8 mmol/L
- **体重**:超重/肥胖者减轻 5-15%
- **戒烟**、规律运动 150 min/周

## 治疗
### 生活方式(基石)
- 医学营养治疗:控制总热量,碳水 45-60%,蛋白 15-20%
- 运动:有氧 + 抗阻,餐后 30-60 min 步行
- 减重 5-15% 可显著改善代谢

### 降糖药物选择
| 药物 | 特点 | 适用 |
|---|---|---|
| **二甲双胍** | 抑制肝糖输出,降 HbA1c 1-1.5% | 一线首选,无禁忌全程保留 |
| **SGLT2 抑制剂** | 排糖、减重、降压、心肾保护 | 心衰、CKD、ASCVD 优选 |
| **GLP-1 受体激动剂** | 降糖 + 减重 + 心血管获益 | 肥胖、ASCVD 优选 |
| **DPP-4 抑制剂** | 葡萄糖依赖性促泌,低血糖少 | 老年、肾功能不全 |
| **磺脲/格列奈** | 促胰岛素分泌,价格低 | 经济条件受限、备选 |
| **TZD(吡格列酮)** | 增敏,NASH 获益 | NAFLD/胰岛素抵抗 |
| **α-糖苷酶抑制剂** | 延缓碳水吸收 | 餐后高血糖为主 |

### 胰岛素
- 起始:基础胰岛素(甘精、地特、德谷)10 U/d 或 0.1-0.2 U/kg
- 强化方案:基础-餐时、预混、CSII
- HbA1c > 9% 或症状重可短期强化

## 并发症筛查
- **眼底**:每年 1 次
- **尿白蛋白/肌酐比(UACR) + eGFR**:每年 1-2 次
- **足部**:神经、血管、皮肤检查每年 1 次
- **神经**:10 g 尼龙丝、音叉
- **血脂、肝功**:启动他汀

## 注意事项
- 二甲双胍:eGFR < 30 停用,< 45 减量
- SGLT2 抑制剂:注意泌尿生殖道感染、酮症
- GLP-1 RA:胃肠道反应、胰腺炎、禁用于 MTC 家族史
- 老年人避免低血糖,SGLT2、DPP-4i 更安全
- **围手术期**、造影、感染时停 SGLT2、调整胰岛素
