# 支气管哮喘

## 概述
支气管哮喘(简称哮喘)是一种以慢性气道炎症和气道高反应性为特征的异质性疾病,临床表现为反复发作的喘息、气急、胸闷或咳嗽等症状,常在夜间和/或清晨发作、加剧,多数患者可自行缓解或经治疗缓解。

## 流行病学
- 全球患病率约 4-5%
- 我国 20 岁以上成人哮喘患病率约 4.2%
- 儿童发病率高于成人,约 3-5%
- 男女比例约 1:1,儿童期男孩多见

## 病因与危险因素
- **遗传因素**:家族过敏史、基因易感性
- **环境因素**:
  - 过敏原:尘螨、花粉、霉菌、动物皮毛、蟑螂
  - 感染:病毒(尤其鼻病毒)、支原体
  - 职业:面粉、化工、染料等
  - 食物:鱼虾、蛋类、牛奶
  - 药物:阿司匹林、β 受体阻滞剂
  - 运动、冷空气、情绪波动

## 临床表现
- **典型症状**:发作性喘息伴呼气相延长
- **伴随症状**:胸闷、咳嗽(常为干咳)、气促
- **夜间症状**:夜间或凌晨加重是特征
- **诱因明确**:接触过敏原、运动、冷空气后发作
- **可逆性**:症状可自行或用药后缓解

## 体征
- 发作时:双肺哮鸣音、呼气延长
- 严重时:端坐呼吸、辅助呼吸肌参与
- 重度:发绀、意识模糊、沉默肺(极危重)
- 缓解期:可无异常体征

## 辅助检查
- **肺功能**:
  - 支气管舒张试验阳性(吸入沙丁胺醇后 FEV1 增加 ≥12% 且绝对值增加 ≥200ml)
  - 呼气流量峰值(PEF)变异率 ≥20%
  - 激发试验阳性(可疑但肺功能正常时)
- **过敏原检测**:皮肤点刺或血清特异性 IgE
- **胸部 X 线**:用于鉴别诊断,哮喘本身无特异表现
- **血常规**:嗜酸性粒细胞可升高

## 诊断标准
1. 反复发作喘息、气急、胸闷、咳嗽
2. 多与接触过敏原、冷空气、运动等有关
3. 发作时双肺哮鸣音、呼气延长
4. 症状可经治疗缓解或自行缓解
5. 除外其他疾病
6. 肺功能证实可逆性气流受限(支气管舒张试验阳性)

## 治疗
### 急性发作期
- **轻中度**:吸入速效 β2 受体激动剂(SABA,如沙丁胺醇)2-4 喷,20 分钟后可重复
- **中重度**:SABA + 全身糖皮质激素(泼尼松 30-50mg/d,3-5 天)
- **危重**:SABA 持续雾化 + 全身激素 + 氧疗 + 必要时机械通气

### 长期控制(分级治疗)
| 级别 | 首选控制药 |
|---|---|
| 1 级(间歇) | 不需长期控制 |
| 2 级(轻度) | 低剂量 ICS(吸入糖皮质激素) |
| 3 级(中度) | 低剂量 ICS+LABA |
| 4 级(重度) | 中高剂量 ICS+LABA |
| 5 级(极重度) | 高剂量 ICS+LABA+口服激素 |

### 常用药物
- **控制药**:ICS(布地奈德、氟替卡松)、LABA(沙美特罗、福莫特罗)、白三烯调节剂(孟鲁司特)
- **缓解药**:SABA(沙丁胺醇、特布他林)
- **生物制剂**:奥马珠单抗(重症过敏性哮喘)

## 自我管理
- 规律使用控制药物,不能自行停药
- 携带缓解吸入剂备用
- 记哮喘日记(峰流速、症状、用药)
- 识别和避免诱因(过敏原、冷空气等)
- 接种流感疫苗、肺炎疫苗
- 定期复诊(至少每 3 个月 1 次)

## 何时就医
- 缓解吸入剂效果持续时间变短(<2-3 小时)
- 静息时即有气促、说话不成句
- 峰流速降至正常 50% 以下
- 口唇指甲发紫、意识改变
- **立即拨打 120**

## 预后
- 多数患者经规范治疗可良好控制
- 约 5-10% 为难治性哮喘
- 重度急性发作可致命(全球每年约 25 万人死于哮喘)
- 早期规范治疗、改善依从性是改善预后关键
