# 肝纤维化无创诊断

## 概述
肝纤维化是慢性肝病进展至肝硬化的关键中间阶段,准确评估分期对治疗决策、预后判断至关重要。肝活检是金标准但有创、可重复性差、采样误差。无创诊断以**血清学标志物**和**肝脏弹性成像(LSM)**为主,二者联合应用已广泛替代活检用于初筛、监测和疗效评估。

## 一、肝脏弹性成像

### 1. 瞬时弹性成像(FibroScan / TE)
- **原理**:通过剪切波在肝组织中的传播速度反映硬度
- **结果**:以 kPa 表示肝脏硬度(LSM, Liver Stiffness Measurement)
- **肝脏脂肪变**:CAP(受控衰减参数) dB/m
- **优势**:无创、快速(< 5 min)、床旁可做
- **局限**:
  - 受肥胖、肋间隙窄、腹水影响
  - ALT 急性升高可假性增高
  - 进食后影响(建议禁食 3 h)

#### FibroScan 切点(慢性乙 / 丙肝、NASH 等常见病因)
| 病因 | F2 | F3 | F4(肝硬化) |
|---|---|---|---|
| 慢性乙肝 | 7.0 | 9.0 | 11.0-12.0 |
| 慢性丙肝 | 7.0 | 9.5 | 12.0-14.0 |
| 酒精性肝病 | 7.0-8.0 | 9.5-11.0 | 12.5-16.0 |
| NAFLD/NASH | 7.0-7.9 | 8.7-9.6 | 11.5-13.6 |
| PBC/PSC | 7.0-8.0 | 9.0-10.0 | 12.0-16.0 |

> 不同厂家、病因、平台有差异,需结合当地标准。

#### CAP 切点
- S1(> 5% 脂肪变):248 dB/m
- S2(> 33%):268 dB/m
- S3(> 66%):280 dB/m

### 2. 声辐射力脉冲成像(ARFI / pSWE)
- 集成于常规超声
- 切点约 1.2-1.5 m/s
- 不受腹水、肋间隙限制

### 3. 二维剪切波弹性成像(2D-SWE)
- 灰阶超声同时成像
- 大样本可重复性好
- 受操作者经验影响较小

### 4. 磁共振弹性成像(MRE)
- 灵敏度、特异度最高
- 切点:F2 约 3.0-3.5 kPa
- 不受腹水、肥胖影响
- 费用高、不普及

## 二、血清学标志物

### 1. APRI(天冬氨酸氨基转移酶与血小板比值)
- **APRI = (AST / AST 正常上限) × 100 / 血小板计数(10⁹/L)**
- 切点:
  - APRI ≥ 2:肝硬化
  - APRI ≥ 1.5:显著纤维化
  - APRI < 1:排除肝硬化
- 简单,适用资源有限地区
- 特异性中等

### 2. FIB-4(基于年龄、转氨酶、血小板)
- **FIB-4 = (年龄 × AST) / (血小板 × √ALT)**
- 切点:
  - < 1.3:排除显著纤维化
  - > 2.67:肝硬化
  - 灰区 1.3-2.67:进一步检查
- 较 APRI 更准确

### 3. NAFLD Fibrosis Score(NFS)
- **NFS = -1.675 + 0.037 × 年龄 + 0.094 × BMI + 1.13 × IFG/糖尿病 + 0.99 × AST/ALT - 0.013 × 血小板(×10⁹/L) - 0.66 × 白蛋白(g/dL)**
- 切点:
  - < -1.455:无显著纤维化
  - > 0.676:肝硬化
- 用于 NAFLD

### 4. FibroTest / FibroMeter
- 商业专利
- 多指标组合(α2-巨球蛋白、触珠蛋白、γ 球蛋白、apoA1、胆红素、ALT)
- 用于慢性乙肝、丙肝、NAFLD
- 准确度接近 LSM

### 5. 透明质酸(HA)、Ⅲ型前胶原(PCⅢ)、Ⅳ型胶原、层粘连蛋白(LN)
- 反映胶原代谢
- 「肝纤四项」,国内常用
- 单一指标特异度不高,联合评估

### 6. ELF(增强肝纤维化检测)
- HA、TIMP-1、PIIINP
- 切点 ≥ 9.8:F3+ 纤维化(NAFLD)

### 7. MELD / Child-Pugh
- 评估肝硬化严重程度和储备

## 三、联合应用策略
- **初筛**:FIB-4(便捷)→ 排除 / 转诊
- **确认**:FibroScan 或 MRE
- **不确定**:联合血清 + 弹性 + 影像
- **肝活检**:
  - 不同方法结果不一致
  - 需精确分期(NASH 试验、新药评估)
  - 病因不明
  - 共病(AIH、PBC 重叠)

## 四、动态监测
- **抗病毒治疗**(慢乙肝、丙肝):3-6 月测 LSM
- **NASH** 药物 / 减重:6-12 月
- **失代偿风险**:LSM 下降提示改善,升高需干预
- **HCC 风险**:LSM > 12-14 kPa 高风险,每 6 月超声 + AFP

## 五、特殊人群
- **儿童**:FibroScan 适用,但切点不同
- **孕妇**:尽量避免
- **胆汁淤积、充血(右心衰)**可假性 ↑ LSM
- **急性肝损伤(ALT > 5 倍正常)**:LSM 假性 ↑,需恢复后评估
- **肥胖**:FibroScan 失败率高,可换 MRE、2D-SWE

## 注意事项
- LSM 与 ALT 急性活动、心衰、胆汁淤积可假性升高
- 肝脏占位、门脉癌栓可局部硬度 ↑
- 不同病因需用相应切点
- 肝硬化早期 LSM 可能正常
- 应与影像、生化、病因综合判断
- 「无创」不能完全替代肝活检(尤其新药试验、病因不明)
