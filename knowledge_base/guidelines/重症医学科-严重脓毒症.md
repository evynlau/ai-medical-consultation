# 严重脓毒症

## 概述
脓毒症(Sepsis)是宿主对感染的失调反应导致的危及生命的器官功能障碍。全球年发病 5000 万例,死亡 1100 万。Sepsis-3 定义(qSOFA、SOFA)取代了严重脓毒症。脓毒性休克(Sepsis-3)是脓毒症的一种,需血管活性药维持 MAP ≥ 65 mmHg 且血乳酸 > 2 mmol/L。

## 定义(Sepsis-3, 2016)

### 脓毒症
- 感染 + **SOFA ≥ 2**
- SOFA ≥ 2:住院死亡率 10%

### 脓毒性休克
- 脓毒症 + 充分液体复苏后仍需**血管活性药**维持 MAP ≥ 65 mmHg
- 血**乳酸 > 2 mmol/L**

### qSOFA(快速筛查, ≥ 2 提示)
- 意识改变(GCS < 15)
- 收缩压 ≤ 100 mmHg
- 呼吸 ≥ 22 次/分

## 病理生理
- 感染 → 免疫激活 → 炎症瀑布(TNF-α、IL-1、IL-6)
- 补体激活、凝血激活(微血栓)
- 内皮损伤、毛细血管渗漏
- 血管张力下降、循环衰竭
- **细胞代谢异常**(线粒体功能障碍)
- 器官灌注不足 → MODS

## 临床识别

### 高危人群
- 老年、婴幼儿
- 免疫抑制(化疗、糖皮质激素)
- 糖尿病、肝硬化、慢性病
- 创伤、手术、ICU

### 早期识别
- **SIRS**(传统, 非特异性):
  - T > 38 或 < 36、HR > 90、RR > 20、Paco₂ < 32、WBC > 12 或 < 4
- **qSOFA**(快速筛查)
- **NEWS**(英国国家早期预警评分)
- **MEWS**(修正早期预警)

### 临床表现
- 发热 / 体温不升、寒战
- 心动过速、呼吸急促
- 意识改变
- 少尿
- 皮肤花斑、毛细血管充盈时间延长
- **乳酸升高**(组织低灌注)

## 治疗

### **「黄金 1 小时」**(Hour-1 Bundle,SCCM 2018)

#### 1. 测乳酸
- 初始乳酸 > 2:3-4 h 复测
- 反映组织灌注

#### 2. 血培养
- 用抗生素前采集(但不延误用药)
- ≥ 2 套(不同部位)

#### 3. 广谱抗生素
- **1 h 内**经验性广谱抗生素
- 院内 1 h 每延迟,死亡率 ↑ 4-7%
- 目标:覆盖最可能病原

#### 4. 液体复苏
- **30 ml/kg**(晶体液)
- 脓毒性休克、有低灌注证据
- 起始 3 h 内完成
- **平衡盐**优于生理盐水(SMART 试验)
  - 乳酸林格液、复方电解质
- 警惕液体过负荷(ARDS、AKI 少尿期)

#### 5. 血管活性药
- **去甲肾上腺素**(首选):0.1-1 μg/kg/min
- 目标 MAP ≥ 65 mmHg
- **多巴胺**(变力性需求)
- **血管加压素**(NE 不足时补充):0.03 U/min
- **肾上腺素**(NE 难治)
- **多巴酚丁胺**(心功能不全)
- **血管紧张素 II**(Giapreza,顽固性)

### 集束化治疗(SCCM / SSC 2021)

#### 复苏目标(3-6 h)
- MAP ≥ 65 mmHg
- 尿量 ≥ 0.5 ml/kg/h
- 乳酸正常化(< 2 mmol/L)
- **毛细血管充盈时间 ≤ 3 s**(ANDROMEDA-SHOCK)

#### 监测
- 动脉血压(有创)
- CVP(目标 8-12 mmHg,潮气量者 12-15)
- 床旁超声(下腔静脉、心功能)
- PiCCO / FloTrac(心输出量、SVV、EVLW)

#### 后续 6 h
- 升压药维持 MAP
- 多巴酚丁胺(心功能障碍)
- 红细胞输注(Hb < 7 g/L,心肌缺血除外 < 8)
- 输血浆 / 血小板(出血时)

### 抗感染治疗
- **经验**:院内、社区、部位、免疫状态
  - **未知**:哌拉西林他唑巴坦 / 美罗培南 / 头孢吡肟
  - **MRSA 风险**:万古霉素、利奈唑胺
  - **真菌**:棘白菌素
- **降阶梯**:48-72 h 根据培养、临床调整
- 疗程:7-10 天(根据病原、反应)
- **PCT** 指导停药(< 0.5 ng/ml 或较峰值 ↓ ≥ 80%)

### 糖皮质激素
- **脓毒性休克**(NE 需求 ≥ 0.25 μg/kg/min,6 h 内)
- 氢化可的松 200 mg/d(50 mg q6h 或持续)
- 疗程 5-7 天,逐步减量
- ADRENAL、APROCCHSS 试验证据
- 不增加感染风险

### 器官支持
- **机械通气**(ARDS)
- **肾脏替代治疗**(AKI)
- **血液净化**(脓毒症,争议)
- **输血策略**:
  - 红细胞:Hb < 7 g/dL(TRICC 试验)
  - 血小板:< 10 × 10⁹/L(无出血) / < 50 × 10⁹/L(出血 / 操作)

### 血糖控制
- 目标 144-180 mg/dL(8-10 mmol/L)
- **NICE-SUGAR 试验**:中等目标
- 避免低血糖(< 110 mg/dL 增加死亡)

### 抗凝
- **DVT 预防**:低分子肝素
- **活化蛋白 C**:已退市
- **抗凝血酶**:不推荐
- **肝素**(脓毒症诱导 DIC):有争议

### 营养
- 早期(< 48 h)肠内营养
- 滋养型 / 充分型:争议
- TARGET:早期 1.2 kcal/ml vs 0.8 kcal/ml 无差异
- 监测胃残留

## 注意事项

### 容量复苏
- **早期积极、后期保守**
- **动态评估**:被动抬腿试验、容量反应性
- **液体选择**:平衡盐(乳酸林格)
- **羟乙基淀粉**(HES):**禁用**(增加 AKI、死亡)
- **白蛋白**:ALBIOS 试验,可能减少休克患者死亡率

### 鉴别诊断
- 全身炎症反应(SIRS)
- 非感染性休克(低血容量、心源性、神经源性)
- 中毒、过敏、自身免疫

### 转归
- 死亡率 25-40%(普通 ICU)
- 脓毒性休克 50%+
- 后期:免疫麻痹、慢性危重症
- 长期:CKD、认知障碍、PICS

### 抗生素管理
- 起始要早、广、足
- 病原学结果出来后降阶梯
- 避免长期广谱(耐药、菌群失调)
- 多学科会诊(感染科、临床药师)

### 感染源控制
- 脓肿引流
- 坏死组织清除
- 感染导管拔出
- 6-12 h 内(可行)
