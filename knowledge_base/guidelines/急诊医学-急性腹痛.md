# 急性腹痛

## 概述
急性腹痛(Acute Abdomen)是急诊最常见的急症之一,**腹腔内脏器急性病理变化**引起的剧烈腹痛,需要**早期诊断、紧急处理**。**内、外、妇科**均可致腹痛,需多学科评估。

## 分类

### 1. 内脏痛(Visceral)
- **钝痛、定位差**
- 早期、脐周
- 自主神经:出汗、恶心
- 肠系膜牵拉、空腔脏器

### 2. 躯体痛(Somatic)
- **锐痛、定位准**
- 腹膜刺激征
- 壁层腹膜

### 3. 牵涉痛(Referred)
- 远离部位
- **胆→右肩、膈**
- **肾→腰、腹股沟**
- **心梗→上腹**
- **阑尾→上腹 → 麦氏**

## 病因(按系统)

### 胃肠道
- **阑尾炎**(最常见外科)
- **肠梗阻**
- **胃穿孔**
- 胃肠炎
- 炎性肠病
- **缺血性肠病**
- 嵌顿疝

### 肝胆
- **胆囊炎**(结石、非结石)
- **胆总管结石**
- **急性胆管炎**
- 肝炎
- 肝脓肿

### 胰
- **急性胰腺炎**

### 脾
- 脾破裂
- 脾梗死

### 肾、泌尿
- **肾绞痛**(结石)
- 肾盂肾炎
- 急性尿潴留

### 血管
- **腹主动脉瘤(AAA)破裂**
- 肠系膜血管栓塞
- 脾动脉瘤
- **腹主动脉夹层**

### 妇科
- **异位妊娠破裂**
- **卵巢囊肿扭转、破裂**
- **盆腔炎(PID)**
- **黄体破裂**
- 痛经

### 全身
- **心肌梗死**(下壁)
- 糖尿病酮症
- 卟啉病
- 过敏性紫癜
- 中毒

### 腹外
- 心梗、肺炎
- 脊柱(带状疱疹)
- 睾丸扭转

## 诊断

### 病史
- **发病**(急、缓、时程)
- **诱因**(餐后、剧烈活动)
- **性质**(刀割、绞、胀、钻)
- **部位**(迁徙)
- **放射**
- **伴随**(发热、呕吐、黄疸、血便、血尿)
- **月经、育龄、性生活**
- 既往(手术、胆、溃疡)
- 用药

### 体格
- **T、HR、BP**(评估)
- **神志**
- **望**(瘢痕、膨隆、肠型)
- **听**(肠鸣)
- **叩**(鼓浊、移动浊)
- **触**(压痛、反跳痛、肌卫)
  - 麦氏点(阑尾)
  - 莫菲征(胆)
  - 肾叩击(肾)
  - 腰大肌、闭孔(阑尾异位)
- **直肠指诊**(必查)
- **妇科检查**(育龄女)

### 实验室
- 血常规、CRP、PCT
- **肝、胰、肾**
- **血淀粉酶/脂肪酶**(胰腺)
- **血气**(酸中毒、乳酸)
- **血糖**
- **凝血**
- **血型 + 配血**(手术)
- **心肌酶、TnI**(心源)
- **尿常规**(肾、尿路、酮体)
- **尿 hCG**(育龄女)
- **血氨、乳酸**(肝)
- 血培养(脓毒)

### 影像
- **腹部立卧位 X**:
  - 膈下游离气体(穿孔)
  - 气液平面(梗阻)
  - 肠管扩张
  - 结石(部分)
- **腹部超声(US)**:
  - 胆、肾、肝、胰(部分)
  - 阑尾(有限)
  - 腹水
  - AAA
  - 床旁(急诊)
- **CT 增强(首选)**:
  - 阑尾、肠梗阻、缺血、胰、AAA
  - 急腹症 **> 80% 确诊**
- **CTA**(血管)
- **MRI**(胆、胰、孕)
- **心电图**(心源)
- **诊断性腹腔灌洗**(DPL,罕)

### 腹腔穿刺
- 血性、脓性、胆汁
- 不凝血(宫外孕、AAAR)
- 淀粉酶(胰腺炎)
- 培养

## 鉴别诊断(关键)

| 部位 | 内科 | 外科 |
|---|---|---|
| **右上腹** | 胆(胆囊炎、胆管炎)、肝(脓肿)、肝炎 | 穿孔(胃、十二指肠)、肝下脓肿 |
| **左上腹** | 胃(胃炎、溃疡)、胰、脾(梗死、破裂) | 脾破裂、AAA、肠梗阻 |
| **上腹** | 胃(溃疡、炎)、心梗、胰、胆 | 穿孔、肠系膜血管、AAA |
| **右下腹** | 阑尾、输尿管结石、肾盂炎、回肠、肠系膜淋巴结 | 阑尾炎、嵌顿疝、Crohn、异位妊娠 |
| **左下腹** | 结肠(憩室、肿瘤、便秘) | 乙状结肠扭转、憩室炎、宫外孕、卵巢 |
| **下腹** | 膀胱、肠、妇科 | 阑尾(异位)、盆腔炎、宫外孕 |
| **脐周** | 肠(肠炎、梗阻、缺血)、早期阑尾 | AAA、肠系膜、胰腺 |
| **弥漫** | 胃肠炎、毒、代谢 | 穿孔、梗阻、缺血、出血 |

## 处理

### 1. 急救
- **禁食、NG**
- **静脉通路**
- **液体**(NS/RL)
- **电解质**
- **血型配血**
- **监测**(q1 h)
- **镇痛**(诊断前可,**吗啡 5 mg IV**:不掩盖)
- **不**强力镇痛(掩盖)
- **抗菌**(感染迹象)
- **吸氧**

### 2. 内科处理
- **胃肠减压**(梗阻、穿孔)
- **补液**
- **PPI**(溃疡)
- **解痉**(胆、肾、肠):山莨菪碱
- **生长抑素**(胰)
- **抗菌**(胆胰、脓毒)

### 3. 外科处理
- **急症手术**:
  - **穿孔**(腹膜炎)
  - **肠扭转**(绞窄)
  - **AAA 破裂**
  - **异位妊娠**(出血)
  - 嵌顿疝(绞窄)
  - 急性出血
  - 肠系膜栓塞
  - 急性胆管炎(胆减压)
  - 化脓性胆囊炎
  - 脾破裂
- **腹腔镜 vs 开腹**

### 4. 介入
- **主动脉瘤破裂**(条件)
- 消化道出血
- 胆道梗阻(ENBD/PTCD)
- 出血(脾、肝、肾动脉)

### 5. 监测
- 生命体征
- 腹部体征
- 引流(色、性、量)
- 实验室(血常规、生化、乳酸)
- **警惕**漏诊

## 关键危急急腹症(不可漏)
- **AAA 破裂**(中老年、低血压、双侧腰)
- **宫外孕破裂**(育龄、停经)
- **肠系膜栓塞**(中老年、心、剧痛+轻体征)
- **穿孔**(气腹、剧痛+板状腹)
- **绞窄性肠梗阻**(嵌顿)
- **主动脉夹层**(高血压、撕裂样)
- **心梗**(心电图、上腹)
- **脾破裂**(外伤)

## 注意事项
- **多学科**评估
- **育龄女**:必查 hCG
- **老年**:不典型
- **妊娠**:禁 X、CT(部分);MRI
- **免疫抑制**:不典型
- **不**对所有腹痛用吗啡(评估)
- **不**忽视休克
- **早手术**:穿孔、AAAR
- **观察**:不明、稳
- **CT** 是核心
