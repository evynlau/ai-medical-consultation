# 硝酸甘油

#### 硝酸甘油
*## 基本信息*## 
- 分类：硝酸酯类扩血管药
- 常见商品名：硝酸甘油片、喷雾剂
- 上市时间：1870年代
- 处方/OTC状态：处方药
*## 适应症*## 
- 心绞痛急性发作
- 急性左心衰竭
- 高血压急症
*## 药理作用*## 
- 释放一氧化氮，扩张血管平滑肌
- 扩张静脉>动脉，降低心脏前负荷
- 改善心肌缺血区域供血
*## 用法用量*## 
- 舌下含服：0.5mg/次，每5分钟重复，最多3次
- 静脉滴注：起始5μg/min，根据血压调整
- 喷雾剂：1-2喷/次，必要时重复
*## 不良反应*## 
- 头痛（常见）
- 低血压、头晕
- 面红、心悸
*## 注意事项*## 
- ⚠️ 首剂可能引起严重低血压（起立性）
- ⚠️ 青光眼患者慎用
- ⚠️ 严禁与PDE5抑制剂（西地那非）合用
*## 禁忌*## 
- 重度低血容量
- 肥厚梗阻性心肌病
- 严重贫血、颅内压增高
*## 相互作用*## 
- 西地那非等PDE5抑制剂：导致致命性低血压
- 高尔曼（二氢吡啶类CCB）：增强降压效果
*## 临床应用要点*## 
- 是心绞痛急性发作的首选急救药物
- 含服起效快（1-3分钟），作用持续30分钟
- 无效时应及时就医，避免延误治疗
