# 支气管扩张诊治

## 概述
支气管扩张(支扩)是各种原因引起的支气管管壁结构破坏,导致**支气管不可逆性扩张、变形**。我国估计成人患病率 1.2%。主要表现:慢性咳嗽、大量脓痰、反复咯血。

## 病因
### 感染后
- **儿童期下呼吸道感染**(麻疹、百日咳、TB、腺病毒、肺炎)
- 坏死性肺炎(金葡菌、肺炎克雷伯菌)

### 免疫缺陷
- 低丙种球蛋白血症(CVID、XLA)
- HIV
- 化疗 / 移植后

### 先天 / 遗传
- **囊性纤维化**(CF,白种人多)
- **纤毛运动障碍**(Kartagener 综合征:支扩 + 鼻窦炎 + 内脏转位)
- α1-抗胰蛋白酶缺乏
- Mounier-Kuhn 综合征(气管巨大症)
- Williams-Campbell 综合征

### 其他
- 异物、肿瘤阻塞
- 误吸、胃食管反流
- **ABPA**(变应性支气管肺曲霉病)
- 结缔组织病(RA、SLE)
- **NTM** 非结核分枝杆菌

## 病理类型
- 柱状(早期,最常见)
- 静脉曲张状(中度)
- 囊状(晚期,最严重)

## 临床表现
- **慢性咳嗽 + 大量脓痰**(痰量 100-400 mL/d)
  - 体位变化咳痰(晨起、变换体位)
  - 痰分层(泡沫、黏液、脓、坏死物)
  - 恶臭提示厌氧菌
- **反复咯血**(70%):少量至大量
- **反复下呼吸道感染**(年 > 3 次)
- 消瘦、乏力、活动气短
- 体检:固定性湿啰音(「音乐家指」)、杵状指(20-30%)、肺心病

## 诊断

### HRCT — 金标准
- 支气管内径 > 伴随动脉(「印戒征」)
- 支气管无逐渐变细
- 距胸壁 1 cm 内可见支气管
- 黏液嵌塞
- 蜂窝 / 囊状改变
- 「印戒征 + 双轨征 + 支气管内可见」三联

### 病原学
- **痰培养 + 药敏**(必备)
  - 铜绿假单胞菌:**预后差**、治疗复杂
  - 金葡菌:警惕 ABPA
  - 流感嗜血杆菌
- **NTM** 培养(3 次晨痰)
- 痰 AFB / 分枝杆菌培养

### 病因筛查
- 免疫球蛋白(IgG、IgA、IgM)
- CF 筛查(汗氯试验 / CFTR 基因)
- 纤毛活检(电镜)
- α1-抗胰蛋白酶
- 曲霉特异性 IgE / 皮肤点刺(ABPA)
- 食管 pH 监测(怀疑反流)

## 急性加重
- 24 h 内咳嗽 / 痰量 / 脓痰 / 呼吸困难 / 乏力中 ≥ 3 项加重
- 治疗:**抗菌 14 d**
  - 无铜绿:**阿莫西林克拉维酸 / 二代头孢 / 多西环素**
  - 既往铜绿 / 频繁加重:抗假单胞 β 内酰胺(头孢他啶、哌拉西林他唑巴坦、环丙沙星)
  - 吸入抗生素(多粘菌素、妥布霉素):备选

## 长期管理

### 气道清除
- **最关键**
- 体位引流(病变部位朝上,重力)
- 拍背、振动背心
- 呼吸训练(主动循环呼吸)
- 高渗盐水雾化(3%、7%)
- 乙酰半胱氨酸 / 桉柠蒎

### 控制感染
- 长期大环内酯:**阿奇霉素 250 mg 每周 3 次 / 每日**(3-12 月)
  - 抗炎 + 免疫调节 + 抗铜绿生物被膜
  - 注意 QT 间期、肝功
- 长期吸入抗生素(铜绿定植):妥布霉素、氨曲南、环丙沙星
- 疫苗(流感、肺炎)
- 戒烟

### 抗炎
- 吸入糖皮质激素(高 EOS / 嗜酸炎症型)
- 大环内酯抗炎

### 咯血处理
- 少量:止血药(氨甲环酸、垂体后叶素)
- 中大量:**BAE**(首选)或手术

### 手术
- **指征**:
  - 局限(单叶或单侧)
  - 大咯血、内科无效
  - 反复感染、无法控制
  - 不能排除肿瘤
- 方式:肺叶切除

### 介入
- BAE:大咯血首选
- 气道内支架:外压性狭窄
- 高频电、激光、APC:肿瘤性阻塞

### 终末期
- 肺移植

## ABPA(变应性支气管肺曲霉病)
- 哮喘 / 支扩患者中
- 诊断(Rosenberg-Patterson 经典标准):
  - 哮喘
  - 肺部浸润影
  - 中心型支扩
  - 血 EOS ↑
  - 曲霉皮试(+)
  - 曲霉特异性 IgE ↑
  - 血清总 IgE ↑
- 治疗:糖皮质激素 + 抗真菌(伊曲康唑、伏立康唑)

## 注意事项
- 急性加重期抗菌 14 d
- **铜绿假单胞菌定植**:难治,长期联合
- 长期大环内酯前查 QT、肝功
- 监测非结核分枝杆菌感染
- 病因筛查至关重要(尤其儿童 / 青少年 / 双侧)
- 自我管理:识别加重早期、及时就诊
- 营养支持
- 心理:慢性病焦虑抑郁
- 疫苗接种(年度流感、肺炎、RSV)
