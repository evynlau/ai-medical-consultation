# 鼻出血处理

## 概述
鼻出血(epistaxis)是耳鼻咽喉科最常见急症,人群终生发生率约 60%。绝大多数为前鼻出血(易止),少数为后鼻出血(量大、危险)。儿童及青少年多为前鼻出血(鼻中隔 Little 区),中老年人警惕高血压、肿瘤。

## 病因

### 局部因素
- **鼻中隔偏曲 / 嵴突**:Little 区黏膜薄、易糜烂
- **鼻部外伤**:挖鼻、揉鼻、打击
- **鼻部炎症**:鼻炎、鼻窦炎、干燥
- **鼻部肿瘤**:
  - 良性:血管瘤、鼻中隔毛细血管瘤
  - 恶性:鼻咽癌、淋巴瘤、上颌窦癌
- **医源性**:手术后、鼻腔填塞
- **鼻异物**(儿童)
- **鼻喷剂刺激**

### 全身因素
- **高血压**(最常见全身因素)
- **凝血障碍**:血小板减少、白血病、再生障碍性贫血、血友病、ITP
- **抗凝药**:华法林、阿司匹林、氯吡格雷、肝素、新型抗凝药(NOAC)
- **血管病变**:动脉硬化、遗传性出血性毛细血管扩张症(HHT)
- **肝肾衰竭**:凝血因子合成减少
- **酒精中毒**
- **内分泌**:妊娠、青春期

## 出血部位
- **前鼻出血(90%)**:
  - **Little 区**(Kiesselbach 丛):鼻中隔前下,血管汇集
  - 儿童、青壮年
- **后鼻出血(10%)**:
  - Woodruff 丛(鼻咽静脉丛)、蝶腭动脉分支
  - 中老年人、高血压、动脉硬化

## 评估
- **病史**:出血量、时间、侧别、诱因、既往史、用药史
- **生命体征**:血压、脉搏(失血性休克早期表现)
- **出血量估计**:
  - 轻度:< 200 mL,生命体征稳定
  - 中度:200-500 mL,心率快
  - 重度:> 500 mL,休克
- **前鼻镜 / 鼻内镜**:定位出血点
- **实验室**(反复 / 量多):
  - 血常规、凝血、肝肾功能
  - 血型、备血

## 治疗

### 现场急救
- **坐位前倾**,勿仰头(防误吸)
- **指压法**:拇指 + 食指捏鼻翼 10-15 min
- 冰袋敷前额、鼻根部
- 心理安慰

### 院内治疗
#### 局部止血
- **血管收缩剂**:1% 麻黄碱 + 肾上腺素棉片 / 棉球(可加表面麻醉剂丁卡因)
- **烧灼法**(出血点可见):
  - 化学烧灼:50% 三氯醋酸、硝酸银
  - 电烧灼:双极电凝、单极
  - 激光:Nd:YAG、二氧化碳
- **前鼻孔填塞**(前鼻出血):
  - 吸收性材料:明胶海绵、氧化纤维素、可降解纳吸棉
  - 凡士林纱条:经典
  - 膨胀海绵(Merocel):便捷
- **后鼻孔填塞**(后鼻出血):
  - Foley 导尿管:球囊扩张
  - 碘仿纱球:经典后鼻孔填塞法
- **鼻内镜下精准止血**:定位蝶腭动脉、筛前 / 筛后动脉
- **血管栓塞**(DSA):难治性动脉性出血

#### 全身治疗
- **补液、输血**(失血量多)
- **止血药**:氨甲环酸、酚磺乙胺
- **抗生素**:填塞后防鼻窦炎
- **控制血压**
- **纠正凝血**:维生素 K、FFP、血小板
- **治疗原发病**

### 手术(反复 / 难治)
- **鼻中隔矫正 + 黏膜划痕**
- **蝶腭动脉结扎术**(内镜下)
- **颈外动脉结扎**(极少)

## 注意事项
- **前鼻出血预后好**,后鼻出血可能致命
- **儿童鼻出血**多自限,Little 区多见
- 警惕**鼻咽癌**(回缩性血涕、单侧)
- **抗凝药使用**需平衡出血与血栓风险(与原主管医生沟通)
- 后鼻孔填塞需**监测 SpO₂**(防阻塞性睡眠呼吸暂停、低氧)
- 填塞 48-72 h 后取出,防感染
- 遗传性出血性毛细血管扩张症(HHT)需长期管理
- **反复鼻出血 + 鼻塞**警惕鼻腔、鼻窦肿瘤,需活检
- **儿童单侧鼻出血 + 脓涕 + 臭味**:警惕鼻腔异物
