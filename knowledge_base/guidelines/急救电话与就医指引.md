# 急救电话与就医指引

## 急救电话

### 120 - 急救中心(中国大陆)
- 免费拨打
- 24 小时
- 任何危及生命的急症
- 调度员会问:地址、电话、患者情况、联系电话

### 拨打 120 时要说清楚
1. **地点**:详细地址(街道、门牌号、显著建筑)
2. **电话**:现场联系电话
3. **人数**:几人需要救治
4. **情况**:患者主要症状、意识状态
5. **已采取措施**:如心肺复苏、止血

## 需要立即拨打 120 的情况

### 意识与生命体征
- 突然意识丧失、昏迷
- 呼吸停止或严重呼吸困难
- 心跳停止、无脉搏
- 大出血(无法用压迫止血)
- 抽搐持续 > 5 分钟

### 急性胸痛(详见胸痛识别)
- 持续 > 15-20 分钟
- 伴大汗、濒死感

### 急性脑血管病(中风 FAST)
- **F**ace:面部不对称、口角歪斜
- **A**rm:一侧肢体无力
- **S**peech:言语不清、失语
- **T**ime:立即就医,记录发现时间

### 急性腹痛
- 剧烈持续 > 1 小时
- 伴休克、便血、呕血

### 严重外伤
- 车祸、高处坠落、刀伤、挤压伤
- 头部外伤伴意识改变

### 其他
- 自杀倾向、严重药物过量
- 急性过敏反应伴呼吸困难
- 严重烧烫伤
- 电击伤、溺水

## 就医流程

### 急诊
- 危急重症 → 立即去最近医院的急诊科
- 分诊护士会按病情严重程度分级
- Ⅰ级(濒危)、Ⅱ级(危重)优先

### 门诊
- 慢性病、稳定期疾病
- 提前预约
- 准备好既往病历、检查报告、用药清单

## 常见病就医科室

| 症状 | 首选科室 |
|---|---|
| 头痛、头晕、肢体麻木 | 神经内科 |
| 胸痛、心悸 | 心血管内科 |
| 咳嗽、喘息、发热 | 呼吸内科 / 发热门诊 |
| 腹痛、腹泻、便秘 | 消化内科 |
| 尿频、尿急、尿痛 | 泌尿外科 / 肾内科 |
| 关节痛、肌肉痛 | 风湿免疫科 / 骨科 |
| 皮疹、瘙痒 | 皮肤科 |
| 眼红、视物模糊 | 眼科 |
| 耳鸣、耳痛、听力下降 | 耳鼻喉科 |
| 牙痛 | 口腔科 |
| 焦虑、失眠、情绪低落 | 心理科 / 精神科 |
| 女性妇科问题 | 妇科 |
| 儿童疾病 | 儿科 |

## 自我观察要点
- 症状起始时间
- 部位、性质、程度
- 诱因(吃什么/做什么后发作)
- 缓解因素
- 伴随症状
- 既往病史、用药史
- 过敏史

## 心理准备
- 就医前整理好病历
- 列出想问医生的问题
- 不要隐瞒病情
- 听从医生建议,不要自行调整方案
- 复诊带齐之前的检查结果
