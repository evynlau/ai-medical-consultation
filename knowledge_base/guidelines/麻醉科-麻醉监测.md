# 麻醉监测

## 概述
麻醉监测(Anesthesia Monitoring)是围术期持续、动态评估患者生命体征、麻醉深度、生理功能的关键措施。是减少麻醉并发症、保障患者安全的核心。ASA「基本麻醉监测标准」是国际共识。

## ASA 基本监测标准(强制)

1. **持续在场**(麻醉医师):整个麻醉过程中
2. **持续监测**:
   - **氧合**(Oxygenation)
   - **通气**(Ventilation)
   - **循环**(Circulation)
   - **体温**(Body temperature)

### 1. 氧合监测
- **吸入氧浓度**(FiO₂):麻醉机监测
- **脉搏血氧饱和度**(SpO₂):持续,声光报警
- **PaO₂**:动脉血气

### 2. 通气监测
- **呼气末 CO₂**(ETCO₂ / Capnography):
  - **必备**
  - 波形 + 数值
  - 波形判断:插管确认、呼吸监测、代谢
- **气道压力**(Paw):峰压、平台压、PEEP
- **潮气量**(Vt):呼出(主要)、吸入
- **呼吸频率**(RR)
- **分钟通气量**(MV)

### 3. 循环监测
- **心电图**(ECG):持续、5 导联(Ⅱ、V5)
  - 心率、心律、ST 段、QRS
- **血压**:无创(NIBP)或**有创**(IBP)
  - NIBP 至少每 5 min
- **脉搏**(指脉氧、动脉压波形)
- **灌注**:尿量、毛细血管充盈

### 4. 体温监测
- **核心温度**:食管、鼻咽、膀胱、直肠、血(肺动脉)
- **皮肤温度**:周围
- **低 / 高温报警**

## 进阶监测

### 麻醉深度
- **BIS**(Bispectral Index,脑电双频谱):
  - 范围 0-100
  - **目标 40-60**(全麻)
  - **< 40**:深度抑制
  - **> 60**:可能知晓
  - **> 70**:觉醒
- **Narcotrend**
- **SedLine**(患者状态指数,PSI)
- **Entropy**:状态熵(SE)、反应熵(RE)
- **听觉诱发电位**(AEP):A-Line
- **预防术中知晓**(1-2% 风险)

### 肌松监测
- **TOF**(四个成串刺激):
  - **TOF 比值**(T4/T1):
    - 0.4-0.7:轻度残留
    - **> 0.9**:拔管标准
    - 1.0:完全恢复
- **DBS**(双重爆发刺激)
- **PTC**(强直后计数):深度肌松评估
- **神经刺激部位**:尺神经、面部神经、胫后神经
- **部位**:
  - **尺神经**(拇内收肌)
  - **面神经**(眼轮匝肌)
  - **胫后神经**(拇展肌)

### 血流动力学
- **有创动脉压**(IBP):
  - 大手术、心脏、神经外科、休克
  - 实时、动脉血气
  - 桡动脉、肱动脉、股动脉
- **中心静脉压**(CVP):
  - 容量评估、给药通路
  - 颈内、锁骨下、股静脉
  - 趋势变化 > 绝对值
- **心输出量**(CO):
  - **肺动脉导管**(PAC, Swan-Ganz):金标准(有创),CO、PCWP、PVR
  - **PiCCO**:CO、SVV、GEDV、EVLW
  - **FloTrac / Vigileo**:CO、SVV
  - **超声 / TEE**:CO、心功能
- **PPV / SVV**:容量反应性

### 心电图进阶
- **12 导联心电图**(术前)
- **ST 段监测**(Ⅱ、V5)
- **心律失常分析**

### 呼吸力学
- **压力-容积(P-V)曲线**
- **P-V 环**(流量-容积环)
- **顺应性**(C):潮气量 / (Pplat - PEEP)
- **阻力**(R):(Ppeak - Pplat)/流速
- **Auto-PEEP**(内源性 PEEP):COPD、哮喘
- **驱动压**(Driving pressure):Pplat - PEEP

### 神经监测
- **脑氧饱和度**(rSO₂ / INVOS / NIRS):
  - 颈动脉内膜剥脱术
  - 心脏手术
  - 脑局部氧合
- **EEG 持续监测**:
  - 癫痫持续、颅内
  - 麻醉深度
- **诱发电位**:
  - 体感诱发电位(SSEP)
  - 运动诱发电位(MEP)
  - **脊柱 / 神经手术**(监测脊髓功能)

### 经食管超声心动图(TEE)
- 心脏手术
- 大血管手术
- 围术期心脏评估
- 实时心功能、容量、瓣膜

### 凝血监测
- **TEG**(血栓弹力图):动态凝血
- **ROTEM**(旋转血栓弹力测定)
- 心脏、肝移植、产科
- **指导输血**:纤维蛋白原、血小板

### 颅内压
- **ICP 监测**(脑室引流、实质内)
- **脑灌注压**(CPP = MAP - ICP)

### 血糖
- 围术期监测(尤其糖尿病、长时间)
- 目标 144-180 mg/dL

## 监测设备

### 标准配置
- **多功能监护仪**(ECG、NIBP、SpO₂、ETCO₂)
- **麻醉机**:氧浓度、气道压、流量、麻醉气体、ETCO₂
- **体温监测**

### 大手术
- **有创动脉压**
- **中心静脉压**
- **肌松监测**
- **BIS**
- **尿量**(导尿管)
- **血糖**

### 心脏手术
- **TEE**(经食管超声)
- **PAC**(肺动脉导管)
- **ACT**(活化凝血时间)
- **TEG / ROTEM**
- **体外循环监测**

### 神经外科
- **脑氧饱和度**
- **SSEP / MEP**
- **颅内压**
- **EEG**

### 特殊
- **胃张力计**:胃肠 pHi(肠缺血)
- **膀胱温度**
- **外周神经刺激器**

## 注意事项

### 监测阈值与报警
- **SpO₂ < 90%**:低氧
- **ETCO₂ < 25**:过度通气、肺栓塞、心脏骤停
- **ETCO₂ > 55**:通气不足
- **MAP < 65 mmHg**:低血压
- **HR < 50 或 > 120**:心动过缓/速
- **体温 < 36°C**:低体温
- **BIS < 40**:麻醉过深
- **BIS > 60**:麻醉过浅

### 术中知晓
- BIS 40-60 减少知晓
- **高风险**:
  - 心脏手术、剖宫产、严重创伤
  - 阿片为主麻醉
- **不可全靠 BIS**:独立判断(血流动力学、MAC)

### 监测技术误差
- **NIBP**:不连续、袖带大小
- **SpO₂**:低灌注、碳氧血红蛋白、亚甲蓝干扰
- **ETCO₂**:呼吸回路漏气、采样管堵塞
- **动脉压**:零点位置、阻尼、阻尼过大
- **CVP**:导管位置、零点

### 整合
- 多参数整合判断
- 不能孤立看单一指标
- **临床经验 + 监测**

### 记录
- **自动麻醉记录**
- 每 5 min 生命体征
- 事件(用药、输液、手术步骤)
- 异常事件及处理

### 团队与交接
- **PACU 交接**
- **术中交接**(如有)
- **转入 ICU 交接**
