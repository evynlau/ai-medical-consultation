# 鼻中隔偏曲

## 概述
鼻中隔偏曲是指鼻中隔偏离中线向一侧或两侧弯曲、嵴突(棘突),引起鼻腔功能障碍。人群中约 30-40% 有不同程度偏曲,需手术矫正的约占 5%。多数为外伤或发育异常,部分继发于鼻腔病变。

## 病因
- **发育异常**:鼻中隔由多块软骨与骨组成,生长速度不均衡,儿童期外伤后易致
- **外伤**:鼻部打击伤、骨折未复位(婴幼儿期未察觉的外伤也可)
- **鼻腔占位**:鼻息肉、肿瘤推挤
- **医源性**:鼻窦手术、鼻中隔手术

## 分型
- **C 形偏曲**:单侧偏曲
- **S 形偏曲**:双向偏曲
- **嵴突(棘突)**:骨棘状突起
- **前脱位**:软骨前缘脱位
- **高位 / 低位偏曲**:高位偏曲常致鼻塞
- **按程度**:
  - 轻度:偏离中线 < 0.3 cm
  - 中度:0.3-0.6 cm
  - 重度:> 0.6 cm

## 临床表现
- **鼻塞**:单侧或双侧(双侧时交替)
- **鼻出血**:嵴突 / 棘突处黏膜薄、易糜烂
- **头痛**:高位偏曲压迫中鼻甲、阻塞鼻窦引流 → 鼻源性头痛
- **鼻窦炎**:OMC 阻塞继发
- **耳鸣、听力下降**:咽鼓管功能障碍
- **打鼾 / 睡眠呼吸暂停**
- **外鼻畸形**:歪鼻

## 诊断
- **前鼻镜检查**:偏曲部位、形态、与鼻甲关系
- **鼻内镜检查**:评估偏曲程度、棘突位置、OMC
- **鼻窦 CT**(冠状位):评估鼻窦、偏曲对鼻窦引流影响
- **合并症评估**:
  - 鼻窦炎 CT
  - 鼻阻力测量(客观)
  - PSG(怀疑 OSA)

## 治疗

### 保守治疗(轻度)
- 鼻用糖皮质激素(消肿)
- 生理盐水冲洗

### 手术治疗
- **适应证**:
  - 持续性鼻塞、药物无效
  - 反复鼻出血
  - 鼻窦炎 / 鼻息肉需同期处理
  - 头痛(鼻源性)
  - OSA 辅助治疗
  - 矫正外鼻畸形

### 鼻中隔黏膜下矫正术(经典)
- **步骤**:
  1. 半坐位、全麻或局麻
  2. 左侧 Killian 切口
  3. 分离黏软骨膜、黏骨膜
  4. 切除偏曲软骨 / 骨
  5. 保留 L 形支架(防鼻梁塌陷)
  6. 缝合切口、双侧鼻腔填塞
- **改良术式**:
  - 鼻中隔成形术:矫正不切除
  - 三线减张:对应力骨折线

### 同期手术
- 鼻中隔矫正 + 鼻窦手术
- 鼻中隔矫正 + 鼻甲手术
- 鼻中隔矫正 + 鼻整形

### 术后处理
- 双侧鼻腔填塞 24-72 h
- 抗生素、止痛
- 鼻用激素 2 周后开始
- 避免外力、擤鼻 2 周

## 注意事项
- **18 岁以下**尽量避免手术(鼻骨发育未成熟)
- **复发率**低,但可能因发育、外伤再发
- 鼻梁塌陷(鞍鼻)是主要并发症
- **鼻中隔穿孔**:双侧黏膜对应损伤
- **脑脊液鼻漏**:筛板损伤(罕见)
- 血肿需及时处理(防软骨坏死、感染)
- 鼻腔粘连需随访、及时分离
- 糖尿病、凝血障碍者需评估
