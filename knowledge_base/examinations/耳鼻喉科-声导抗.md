# 声导抗

## 概述
声导抗(acoustic immittance)是测量外耳道压力变化时中耳声顺(顺应性)的变化,包括**鼓室声导抗(鼓室图)**和**声反射**,是评估中耳功能、咽鼓管功能、听神经反射通路的客观听力学检查。

## 原理

### 声导纳 / 声顺
- 中耳系统接受声能的能力(顺应性)
- 与中耳压力、劲度、质量相关
- **正常**:中耳压力 = 大气压、声顺最大

### 鼓室声导抗测试
- 外耳道气压从 +200 daPa 扫至 -400 daPa
- 同步测量声顺
- 绘制鼓室图(tympanogram)

### 声反射
- 强声刺激 → 镫骨肌收缩 → 鼓膜声顺变化
- 反射弧:耳蜗 → Ⅷ → Ⅶ → 镫骨肌
- 同侧、对侧均可测

## 检查设备
- **声导抗仪**(中耳分析仪):
  - 226 Hz、1000 Hz 探测音
  - 成人 / 儿童模式
  - 自动 / 手动

## 测试项目

### 1. 鼓室图(Tympanometry)
#### A 型(正常)
- 峰值:压力 0 ± 100 daPa,声顺 0.3-1.6 mL
- 正常中耳

#### B 型(平坦)
- 无明显峰值、声顺低平
- **中耳积液**(OME)
- **鼓膜穿孔**(大量容积)
- **耵聍堵塞**
- **探头贴壁**

#### C 型(负压)
- 峰值 < -100 daPa
- **咽鼓管功能障碍、早期 OME**

#### As 型(低幅)
- 声顺 < 0.3 mL
- **听骨链固定**(耳硬化症、鼓室硬化)

#### Ad 型(高幅)
- 声顺 > 1.6 mL
- **听骨链中断**、鼓膜松弛

#### D 型
- 切迹 / 双峰:鼓膜异常活动
- **鼓膜萎缩**

#### E 型
- 异常尖锐高峰

### 2. 静态声顺
- 鼓膜最大声顺(峰值高度)
- 反映中耳劲度

### 3. 外耳道容积(ECV)
- 成人:0.6-2.0 mL
- 儿童:0.4-1.0 mL
- **ECV 增大**:鼓膜穿孔
- **ECV 减小**:耵聍、探头贴壁

### 4. 咽鼓管功能
- **Valsalva 法**
- **Toynbee 法**
- **正 / 负压平衡试验**
- 鼓膜完整时测

### 5. 声反射测试(Acoustic Reflex)
- **反射阈**:正常 70-100 dB HL
- **同侧、对侧**均可测
- **临床意义**:
  - **反射消失**:
    - 重度聋(纯音听阈 > 反射阈)
    - 中耳积液(声顺变化)
    - **听神经瘤**(蜗后病变,反射衰减)
    - 面神经麻痹(镫骨肌支)
  - **反射衰减**(蜗后):阳性提示
  - **重振**:反射阈与听阈差 ≤ 60 dB(耳蜗病变)

## 适应证
- 中耳疾病筛查 / 诊断
- OME 诊断(关键)
- 鼓膜穿孔评估
- 听骨链评估
- 咽鼓管功能障碍
- 面神经麻痹定位(镫骨肌支)
- 听神经病 / 听神经瘤筛查
- 婴幼儿听力筛查
- 鼓室图测量(中耳功能客观评估)

## 临床应用

### 分泌性中耳炎(OME)
- **B 型曲线**:典型
- C 型:早期 / 恢复期

### 鼓膜穿孔
- B 型 + ECV ↑

### 耳硬化症
- **As 型**(低声顺)
- 韦氏误听(反向)

### 听骨链中断
- **Ad 型**(高声顺)

### 咽鼓管功能障碍
- C 型,吞咽后改善

### 听神经瘤
- **声反射消失 / 衰减**(关键)
- 需结合 ABR

### 面神经麻痹定位
- 镫骨肌反射存在:病变在镫骨肌支以下
- 反射消失:病变在镫骨肌支以上

## 注意事项
- **测试前耳镜检查**(排除耵聍、穿孔)
- **探头密闭**(贴壁影响结果)
- **压力范围**:婴幼儿慎用负压(中耳损伤)
- **婴幼儿用 1000 Hz 探测音**(226 Hz 灵敏度差)
- **测试中不吞咽、不说话、不动**
- **急性中耳炎期**压力测试需谨慎
- 鼓膜穿孔禁用正压(可加重损伤)
- 测试结果**结合纯音测听、听力学综合判断**
- **鼓室图正常**不能完全排除中耳病变
- 测试需要患者**静坐**
