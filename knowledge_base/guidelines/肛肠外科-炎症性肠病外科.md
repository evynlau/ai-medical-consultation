# 炎症性肠病外科

## 概述
炎症性肠病(IBD)包括溃疡性结肠炎(UC)和克罗恩病(CD),约 70-80% CD、20-30% UC 在病程中需手术治疗。手术不能根治,但可控制并发症、改善生活质量、挽救生命。

## 克罗恩病手术适应证
- **并发症**:
  - 肠梗阻(纤维狭窄,40-50%)
  - 内瘘/外瘘
  - 腹腔脓肿(15-25%)
  - 穿孔、急性腹膜炎
  - 大出血
- **内科治疗失败**:难治性、激素依赖
- **癌变**(结直肠、肛管)
- **儿童生长发育迟缓**

## 溃疡性结肠炎手术适应证
- **急性重症**(中毒性巨结肠、穿孔、出血)
- 内科治疗失败(激素依赖或难治)
- 癌变、高级别上皮内瘤变
- 儿童生长发育受限

## 手术原则
- CD:尽力保留肠管,**限制性切除**
- UC:**全结肠直肠切除**(病变广泛)
- 微创首选
- 围手术期营养支持、免疫抑制剂管理

## CD 术式

### 一、小肠 CD
- 狭窄成形术(strictureplasty):
  - Heineke-Mikulicz(< 10 cm)
  - Finney(10-20 cm)
  - Michelassi(> 20 cm)
- 节段性切除(狭窄 > 50 cm、严重病变)

### 二、结肠 CD
- 节段性结肠切除
- 回盲部切除(最常见)
- 全结肠切除术(广泛)

### 三、肛周 CD
- 脓肿:引流
- 瘘管:挂线、生物胶
- 避免激进手术(伤口不愈)
- 生物制剂(英夫利西、阿达木、维得利珠)是关键

### 四、腹腔脓肿
- 穿刺引流 + 抗生素
- 择期处理原发病灶

## UC 术式
### 一、IPAA(回肠储袋肛管吻合)
- **金标准**
- 全结肠直肠切除 + 回肠 J 型储袋
- 保留肛门、控便
- 贮袋炎(30-50%)是主要远期问题

### 二、末端回肠造瘘
- **全结直肠切除 + 永久性回肠造瘘**(Brooke)
- 适合高龄、肛门功能差

### 三、IPAA vs 永久造瘘
- 60-80% UC 患者适合 IPAA
- 直肠癌变、肛门失禁:永久造瘘

## 围手术期管理
- 停用硫唑嘌呤 2 周、甲氨蝶呤 1 周
- **英夫利西**:围手术期可继续
- **糖皮质激素**:尽量减量至泼尼松 < 20 mg/d
- **营养支持**:CD 营养不良多见
- **预防血栓**(IBD 本身高凝)
- **预防感染**:抗生素

## 术后监测
- 内镜、影像
- 复发监测(回肠末端镜、粪钙卫蛋白)
- CD 术后 5 年内镜下复发 60-80%
- 贮袋炎:益生菌、美沙拉秦、灌袋、布地奈德、生物制剂

## 注意事项
- CD 是「良性病恶性表现」,反复手术风险高
- 重视心理、营养、生育
- 戒烟(CD 复发重要因素)
- 妊娠期:多数药物安全(英夫利西、阿达木)
- 监测:肠镜(癌变)、影像
- 多学科(MDT)决策:胃肠、影像、营养、手术
