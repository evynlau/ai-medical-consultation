# 口腔 X 线片检查

## 概述
口腔 X 线片是口腔疾病诊断最常用、最基础的影像学方法,包括根尖片、咬合片、全景片等。X 线通过不同密度组织(牙釉质、牙本质、骨、软组织)的衰减形成影像,可显示龋坏、根尖周病变、牙周骨、颌骨等多方面信息。

## 口腔 X 线片类型

### 1. 根尖片(Periapical radiograph)
- **应用**:最常用
- **范围**:3-4 颗牙 + 根尖周
- **优点**:清晰度高、分辨率高
- **缺点**:范围小
- **适应证**:牙髓炎、根尖周炎、牙折、根管治疗评估

### 2. 咬合片(Occlusal radiograph)
- **应用**:腭部、颌骨、上颌窦、颌下腺导管
- **范围**:较大区域
- **适应证**:腭裂、埋伏牙、颌骨囊肿、上颌窦

### 3. 全景片(Orthopantomogram, OPG)
- **应用**:筛查、整体评估
- **范围**:全口牙 + 双侧颌骨 + 颞下颌关节
- **优点**:范围广、放射量低
- **缺点**:分辨率低、有放大、有重叠
- **适应证**:智齿拔除前、颌骨病变、TMJ 初筛、修复前评估

### 4. 头颅侧位片(Lateral cephalogram)
- **应用**:正畸
- **适应证**:错颌畸形分析、生长发育评估

### 5. 头颅正位片(PA cephalogram)
- **应用**:颌面不对称、骨折

### 6. 翼片(Bitewing radiograph)
- **应用**:冠部龋坏、牙槽嵴高度
- **适应证**:早期邻面龋、牙周骨水平

## 根尖片拍摄技术

### 设备
- 牙科 X 光机(60-70 kVp, 7-10 mA)
- 数字传感器(CR、DR)或传统胶片
- 平行投照 / 分角线投照

### 步骤
1. 患者坐位,头部固定
2. 胶片 / 传感器放置(口内)
3. **平行投照**(长锥):平行 / 长筒
4. 曝光(短时间)
5. 冲洗(传统)或传输(数字)

### 平行投照 vs 分角线投照
- **平行投照**(长锥):更准确,失真小
- **分角线投照**:传统,失真较大

## 数字成像 vs 传统胶片

### 数字成像(DR/CR)
- **优点**:
  - 曝光量减少 50-90%
  - 即时图像
  - 图像后处理(增强、放大)
  - 便于存储、传输
  - 环保
- **缺点**:初始投入高

### 传统胶片
- 优点:成本低
- 缺点:曝光量大、需冲洗、储存不便

## 适应证

### 龋病
- 浅龋不显影(影响小)
- 中深龋清晰(透射影)
- 邻面龋(翼片最佳)

### 牙髓病
- 深龋近髓
- 根管治疗评估
- 牙根吸收、内吸收

### 根尖周病
- **根尖片**:必备
- 根尖透射影、骨密度改变
- 慢性根尖脓肿、骨膜下脓肿(弥漫性透射)
- 根尖囊肿

### 牙周
- **翼片 + 根尖片**:牙槽骨水平
- 骨丧失类型、程度
- 根分叉病变

### 外伤
- 冠折、根折
- 牙脱位
- 颌骨骨折

### 发育
- 牙根发育
- 阻生牙、埋伏牙
- 多生牙
- 牙瘤、囊肿

### 肿瘤
- 牙源性 / 非牙源性肿瘤
- 成釉细胞瘤、牙骨质瘤等

### 唾液腺
- 结石(咬合片、唾液腺造影)
- 颌下腺导管结石

### TMJ
- 关节间隙、骨质改变(许勒位、经咽侧位)
- 不如 CBCT、MRI

### 拔牙 / 手术前
- 牙根形态、根分叉
- 与下颌管、上颌窦关系

## 正常影像识别

### 牙体
- 牙釉质(最致密、白)
- 牙本质(浅灰)
- 牙髓腔、根管(低密度)
- 牙骨质

### 牙周
- **牙槽骨嵴顶**:距 CEJ < 2 mm
- 牙周膜(细黑线)
- 骨硬板(白线)

### 根尖周
- 正常:无透射影

### 解剖标志
- 颏孔、下颌管、上颌窦
- 腭中缝、鼻腔
- 颞下颌关节

## 异常影像

### 透射影(低密度)
- 龋坏
- 根尖周病变
- 囊肿、肿瘤
- 骨折线

### 不透射影(高密度)
- 充填体、修复体
- 牙石、骨硬化
- 骨瘤、牙瘤
- 异物

### 混合型
- 牙骨质瘤、骨化纤维瘤

## 局限

### 根尖片
- 早期龋、早期骨丧失不易显示
- 根管充填细节
- 解剖结构重叠

### 全景片
- **分辨率低**
- 重叠(颈椎)
- 早期根尖病变(密度叠加掩盖)
- 失真(放大率不一)

## 注意事项
- **孕妇**:尽量避免(尤其孕早期)、铅衣保护
- **儿童**:减少曝光、低剂量、儿童模式
- **甲状腺防护**(颈铅)
- **性腺防护**(铅围裙)
- **ALARA 原则**(合理低剂量)
- **数字成像**:曝光量小
- **术前、治疗后**常规拍片
- 解读需结合临床
- 重复拍片需有指征
