# 颈动脉超声

## 概述
颈动脉超声结合**二维灰阶、彩色多普勒、频谱多普勒**评估**颈动脉壁结构与血流动力学**,是**颈动脉粥样硬化、狭窄、闭塞**的首选无创筛查与随访工具。常规包括**颈总动脉(CCA)、颈内动脉(ICA)、颈外动脉(ECA)、椎动脉(VA)**。无创、可重复、无辐射,适用于卒中筛查、术前评估、随访。

## 适应证
- **脑卒中、TIA 筛查**
- **颈动脉粥样硬化随访**
- **颈动脉支架 / 剥脱术前评估、术后随访**
- **颈部杂音**
- **无症状颈动脉狭窄**(高危人群筛查)
- **颈部外伤、夹层**
- **颈部包块鉴别**
- **眩晕 / 后循环缺血**:评估椎动脉
- **血管炎**(Takayasu、GCA)
- **锁骨下盗血**
- **动脉瘤、夹层、动静脉瘘**
- **心脏手术前**(CABG 同期 CEA)

## 禁忌证
- **无绝对禁忌**
- **相对**:**颈部严重创伤、气管切开、敷料、不能配合**

## 检查前准备
- **安静休息 5-10 min**
- **禁烟、咖啡 2 h**
- **去枕仰卧位**、头偏向对侧
- **颈部充分暴露**

## 评估参数

### 1. 内中膜厚度(IMT)
- **正常 IMT**:**< 1.0 mm**
- **1.0-1.5 mm**:**内中膜增厚**(危险因素)
- **> 1.5 mm**:**斑块**(定义)
- 测量:**颈总动脉分叉下方 1-1.5 cm 远端壁**
- **意义**:**心脑血管事件独立预测因子**(MESA、ARIC 研究)

### 2. 斑块评估
- **形态**:
  - **规则 / 不规则**
  - **表面**:光滑、**溃疡**(> 2 × 2 mm 凹陷)
- **回声**(与胸锁乳突肌相比):
  - **低回声**(soft):脂质、出血,**不稳定**
  - **等回声**:纤维
  - **强回声**:钙化(后方声影)
  - **混合回声**
- **稳定性**:
  - **不稳定斑块**:**低回声 / 混合回声、薄纤维帽、溃疡、出血、表面不规则**
  - **稳定斑块**:**强回声、规则**

### 3. 血流动力学
#### 正常流速
| 部位 | PSV(cm/s) | EDV(cm/s) |
|---|---|---|
| **CCA** | 80-120 | 20-40 |
| **ICA** | 60-100 | 20-40 |
| **ECA** | 70-120 | 20-40 |
| **VA** | 30-60 | 10-25 |

#### 颈内动脉狭窄分级(SRU / ACAS)
| 狭窄 | PSV(cm/s) | EDV(cm/s) | PSV ICA/CCA |
|---|---|---|---|
| **正常 / < 50%** | < 125 | < 40 | < 2.0 |
| **50-69%** | 125-230 | 40-100 | 2.0-4.0 |
| **> 70%** | > 230 | > 100 | > 4.0 |
| **闭塞** | 无 | 无 | - |

> **90-99%**:PSV 显著增高 / EDV 增 / 远端减低
> **完全闭塞**:无血流信号

#### 频谱特征
- **正常**:收缩期陡升、舒张期持续
- **狭窄近端**:**「慢波」**、**圆钝**
- **狭窄处**:**频谱增宽、湍流**
- **远端**:**阻力降低、舒张期增高**(颅内阻力)
- **闭塞**:**无血流**

#### 椎动脉
- **椎动脉型 TIA / 后循环缺血**
  - **VA 起源异常**、**狭窄、闭塞**
  - **椎动脉流速降低**、**阻力指数**
- **锁骨下盗血**:**VA 逆向血流**(锁骨下狭窄)
  - 束臂试验阳性

## 临床应用
### 1. 颈动脉粥样硬化 / 狭窄
- **无症状**:
  - **< 60%**:内科治疗
  - **60-99%**:药物 vs 颈动脉内膜剥脱(CEA)/ 颈动脉支架(CAS)——个体化
- **症状性**:
  - **70-99%**:**CEA**(首选,**NASCET 标准**)
  - **50-69%**:男性、近 2 周内症状可获益
  - **< 50%**:药物
- **围 CEA / CAS**:术前定位、术后随访(6 月、12 月,后 1 年一次)
- **CEA 后监测**:**再狭窄**(> 70%):CAS 或再手术

### 2. 颈动脉夹层
- **青年卒中**重要原因
- **直接征象**:**管腔逐渐狭窄 / 火焰状闭塞**、**壁内血肿**(肌层低回声)
- **双腔征**
- **不规则壁**、**内膜片**

### 3. 颈动脉瘤
- **膨大> 50% 直径**、**瘤样扩张**

### 4. 椎动脉病变
- **椎动脉型 TIA、Wallenberg 综合征**:
  - 起源异常(主动脉弓或锁骨下)
  - 狭窄、闭塞
- **锁骨下盗血综合征**:
  - 患侧 VA 收缩期**反向或双向**
  - 束臂试验(握拳 + 加压 → 释放)
  - 患侧桡动脉搏动减弱、双上肢血压差 > 20 mmHg

### 5. 颈动脉体瘤
- **颈总分叉处低回声、血供丰富包块**
- 排挤 ICA、ECA

### 6. Takayasu 动脉炎
- **年轻女性、亚洲**、**大动脉受累**
- 颈动脉、锁骨下动脉壁增厚,**「通心粉征」**、**「环周增厚」**(长节段)
- 活动期:管壁低回声

### 7. 颈部放疗后
- 颈动脉壁增厚、狭窄加快

## 操作要点
- **探头**:**7.5-10 MHz 线性**(体瘦);**5 MHz**(深部)
- **三个位面**:横切、纵切、冠状
- **连续扫查**:CCA、ICA、ECA、VA
- **纵切面测流速、IMT**
- **频谱采样**:**声束与血流夹角 < 60°**,通常 45-60°

## 注意事项
- **狭窄评估**:**长节段、严重钙化**可致声影、流速不准确
- **近端狭窄**(主动脉、无名动脉)可能高估 ICA
- **对侧 ICA 闭塞**:同侧 ICA PSV 代偿增快(生理性)
- **串联病变**:颅内 ICA 狭窄可致颈段 ICA 速度降低
- **斑块溃疡**:**> 2 mm 凹陷**:**增加卒中风险**
- **CEA 术后随访**:**再狭窄多在 1-2 年**
- **椎动脉不显影**:**椎动脉发育不良 / 闭塞**(需结合对侧)
- **束臂试验**:**锁骨下盗血**确诊
- **影响流速因素**:**心功能、贫血、甲亢**(PSV 升高)
- **限制**:**不能直接显示颅内段 ICA**(TCD / CTA 补充)
- **颈动脉斑块随访**:6-12 月一次,IMT 增厚 / 新发斑块 → 强化他汀
- **高强度他汀**:**LDL-C < 1.8**(颈动脉斑块强适应证)

## 报告基本要素
1. **双侧颈总、颈内、颈外、椎动脉**
2. **IMT**、**斑块(部位、回声、大小、形态、是否溃疡)**
3. **流速(PSV、EDV)、频谱形态**
4. **狭窄程度**(SRU / ECST / NASCET 标准化)
5. **侧支、闭塞、夹层等**
6. **建议**(MRA / CTA / 神经科 / 心血管危险因素评估)
