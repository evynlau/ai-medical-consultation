# 痤疮诊治

## 概述
痤疮(Acne Vulgaris)是毛囊皮脂腺单位的慢性炎症性皮肤病,以粉刺、丘疹、脓疱、结节、囊肿及瘢痕为特征。青少年发病率 35-90%,成人持续型(尤其女性)逐渐增多。中国痤疮患病率在 12-25 岁约 8.1%。

## 病因与发病机制
四大发病环节:
1. **皮脂分泌亢进**(雄激素作用)
2. **毛囊角化异常**(毛囊漏斗部角栓形成)
3. **痤疮丙酸杆菌**(C.acnes)增殖
4. **炎症反应**(IL-1、TLR 受体激活)
- **诱因**:遗传、雄激素、月经周期、饮食(高 GI、奶制品)、压力、化妆品、药物(糖皮质激素、锂、雄激素、抗癫痫药)

## 临床表现与分级
### Pillsbury 四级分类
- **轻度(I)**:粉刺(黑头、白头),少量丘疹脓疱
- **中度(II)**:I + 较多丘疹脓疱,皮损限于面部
- **中度(III)**:II + 结节,面部、躯干
- **重度(IV)**:囊肿、聚合性、瘢痕

### 中国改良分级(更细化)
- Ⅰ级:粉刺为主
- Ⅱ级:粉刺 + 丘疹脓疱
- Ⅲ级:有结节
- Ⅳ级:囊肿、瘢痕

### 特殊类型
- **聚合性**:多发囊肿、窦道、瘢痕
- **暴发性**:突发全身溃疡、发热、关节痛、白细胞↑
- **新生儿 / 婴儿 / 青春期前**:注意内分泌评估
- **化妆品性**、**药物性**、**职业性**

## 辅助检查
- **典型者**:临床诊断
- **顽固型 / 女性迟发 / 多毛 / 月经稀发**:性激素、睾酮、LH/FSH、孕酮、催乳素、卵巢超声(排除 PCOS)
- **聚合性 / 暴发性**:血常规、ESR、骨髓(排除 SAPHO)

## 治疗

### 外用药(轻度及辅助)
- **维 A 酸类**:阿达帕林、维 A 酸(0.025%、0.05%)、他扎罗汀(粉刺溶解 + 抗炎)
- **过氧化苯甲酰**(BPO):2.5-5%,杀菌 + 轻度溶解粉刺,不产生耐药
- **抗生素**:克林霉素、夫西地酸、红霉素(避免单独使用,> 12 周耐药)
- **联合**:BPO + 阿达帕林(BPO 早上,维 A 酸晚上),效果最佳

### 系统治疗

#### 中度及以上 / 顽固型
- **抗生素**(口服):多西环素 100 mg bid、米诺环素 50 mg bid、阿奇霉素脉冲疗法;**疗程 ≤ 8 周**,须联合 BPO 防耐药
- **异维 A 酸**(Isotretinoin,13-顺式维 A 酸):
  - **指征**:重度、结节囊肿性、聚合性、瘢痕倾向、其他治疗失败
  - **剂量**:0.5-1 mg/kg/d,目标累积剂量 120-150 mg/kg
  - **疗程**:5-8 个月
  - **效力**:抑制皮脂分泌 + 抗角化 + 抑菌 + 抗炎(几乎 100% 起效)
  - **监测**:肝功能、血脂、血糖;育龄女性严格避孕(致畸,避孕 1 个月前、治疗中、停药 3 个月后)

#### 女性激素相关
- **达英-35**(复方醋酸环丙孕酮):月经后 1-5 d 起服,21 d 周期
- **螺内酯**:抗雄激素,40-200 mg/d
- **避孕药**(含雌孕激素联合)

### 物理治疗
- **光动力(PDT)**:ALA + 红光,中重度炎症性
- **强脉冲光(IPL)**:红印、毛细血管扩张
- **点阵激光**:萎缩性瘢痕
- **化学剥脱**:果酸(20-70%)、水杨酸(20-30%)、TCA:粉刺、痘印
- **囊肿内注射**:曲安奈德(单发顽固结节)

## 注意事项
- **饮食**:低 GI、限制脱脂奶 / 乳清蛋白、巧克力
- **皮肤护理**:温和洁面、保湿、不挤痘、防晒(预防色素沉着)
- **疗程长**:维 A 酸起效 4-8 周,异维 A 酸 4-6 周起效
- **耐药管理**:避免长期单用外用抗生素;红霉素、克林霉素耐药率高
- **暴发性痤疮**:泼尼松短期 + 异维 A 酸(先控制炎症)
- **心理影响**:重度者抑郁、社交回避,需关注
- **婴幼儿痤疮**:6 月前不治疗(< 1 岁多自愈),注意性早熟
