# 艾滋病 HAART

## 概述
艾滋病(HIV/AIDS)由人类免疫缺陷病毒(HIV)感染引起。我国估计**现存活 HIV 感染者/AIDS 患者约 122 万**。**高效抗反转录病毒治疗(HAART)**使 HIV 成为慢性可控疾病,规范治疗者预期寿命接近正常。**早发现、早治疗**(无论 CD4)**是关键**。

## 病原
- **HIV-1**(全球、我国主要)
- **HIV-2**(西非、罕见)
- 攻击 **CD4⁺ T 细胞**
- 单链 RNA 病毒,反转录病毒科

## 传播
- **性传播**(同性、异性)
- **血液**:共用针具、输血、血制品
- **母婴**:胎盘、产道、母乳

## 临床表现

### 急性期(2-4 周)
- 单核细胞增多症样:发热、咽痛、淋巴结、肌痛、皮疹
- 多自限

### 无症状期(数年)
- CD4 缓慢下降(每年 50-80)

### 艾滋病期
- CD4 < 200(部分 < 350)
- **机会性感染**:
  - **PCP**(耶氏肺孢子菌肺炎):CD4 < 200
  - **弓形虫脑病**:CD4 < 100
  - **CMV 视网膜炎、食管炎**:CD4 < 50
  - **鸟分枝杆菌(MAC)**
  - **隐球菌脑膜炎**
  - **TB**(常现,任何 CD4)
- **肿瘤**:
  - **卡波西肉瘤**(KS,HHV-8)
  - **淋巴瘤**(原发 CNS、Burkitt)
  - **宫颈癌**
  - **肛门癌**
- **HIV 消耗综合征**、痴呆

## 诊断
- **初筛**:
  - **第四代抗原抗体联合**(HIV Ag/Ab Combo):可 2-4 周阳性
  - **快速试纸**(指尖血)
- **确证**:
  - **蛋白印迹(WB)**
  - **HIV-1/HIV-2 抗体分型**
  - **核酸检测(NAT, HIV RNA)**:急性期
- **CD4⁺ T 淋巴细胞**(基线 + q3-6 月)
- **HIV RNA(病毒载量,VL)**:基线 + 治疗中
- **耐药检测**(Genotype):治疗前、失败时

## HAART 治疗

### 治疗指征
- **所有 HIV 感染者**(无论 CD4) — WHO 2015 起
- 妊娠、活动性 TB/机会性感染、肾病、心血管高风险

### 目标
- **VL < 50 copies/mL**(不可检测)
- CD4 恢复(每年 50-150)
- 预防机会性感染、减少传播

### 一线方案(我国 2023、中国艾滋病诊疗指南)
- **整合酶抑制剂(InstI)为核心**:
  - **多替拉韦(DTG) + TDF/FTC**(TDF/FTC+DTG)
  - **多替拉韦 + 3TC**(部分)
  - **比克替拉韦(BIC) + TAF/FTC**
- **非核苷类(NNRTI)**:依非韦伦(EFV)、利匹韦林(RPV)
  - **多拉韦林(DOR)**:新 NNRTI
- **蛋白酶抑制剂(PI)**:**克力芝**(LPV/r)、多替阿巴拉那(DRV/c)
- **核苷(NRTI)骨架**:
  - TDF(替诺福韦)/FTC
  - **TAF**(丙酚替诺福韦)/FTC
  - **ABC**(阿巴卡韦)/3TC(必查 HLAB*5701)

### 优选方案
- **DTG + 3TC**(2 药方案,部分 1L)
- **BIC/TAF/FTC**(B/F/TAF)
- **DTG + TDF/FTC**
- **DTG + ABC/3TC**

### 特殊人群
- **妊娠**:DTG + TDF/FTC(2024 优选)
- **HBV 共感染**:含 TDF/FTC、TAF/FTC
- **TB**:**DTG + TDF/FTC + 多利培南**(1L TB 治疗) → **3TC 序贯**
- **肾功能不全**:避免 TDF(改 TAF 或 ABC)
- **儿童**:ABC + 3TC + LPV/r / DTG
- **静脉吸毒**:BUP + 哈药,依非韦伦 + TDF/FTC

## 机会性感染预防
- **CD4 < 200**:**SMZ-TMP 1 片 qd**(PCP)
- **CD4 < 100**:**弓形虫预防**(SMZ-TMP 1 片 qd)
- **CD4 < 50**:**CMV 筛查**(眼底)
- **复方新诺明**耐药:喷他脒(气雾)、阿托伐醌

## 免疫重建炎症综合征(IRIS)
- 治疗中免疫恢复 → 既往感染(隐球菌、TB、JCV)炎症反应
- 表现:发热、淋巴结肿大、原有病灶加重
- 处理:**继续 HAART**;糖皮质激素(中-重)

## 监测
- **基线**:CD4、VL、HLA-B*5701、肝肾、血脂、HBV/HCV/TP
- **治疗中**:
  - VL 4-8 周后下降,6 月应 < 50
  - CD4 3-6 月 1 次
  - 肝肾、血脂、血糖
  - 生育/性伴侣咨询

## HIV 暴露处理(职业)
- **立即**:冲洗、消毒、上报
- **PEP**(72 h 内,4-6 周 3 药):DTG + TDF/FTC
- 随访 HIV 抗体 6 周、12 周、6 月

## 母婴阻断
- 孕妇 HAART
- **剖宫产**(VL > 1000)
- 婴儿预防性抗病毒(2-4 周)
- 人工喂养
- 阳性率 < 1%

## 注意事项
- **依从性是治疗核心**(< 95% 易耐药)
- **不可单药治疗**
- 治疗前**基线耐药**(尤其 NNRTI 区)
- 药物相互作用(如利福平 + PI)
- **TDF 肾毒、骨密度**
- **DTG 增重、罕见神经管畸形**(妊娠早期)
- **ABC 超敏**(HLA-B*5701+)
- 心理支持、歧视防治
- **定期筛查**:性传播、HPV、肛肠癌、宫颈癌
- **心理咨询、戒毒**(如有)
