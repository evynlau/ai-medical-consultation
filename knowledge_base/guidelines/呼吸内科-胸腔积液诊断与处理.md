# 胸腔积液诊断与处理

## 概述
胸腔积液是胸膜腔内液体异常聚积。我国病因最常见为结核性、恶性、肺炎旁(类肺炎旁 / 复杂性肺炎旁积液 / 脓胸)和心衰漏出液。

## 病理生理
- 胸膜腔每天产生 100-200 mL 液体(壁层胸膜),由壁层淋巴管回吸收
- 产生过多 / 回吸收障碍 → 积液
- 漏出液(静水压↑/胶体压↓)vs 渗出液(通透性↑)

## 病因
### 漏出液
- 心衰(最常见)
- 肝硬化(肝性胸水,右侧多见)
- 肾病综合征
- 黏液性水肿
- Meigs 综合征(卵巢纤维瘤)

### 渗出液
- **感染**:肺炎旁、TB、病毒、真菌
- **肿瘤**:肺癌、转移性(乳腺、淋巴瘤)、间皮瘤
- **PE**:肺梗死
- **结缔组织病**:RA、SLE
- **胰腺炎**(左侧)、食管破裂
- **乳糜胸**:胸导管损伤、肿瘤阻塞
- **药物**:胺碘酮、呋喃妥因、苯妥英

## 临床表现
- **症状**:呼吸困难、咳嗽、胸痛(胸膜性)、端坐呼吸
- 体征:患侧胸廓饱满、语颤减弱、叩浊、呼吸音减弱或消失
- 大量积液:气管向对侧移位
- **量**:
  - 少量:< 300 mL(仅肋膈角变钝)
  - 中量:500-1500 mL
  - 大量:> 1500 mL

## 影像学
- **胸片**:
  - 站立后前位:> 200 mL 可见
  - 侧卧位:10 mL 即可见
  - **包裹性**(胸膜粘连时)
- **超声**:
  - 敏感度 95%+
  - 引导穿刺
  - 评估分隔、包裹
- **CT**:
  - 详细评估:位置、量、有无包裹、纵隔淋巴结、肺实质
  - 鉴别良恶性(胸膜结节、增厚)
- **PET/CT**:恶性鉴别

## 诊断性胸腔穿刺
- **指征**:
  - 单侧积液 + 病因不明
  - 发热 / 胸痛
  - 不像漏出液
  - 大量积液
- **禁忌**:凝血严重异常、不能配合(相对)
- **位置**:腋后线 7-9 肋间(叩浊区),B 超定位
- **常规送检**:
  - 常规 + 生化(蛋白、LDH、葡萄糖)
  - 细胞计数 + 分类
  - 细菌培养 + 药敏
  - 细胞学(3 次阳性率 60-80%)
  - pH(需血气分析仪,肝素化注射器)
  - ADA(腺苷脱氨酶,TB 敏感)
  - 根据临床:乳糜试验、淀粉酶、免疫指标

## Light 标准(渗出液)
满足任一:
- 积液蛋白 / 血清蛋白 > 0.5
- 积液 LDH / 血清 LDH > 0.6
- 积液 LDH > 2/3 正常上限

## 漏出液 vs 渗出液
| 特征 | 漏出 | 渗出 |
|---|---|---|
| 外观 | 透明、淡黄 | 混浊、血性、脓性 |
| 蛋白 | < 30 g/L | > 30 g/L |
| 比重 | < 1.015 | > 1.018 |
| Rivalta | 阴性 | 阳性 |
| 细胞数 | < 500 | > 500 |
| LDH | 低 | 高 |
| 病因 | 心衰、肝硬化、肾 | 感染、肿瘤、PE |

## 各类胸水特征
- **肺炎旁(单纯)**:中性粒、pH > 7.2、葡萄糖 > 60、LDH < 1000
- **复杂性肺炎旁**:pH < 7.2、葡萄糖 < 60、LDH > 1000、细菌阳性 → **需引流**
- **脓胸**:脓性、细菌阳性 → 闭式引流
- **结核性**:淋巴细胞为主、ADA > 40、IFN-γ ↑、培养(+)率 < 20%
- **恶性**:血性多见、细胞学(+) 60-80%、CEA ↑
- **乳糜胸**:乳白色、甘油三酯 > 1.24 mmol/L、乳糜微粒
- **类风湿**:葡萄糖极低(< 30)、LDH ↑、LDH / 血清 > 2

## 治疗
### 漏出液(治疗原发病)
- 心衰:利尿、强心
- 肝硬化:限盐、利尿、TIPS
- 难治:胸穿抽液、留置导管、Denver 胸膜腹膜分流

### 渗出液
**肺炎旁积液 / 脓胸**:
- 单纯:抗生素
- 复杂性:**胸腔引流**(< 14 d 闭合)
- 包裹性:胸腔内纤溶(tPA + DNase)、VATS(胸腔镜清创)

**结核性胸腔积液**:
- 抗结核(HREZ 2 月 / HR 4 月)总疗程 6-9 月
- 中等量以上:**诊断性抽液 + 糖皮质激素**(泼尼松 30 mg/d × 2-4 周,渐减)

**恶性胸腔积液**:
- 治疗原发肿瘤
- 全身化疗 / 靶向 / 免疫
- **难治性**:
  - 胸膜固定术(滑石粉)
  - 留置导管(IPC)
  - 胸腔内化疗 / 硬化剂

**乳糜胸**:
- 低脂饮食、中链甘油三酯
- 病因治疗
- 持续:胸导管结扎

## 注意事项
- **包裹性积液**:B 超定位穿刺
- **血性积液**:不能直接诊断恶性(TB、PE、外伤)
- **双侧积液**:常为漏出(心衰、肾、肝);单侧多渗出
- **单侧大量积液 + 心脏小**:警惕恶性
- 老年 + 慢病 + 利尿不缓解:行胸穿
- 复发性积液:考虑 IPC(留置)
- 凝血障碍、血小板 < 50:慎穿
