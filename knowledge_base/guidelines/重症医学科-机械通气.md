# 机械通气

## 概述
机械通气(Mechanical Ventilation)是重症医学基础支持手段,提供氧合、通气支持,但本身可引起呼吸机相关肺损伤(VILI)、VAP、膈肌功能障碍。规范应用、维护、转撤是改善 ICU 预后的关键。

## 适应证
- **氧合障碍**:PaO₂ < 60 mmHg、SpO₂ < 90%
- **通气障碍**:PaCO₂ > 50 mmHg、pH < 7.25
- **呼吸衰竭**、呼吸肌疲劳
- **重大手术**:全身麻醉、心脏手术
- **颅内高压**:过度通气(短时)
- **神经肌肉疾病**:连枷胸、重症肌无力

## 基础概念

### 呼吸力学
- **Vt**(潮气量):6-8 ml/kg(肺保护 4-8 ml/kg)
- **f**(呼吸频率):12-20
- **I:E**(吸呼比):1:2
- **FiO₂**:21-100%
- **PEEP**:5-15 cmH₂O(ARDS)
- **Pplat**(平台压):≤ 30 cmH₂O
- **驱动压**(ΔP = Pplat - PEEP):≤ 15 cmH₂O

### 通气模式

#### 容量控制(VCV)
- 设置 Vt、f、FiO₂
- 压力随顺应性变化
- 平台压可高
- 适用于正常肺

#### 压力控制(PCV)
- 设置 Pin、f、FiO₂
- Vt 随顺应性变化
- 压力限制好
- 适用 ARDS、儿童

#### 压力调节容量控制(PRVC / VC+)
- 自动调节压力保证目标 Vt
- 兼顾两者

#### 同步间歇指令通气(SIMV)
- 强制呼吸 + 自主呼吸
- 用于撤机过渡

#### 压力支持(PSV)
- 自主呼吸 + 压力辅助
- 撤机首选
- **PS 6-8 cmH₂O**(克服管路阻力)
- **PS 8-15 cmH₂O**(部分支持)
- **PS 15-30 cmH₂O**(完全支持)

#### 持续气道正压(CPAP)
- 自主呼吸 + PEEP
- 用于撤机、阻塞性睡眠呼吸暂停

#### 双水平气道正压(BiPAP)
- 高压 IPAP + 低压 EPAP
- 类似 PS + PEEP
- 无创通气常用

#### 神经调节通气辅助(NAVA)
- 膈肌电活动(EAdi)触发
- 人机协调更好

#### 气道压力释放通气(APRV)
- 高水平持续 + 短时释放
- 适用 ARDS(争议)

#### 高频振荡(HFOV)
- 呼吸频率 3-15 Hz
- 小 Vt、高 mPaw
- ARDS:目前**不推荐常规**(OSCAR、OSCILLATE 失败)

## 初始设置
- **Vt**:6-8 ml/kg 理想体重
- **f**:12-20
- **PEEP**:5 cmH₂O 起
- **FiO₂**:维持 SpO₂ ≥ 92%
- **I:E**:1:2
- **触发**:压力 -1 至 -2 cmH₂O
- **流速**:60 L/min
- **湿化**:主动湿化(35-41°C)

## PEEP 设置
### 生理作用
- 防止肺泡萎陷、复张塌陷肺
- 增加 FRC、改善氧合
- 减少 VILI

### 选择策略
- **ARDSNet 表格**(按 FiO₂)
- **驱动压导向**:最小驱动压的 PEEP
- **最佳顺应性 PEEP**(P-V 曲线)
- **食道压**(Pes):维持呼气末正压高于胸腔压
- **电阻抗断层**(EIT):均质性最优
- **CT**:复张最大化

## 肺保护性通气(ARDS)
- **低潮气量**(LTVV):6 ml/kg(PBW)
- **平台压 ≤ 30 cmH₂O**
- **驱动压 ≤ 15 cmH₂O**
- **允许性高碳酸血症**(pH ≥ 7.20)
- **高 PEEP**(ARDSNet 高 PEEP)
- **俯卧位 ≥ 16 h/d**(PaO₂/FiO₂ < 150)
- **肌松剂 48 h**(重度)

## 撤机

### 评估每日
- 病因解决或改善
- 氧合:PaO₂/FiO₂ ≥ 200、PEEP ≤ 5-8
- 血流动力学稳定(无高剂量升压药)
- 意识清、能配合
- 咳嗽反射好
- 无高热、感染

### 自主呼吸试验(SBT)
- **30-120 min**
- T 管 / 低水平 PSV(5-8 cmH₂O)
- 评估:
  - 浅快呼吸指数(RSBI = f/Vt)< 105
  - 呼吸频率 8-35
  - SpO₂ ≥ 90%
  - HR、BP 变化 < 20%
  - 无明显窘迫

### 拔管
- SBT 通过 + 气道保护反射好
- 拔管前:气囊漏气试验(喉头水肿高危)
- 拔管后监测 ≥ 48 h
- **NIV / HFNC**(高危患者预防再插管)

### 拔管失败风险
- **HFNC**(经鼻高流量氧):拔管后预防
- **NIV**(无创正压通气):高风险 COPD、心衰
- 拔管后 48 h 内再插管 10-15%

## 监测

### 呼吸力学
- P-V 曲线:低位拐点(LIP)、高位拐点(UIP)
- 内源性 PEEP(Auto-PEEP):COPD、哮喘
- 顺应性:正常 50-80 ml/cmH₂O

### 血气
- 每日 + 变化时
- 调整 FiO₂、PEEP、f

### 影像
- 床旁胸片 / 超声每日评估
- 识别导管位置、肺部病变、气胸

### 容量
- 每日液体平衡
- 体重

## 并发症

### 呼吸机相关肺损伤(VILI)
- **气压伤**:气胸、纵隔气肿
- **容积伤**:过度膨胀
- **不张伤**:反复开放 / 关闭
- **生物伤**:炎症因子释放
- **预防**:低 Vt、低 Pplat、低驱动压

### 呼吸机相关肺炎(VAP)
- **48 h 后**机械通气肺炎
- 发生率 8-28%
- **预防**(集束化):
  - 半卧位 30-45°
  - 每日镇静唤醒 + 呼吸试验
  - 口腔护理(氯己定)
  - 声门下分泌物吸引
  - 避免胃过度扩张
  - 尽早撤机
  - 限输血

### 膈肌功能障碍
- 控制通气 18-24 h 开始萎缩
- **过度辅助**(PS 过高)也致废用
- **保护性自主呼吸**

### 氧中毒
- 长时间高 FiO₂(> 60%)
- 吸收性肺不张、自由基损伤
- 目标 FiO₂ < 60%

### 气管插管相关
- 误吸、口鼻损伤、声带损伤、声门下狭窄
- 气囊压力 25-30 cmH₂O

## 特殊通气

### 俯卧位通气
- ARDS PaO₂/FiO₂ < 150
- 每日 ≥ 16 h
- 连续 3-4 天
- 减少肺损伤、复张塌陷肺

### 无创通气(NIV)
- **指征**:
  - COPD 急性加重(首选)
  - 心源性肺水肿
  - 免疫抑制者低氧
  - 拔管后预防
- **相对禁忌**:意识障碍、呕吐、不能配合、气道分泌物多
- **设备**:BiPAP
- 起始:IPAP 8-12、EPAP 4-6

### 高流量氧疗(HFNC)
- **流量**:20-60 L/min
- **FiO₂**:21-100%
- **湿化温化**:37°C、100% 相对湿度
- **指征**:轻度-中度低氧、拔管后
- **生理**:冲洗鼻咽死腔、轻 PEEP 效应
- 耐受性好

### 体外支持(ECMO)
- **VV-ECMO**:呼吸衰竭
- **VA-ECMO**:心源性休克

## 注意事项

### 转运
- 充分固定、备便携呼吸器
- 转运中监测
- 物品齐全(吸引、氧、复苏)

### 撤机延迟
- 原因:心肺功能不全、神经精神、营养差
- 综合康复、运动训练
- 困难撤机(> 7 d):T 管、逐步降 PSV

### 长期机械通气
- 气管造瘘(> 7-14 d 通气)
- 长期护理、家庭通气

### 谵妄
- ABCDEF bundle
- 减少镇静

### 团队
- 呼吸治疗师(RT)
- 医生、护士
- 多学科查房
