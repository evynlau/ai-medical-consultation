# 咯血诊治

## 概述
咯血指喉以下呼吸道出血,经口腔咯出。**大咯血**指 24 h 出血 ≥ 200 mL 或单次 ≥ 100 mL 或出血速度致气道阻塞 / 窒息,需紧急处理。

## 病因

### 支气管肺疾病
- **支气管扩张**(最常见,中大量)
- 肺癌 / 支气管癌
- 肺炎、肺脓肿
- 肺结核
- 真菌感染(曲霉球)

### 心血管
- 二尖瓣狭窄(最常见心源性)
- 急性左心衰
- 肺栓塞 / 肺梗死
- 肺动静脉瘘

### 其他
- 出血体质、抗凝药
- 自身免疫病(肉芽肿性多血管炎、Goodpasture、贝赫切特)
- 胸外伤
- **医源性**(支气管镜活检、肺活检)
- 隐源性:10-20%

## 临床表现
- **咯出物性状**:
  - 鲜红:动脉血、肺癌
  - 暗红:慢支、支扩
  - 粉红色泡沫:急性左心衰
  - 脓血痰:肺脓肿
  - 铁锈色:肺炎球菌肺炎
- **伴随**:
  - 大量脓痰:支扩、肺脓肿
  - 午后低热、盗汗:TB
  - 呼吸困难:大量、窒息
  - 胸痛:PE、肺癌
- **前驱**:咽痒、咳嗽
- **窒息前兆**:
  - 咯血突然减少或停止
  - 胸闷、烦躁、挣扎
  - 面色发绀、呼吸急促
  - 意识障碍

## 鉴别诊断(三大出血)
| | 咯血 | 呕血 | 鼻咽部出血 |
|---|---|---|---|
| 病史 | 呼吸疾病 | 消化疾病 | 鼻咽部 |
| 颜色 | 鲜红 / 暗红 | 棕黑 / 暗红 | 鲜红 |
| 内容 | 痰 + 血 | 食物 + 血 | 鼻涕带血 |
| 酸碱 | 碱性 | 酸性 | 碱性 |
| 前驱 | 咽痒、咳 | 恶心、上腹痛 | 鼻塞、鼻血 |
| 大便 | 无特殊 | 黑便 | 无 |
| 痰色 | 持续血痰数天 | 无 | 无 |

## 严重度评估
- **少量**:< 100 mL/24h
- **中量**:100-500 mL/24h
- **大量**(大咯血):> 500 mL/24h 或 > 100 mL/次
- **致死性**:
  - 出血速度 > 150 mL/h
  - 窒息
  - 失血性休克

## 紧急处理

### 体位
- **患侧卧位**(防止血液流入健侧)
- 头低足高
- 清醒:坐位 / 半坐位,患侧朝下
- 昏迷:平卧、头偏一侧

### 保持气道通畅
- 头偏一侧
- 吸引器准备
- 窒息时:**紧急气管插管 / 硬镜吸引**

### 监护与支持
- 大口径静脉通道(2 条)
- 备血
- 监测 SpO₂、心率、血压
- 血常规、凝血、血型

### 药物治疗
- **垂体后叶素**:5-10 U 静推 + 10-20 U 持续泵入
  - 禁忌:高血压、冠心病、孕妇
- **酚妥拉明**:5-10 mg 静推 + 持续
- **氨甲环酸**:1 g 静推 + 持续
- **巴曲酶**:1-2 kU 静推
- **抗生素**:感染性(肺炎、TB)
- **镇静**:地西泮 5-10 mg
- **止咳**:可待因 30 mg(中等量,大咯血禁用)

### 介入 / 手术
- **支气管动脉栓塞(BAE)**:
  - 适应:大咯血、内科无效
  - 急诊 / 抢救
  - 成功率 75-90%
- **外科手术切除**:
  - 适应:BAE 失败、明确部位、不能 BAE
  - **24 h 内 > 600 mL** → 死亡率高
- **支气管镜**:
  - 诊断 + 治疗(冰盐水 + 肾上腺素、电凝、激光)

## 各病因治疗

### 支气管扩张咯血
- 抗感染(铜绿假单胞菌重点)
- 体位引流
- BAE(首选)
- 反复发作:手术切除

### 肺结核咯血
- 抗结核(HRZE)
- 加用垂体后叶素
- BAE(主支气管动脉)

### 肺癌咯血
- 支气管镜下止血
- 放疗(止血 + 抗肿瘤)
- 介入栓塞(支气管动脉 + 肺动脉)
- 姑息治疗

### 心源性咯血
- 治疗心衰(利尿、扩血管)
- 二尖瓣狭窄:球囊成形 / 换瓣

## 窒息抢救
1. 体位引流:头低足高、患侧朝下
2. 拍背
3. 吸引(口鼻、气管插管)
4. 紧急硬镜吸引 / 取出血块
5. 高频通气
6. 心肺复苏(必要时)

## 注意事项
- **窒息是大咯血主要死因**,不是失血性休克
- 失血性休克罕见(> 1000 mL)
- **不能**为了"止血"而镇咳过度(排血不畅 → 窒息)
- 老年人合并症多,预后差
- 反复咯血:戒烟、感染控制、规律随访
- **儿童咯血**:气管异物、TB、特发性含铁血黄素沉着症
