# 经颅多普勒超声

## 概述
经颅多普勒超声(TCD)是利用**低频超声**(2 MHz)穿透颅骨薄区(颞窗、枕窗、眼窗、颌下窗),探测**颅内大动脉血流速度、频谱、方向**的无创床旁检查。主要评估**脑血流动力学、血管痉挛、狭窄、闭塞、栓子监测、侧支循环及脑死亡**。优点:无创、可重复、实时、床旁、成本低;缺点:操作者依赖、颅骨穿透差(尤其老年人、女性)。

## 适应证
- **蛛网膜下腔出血后脑血管痉挛监测**
- **急性缺血性脑卒中**:
  - 颅内大血管闭塞 / 狭窄的诊断与监测
  - 溶栓 / 取栓术前评估
  - 侧支评估(Willis 环)
- **颅内动脉狭窄筛查**(Moyamoya、动脉粥样硬化)
- **微栓子监测(MES)**:CEA / CAS 术中、卵圆孔未闭、心源性
- **右向左分流筛查**(PFO)
- **镰状细胞病**卒中风险评估
- **脑死亡诊断与确诊试验**
- **颅高压 / 脑循环停止**:舒张期血流、振荡波、钉子波
- **颈动脉内膜剥脱术监测**

## 检查窗与探测血管

| 窗 | 部位 | 可探测血管 |
|---|---|---|
| **颞窗** | 颧弓上方 | MCA(主要)、ACA、AcoA、ICA-T、PCA |
| **枕窗** | 枕骨大孔 | VA(椎动脉)、BA(基底动脉)、PICA |
| **眼窗** | 闭合眼睑 | OA(眼动脉)、CS(颈内动脉海绵窦段) |
| **颌下窗** | 下颌角下 | 颈外、ICA 起始、ECA |

**深度(Depth)**:
- MCA:**50-55 mm**(中段)
- ACA:**70-80 mm**(对侧 A1)
- PCA:**60-70 mm**(P1、P2)
- BA:**80-100 mm**
- VA:**55-80 mm**

## 评估参数

### 1. 血流速度(CMFV)
- **MCA**:60-80 cm/s(平均)
- **ACA**:50-70 cm/s
- **PCA**:40-60 cm/s
- **VA、BA**:40-60 cm/s

### 2. 狭窄诊断
- **平均流速 > 120 cm/s**(MCA):**提示狭窄**
- 高度狭窄:
  - **> 80 cm/s**:侧枝代偿
  - **狭窄段 MFV 升高 + 远端衰减**(低)
- 严重狭窄 / 闭塞:
  - 远端流速明显减低
  - **侧支代偿**(对侧 A1、ACoA、PCoA)

### 3. Lindegaard 指数(LR)
**LR = MFV_MCA / MFV_ICA 颈段**
- **> 3**:**脑血管痉挛**
- **> 6**:**重度痉挛**
- 鉴别:**全脑充血** vs **血管痉挛**:
  - 充血:颅内、颅外血流均增快,LR < 3
  - 痉挛:仅颅内,LR > 3

### 4. 频谱
- **正常层流**:正相、收缩期陡、舒张期
- **狭窄/痉挛**:频谱紊乱、湍流、**「乐性杂音」**(高强度信号)
- **狭窄远端**:**「慢波」**(波形圆钝、峰时延后)
- **颅高压**:舒张期血流减低 → 震荡波 → **钉子波**(收缩期短钉、舒张期无流)→ 血流消失

### 5. 搏动指数(PI)
- **PI = (PSV - EDV) / MFV**
- 正常 **0.6-1.1**
- **PI 升高**:**颅高压、远端狭窄**
- **PI 降低**:**动静脉瘘、贫血**

### 6. 微栓子信号(MES)
- **HITS**(高强度短暂信号):短时程(< 300 ms)、强度 > 3 dB、单向、伴声
- **气栓**:典型「鸟鸣」样
- **固体栓**:不同
- 监测:CEA / CAS 术中、PFO、房颤

### 7. 脑死亡 TCD 模式
- **收缩期小钉波**(钉子波)
- **舒张期无血流**
- **振荡波**(reverberating flow):收缩期正向、舒张期反向
- 排除:10-30 min 内可逆恢复
- **必须双侧、多窗**

## 临床应用
### 1. SAH 血管痉挛
- **监测时机**:**出血后 3-14 d**
- 每日 TCD + LR > 3 提示痉挛
- LR > 6 高度提示
- 配合 CT 灌注 / CTA

### 2. 缺血性脑卒中
- **超急性期**:**大血管闭塞**(MCA M1)诊断
- **取栓术后**:**血管再通评估**(TICI 对应)
- **颈动脉闭塞**:**颞窗信号消失**+**侧支开放**
- **微栓子**:**提示动脉-动脉栓塞源**

### 3. 颅内动脉狭窄
- **大脑中动脉狭窄**:
  - MFV 140-200 cm/s:轻
  - 200-280:中
  - > 280:重
- 抗血小板 / 强化他汀 / 支架

### 4. 镰状细胞病
- **TAMV**(时间平均最大流速) **> 200 cm/s**:**儿童卒中高危**
- 启动输血治疗

### 5. 颈动脉内膜剥脱 / 支架
- **术中监测**:夹闭时残端压、EEG、TCD
- **MES 监测**:中风风险
- **术后高灌注**:MFV ↑ > 100% 警惕

### 6. PFO 筛查
- **盐水激发试验**(agitated saline):经肘静脉、配合 Valsalva
- **微气泡**:**> 10 s 内**颅内出现 → 右向左分流

## 检查前准备
- **禁烟、禁咖啡 2 h**
- **休息 5-10 min**
- 避免高噪音(影响频谱)
- **充分耦合剂**

## 注意事项
- **颞窗穿透失败**:**老年人、女性、颞骨增厚**——约占 10-20%
  - 处理:**改眼窗、枕窗**;经眼窗避免功率 > 10%(白内障风险)
- **MCA 与 PCA 同深度重叠**:通过**颈动脉按压**(诊断颞浅)、**睁闭眼**(PCA 改变)鉴别
- **血管痉挛** vs **充血**:LR 比值鉴别
- **MCA 平均流速 > 200 cm/s**:**高度提示严重痉挛**,需紧急处理(3H、Nimodipine)
- **脑死亡 TCD**:**必须双侧、多次、经验丰富的医师**,结合临床判定
- **PFO 检查**:Valsalva 动作质量影响敏感性
- **可与 CTA、MRA 联合**:TCD 敏感 + 影像直观
- **微栓子监测**:CEA 术中
- **流速变化绝对值**意义小于**相对变化**(自身对照)

## 局限性
- **颞窗穿透差**:10-20% 患者
- **深穿支、皮质小动脉**难显示
- **不能替代 DSA** 确诊动脉瘤、AVM
- **严重狭窄/闭塞** 远端流速可低
- **术者依赖**
