# 检验科-降钙素原检测

## 概述
降钙素原（Procalcitonin，PCT）是降钙素（calcitonin）的前体肽，由甲状腺滤泡旁细胞（C细胞）合成。正常情况下， PCT在甲状腺C细胞内被水解为降钙素，因此血清水平极低（<0.05ng/mL）。当严重细菌感染、脓毒症、全身性炎症反应时，甲状腺以外的组织（如肺、肝、肾、胃肠道）也能大量产生PCT，导致血清浓度显著升高。PCT是目前最具特异性的细菌感染标志物之一，其水平与感染严重程度呈正相关，被广泛用于细菌感染性疾病的辅助诊断、抗生素治疗决策、危重症患者预后评估。

## 检查方法
- **标本采集**：静脉采血2-3ml，注入含促凝剂或分离胶的真空采血管中，室温静置30分钟待其充分凝固后，离心分离血清进行检测。
- **标本类型**：血清（首选）、血浆（肝素抗凝血浆可用）。
- **标本保存**：血清样本可在室温保存24小时，2-8℃冷藏可保存5天，-20℃以下冷冻可保存3个月。避免反复冻融。
- **检测方法**：
  - **电化学发光免疫分析法（ECLIA）**：采用双抗体夹心原理，灵敏度高达0.02ng/mL，是目前临床最常用的方法（如罗氏 Cobas 系统）。
  - **化学发光免疫分析法（CLIA）**：灵敏度与ECLIA相当，自动化程度高。
  - **免疫层析法（POCT）**：床旁快速检测，灵敏度约0.1-0.5ng/mL，适用于急诊和ICU床旁检测。
  - **酶联免疫吸附法（ELISA）**：灵敏度较高，但操作复杂，临床少用，主要用于科研。
- **结果报告**：以ng/mL或μg/L表示（1ng/mL=1μg/L）。

## 正常参考值
- **正常人**：<0.05ng/mL（<0.5μg/L）
- **健康新生儿**：出生后24小时内可生理性升高至约2ng/mL，之后逐渐下降，72小时后恢复正常。
- **老年人**：参考值同成人。
- **妊娠期女性**：参考值同成人，但部分研究发现妊娠晚期可轻度升高。

## 临床意义
### PCT升高的常见原因
- **细菌感染**：是PCT升高最主要的临床原因。
  - **脓毒症/菌血症**：PCT显著升高，常>2ng/mL，甚至可达数十至数百ng/mL，是诊断脓毒症的重要辅助指标。
  - **社区获得性肺炎（CAP）**：细菌性肺炎PCT常>0.25ng/mL，病毒性肺炎多<0.1ng/mL。
  - **细菌性脑膜炎**：PCT显著升高，是细菌性脑膜炎与病毒性脑膜炎鉴别的重要指标。
  - **腹腔感染**：腹膜炎、胆管炎、阑尾炎等。
- **真菌感染**：侵袭性真菌感染（如侵袭性曲霉病、念珠菌血症）可中度升高，但需注意与细菌感染鉴别。
- **全身性炎症反应综合征（SIRS）**：严重创伤、手术、大面积烧伤、急性胰腺炎等可引起PCT轻度至中度升高。
- **器官功能障碍**：急性呼吸窘迫综合征（ARDS）、急性肾损伤（AKI）、多器官功能障碍综合征（MODS）。
- **某些病毒感染**：腺病毒、呼吸道合胞病毒、流感病毒等可轻度升高，但一般<0.5ng/mL。
- **某些肿瘤**：甲状腺髓样癌（MTC）是PCT的肿瘤标志物；部分小细胞肺癌、甲状腺滤泡癌可轻度升高。
- **药物影响**：抗胸腺细胞球蛋白（ATG）、抗CD3抗体（OKT3）等免疫抑制剂治疗时可升高。

### PCT水平的临床解读
| PCT水平 | 临床意义 |
|---------|----------|
| <0.05ng/mL | 正常下限，排除细菌感染（窗口期内感染除外） |
| 0.05-0.25ng/mL | 轻度升高，可能为局部细菌感染、轻微炎症或病毒感染 |
| 0.25-0.5ng/mL | 中度升高，提示可能存在细菌感染，建议启动抗生素 |
| 0.5-2ng/mL | 显著升高，高度提示细菌感染（如脓毒症），应启动抗生素治疗 |
| >2ng/mL | 极显著升高，强烈提示全身性细菌感染/脓毒症，需积极抗感染治疗 |

### PCT动态监测的临床价值
- **抗生素治疗决策**：根据PCT水平指导抗生素启动和停药时机，PCT<0.25ng/mL或从峰值下降>80%可考虑停药。
- **疗效评估**：有效抗感染治疗后，PCT在24-48小时内显著下降；若PCT持续不降或反而升高，提示治疗失败或需调整方案。
- **预后评估**：脓毒症患者入院时PCT水平与预后相关，持续升高提示预后不良。
- **术后感染监测**：大手术后24-48小时PCT可生理性升高，若术后第5天仍持续升高提示并发感染。

### PCT降低的常见原因
- **病毒感染**：单纯病毒感染PCT一般<0.1ng/mL（部分病毒可轻度升高）。
- **非感染性炎症**：自身免疫性疾病活动期（如类风湿关节炎、SLE）可轻度升高，但通常<0.5ng/mL。
- **局部细菌感染**：轻微感染如蜂窝织炎、脓肿等可轻度升高。
- **正常生理状态**：健康人血清PCT极低。

## 注意事项
- **采血时机**：PCT在炎症刺激后2-4小时开始升高，峰值在12-24小时，建议在症状出现后6-24小时采血。
- **采血部位**：避免从输液管路采血，以免稀释或污染。
- **检测方法统一**：不同检测系统间存在差异，动态监测应使用同一系统。
- **结果解读**：PCT为辅助诊断指标，必须结合临床表现、影像学检查及血常规等综合判断。
- **窗口期**：严重感染早期（发病<3小时）采血，PCT可能仍在正常范围，需在6-24小时后复查。
- **新生儿监测**：出生后48-72小时内PCT生理性升高，先心病手术患儿需注意评估。
- **药物干扰**：升高的药物少见，但抗胸腺细胞球蛋白、糖皮质激素可影响结果。
- **特殊情况**：慢性肾衰竭患者基础PCT水平可轻度升高，需注意解读。
