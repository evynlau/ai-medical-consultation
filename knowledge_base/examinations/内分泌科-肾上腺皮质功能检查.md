# 肾上腺皮质功能检查

## 概述
肾上腺皮质功能检查是评估下丘脑-垂体-肾上腺轴(HPA)功能、诊断皮质醇增多/减退、醛固酮、性腺等肾上腺相关疾病的核心项目。包括基础激素、动态试验、影像、病理,辅助库欣综合征、原发性醛固酮增多症、肾上腺皮质功能减退、肾上腺意外瘤等疾病诊断。

## 主要项目

### 一、糖皮质激素
- **皮质醇(Cortisol)**
  - 晨 8 时:参考 5-25 μg/dL(140-700 nmol/L)
  - 午夜 0 时:< 1.8 μg/dL(50)
  - **昼夜节律**:晨高、午夜低,节律消失提示库欣
- **24h UFC(尿游离皮质醇)**:反映日均分泌,库欣筛查
  - 参考:20-90 μg/24h(随方法)
- **ACTH(促肾上腺皮质激素)**
  - 晨 8 时:10-60 pg/mL
  - 库欣病:正常/升高(20-200)
  - 异位 ACTH:显著升高(> 200)
  - 原发肾上腺:抑制(< 5)
  - 继发(垂体):低或不适当地「正常」
- **DHEA-S(脱氢表雄酮)**:肾上腺雄激素,肾上腺癌↓
- **17-OHCS、17-KS(传统)**

### 二、盐皮质激素
- **醛固酮(ALD)**
  - 卧位:3-16 ng/dL
  - 立位:4-31 ng/dL
  - **ARR(ALD/Renin)**:PA 筛查
- **肾素活性(PRA)** 或 **直接肾素(DRC)**
- **ARR**:> 20-30 提示 PA

### 三、性腺(肾上腺来源)
- **DHEA-S**、**雄烯二酮**、**睾酮**(女)
- 肾上腺癌:雄激素显著↑

### 四、儿茶酚胺(髓质)
- **血浆游离甲氧基肾上腺素(MN)**
- **血浆甲氧基去甲肾(NMN)**
- **24h 尿 CA、NMN/MN、VMA**
- 详见嗜铬细胞瘤指南

### 五、电解质
- **Na⁺ ↑、K⁺ ↓**:醛固酮、库欣(11β-HSD2 受抑)
- **Na⁺ ↓、K⁺ ↑**:肾上腺皮质功能减退
- **血糖**:库欣可高

## 动态试验

### 库欣综合征诊断
| 试验 | 方法 | 阳性 |
|---|---|---|
| **LDDST(过夜 1 mg)** | 夜 11 时 1 mg,8 时皮质醇 | > 1.8 μg/dL |
| **LDDST(48 h 2 mg)** | 0.5 mg q6h × 2d | > 1.8 μg/dL |
| **24h UFC** | 24h 尿 | > 1-2 倍正常上限 |
| **午夜唾液皮质醇** | 夜间 23 时 | > 4 nmol/L |

### 库欣分型
- **大剂量 DST(8 mg)**:Cushing 病抑制(皮质醇 < 50% 基础)
- **CRH 兴奋**:Cushing 病反应过强
- **HDDST + CRH**:提高鉴别
- **IPSS(岩下窦取血)**:垂体定位金标准

### 肾上腺皮质功能减退
- **晨皮质醇 < 3 μg/dL** → 确诊不全
- **3-15 μg/dL** → ACTH 兴奋试验(短 Synacthen 250 μg iv)
  - 30/60 min 皮质醇 < 18-20 μg/dL → 肾上腺不全
- **ACTH 测定**:
  - ↑:原发(Addison)
  - ↓/「正常」:继发(垂体)
- **长期 ACTH 兴奋**:鉴别原/继发
- **胰岛素低血糖**(复杂、金标准)

### 原发性醛固酮增多症
- **ARR 筛查** → **盐水负荷 / 卡托普利 / 氟氢可的松抑制** 确诊
- **AVS**:分型
- 详见 PA 指南

## 临床判读

### 库欣综合征
- 表现 + UFC ↑、LDDST 不被抑制 → 确诊
- ACTH 测因 + 影像 + IPSS → 分型

### 原发肾上腺皮质功能不全
- 晨皮质醇 ↓、ACTH ↑
- 低钠、高钾、低血压
- 病因:Addison、结核、转移、术后

### 继发肾上腺皮质功能不全
- ACTH ↓、皮质醇 ↓
- 长期糖皮质激素抑制 HPA 轴

## 注意事项
- 抽血时间:晨 8 时皮质醇、ACTH
- 避应激:隐匿肾上腺不全可出现肾上腺危象
- 妊娠:CBG ↑,皮质醇 ↑ 2-3 倍
- 避孕药:CBG ↑,总皮质醇 ↑,看 FT
- 长期糖皮质激素使用史:查 HPA 轴
- 检验前避免地塞米松干扰
- 库欣 + 低钾:警惕异位 ACTH、严重库欣病
- ARR 测:纠正低钾、停干扰药
- 肾上腺意外瘤:必查皮质醇、ACTH、醛固酮、儿茶酚胺、性激素
