# 主动脉夹层手术

## 概述
主动脉夹层(AD)是主动脉内膜撕裂,血液进入中膜形成假腔的致命性大血管急症。**A 型(累及升主动脉)为外科急症**,**B 型(仅降主动脉)以内科为主**。Stanford 分型指导治疗。

## 适应证

### A 型(外科)
- 所有 A 型 AD 一经诊断立即手术
- 升主动脉置换 + 弓部重建
- 合并主动脉瓣反流:同期 Bentall / Wheat / David
- 弓部受累:全弓 / 半弓置换
- 冠脉受累:同期 CABG

### B 型(内科为主,介入/手术指征)
- 顽固性疼痛、血压难控
- 脏器灌注不良(肠系膜、肾、肢体、脊髓)
- 主动脉直径快速增大
- 破裂先兆(壁内血肿扩大、PAU 加深)
- 主动脉直径 > 55 mm
- 马凡综合征
- 难控高血压

## 术前评估
- **CTA 全主动脉**(金标准)
- 心脏超声(TTE/TEE):瓣膜、心包、冠脉开口
- 心电图
- 血气、肾功、电解质
- 凝血功能
- 血型、备血
- 双侧桡动脉血压

## 手术方式

### A 型
- **升主动脉置换**(Bentall / Wheat / David / Cabrol)
- **Bentall**(机械瓣 + 升主动脉 + 冠脉再植)
- **Wheat**(保留主动脉窦的瓣膜置换 + 升主动脉置换)
- **David**(主动脉瓣成形 + 升主动脉置换)
- **弓部重建**:
  - 半弓置换(病变局限)
  - 全弓置换 + 象鼻支架(累及弓部)
- **孙氏手术**(主动脉弓全弓置换 + 降主动脉支架)
- **冠脉移植** / 主动脉根部替换

### B 型
- **TEVAR**(胸主动脉腔内修复):
  - 覆膜支架封闭破口
  - 微创、恢复快
  - 已成为复杂 B 型首选
- **外科**:B 型严重并发症(破裂、灌注不良)TEVAR 失败

## 术前控制
- 收缩压 < 120 mmHg(目标)
- 心率 < 60 次/分
- β 阻滞剂(艾司洛尔、美托洛尔)优先
- 血管扩张剂(硝普钠、尼卡地平):必须在 β 阻滞剂后
- 镇痛(吗啡)

## 术后管理

### ICU 监护
- 24-72 h
- 血压、心率、SpO₂、尿量
- 引流量、警惕再出血
- 心电图(冠脉、瓣膜)
- 神经查体(脑、脊髓)
- 血气、肾功、电解质

### 血压控制(继续)
- 收缩压 < 120 mmHg
- 长期 β 阻滞剂
- ACEI / ARB(马凡、主动脉根部扩张)
- 他汀

### 抗凝
- 机械瓣置换(Bentall):终身华法林
- 生物瓣:3-6 个月
- 单纯升主动脉置换:不需

## 主要并发症

### 早期
- 出血
- 脑卒中(2-5%)
- 脊髓缺血、截瘫(降主动脉手术 5-10%)
- 急性肾损伤
- 心衰、心律失常
- 感染
- 凝血病

### 中远期
- 假腔持续灌注
- 远端主动脉扩张、瘤变
- 再次夹层
- 支架移位、内漏(TEVAR)
- 主动脉瓣反流

## 远期随访
- 出院 1 月、3 月、6 月、12 月,之后每年
- 主动脉 CTA / MRI
- 严格控制血压(收缩压 < 120)
- β 阻滞剂 + ARB(马凡)
- 戒烟
- 限制运动(举重、剧烈)

## 特殊人群
- **马凡综合征**:主动脉根部 ≥ 50 mm 手术,术后 β 阻滞剂 + ARB
- **妊娠**:
  - A 型:紧急手术(母体死亡率 25%)
  - B 型:药物治疗
  - 避免 ACEI/ARB
- **Loeys-Dietz**:阈值更低(40-42 mm)
- **二叶主动脉瓣**:主动脉 ≥ 50 mm 考虑预防

## 预后
- A 型手术死亡率 10-20%(经验丰富中心 < 10%)
- B 型:内科治疗死亡率 10%,TEVAR 改善
- 远期 5 年生存 60-80%

## 注意事项
- 任何突发胸背痛 + 双上肢血压差 + 撕裂样 = 主动脉夹层
- 抗凝、溶栓 **禁忌**(误诊为 AMI 风险)
- 剧烈运动、血压控制不佳是再发危险因素
- 支架患者:MRI 检查限制(部分可)
- 围术期 ACT 控制
- 主动脉人工血管感染:罕见但致命
- 患者教育:控制血压、自我监测
