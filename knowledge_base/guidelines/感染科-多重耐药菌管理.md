# 多重耐药菌管理

## 概述
多重耐药菌(MDRO)指对临床使用的三类或以上抗菌药物同时呈现耐药的细菌。常见:**MRSA、VRE、CRE、CR-AB(鲍曼)、CR-PA、产 ESBL、MDR-TB**。其感染增加死亡率、住院时间和费用。**抗菌药管理(AMS)+ 院感干预**是核心。

## 主要 MDRO
### 革兰阳性
- **MRSA**(耐甲氧西林金葡菌)
- **VRE**(耐万古霉素肠球菌)
- **MRCNS**(凝固酶阴性葡萄球菌)

### 革兰阴性(重点)
- **CRE**(耐碳青霉烯肠杆菌科):KPC、NDM、VIM、OXA-48
- **CR-AB**(耐碳青霉烯鲍曼不动杆菌)
- **CR-PA**(耐碳青霉烯铜绿假单胞菌)
- **产 ESBL 大肠、肺炎克雷伯**
- **MDR-PA、MDR-AB**

### 分级
- **MDR**:耐 ≥ 3 类
- **XDR**:耐 ≥ 1 类(除外 1-2 类)
- **PDR**(全耐):对所有可用抗菌耐药

## 危险因素
- **既往抗菌药**(广谱、长期)
- 反复住院、ICU、长期
- 介入装置(中心静脉、导尿、引流、气管插管)
- 免疫抑制(化疗、移植)
- **MDRO 流行地区**
- **MDRO 定植/感染史**

## 感染部位
- 血流、肺部、泌尿、伤口、腹腔
- 创面、皮肤

## 诊断
- **微生物培养** + **药敏**(MIC)
- **分子检测**(快速):
  - CRE 筛查(CIM、CARB、NDM、KPC)
  - MRSA 筛查(鼻前庭)
  - **mCIM / eCIM**(改良碳青霉烯失活法)
- **同源性分析**(脉冲场凝胶电泳 PFGE、WGS)
- 报告和上报

## 治疗原则

### 核心
- **抗菌药使用降级**(降阶梯、目标治疗)
- **优化 PK/PD**:剂量、给药方式、疗程
- **联合治疗**(严重、XDR、CRE)
- **新型药物**(头孢他啶阿维巴坦、亚胺培南-雷利巴坦、头孢地尔)

### 经验性治疗
- **既往培养** + **本院 / 科室药敏**
- **重症**:覆盖 MDRO + 联合
- **非重症**:暂用窄谱、培养指导

### 主要治疗方案

#### MRSA
- **首选**:**万古霉素** 25-30 mg/kg/d IV(谷浓度 15-20 mg/L,严重 20-25)
- **利奈唑胺** 600 mg q12h(IV/口服)
- **达托霉素**(肺炎不能用,被灭活) 6-10 mg/kg
- **替考拉宁**(可替代,谷 15-30)
- **头孢洛林**(皮肤)
- **特拉万星**(皮肤、ABSSSI)

#### VRE
- **利奈唑胺**(一线)
- **达托霉素**
- **奥利万星**(皮肤)

#### CRE
- **新药优先**:
  - **头孢他啶阿维巴坦**(CZA, KPC、OXA-48)
  - **美罗培南-法硼巴坦**(MEV, KPC)
  - **亚胺培南-西司他丁-雷利巴坦**(IMI-REL, KPC)
  - **头孢地尔**(Cefiderocol, NDM、OXA 等)
- **老药联合**:
  - **多黏菌素 B/E** 9-10 MU/日 + **碳青霉烯**(双剂量延长输注) + **替加环素**
  - **磷霉素**(辅助)
  - **氨基糖苷**(局部、全身)

#### CR-AB
- **舒巴坦** 含制剂:**头孢哌酮舒巴坦**(高剂量,9-12 g/d)
- 多黏菌素 + 舒巴坦 + 替加环素
- 头孢哌酮舒巴坦 + 米诺环素
- 多黏菌素 + 碳青霉烯(部分)

#### CR-PA
- **头孢洛扎他唑巴坦**(C/T)
- **头孢他啶阿维巴坦**
- **多黏菌素 + β 内酰胺**(有活性)
- **头孢地尔**

## 防控措施

### 1. 抗菌药管理(AMS)
- **分级**(非限制、限制、特殊)
- **审批制度**(特殊级、限制级)
- **多学科**:感染病、临床、药学、检验
- 关注:**DDD/DOT、菌检率**
- **目标治疗** ≥ **经验治疗**
- 周期性抗菌药使用评估
- 限制:**碳青霉烯、替加环素、多黏菌素、第四代头孢**
- **降阶梯**

### 2. 接触隔离
- **接触传播 + 单间**(优)或同种同源集中
- **专用器械**、标识
- 人员限制、探视管理

### 3. 手卫生 + 院感
- **5 时刻**手卫生
- **个人防护**(手套、隔离衣)
- **环境清洁**(终末消毒)
- **器械消毒**(高水平)
- **耐药菌定植筛查**(高危:ICU、长期、移植)

### 4. 主动筛查
- 高危入 ICU 患者
- 接触者追踪
- 培养:鼻拭子(筛查 MRSA)、直肠拭子(CRE、VRE)

### 5. 监测
- 微生物耐药谱(WHONET)
- 抗菌药使用强度
- MDRO 检出率、定植率

### 6. 去定植(选择性)
- **MRSA 鼻定植**:莫匹罗星(鼻)、氯己定(沐浴)
- 手术前、ICU、免疫抑制
- **VRE、CRE**:尚无标准化去定植方案

### 7. 暴发管理
- 流行病学调查(危险因素)
- 同源性分析
- 隔离加强、病房关闭
- 经验治疗调整

## 注意事项
- **MDRO 感染 ≠ 定植**:评估感染指征再用药
- **不滥用碳青霉烯**(是耐药主因)
- **降阶梯**快(48-72 h)
- **剂量足、PK/PD 优化**(美罗培南延长 3 h,谷 4-8 MIC)
- **多黏菌素** 监测肾功能
- **替加环素** 血药低,慎用于血流(部分)+ 剂量上界
- **新型药**(CZA、头孢地尔)严格适应证,减少滥用
- **病历**标识
- **转科/转院**告知
- **医院-社区协作**(转诊、养老)
