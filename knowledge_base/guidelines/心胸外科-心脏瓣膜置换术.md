# 心脏瓣膜置换术

## 概述
心脏瓣膜置换术是治疗**严重瓣膜病**的经典手术,用机械瓣或生物瓣替换病损瓣膜。**机械瓣耐久、生物瓣免抗凝**,选择需综合年龄、生活方式、合并症、能否抗凝等因素。

## 适应证

### 二尖瓣狭窄
- 重度 MS(MVA < 1.0 cm²)+ 症状
- 重度 MS + 房颤 / 栓塞
- 重度 MS + 肺动脉高压

### 二尖瓣反流
- 急性重度 MR(乳头肌断裂等)
- 慢性重度 + 症状 / LVEF 30-60% / LVESD ≥ 40 mm
- 修复失败

### 主动脉瓣狭窄
- 重度 AS + 症状
- 重度 AS + LVEF < 50%
- 极重度 AS(Vmax > 5.0 m/s)+ 无症状

### 主动脉瓣反流
- 急性重度 AR(主动脉夹层、感染)
- 慢性重度 + 症状 / LVEF < 50% / LVESD > 50 mm

### 三尖瓣反流
- 重度继发性 TR 修复同期
- 重度原发性 TR

## 瓣膜选择

### 机械瓣
- 优点:**耐久性极长**(> 30 年)
- 缺点:**终身抗凝**(INR 2-3;二尖瓣 2.5-3.5)
- 适用:年龄 < 50-60(预期寿命 > 20 年)
- 适用:已长期抗凝(房颤、机械瓣另一位置换)
- 慎用:不能抗凝(出血高危)、生活方式
- 类型:双叶瓣(St. Jude、Carbomedics)

### 生物瓣
- 优点:**不需终身抗凝**(3-6 个月后)
- 缺点:**耐久性有限**(10-15 年退化)
- 适用:年龄 > 65-70、孕妇、不愿抗凝
- 类型:猪瓣(Medtronic Hancock)、牛心包瓣(Carpentier-Edwards)
- **TAVR 主动脉瓣**:适用老年、高危

## 手术方式

### 二尖瓣
- **正中开胸**:标准
- **微创(MICS)**:右胸小切口
- **机器人**:Da Vinci

### 主动脉瓣
- **正中开胸 + 体外循环**:标准
- **微创(MICS)**:部分胸骨切开
- **TAVR(经导管)**:高危患者替代

### 同期手术
- CABG + 瓣膜
- 多瓣膜置换
- 升主动脉瘤(Bentall 术)

## 术前准备
- 心脏超声(TTE + TEE 评估)
- 冠脉造影(> 40 岁)
- 冠脉 CTA(年轻女性可替代)
- 颈动脉超声(> 65 岁)
- 血气、肝肾、电解质
- 牙科检查(IE 预防)
- 备血、停抗凝
- 抗凝桥接(机械瓣)

## 术后管理

### 监护
- ICU 24-48 h
- 心律(房颤 30%)、血压、SpO₂
- 引流(警惕心包填塞)
- 心肌酶、cTn
- 临时起搏线

### 抗凝(关键)
- **生物瓣**:华法林 3-6 个月(INR 2-3)→ 阿司匹林
- **机械瓣**:**终身华法林**
  - 主动脉瓣:INR 2.0-3.0
  - 二尖瓣:INR 2.5-3.5
  - 机械瓣 + 房颤/栓塞史:INR 3.0-4.0
- 桥接:术前 5 天停华法林,INR < 2,改低分子肝素
- 阿司匹林 75-100 mg 长期

### 感染预防
- **IE 预防**:术前 30-60 min 抗生素
- 术后注意卫生、牙科、皮肤
- 早期识别 IE 症状(发热、心衰加重)

### 心功能
- 强心、利尿(必要时)
- 抗心律失常
- IABP(高危)

## 并发症

### 早期
- 出血、心包填塞
- 围术期 MI、卒中
- 心律失常
- 急性心衰
- 感染(纵隔、IE)
- 瓣周漏

### 中远期
- 抗凝相关出血(1-2%/年)
- 血栓栓塞
- IE(终生风险 1-3%)
- **生物瓣结构衰败**(SVD):10-15 年
- 机械瓣功能障碍(罕见)
- 再次手术

## 瓣膜选择决策
| 患者特征 | 推荐 |
|---|---|
| < 50 岁 | 机械瓣(耐久性) |
| 50-65 岁 | MDT(患者意愿、生活方式) |
| > 65 岁 | 生物瓣(免抗凝) |
| 孕妇 / 育龄 | 生物瓣(避免华法林致畸) |
| 不能抗凝 | 生物瓣 |
| 已抗凝(房颤) | 机械瓣 |
| 透析 | 生物瓣(加速钙化) |
| 主动脉瓣 | TAVR(高危) |

## 妊娠与瓣膜
- 机械瓣妊娠高危(华法林致畸 / 肝素替代风险)
- MDT(心内、产科、麻醉、新生儿)
- < 13 周:低分子肝素(严密抗 Xa 监测)
- 13-36 周:华法林可用
- 围产期:肝素桥接
- 阴道分娩慎用(增加出血)

## 随访
- 出院 1 月、3 月、6 月、12 月,之后每年
- 心脏超声(TTE):生物瓣 1 年后每 1-2 年;机械瓣 5 年后每 3-5 年
- 抗凝监测(INR):机械瓣每月
- 牙科、操作前 IE 预防
- 注意:任何发热、新发杂音 → 立即就诊

## 注意事项
- 任何瓣膜手术患者,IE 是一生风险
- 抗凝饮食稳定(维生素 K 一致)
- 避免剧烈运动(生物瓣更安全)
- **不推荐生物瓣患者长期抗凝** (3-6 个月后)
- 新发症状(气短、晕厥) → 瓣膜功能障碍 → 紧急就诊
- 抗凝 + 抗血小板 + 出血风险:平衡
