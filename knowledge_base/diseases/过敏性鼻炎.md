# 过敏性鼻炎

## 概述
过敏性鼻炎(变应性鼻炎)是易感人群接触致敏原后,由 IgE 介导的鼻黏膜慢性炎症。全球发病率 10-25%。

## 常见过敏原
- 花粉(春季/秋季)
- 尘螨
- 霉菌
- 动物皮屑
- 蟑螂粪便
- 某些食物

## 典型症状
- 阵发性喷嚏(连续 3 个以上)
- 大量清水样鼻涕
- 鼻塞
- 鼻痒
- 眼痒、流泪(过敏性结膜炎)
- 嗅觉减退
- 鼻黏膜苍白水肿

## 分类
- 季节性(花粉症)
- 常年性

## 治疗
- 避免接触过敏原
- 鼻用糖皮质激素(首选):布地奈德、糠酸莫米松
- 抗组胺药:西替利嗪、氯雷他定
- 减充血剂:短期(< 7 天)用于缓解鼻塞
- 免疫治疗(脱敏):明确过敏原时的根治方法
- 鼻腔冲洗:生理盐水

## 与感冒区分
| 特征 | 过敏性鼻炎 | 普通感冒 |
|---|---|---|
| 喷嚏 | 连续多个 | 偶尔 |
| 鼻涕 | 清稀、量大 | 先清后稠 |
| 鼻痒 | 明显 | 轻 |
| 全身症状 | 无 | 有(发热、乏力) |
| 病程 | > 1 周反复 | 5-7 天 |

## 何时就医
- 症状影响睡眠、工作
- 合并哮喘
- 药物治疗效果不佳
- 需明确过敏原(可做过敏原检测)

## 预防
- 花粉季节戴口罩、关窗
- 床单被罩勤洗勤晒(防螨)
- 避免饲养宠物或勤洗澡
- 保持室内清洁干燥
