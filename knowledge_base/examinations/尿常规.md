# 尿常规检查(Urinalysis)

## 概述
尿常规是最常用的临床检验项目之一,通过物理、化学、显微镜检查对尿液进行综合分析,可反映泌尿系统疾病、糖尿病、肝胆疾病、代谢性疾病等。

## 检查内容
### 物理指标
- **尿量**:正常 1000-2000ml/24h
- **颜色**:淡黄色透明
- **透明度**:清晰透明
- **比重**:1.005-1.030(反映尿液浓缩功能)
- **气味**:轻微氨味

### 化学指标(试纸法)
- **pH**:5.0-7.0(弱酸性)
- **蛋白尿**:阴性
- **尿糖**:阴性
- **酮体**:阴性
- **尿胆原**:弱阳性
- **胆红素**:阴性
- **亚硝酸盐**:阴性
- **白细胞酯酶**:阴性
- **隐血**:阴性
- **维生素 C**:有干扰

### 显微镜检查
- **红细胞(RBC)**:0-3/HPF
- **白细胞(WBC)**:0-5/HPF
- **上皮细胞**:少量
- **管型**:偶见透明管型
- **结晶**:可少量
- **细菌、酵母菌**:阴性
- **寄生虫**:阴性

## 临床意义

### 蛋白尿
**生理性**:发热、剧烈运动、寒冷、紧张
**病理性**:
- 肾小球疾病(肾病综合征、肾小球肾炎)
- 肾小管疾病(间质性肾炎)
- 泌尿系感染
- 多发性骨髓瘤(Bence-Jones 蛋白)
- 体位性蛋白尿(直立时出现)
- 24 小时尿蛋白定量 >3.5g/d → 肾病综合征

### 血尿(尿红细胞增多)
**镜下血尿**:>3 RBC/HPF
**肉眼血尿**:>2000 RBC/ml(每升尿 1ml 血)
**病因**:
- **泌尿系结石**(最常见)
- **感染**:膀胱炎、肾盂肾炎
- **肿瘤**:肾癌、膀胱癌
- **肾炎**:IgA 肾病、肾小球肾炎
- **外伤**
- **前列腺增生或癌**
- 假性血尿:月经、痔疮血污染

### 尿糖
- **血糖正常时糖尿**:肾性糖尿
- **血糖升高糖尿**:糖尿病最常见
- 其他:妊娠、应激、饮食
- 肾糖阈约 10 mmol/L

### 酮体
- **糖尿病酮症酸中毒**(最重要)
- 长期饥饿、剧烈运动
- 妊娠剧吐
- 低碳水化合物饮食

### 白细胞尿 / 脓尿
- >5 WBC/HPF
- 提示泌尿系感染(膀胱炎、肾盂肾炎、尿道炎)
- 需结合尿培养

### 亚硝酸盐阳性
- 提示细菌感染(能将硝酸盐还原为亚硝酸盐)
- 常见于大肠杆菌等革兰阴性菌
- 阴性不能排除感染

### 尿胆原 / 胆红素
- 胆红素阳性 + 尿胆原阳性:肝细胞性黄疸
- 胆红素阴性 + 尿胆原强阳性:溶血性黄疸
- 胆红素阳性 + 尿胆原阴性:梗阻性黄疸

## 标本采集
- **清洁中段尿**(最常用):清水冲洗外阴后,弃前段尿,接中段尿
- **晨尿**(首选):浓缩,异常检出率高
- **随机尿**:任意时间,方便但敏感性低
- **24 小时尿**:定量检查(蛋白、肌酐等)
- **导尿**:特殊情况,避免污染
- 标本 1-2 小时内送检,室温不超过 2h
- 女性避免经期取样
- 避免剧烈运动后立即取样

## 常见疾病尿检表现
| 疾病 | 典型表现 |
|---|---|
| 急性膀胱炎 | 浑浊尿、白细胞酯酶 +、亚硝酸盐 +、白细胞 + |
| 肾盂肾炎 | 脓尿 + 白细胞管型 + 发热 |
| 肾小球肾炎 | 血尿 + 蛋白尿 + 红细胞管型 |
| 肾病综合征 | 大量蛋白尿(+++以上)+ 浑浊 |
| 糖尿病 | 尿糖 +、可能酮体 + |
| 尿路结石 | 血尿 ± 结晶 ± 疼痛 |
| 肝细胞性黄疸 | 尿胆红素 + 尿胆原 + |
| 溶血性黄疸 | 尿胆红素 - 尿胆原 +++ |

## 注意事项
- 饮食、药物可影响结果
- 大量饮水可稀释尿液,造成假阴性
- 标本污染(白带、粪便)易致误判
- 单次异常需复查确认
- 持续异常需进一步检查(血常规、影像学)
- **不能仅凭尿常规诊断疾病**,需结合临床

## 何时复查
- 第一次异常:1 周内复查
- 持续异常:进一步评估(肾功能、影像)
- 血尿 + 蛋白尿:警惕肾脏疾病,需就诊
- 持续糖尿:查血糖、确诊糖尿病
- 持续脓尿:尿培养 + 药敏
