# 肾积水诊治

## 概述
肾积水是各种原因导致的**尿液排出受阻**,肾盂肾盏扩张,晚期压迫肾实质致肾功损害。是临床常见的泌尿外科问题,可急性、慢性、单侧、双侧。

## 病因(按解剖位置)

### 1. 输尿管上段
- **肾盂输尿管连接部(UPJ)梗阻**(先天性最常见)
  - 内在:狭窄、瓣膜、息肉
  - 外在:异位血管、纤维索带、马蹄肾
- 结石
- 肿瘤

### 2. 输尿管中段
- 结石
- 腹膜后纤维化
- 异位血管压迫
- 输尿管肿瘤
- 妊娠(生理性,可重度)

### 3. 输尿管下段
- **结石**(最常见)
- 膀胱癌侵犯
- 输尿管膨出
- 输尿管口狭窄

### 4. 膀胱、尿道
- 膀胱颈梗阻(BPH、肿瘤)
- **神经源性膀胱**
- 膀胱结石
- 尿道狭窄

## 临床表现

### 慢性、单侧
- 早期无症状
- 腰部钝痛
- 反复尿路感染
- 高血压
- 体检偶然发现

### 急性、双侧、孤立肾
- **无尿、急性肾衰**
- 肾绞痛样疼痛
- 恶心呕吐
- 水中毒、电解质紊乱

### 合并感染
- 脓肾
- 发热、寒战
- 腰痛剧烈

## 诊断

### 实验室
- 尿常规
- 血常规
- **血肌酐、尿素氮**(双侧积水)
- 电解质
- 尿培养

### 影像(核心)
- **B 超**(首选):
  - 肾盂肾盏扩张 > 1 cm
  - 积水程度分级
  - 输尿管扩张
  - 梗阻部位定位
- **CTU**(CT 尿路造影):
  - 梗阻部位
  - 病因(肿瘤、结石、纤维化)
  - 解剖评估
- **MRU**:
  - 孕妇、儿童
  - 肾功能不全
  - 不需碘造影
- **静脉肾盂造影(IVP)**:部分中心仍用
- **利尿肾图**(**Mag3 / DTPA**):
  - 评估分肾功能
  - 评估梗阻严重度
  - 利尿后曲线
- **逆行肾盂造影**:不明确时

## 积水程度分级

### B 超
- **轻度**:肾盂扩张 1-2 cm
- **中度**:肾盂 2-3 cm + 肾盏扩张
- **重度**:肾盂 > 3 cm + 肾盏明显扩张 + 肾实质变薄

### SFU 分级(小儿常用)
- 0:无扩张
- 1:肾盂轻度
- 2:肾盂扩张
- 3:肾盂 + 肾盏
- 4:严重 + 肾实质变薄

## 治疗

### 急性
- **解除梗阻**(关键)
- 导尿(下尿路)
- **输尿管支架**(D-J 管):内引流
- **经皮肾造瘘(PCN)**:外引流
- 抗感染
- 急性肾衰:补液、透析

### 慢性
- **病因治疗**:
  - 结石:ESWL / URL / PCNL
  - 肿瘤:手术 / 放化疗
  - 狭窄:扩张 / 重建
  - BPH:药物 / TURP
- 肾切除:无功能肾(< 10% 分肾)
- 长期管理:定期复查

### UPJ 梗阻

**诊断**:
- B 超、CTU
- 利尿肾图(GFR + 利尿后曲线)
- MRU

**治疗**:
- **症状性**(腰痛、感染、结石、血尿、肌酐)
- **分肾功能 < 35%**
- 反复发作
- **离断性肾盂成形术(Anderson-Hynes)**:
  - **金标准**
  - 开放 / 腹腔镜 / 机器人
  - 切除狭窄段 + 重新吻合
  - 成功率 95%+
- **内镜**:
  - 球囊扩张
  - 顺行 / 逆行内切开
  - 短期成功 70-80%,长期 60-70%
  - 适应:小、轻、复发病例
- 肾切除:无功能、复发

### 腹膜后纤维化
- 特发 / 继发
- **输尿管松解 + 大网膜包裹**
- 联合:激素 / 他莫昔芬

### 神经源性膀胱
- 间歇导尿(首选)
- 药物
- 膀胱造瘘
- 输尿管再植

## 注意事项
- **双侧 / 孤立肾**积水 = 急症
- 急性无尿:立即引流
- 妊娠:大部分可观察(产后缓解)
- 长期积水:肾功进行性下降
- 分肾功能评估重要
- 小儿:早期发现(产检 B 超)
- 反复尿路感染:查原因
- 不可盲目肾切除(评估分肾)
- 终身随访(部分患者)

## 预后
- 短期引流:肾功可部分恢复
- 慢性长期(> 2 周):部分不可逆
- UPJ 离断成形术成功率 90-95%
- 内镜 60-80%
- 肿瘤性:依病因
