# 失眠中医辨证

## 概述
失眠在中医属「不寐」范畴,以经常性不能获得正常睡眠为特征,表现为入睡困难、睡眠不深、易醒、早醒、多梦、醒后不易再睡。中医认为「阳不入阴」为基本病机,与心、肝、脾、肾密切相关。

## 病因病机
- **情志失调**:郁怒伤肝、思虑伤脾、惊恐伤肾
- **饮食不节**:暴饮暴食、肥甘厚味、咖啡浓茶
- **劳逸失调**:过劳、过逸
- **病后体虚**:血虚、年迈血少
- **基本病机**:**阴阳失调、阳不入阴**

## 辨证分型

### 1. 肝郁化火
- **主症**:入睡困难、辗转反侧、多梦
- **伴随**:急躁易怒、口苦咽干、头晕头胀、目赤耳鸣、便秘尿黄
- **舌脉**:舌红苔黄、脉弦数
- **治法**:疏肝清热、安神
- **方药**:**龙胆泻肝汤**加减
- **中成药**:龙胆泻肝丸(注意肾毒性)、加味逍遥丸

### 2. 痰热扰心
- **主症**:心烦不寐、胸闷头重
- **伴随**:痰多色黄、嗳气吞酸、口苦、目眩
- **舌脉**:舌红苔黄腻、脉滑数
- **治法**:清热化痰、和中安神
- **方药**:**黄连温胆汤**加减
- **中成药**:黄连温胆丸

### 3. 心脾两虚
- **主症**:多梦易醒、醒后难睡
- **伴随**:心悸健忘、神疲乏力、面色少华、食欲不振、便溏
- **舌脉**:舌淡苔薄、脉细弱
- **治法**:补益心脾、养血安神
- **方药**:**归脾汤**加减
- **中成药**:归脾丸(合剂)、人参归脾丸、柏子养心丸

### 4. 心肾不交
- **主症**:心烦不寐、五心烦热
- **伴随**:头晕耳鸣、口干少津、腰膝酸软、遗精、健忘
- **舌脉**:舌红少苔、脉细数
- **治法**:滋阴降火、交通心肾
- **方药**:**黄连阿胶汤** / **交泰丸**(黄连、肉桂) / **天王补心丹**
- **中成药**:交泰丸、天王补心丹(丸/片)、知柏地黄丸

### 5. 心胆气虚
- **主症**:不寐多梦、易惊醒
- **伴随**:胆怯恐惧、气短自汗、倦怠乏力
- **舌脉**:舌淡、脉细弱
- **治法**:益气镇惊、安神定志
- **方药**:**安神定志丸** / **酸枣仁汤**
- **中成药**:安神补心丸、安神定志丸

### 6. 阴虚火旺
- **主症**:心烦不寐、盗汗
- **伴随**:五心烦热、口干咽燥、头晕耳鸣、健忘
- **舌脉**:舌红少苔、脉细数
- **治法**:滋阴清热、安神
- **方药**:**黄连阿胶汤** / **知柏地黄丸**

## 常用安神药对

### 重镇安神
- **龙骨、牡蛎**:镇惊安神、平肝潜阳
- **朱砂**(有毒,慎用)、磁石、珍珠母

### 养心安神
- **酸枣仁**:养肝血、安神,**虚烦不眠要药**(30 g)
- **柏子仁**:养心润肠
- **远志**:安神益智、祛痰开窍
- **合欢皮**:解郁安神
- **夜交藤**(何首乌藤):养血安神、祛风通络
- **茯神**:宁心安神

### 解郁安神
- **合欢花、玫瑰花、佛手**

## 特色治疗

### 针灸
- **主穴**:神门、内关、百会、安眠
- **配穴**:
  - 肝郁:太冲、期门
  - 痰热:丰隆、内庭
  - 心脾虚:足三里、三阴交
  - 心肾不交:心俞、肾俞、太溪
  - 心胆虚:胆俞、丘墟

### 耳穴
- **神门、皮质下、心、肾、交感**
- 王不留行籽贴压,每日按压 3-5 次

### 推拿
- **头部**:印堂、神庭、太阳、风池
- **腹部**:中脘、气海、关元
- **穴位**:涌泉(睡前搓热)、神门、内关

### 食疗
- **心脾两虚**:龙眼红枣粥、百合银耳莲子羹、酸枣仁粥
- **阴虚**:枸杞菊花茶、麦冬茶
- **痰热**:薏苡仁粥、荷叶粥
- **肝郁**:玫瑰花茶、合欢花茶

### 足浴
- **磁石、菊花、黄芩、夜交藤**煎水,睡前泡脚 20-30 min
- 涌泉穴(吴茱萸粉醋调敷贴)

### 导引
- **八段锦**、**五禽戏**、**站桩**
- **呼吸吐纳**、**冥想**、**渐进性肌肉放松**
- **子午觉**:子时(23-1)、午时(11-13)

## 注意事项

### 生活方式
- 规律作息,**子时前入睡**(11 点前)
- 避咖啡、浓茶、晚餐过饱
- 卧室安静、避光、凉爽
- 床只用于睡眠(条件反射建立)

### 情志
- 情绪疏导、压力管理
- 严重者心理治疗

### 西医结合
- **慢性失眠**:CBT-I 一线(中医可辅)
- **严重失眠**:短期佐匹克隆 / 右佐匹克隆
- 中西医结合优势:
  - 减少安眠药用量
  - 减少戒断
  - 调节体质根本

### 禁忌
- **朱砂**(硫化汞):**禁长期服用**,肝肾损伤
- **补益安神药**(归脾丸等):**感冒、痰热者慎用**(闭门留寇)
- **清热安神**(龙胆泻肝丸):**中病即止**,伤脾胃
- **孕妇**:活血、矿物药慎用
