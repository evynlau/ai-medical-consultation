# 内分泌科-胰岛素与C肽检查

## 概述
胰岛素（Insulin）和 C 肽（C-peptide）是胰岛 β 细胞分泌的两种密切相关的物质。胰岛素原（Proinsulin）在 β 细胞内被蛋白酶水解，裂解为**胰岛素**（Insulin）和**连接肽**（C-peptide），两者以等摩尔比例释放入血。

胰岛素是机体唯一的降糖激素，主要功能是促进细胞摄取葡萄糖、抑制糖异生和糖原分解、促进糖原合成和脂肪、蛋白质合成，从而降低血糖。C 肽与胰岛素呈 **1:1** 等摩尔释放，且 C 肽在外周血中半衰期更长（约 30-35 分钟），浓度相对稳定，是评估**内源性胰岛素分泌功能**的理想指标。

胰岛素和 C 肽检查主要用于糖尿病分型诊断、胰岛 β 细胞功能评估、胰岛素瘤诊断、胰岛素抵抗评估及糖尿病治疗方案制定，是内分泌科重要的功能性检查项目。

## 检查方法
### 标本采集
- **血清标本**：空腹静脉采血 3-5 mL，分离血清
- 如同时做葡萄糖耐量试验（OGTT），需多点采血（空腹、30 分钟、60 分钟、120 分钟、180 分钟）
- 应避免溶血

### 检测方法
1. **化学发光免疫分析法（CLIA）**：临床最常用的方法
   - 采用荧光或化学发光物质标记胰岛素或 C 肽抗体
   - 高灵敏度、高特异性，可定量检测
   - 全自动化学发光免疫分析仪检测

2. **酶联免疫吸附法（ELISA）**
   - 经典免疫学方法
   - 灵敏度较好，但操作时间较长

3. **放射免疫分析法（RIA）**（已较少使用）
   - 经典方法，存在放射性污染

4. **电化学发光免疫分析法（ECLIA）**
   - 高灵敏度、宽线性范围

### 功能性试验
1. **口服葡萄糖耐量试验（OGTT）+ 胰岛素/C 肽释放试验**
   - 空腹采血后口服 75 g 葡萄糖，分别于 30 分钟、60 分钟、120 分钟、180 分钟采血
   - 同时测定血糖、胰岛素、C 肽
   - 评估 β 细胞对葡萄糖刺激的胰岛素分泌功能

2. **胰高血糖素激发试验**
   - 静脉注射胰高血糖素 1 mg，测定注射前后胰岛素/C 肽变化
   - 用于评估 β 细胞储备功能

3. **精氨酸激发试验**
   - 静脉滴注精氨酸，刺激 β 细胞分泌胰岛素

4. **稳态模型评估（HOMA）**
   - **HOMA-IR**：评估胰岛素抵抗程度
   - **HOMA-β**：评估 β 细胞分泌功能
   - 计算公式需要空腹血糖和空腹胰岛素

## 正常参考值
### 空腹值
| 项目 | 参考范围 |
|------|----------|
| 空腹胰岛素 | 2.6-24.9 μU/mL（或 18-174 pmol/L） |
| 空腹 C 肽 | 0.8-4.2 ng/mL（或 0.26-1.39 nmol/L） |
| 空腹胰岛素/C 肽比值 | 无固定参考值，但有助于鉴别 |

### OGTT 联合胰岛素/C 肽释放试验（参考值）
| 时间点 | 血糖（mmol/L） | 胰岛素（μU/mL） | C 肽（ng/mL） |
|--------|----------------|-----------------|---------------|
| 空腹 | 3.9-6.1 | 2.6-24.9 | 0.8-4.2 |
| 30 分钟 | < 10.0 | 约为空腹 5-10 倍 | 约为空腹 2-3 倍 |
| 60 分钟 | < 11.1 | 达峰值 | 达峰值 |
| 120 分钟 | < 7.8 | 开始下降 | 开始下降 |
| 180 分钟 | < 7.8 | 恢复接近空腹 | 恢复接近空腹 |

注：不同检测系统参考值有差异。

## 临床意义
### 1 型糖尿病与 2 型糖尿病的鉴别
| 特征 | 1 型糖尿病 | 2 型糖尿病 |
|------|------------|------------|
| 空腹胰岛素 | 低/测不出 | 正常/升高/略低 |
| 空腹 C 肽 | 低/测不出 | 正常/升高/略低 |
| OGTT 胰岛素曲线 | 低平（无峰值） | 高峰延迟或正常 |
| OGTT C 肽曲线 | 低平（无峰值） | 高峰延迟或正常 |
| 胰岛素/C 肽比值 | — | 有助于判断 |

- **1 型糖尿病**：胰岛素和 C 肽水平极低或测不出，曲线低平，提示 β 细胞严重破坏
- **2 型糖尿病**：胰岛素和 C 肽水平可正常、升高或略低，曲线高峰延迟（120 分钟达峰），反映胰岛素分泌迟缓和/或胰岛素抵抗

### 胰岛素瘤（胰岛 β 细胞瘤）
- **空腹胰岛素和 C 肽均显著升高**
- 出现**低血糖**时胰岛素和 C 肽仍处于高水平（生理性低血糖时胰岛素分泌应被抑制）
- **胰岛素/C 肽比值**：内源性胰岛素过高时比值 > 1；外源性胰岛素注射时比值可异常升高（因 C 肽被外源胰岛素抑制）
- 结合胰高血糖素激发试验、72 小时饥饿试验确诊

### 胰岛素抵抗评估
- **HOMA-IR** = 空腹血糖（mmol/L）× 空腹胰岛素（μU/mL） / 22.5
  - > 2.5 提示胰岛素抵抗（不同人群切点有差异）
- 高胰岛素正常血糖钳夹试验是评估胰岛素抵抗的金标准，但操作复杂

### 胰岛素/C 肽比值的鉴别意义
| 情况 | 胰岛素 | C 肽 | 临床意义 |
|------|--------|------|----------|
| 内源性高胰岛素血症 | 升高 | 升高 | 胰岛素瘤、2 型糖尿病 |
| 外源性胰岛素注射 | 升高 | 被抑制（低） | 胰岛素治疗或人为造成 |
| 胰岛 β 细胞破坏 | 低 | 低 | 1 型糖尿病、胰腺切除 |

### 糖尿病治疗方案的指导意义
- 胰岛素和 C 肽水平极低：提示需要**胰岛素替代治疗**（1 型糖尿病或晚期 2 型糖尿病）
- 胰岛素和 C 肽水平正常或升高：提示以**胰岛素抵抗**为主，可考虑胰岛素增敏剂治疗
- C 肽可帮助区分**外源性胰岛素注射**（C 肽被抑制）和内源性胰岛素分泌，指导治疗决策

## 注意事项
- **采血时间**：胰岛素和 C 肽释放试验需严格按时采血，时间误差影响结果解读
- **空腹要求**：空腹采血前需禁食 8-12 小时，可适量饮水
- **药物影响**：胰岛素注射、口服降糖药、糖皮质激素等药物可影响检测结果；试验前需遵医嘱调整用药
- **胰岛素抗体干扰**：体内存在胰岛素抗体时可能影响胰岛素检测准确性
- **C 肽与胰岛素的关系**：生理状态下两者以 1:1 等摩尔释放，但外源性胰岛素注射会破坏此比例
- **动态监测意义**：单次检测价值有限，OGTT 联合胰岛素/C 肽释放试验能更全面评估 β 细胞功能
- **低血糖病因鉴别**：低血糖患者同时测定血糖、胰岛素和 C 肽可鉴别低血糖病因（胰岛素瘤 vs. 外源性胰岛素 vs. 反应性低血糖）
- **肾功能和 C 肽**：C 肽主要经肾脏代谢，肾功能不全时 C 肽水平可能升高
- **参考值差异**：不同检测系统参考值不同，建议固定检测系统进行动态比较
- **胰岛素注射患者的监测**：长期胰岛素注射患者监测 C 肽可评估自身内源性胰岛素分泌能力
