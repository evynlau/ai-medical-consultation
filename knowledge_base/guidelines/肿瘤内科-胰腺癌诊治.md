# 胰腺癌诊治

## 概述
胰腺癌是预后最差的消化道恶性肿瘤,5 年生存率 < 10%。我国年新发约 12 万,死亡接近新发。**导管腺癌(PDAC)**占 85-90%。早期诊断困难,80% 确诊时已失去手术机会。**CA19-9**是最重要的血清标志物。

## 危险因素
- 长期吸烟(最重要)
- 慢性胰腺炎、肥胖、2 型糖尿病(尤其新发)
- 遗传易感:BRCA1/2、CDKN2A、STK11/LKB1、林奇、MMR 基因、Peutz-Jeghers
- 家族史、高脂高肉饮食、酗酒

## 筛查
- 不推荐普通人群
- **高危**(≥ 1 个一级亲属或已知胚系突变 + 胰腺囊性病变):MRI/MRCP 或 EUS 交替,每年 1 次

## 病理
- 90% **导管腺癌**(PDAC)
- 少见:腺泡细胞癌、神经内分泌肿瘤、IPMN 相关癌、实性假乳头状瘤、腺鳞癌
- 免疫组化:CK7、CK19、CEA、CA19-9、MUC1/4、SMAD4 失表达
- **分子检测**(晚期):
  - **BRCA1/2、ATM、PALB2**(胚系 + 体系)
  - **KRAS G12C**(罕见)、**NRG1、NTRK、HER2、MMR/MSI**
  - **KRAS-TP53-SMAD4-CDKN2A** 核心驱动

## 分期
- TNM 第 8 版
- **可切除**、**临界可切除(borderline)**、**局部进展期、转移性**
- 评估依赖**多层螺旋 CT(胰腺专用)+ 血管重建**

## 诊断
- **影像**:
  - **胰腺薄层增强 CT(双期)**:可切除性评估首选
  - **MRI/MRCP**:肝小转移、胰管细节
  - **EUS(超声内镜) + 细针穿刺(FNA)**:确诊首选,尤其是诊断 + 取材
  - **PET-CT**:隐匿转移、术前评估
  - **腹腔镜探查**:腹膜转移排查(CA19-9 高、T4 倾向)
- 标志物:**CA19-9**(基线,预后、复发监测);CEA(辅助)
- Lewis 抗原阴性者 CA19-9 不升高(< 10% 人群)
- **基线 CA19-9 ≥ 500 U/mL** 提示隐匿转移

## 治疗

### 可切除胰腺癌
- **术前评估**:MDT、CT/MRI、CA19-9
- **Whipple(胰十二指肠切除)**:胰头、壶腹部
  - 体尾部:**胰体尾 + 脾切除**
  - **新辅助化疗**(高危、临界可切除):**FOLFIRINOX** 或 **吉西他滨 + 白蛋白紫杉醇**(推荐 ≥ 4 周期)
  - 术后辅助:**mFOLFIRINOX 6 月**(PRODIGE-24,体能好者首选)、S-1(亚洲,日本)6 月、吉西他滨 + 卡培他滨
- **辅助放疗**:切缘阳性(R1)考虑

### 临界可切除
- **FOLFIRINOX** 或 **AG**(吉西他滨 + 白蛋白紫杉醇)新辅助 → 评估 → 手术

### 局部进展期
- 同步放化疗(吉西他滨/5-FU + 放疗) ± 化疗
- 转化后手术

### 转移性胰腺癌
- **一线**:
  - **体能良好(ECOG 0-1)**:**FOLFIRINOX** ± 伊立替康脂质体(NAVIPAC)
  - 或 **AG**(吉西他滨 + 白蛋白紫杉醇,MPACT)
  - **体能差**:吉西他滨单药
- **二线**:
  - 一线为 FOLFIRINOX → 吉西他滨 + 紫杉
  - 一线为 AG → FOLFIRI / 伊立替康脂质体 + 卡培他滨 / FOLFIRINOX(谨慎)
- **BRCA1/2 突变**:**含铂化疗**敏感 + **奥拉帕利维持**(POLO 研究)
- **MSI-H/dMMR**:帕博利珠单抗
- **NTRK、KRAS G12C、HER2、NRG1**:对应靶向药物
- **疼痛**:腹腔神经丛阻滞/松解、EUS 引导

## 对症支持
- **梗阻性黄疸**:ERCP + 金属支架(不可切除);术前可短暂 ENBD/PTCD
- **十二指肠梗阻**:胃空肠吻合
- **疼痛**:WHO 三阶梯镇痛、神经病理性用加巴喷丁
- **营养**:胰酶替代、肠内营养
- **静脉血栓**:LMWH 治疗

## 注意事项
- **CA19-9 基线 + 治疗后动态监测**
- 戒烟、戒酒
- 关注**新发糖尿病**(可能为早期信号)
- 心理支持贯穿全程
- **维持治疗**:稳定者可低强度化疗维持
- 体能差(ECOG ≥ 3)以最佳支持为主
