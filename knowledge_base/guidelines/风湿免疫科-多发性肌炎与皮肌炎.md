# 多发性肌炎与皮肌炎

## 概述
多发性肌炎(PM)和皮肌炎(DM)是以骨骼肌炎症为特征的特发性炎性肌病(IIM)。我国患病率约 0.5-1/10 万,女性多见(2:1),可累及多系统(肺、关节、皮肤、心)。临床无肌病皮肌炎(CADM) 是特殊亚型。

## 分类(基于抗体 + 病理)

### 经典
- 多发性肌炎(PM)
- 皮肌炎(DM)

### 特殊亚型
- **无肌病皮肌炎(CADM)**:典型皮疹 + 无肌炎
- **抗合成酶综合征(ASS)**:
  - 抗 Jo-1(组氨酰)、PL-7、PL-12、EJ、OJ、KS、Zo、Ha
  - 「三联征」:肌炎 + ILD + 关节炎
  - 「技工手」、雷诺、发热
- **免疫介导坏死性肌病(IMNM)**:
  - 抗 SRP、抗 HMGCR(他汀相关)
  - 严重肌炎、坏死重、激素抵抗
- **包涵体肌炎(IBM)**:
  - 老年、对称、近端 + 远端、激素无效
- **重叠肌炎**:合并 SLE、SSc、RA、干燥
- **肿瘤相关肌炎**:DM > PM,中老年、严重

## 诊断标准

### Bohan & Peter 标准(1975)
1. 对称性近端肌无力
2. 肌酶升高(CK、AST、ALT、LDH、aldolase)
3. EMG 肌源性损害
4. 肌肉活检异常
5. 典型皮疹(诊断 DM)
- PM:4 项中 3 项;DM:皮疹 + 其他 3 项中 ≥ 2 项
- 排除:感染、内分泌、药物、神经

### 2017 EULAR/ACR 分类(更全面)
- 概率模型,结合肌力、肌酶、活检、抗体、EMG、皮疹

## 临床表现

### 肌肉
- **近端肌无力**(对称):
  - 髋:蹲、起立、上楼梯困难
  - 肩:抬臂、洗头、梳头
  - 颈:抬头
- **远端相对保留**(区别于肌营养不良)
- **肌痛、压痛**(20-30%)
- **吞咽困难**(25%):鼻音、呛咳
- **呼吸肌受累**(少):呼吸困难

### 皮肤(DM)
- **向阳疹(日光疹)**:眶周水肿性紫红斑(特征)
- **Gottron 丘疹**:指关节 / PIP、伸面(特征)
- **Gottron 征**:紫红色斑、鳞屑
- **披肩征**:颈、肩、上背(Shawl sign)
- **V 征**:颈前、上胸部
- **甲周毛细血管**:扩张、出血、栓塞
- **甲褶梗死**:血管炎
- **硬皮病样皮疹**:重叠 SSc
- **钙质沉着**:儿童 DM、慢性
- **溃疡**:血管炎(尤其 CADM)

### 关节
- 多关节炎(对称、非侵蚀):ASS
- 「技工手」(mechanic's hands):ASS 标志
- 雷诺现象(30%)

### 肺部(ILD,关键预后)
- **20-65%**(DM > PM)
- **ASS + 抗 MDA5**:快速进展性 ILD(RP-ILD)
- **CADM + 抗 MDA5**:RP-ILD(东亚)
- 干咳、进行性呼吸困难
- HRCT:磨玻璃、网格、实变

### 心脏
- 心肌炎(罕见,但严重)、传导阻滞、心衰
- 亚临床多见

### 其他
- 发热(尤其 ASS)
- 淋巴结肿大(儿童、肿瘤相关)
- 肝脾大
- 肾脏(罕见)
- 胃肠道:吞咽、消化道出血、儿童 DM 严重
- 脂肪营养不良、儿童 DM

## 实验室

### 自身抗体(关键分类)

#### 肌炎特异性抗体(MSA)
- **抗 Jo-1(抗 HRS)**:ASS 15-30%
- **抗 Mi-2**:DM 经典(5-10%),预后好、对激素反应好
- **抗 MDA5**:DM / CADM,R**P-ILD**(危重)
- **抗 TIF1-γ**:DM、**肿瘤相关**(尤其儿童 DM)
- **抗 NXP2**:DM、肿瘤相关
- **抗 SRP**:IMNM(重症、激素抵抗)
- **抗 HMGCR**:IMNM(他汀相关)
- **抗 SAE**:DM、皮疹重

#### 肌炎相关性抗体(MAA)
- ANA、RF、抗 SSA、抗 RNP、抗 PM-Scl

### 肌酶谱(关键)
- **CK**(肌酸激酶):最敏感(可达 100×)
- **AST、ALT、LDH、aldolase**
- 肌炎活动平行
- **CK 正常**:部分 DM、CADM、儿童 DM
- **IMNM**:CK 极高(20-50×)
- **抗 MDA5**:CK 常正常(IL-2R、铁蛋白↑)

### 其他
- **ESR、CRP**:升高(ASS 强)
- **血常规**:贫血、白细胞 ↑
- **铁蛋白**:抗 MDA5(危重)
- **IL-2R(可溶性 CD25)**:淋巴细胞活化的金指标,提示严重
- **醛缩酶**:敏感性同 CK
- **肌红蛋白**:肾功能损伤风险
- **肝肾**:基线、监测

### EMG(肌电图)
- **三联征**:
  - 短时限、低波幅、多相
  - 自发电位(纤颤、正锐波)
  - 插入活动增强
- 受累肌群分布(近端)

### 影像
- **肌 MRI**:T2/STIR 肌内高信号(水肿)
- **HRCT 肺**:ILD、磨玻璃
- **肌肉超声**:水肿、脂肪化

### 肌肉活检
- **PM**:CD8+ T 细胞、内膜、MHC-Ⅰ(肌纤维)
- **DM**:CD4+ T、B 细胞、**束周萎缩**(perifascicular atrophy)
- **IMNM**:坏死重、巨噬细胞
- **包涵体**:镶边空泡、蛋白质沉积

### 肿瘤筛查
- 中老年 DM、抗 TIF1-γ、抗 NXP2
- **胸腹 CT、肠镜、乳腺 / 妇科 / 前列腺**
- 必要时 PET-CT

## 治疗

### 1. 糖皮质激素(**一线**)
- **泼尼松 1 mg/kg/d**(严重 1.5-2 mg/kg)
- **冲击**:甲泼尼龙 1 g iv × 3 d(严重、危重)
- **缓解后缓慢减量**(2-3 年)
- 不宜过快(复发风险)
- 注意副作用(骨质疏松、血糖、感染)

### 2. 免疫抑制剂(联合或难治)

#### 一线联合
- **MTX**:7.5-25 mg/wk(轻-中度)
- **AZA**:2-3 mg/kg/d(维持)
- **MMF**:2-3 g/d(尤其 ILD)
- **CTX**:严重 / 危重(NIH 方案)
- **他克莫司**:尤其 ILD(ASS、MDA5)
- **环孢素**:难治、ILD

#### 生物制剂
- **利妥昔单抗**(CD20):难治、MSA+、CTX 替代
- **托珠单抗**(IL-6R):难治
- **JAK 抑制剂**:顽固
- **IVIG**:严重、难治、皮损

### 3. 治疗策略

#### 经典 PM / DM
- 激素 + MTX / MMF
- 难治:加利妥昔单抗、IVIG
- 持续 2-3 年

#### ASS
- 激素 + MTX / 他克莫司 / MMF
- **ILD 进展**:MMF + 他克莫司(多靶点)

#### 抗 MDA5 + RP-ILD
- **强化**:激素冲击 + MMF + 他克莫司 + CTX(三/四联)
- **血浆置换**(重症)
- **JAK 抑制剂**:研究(有效)
- **死亡率仍高**(50%)

#### IMNM
- 激素 + MTX / 利妥昔单抗 / IVIG
- 激素常**单用无效**
- **停他汀**(HMGCR)

#### 包涵体肌炎(IBM)
- 激素一般无效
- 物理治疗、支持

### 4. 支持
- **物理治疗**:预防萎缩、康复
- **吞咽评估**:言语治疗
- **营养**:高蛋白、肌萎缩
- **骨保护**:钙 + D、双膦酸盐
- **疫苗**:灭活、避免活疫苗
- **预防 PCP**:激素 + 免疫抑制

## 注意事项

### 监测
- 肌力(MMT-8):每月
- CK、铁蛋白(抗 MDA5)、IL-2R:每月
- 肺功能 + HRCT:3-6 月
- 肝肾、血常规:每月
- 肿瘤筛查:每年(尤其高危)

### 危重指标
- 抗 MDA5(尤其 CADM 男性)
- 铁蛋白 ↑↑、IL-2R ↑
- RP-ILD 进行性
- **不治疗快速死亡**

### 感染
- 免疫抑制 + 激素:肺炎、PCP、CMV、真菌
- **PCP 预防**(高剂量激素)
- CMV PCR 监测

### 儿童 DM
- 血管病重(胃肠道穿孔、溃疡)
- 钙化常见
- 生长、骨发育

### 妊娠
- 缓解 ≥ 1 年考虑
- HCQ 可用
- MTX、CTX、MMF 致畸

### 预后
- 经典 PM/DM:5 年生存率 > 80%
- ASS + ILD:差异大
- 抗 MDA5 + RP-ILD:6 月生存率 50%
- IMNM:激素反应差,致残高
