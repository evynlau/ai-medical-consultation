# 急性中毒总论

## 概述
急性中毒是急诊常见急症,占急诊 5-10%。**毒物**包括药物、农药、化学品、有毒动植物、CO 等。**早期识别、脱离毒源、稳定生命体征、解毒、清除未吸收毒物、对症支持**是处理原则。

## 流行病学
- 我国中毒前 5:**酒精、有机磷、百草枯、CO、镇静催眠**
- 农药致死主因
- 自杀、误服为主

## 毒物分类

### 1. 农药
- **有机磷**、**百草枯**(禁用,极毒)、**杀鼠剂**(抗凝、毒鼠强)
- **拟除虫菊酯**

### 2. 药物
- 镇静催眠(苯二、苯巴比妥)
- **阿片**(吗啡、海洛因、芬太尼)
- 抗精神病
- 抗抑郁(三环)
- **洋地黄**
- 对乙酰氨基酚

### 3. 化学品
- **CO**(一氧化碳)
- 氰化物
- **甲醇、乙二醇**
- 苯、酚
- 强酸、强碱

### 4. 毒品
- 海洛因、冰毒、K 粉
- 大麻、摇头丸

### 5. 动植物
- 河豚、毒蘑菇
- 蛇毒
- 蜂蛰
- 曼陀罗

### 6. 金属
- 铅、汞、砷
- 铁

## 临床表现

### 综合征识别
| 综合征 | 表现 | 毒物 |
|---|---|---|
| **胆碱能** | 汗、涎、流泪 + N/M | 有机磷 |
| **抗胆碱** | 干、红、盲、狂、热、瘫 | 阿托品、TCA、抗组胺 |
| **阿片** | 昏迷 + 呼吸抑制 + 针瞳 | 阿片 |
| **拟交感** | 激动、出汗、心快、压高 | 可卡因、苯丙胺 |
| **血清素** | 激动、肌阵挛、反射亢、高热 | SSRI + MAOI、5-HT 类 |
| **恶性综合征** | 高热、肌僵、COA | 抗精神病 |
| **酒精** | 共济、意识 | 醇、苯二、GHB |
| **高铁 Hb** | 发绀(巧克力色血) | 亚硝酸盐、苯佐卡因 |
| **氰化物** | 呼吸苦杏仁味、PaO₂ 正常 | 氰化氢、硝普盐 |
| **CO** | 意识、皮肤樱桃红 | 一氧化碳 |
| **TCA** | QRS、癫痫、低血压 | 三环 |
| **洋地黄** | 恶心、黄绿、心律失常 | 强心苷 |

## 评估

### 病史
- **毒物**(种、量、时间)
- **途径**(口服、吸入、皮肤、注射)
- **现场**
- 既往、基础病
- 共同暴露(CO、家庭)
- **空瓶、残留**

### 体检
- **生命体征**(T、HR、BP、RR、SpO₂)
- **意识**(GCS)
- **瞳孔**(针瞳 vs 散瞳)
- **皮肤**(红、湿、出汗、注射)
- **气味**(酒精、苦杏仁、蒜味)
- **心律**

### 实验室
- **血气**(酸碱、乳酸)
- **电解质**(Na、K、阴离子间隙)
- **血糖**
- **毒物血浓度**(特殊)
- **肝、肾、肌酶**(横纹肌)
- **凝血**
- **ECG**(QRS、QT)
- **影像**(X、CXR)

## 处理

### 1. 急救 ABC
- **气道**:保护、气管插管
- **呼吸**:吸氧、机械
- **循环**:液体、升压、抗心律
- **昏迷**:葡萄糖、纳洛酮
- **心律**:按 ACLS

### 2. 清除未吸收毒物

#### 皮肤
- **大量清水冲洗**(持续)
- 脱衣、隔离

#### 眼
- 大量生理盐水冲洗 15-30 min

#### 吸入
- **脱离**(救援者注意)
- 通风、给氧

#### 口服
- **催吐**(1 h 内大毒)
  - **不**对昏迷、腐蚀、惊厥、孕妇
  - **不**对儿童(常用)
- **洗胃**:
  - **6 h 内**(后部分)
  - **温水、生理盐水**(反复)
  - **量大毒**:可达 10-20 L
  - **不**:腐蚀性、汽油
  - **不**:无气道保护
- **活性炭**(1-2 h 内,部分延长)
  - 1 g/kg(50-100 g)
  - 反复 6-12 h(肠循环)
  - **不**:金属、醇、腐蚀、铁
- **导泻**(不常规):硫酸镁、聚乙二醇
- **全肠灌洗**(肠溶、缓释):PEG

### 3. 加速排泄
- **利尿**(强极性)
- **血液透析**(HD):
  - 分子小、水溶、低蛋白
  - **甲醇、乙二醇、锂、水杨酸**
- **血液灌流(HP)**:脂溶、蛋白结合
  - **百草枯、有机磷、苯巴比妥**
- **CRRT**(不稳定)
- **血浆置换**(部分)
- **MOF**(严重)

### 4. 解毒剂(特效)
| 毒物 | 解毒 |
|---|---|
| **有机磷** | 阿托品、氯解磷定 |
| **阿片** | **纳洛酮** |
| **苯二** | 氟马西尼(慎) |
| **对乙酰氨基酚** | **NAC** |
| **CO** | 高压氧 |
| **氰化物** | 亚硝酸钠、硫代硫酸钠、羟钴胺 |
| **高铁 Hb** | 亚甲蓝 |
| **甲醇/乙二醇** | 乙醇/甲吡唑 + 透析 |
| **铁** | 去铁胺 |
| **洋地黄** | **地高辛抗体 Fab** |
| **TCA** | 碳酸氢钠 |
| **β 阻** | 胰高血糖素、肾上腺素 |
| **CCB** | 钙、胰高血糖素、IV 脂肪 |
| **抗凝(华法林)** | Vit K1、FFP、PCC |
| **肝素** | 鱼精蛋白 |
| **异烟肼** | 维生素 B6 |
| **降糖药** | 葡萄糖、胰高血糖素 |
| **酒精** | 维生素 B1、糖 |
| **百草枯** | **无**(早期处理) |

### 5. 支持对症
- **控制抽搐**:苯二(地西泮、咪达唑仑)
- **高温**:降温
- **横纹肌溶**:水化、碱化
- **肾衰**:透析
- **感染**:抗菌
- **营养支持**

## 注意事项
- **院前识别**(报警)
- **自身安全**(CO、毒气)
- **解毒剂预先备**
- **可毒物联合**(CO+镇静)
- **不**:催吐对强酸、煤油、惊厥、孕妇
- **气道保护**(昏迷)
- **不**:活性炭金属、醇、腐蚀
- **特效解毒** 早
- **不**延误透析
- **心理干预**(自杀)
- **上报**(CO 群发)

## 特殊场景
- **群体中毒**(CO、食物、毒气):应急救援
- **故意**(自杀):心理干预、风险评估
- **工业**:化学品、气体
- **儿童**:误服剂量、种类

## 注意事项总结
- **ABC 优先**
- **G I Decontamination** 原则
- **特效解毒** 早
- **支持不放松**
- **公众教育**(CO、农药)
- **心理**
