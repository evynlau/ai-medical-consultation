# 心肌病分类与处理

## 概述
心肌病是一组异质性心肌疾病,表现为心肌结构与功能异常(非冠脉、高血压、瓣膜、先天性所致)。2013 ESC 立场声明将其分为:

## 主要类型

### 1. 肥厚型心肌病(HCM)
- **特征**:非对称性室间隔肥厚(IVS ≥ 15 mm),伴左室流出道梗阻
- **遗传**:常染色体显性,β-肌球蛋白重链(MYH7)、肌球蛋白结合蛋白 C(MYBPC3)突变最常见
- **症状**:劳力性呼吸困难、胸痛、晕厥、SCD
- **体征**:胸骨左缘 3-4 肋间收缩期喷射性杂音(蹲位减轻、Valsalva 加重)
- **检查**:心电图(病理性 Q 波 + 左室高电压)、心脏超声(IVS/LVPW ≥ 1.3)、心脏 MRI(延迟强化)
- **治疗**:
  - 避免剧烈运动、脱水
  - 药物治疗:β 阻滞剂(首选)、非二氢吡啶 CCB(地尔硫䓬、维拉帕米)
  - 梗阻严重:室间隔心肌消融术(ASA)或外科切除
  - SCD 高危:ICD 植入(5 年 SCD 风险 ≥ 6%)
- **SCD 风险评估**:HCM Risk-SCD Calculator
- **家族筛查**:一级亲属心电图 + 超声心动图

### 2. 扩张型心肌病(DCM)
- **特征**:左室或双心室扩大,收缩功能减低(LVEF < 45%),非其他原因所致
- **病因**:特发性(30%)、遗传(TTN 截断突变等)、病毒/免疫、酒精/化疗、中毒
- **症状**:心衰(劳力性气短)、室性心律失常、栓塞
- **治疗**:
  - 戒酒、停用蒽环类等病因处理
  - 标准抗心衰「四联」(ARNI/ACEI、β 阻滞剂、MRA、SGLT2i)
  - 心脏再同步化(CRT):LBBB + QRS ≥ 150 ms + LVEF < 35%
  - 难治:左室辅助装置(LVAD)、心脏移植
- **家族筛查**

### 3. 限制型心肌病(RCM)
- **特征**:舒张功能严重受损,室壁僵硬、心房显著扩大,而室壁厚度、室腔大小基本正常
- **病因**:淀粉样变(最常见)、结节病、放射、嗜酸性粒细胞增多症
- **诊断**:心脏 MRI 钆延迟强化 + 心内膜活检
- **治疗**:对症、利尿;**避免**地高辛、CCB;心脏淀粉样变可化疗

### 4. 致心律失常性右室心肌病(ARVC)
- **特征**:右室心肌被纤维脂肪组织替代,室性心律失常、SCD
- **遗传**:常染色体显性,PKP2、DSP 等桥粒蛋白突变
- **诊断**:2010 修订 Task Force 标准(结构、功能、心电图、组织、基因)
- **治疗**:
  - 限制剧烈运动
  - β 阻滞剂
  - ICD(明确 SCD 幸存者、室速晕厥者)

### 5. 围产期心肌病(PPCM)
- **诊断标准**:
  - 妊娠晚期或产后 5 个月内
  - 无其他明确心衰原因
  - LVEF < 45%
- **治疗**:标准抗心衰(**ACEI/ARB 哺乳期禁用**,可用溴隐亭)
- **预后**:30-50% 完全恢复

## 其他类型
- **Takotsubo(应激性)心肌病**:情绪应激诱发的可逆性心尖气球样变,酷似 STEMI
- **左室致密化不全(NVCM)**:先天性,左室肌小梁增多、深陷隐窝
- **心脏淀粉样变**:免疫球蛋白轻链型(AL)或转甲状腺素蛋白型(ATTR)

## 注意事项
- 任何年轻(< 55 岁)SCD 需排查 HCM、ARVC、长 QT、Brugada
- 心肌炎恢复期(3-6 个月)避免剧烈运动(再发风险)
- 化疗前(尤其蒽环类)评估基线心功能,定期监测
- 家族性心肌病应行家系筛查和遗传咨询
