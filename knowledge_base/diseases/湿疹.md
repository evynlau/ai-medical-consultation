# 湿疹(特应性皮炎)

## 概述
湿疹是由多种内外因素引起的具有明显渗出倾向的瘙痒性皮肤炎症反应,皮疹多样性、对称分布、剧烈瘙痒、反复发作。急性期以丘疱疹为主,有渗出倾向;慢性期以苔藓样变为主。广义包括特应性皮炎、接触性皮炎、脂溢性皮炎等。

## 流行病学
- 一般人群患病率约 3-5%
- 儿童患病率高达 10-20%
- 工业国家发病率持续上升
- 男女无明显差异

## 病因
- **内因**:
  - 遗传过敏体质(父母有哮喘、过敏性鼻炎、湿疹)
  - 免疫功能异常(Th1/Th2 失衡)
  - 内分泌、代谢紊乱
  - 精神紧张、焦虑
- **外因**:
  - 食物过敏原:牛奶、鸡蛋、花生、海鲜
  - 吸入性:尘螨、花粉、霉菌
  - 接触性:羊毛、化纤、染料、洗涤剂
  - 感染:金黄色葡萄球菌、马拉色菌
  - 气候:干燥、寒冷、炎热

## 临床表现
### 急性湿疹
- 红斑、丘疹、水疱
- 糜烂、渗出
- 边界不清
- 剧烈瘙痒
- 对称分布

### 亚急性湿疹
- 红肿减轻
- 渗出减少
- 出现鳞屑、结痂
- 仍有瘙痒

### 慢性湿疹
- 皮肤粗糙、增厚
- 苔藓样变(皮革样)
- 色素沉着或减退
- 皲裂
- 反复发作

### 特殊类型
- **手部湿疹**:最常见,职业相关
- **乳房湿疹**:需排除 Paget 病
- **阴囊/阴唇湿疹**:剧烈瘙痒
- **婴儿湿疹**:面颊、头皮、尿布区

## 辅助检查
- **斑贴试验**:找接触性过敏原
- **点刺试验或 IgE 检测**:吸入/食物过敏
- **皮肤活检**:不典型者排除其他病
- **真菌镜检**:鉴别手足癣

## 诊断
- 临床诊断为主
- 多形性皮损、对称分布、剧烈瘙痒、反复发作
- 慢性期特征:苔藓样变、色素沉着

## 治疗
### 一般治疗
- 避免搔抓、热水烫洗、肥皂刺激
- 保持皮肤清洁湿润
- 穿宽松纯棉衣物
- 避免已知过敏原
- 避免精神紧张
- 饮食调整(怀疑食物过敏者)

### 外用治疗(首选)
- **急性期**:炉甘石洗剂、3%硼酸溶液湿敷
- **糖皮质激素软膏**:分级使用
  - 弱效:氢化可的松(面部、婴幼儿)
  - 中效:地奈德、糠酸莫米松
  - 强效:卤米松、倍氯米松
  - 超强效:氯倍他索(短期)
- **钙调磷酸酶抑制剂**:他克莫司、吡美莫司(面部、皮肤薄嫩处)
- **保湿剂**:每日多次(关键!)

### 系统治疗
- **抗组胺药**:西替利嗪、氯雷他定、依巴斯汀(止痒)
- **糖皮质激素**:严重急性发作短期用
- **免疫抑制剂**:环孢素、甲氨蝶呤(顽固病例)
- **生物制剂**:度普利尤单抗(中重度特应性皮炎)
- **JAK 抑制剂**:乌帕替尼(近年新药)

### 物理治疗
- 紫外线(UVA/UVB):慢性顽固性
- PUVA
- 激光

## 自我管理
- **保湿!保湿!保湿!** 每日多次,尤其洗澡后
- 避免诱发因素(过敏原、刺激物)
- 洗澡:温水、短时、少用肥皂
- 衣物:纯棉、宽松
- 环境:湿度 50-60%、温度适宜
- 心理调适(瘙痒-焦虑恶性循环)
- 规律作息

## 何时就医
- 皮疹广泛、症状重
- 瘙痒影响睡眠、工作
- 出现感染(红肿加重、脓液、发热)
- 反复发作、自行治疗无效
- 婴儿湿疹
- 严重过敏反应

## 不同部位湿疹特点
| 部位 | 特点 |
|---|---|
| 头皮 | 油腻性鳞屑、瘙痒 |
| 面部 | 红斑、丘疹、明显瘙痒 |
| 手部 | 接触性多见、皲裂 |
| 乳房 | 需排除 Paget 病 |
| 阴囊 | 慢性顽固、瘙痒剧烈 |
| 小腿 | 多伴静脉曲张 |
| 婴儿 | 急性多见、渗出明显 |

## 预后
- 急性湿疹:1-2 周可缓解
- 慢性湿疹:易反复,病程长
- 婴儿湿疹:约 50% 1 岁内自愈,30% 持续到成年
- 顽固性需长期维持治疗
- 保湿和避免诱因是预防复发的关键
