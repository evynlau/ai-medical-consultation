# 慢性扁桃体炎

## 概述
慢性扁桃体炎是腭扁桃体的慢性炎症性疾病,主要由急性扁桃体炎反复发作或隐匿性感染发展而来。临床表现为扁桃体慢性肿大、隐窝内细菌/脱落上皮堆积形成干酪样分泌物、反复咽痛发作。是儿童及青少年常见的上呼吸道疾病,严重者可影响呼吸及吞咽功能,甚至引起全身并发症。

## 分类
- 增生性扁桃体炎(增殖型,扁桃体肥大)
- 纤维性扁桃体炎(纤维型,瘢痕形成)
- 隐窝型慢性扁桃体炎(最常见,隐窝扩大,分泌物潴留)
- 实质型慢性扁桃体炎(支持组织减少,淋巴细胞浸润)

## 危险因素
- 急性扁桃体炎反复发作(每年>3-4次)
- 慢性隐匿性感染(细菌持续存在于扁桃体隐窝)
- 邻近器官炎症(慢性鼻窦炎、慢性咽炎)
- 腺样体肥大(儿童常见,阻塞后鼻孔)
- 免疫功能低下(营养不良、慢性疾病)
- 长期吸烟、饮酒
- 环境污染(粉尘、有害气体刺激)
- 维生素缺乏(维生素A、C缺乏)
- 体质因素(特应性体质)

## 常见症状
- 反复咽痛发作(每月或数周一次)
- 咽部异物感、阻塞感
- 张口呼吸(扁桃体肥大时)
- 睡眠打鼾(尤其儿童)
- 吞咽困难(大扁桃体时)
- 夜间睡眠呼吸暂停(严重者)
- 声音含糊(开放性鼻音)
- 反复低热(慢性炎症活动期)
- 颈部淋巴结肿大
- 口臭(隐窝内分泌物腐败)
- 消化不良、纳差(毒素吸收)
- 儿童可出现"腺样体面容"(颌骨变长、硬腭高拱)

## 并发症
- 扁桃体周围脓肿(扁桃体周炎)
- 风湿热(链球菌感染后免疫反应)
- 急性肾炎(链球菌感染后免疫复合物沉积)
- 心肌炎
- 关节炎
- 颈淋巴结炎
- 慢性鼻窦炎(后鼻孔分泌物刺激)
- 中耳炎(咽鼓管功能异常)
- 支气管肺炎(下行感染)
- 睡眠呼吸暂停综合征(夜间低氧)
- 长期张口呼吸导致颌面部发育异常

## 治疗原则
- 一般治疗:休息、多饮水、营养支持
- 药物治疗:
  - 抗生素(青霉素类、头孢类,针对乙型溶血性链球菌)
  - 局部用药(复方硼砂溶液漱口、碘含片)
  - 免疫调节剂(匹多莫德、泛福舒)
  - 中药制剂(清热解毒类:牛黄解毒片、蓝芩口服液)
- 手术治疗(适应证):
  - 反复急性发作(每年>4次或连续2年>3次/年)
  - 扁桃体过度肥大导致上呼吸道梗阻
  - 睡眠呼吸暂停综合征
  - 药物治疗无效,症状持续不缓解
  - 已出现风湿热、肾炎等并发症
  - 单侧扁桃体迅速增大(需排除肿瘤)
- 手术方式:扁桃体切除术(扁桃体全切)、低温等离子消融术
- 儿童手术需严格把握指征,<4岁一般不推荐切除

## 何时就医
- 咽痛剧烈伴高热>3天不缓解
- 吞咽困难导致无法进食进水
- 呼吸困难或睡眠打鼾明显加重
- 出现颈部强直或张口困难(警惕扁桃体周脓肿)
- 反复咽痛发作频繁(每月数次)
- 发现扁桃体不对称增大或表面有溃疡
- 出现心悸、关节肿痛、血尿(警惕全身并发症)
- 儿童出现发育迟缓或"腺样体面容"
- 药物治疗效果不佳

## 预防
- 积极治疗急性扁桃体炎(规范抗生素疗程,不可提前停药)
- 增强体质(适度运动、均衡营养、充足睡眠)
- 避免受凉感冒
- 保持口腔卫生(刷牙漱口,治疗龋齿)
- 积极治疗邻近器官炎症(慢性鼻窦炎、咽炎)
- 避免接触粉尘和有害气体
- 戒烟限酒
- 补充维生素(维生素C、A)
- 免疫功能低下者需加强监测
- 季节变化时注意防护(流感季节少去人群密集处)
