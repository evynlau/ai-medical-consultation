# 老年高血压

## 概述
我国 60+ 高血压患病率 50-60%,80+ > 80%。**单纯收缩期高血压(ISH)**多见,与动脉硬化相关。老年高血压**异质性大、靶器官损害多、共病多**。**个体化目标、谨慎降压、关注直立性低血压、衰弱、跌倒**是核心。

## 特点
- **ISH**(SBP ≥ 140,DBP < 90) 常见
- **脉压增大**(> 60 mmHg)
- **血压波动大**(昼夜、清晨)
- **体位性低血压**(OH):立位 SBP ↓ ≥ 20 或 DBP ↓ ≥ 10
- **餐后低血压**
- **白大衣高血压**
- **继发**(肾动脉、内分泌、睡眠呼吸暂停)注意
- **晨峰** 高发
- **心脑肾** 损害多

## 诊断
- **诊室血压 ≥ 140/90**(3 次,非同日)
- **诊室外确认**(家庭 ≥ 135/85、动态 ≥ 130/80)
- **24 h 动态**:评估昼夜节律
- 测:坐位 5 min, 双臂, ≥ 3 次
- **立位血压**(老人、糖尿病):3 min 立位
- 评估:靶器官、共病、衰弱、用药

## 治疗目标
- **65-79 岁**:耐受可降至 < 140/90
- **≥ 80 岁** 或 衰弱:**< 150/90**(初始)
- **IS H**:**SBP < 150**(可耐受 140)
- **D BP < 90**(不低至 60 以下)
- **直立 SBP ≥ 90 mmHg**
- **降压要慢**(避免低灌注)

## 治疗策略

### 1. 生活方式
- **减盐**(< 5 g/d)
- **DASH / 平衡**
- **运动**(有氧 + 抗阻)
- **减重**(BMI < 25)
- **戒烟限酒**
- 心理

### 2. 药物

#### 起始
- **单药**(1 级、低危):**CCB、ACEI/ARB、利尿剂**
- **联合**(2 级 / > 150/90):**SPC**(单片复方)
  - **ACEI/ARB + CCB**
  - **ACEI/ARB + 噻嗪**
  - **CCB + 噻嗪**

#### 推荐
- **ISH**:**CCB**(利尿剂、ACEI/ARB)
- **DASH**
- **心衰**:**ACEI/ARB + β + MRA + 噻嗪**
- **肾衰**:**ACEI/ARB**
- **冠心病**:**β + ACEI/ARB**
- **卒中**:**ACEI/ARB + CCB**
- **糖尿病**:**ACEI/ARB + CCB**
- **前列腺**(BPH):α 阻(注意 OH)
- **OSA**:CPAP + 减重

#### 常用
- **CCB**:**氨氯地平** 2.5-10 mg、硝苯地平控释
- **ACEI**:**培哚普利**、贝那普利、雷米普利
- **ARB**:**缬沙坦、替米沙坦、厄贝沙坦、奥美沙坦**
- **利尿**:**吲达帕胺** 1.5 mg、氢氯噻嗪 12.5-25 mg
- **β 阻**:**美托洛尔、比索洛尔**(心绞痛、心衰、冠心病)
- **α 阻**:哌唑嗪、多沙唑嗪(前列腺,可 OH)

#### 注意
- **β 阻** 慎用老年(可能抑郁、疲劳)
- **α 阻** 慎(可 OH)
- **直立性低血压** 高危:慎用 α、CCB、αβ
- **衰弱**:缓、个体化
- **降压起始 1/2 剂量**,缓慢

### 3. 体位性低血压(OH)
- **停** OH 致药(α、利尿、血管扩张)
- **穿弹力袜、卧-立-走**
- **补液**
- **米多君**(顽固)

### 4. 餐后低血压
- **少食多餐**
- **低碳水**
- 避免餐前降压药
- 餐前饮水

### 5. 清晨高血压
- **晨起前药**
- **长效 + 控制晨峰**(替米沙坦、氨氯地平)
- **动态血压**

## 监测
- **家庭血压**(电子、上臂)
- **定期动态**(评估)
- **立位血压**(起立)
- **靶器官**(心、肾、视网膜)
- **电解质、肾功**(利尿、ACEI/ARB)
- **衰弱、跌倒**

## 多病共病
- 卒中、TIA
- 心衰(目标 < 130)
- 冠心病(< 130/80)
- 糖尿病(< 130/80)
- 肾衰(监测 eGFR、K)
- 心房颤动

## 注意事项
- **个体化目标**(衰弱、年龄、预期寿命)
- **缓慢降压**
- **OH、跌倒** 关注
- **晨峰** 控制
- **衰弱** 不严格(< 150/90)
- **不可过低 DBP**(< 60, 冠状动脉灌注)
- **多重用药** 精简
- **季节变化**(夏低冬高)
- **动态血压评估** 周期
- **家属教育**
