# 分泌性中耳炎

## 概述
分泌性中耳炎(OME)是中耳积液(包括浆液、黏液)而无急性感染症状的疾病,鼓膜完整。是儿童听力下降最常见原因,2-5 岁高发,约 90% 学龄前儿童曾有过。

## 病因与发病机制

### 核心机制:**咽鼓管功能障碍(Eustachian tube dysfunction, ETD)**
- 中耳通气、引流、清洁功能障碍
- 中耳负压 → 黏膜渗液 → 积液
- 黏液纤毛清除受损

### 儿童高发因素
- 咽鼓管短、平、水平
- 腺样体肥大(机械压迫、慢性炎症)
- 上呼吸道感染
- 鼻窦炎、过敏性鼻炎
- 腭裂(解剖异常)
- 唐氏综合征

### 成人因素
- 鼻咽癌(单侧 OME 警示!)
- 鼻咽部腺样体残留
- 鼻部变应性、炎症
- 放射性损伤
- 鼻咽部手术
- 放疗
- 鼻咽癌筛查指征:**单侧 OME + 成人 = 鼻咽镜**

## 临床表现
- **听力下降**(儿童:反应慢、看电视音量大、学习差)
- **耳闷**:耳内压迫感
- **耳鸣**:低调
- **自声过强**:听自己声音变响
- **轻微耳痛**(急性加重时)
- **急性感染者**:耳痛、发热

## 诊断

### 病史与体征
- 反复上呼吸道感染史
- **耳镜 / 耳内镜**:
  - **鼓膜内陷**:锤骨短突突出、锤骨柄横位、光锥变形或消失
  - **鼓室积液征**:
    - 气泡(气 - 液平面)
    - 鼓膜琥珀色、橘黄色
    - 鼓膜肥浊
  - 鼓膜活动度减低(鼓气耳镜)

### 声导抗(关键)
- **B 型曲线**(平坦):典型 OME
- **C 型曲线**(负压):咽鼓管功能障碍早期
- **As 型**:听骨链固定

### 纯音测听
- 传导性聋,平均 20-30 dBHL
- 气骨导差

### 鼻咽镜
- **成人单侧 OME 必须鼻咽镜**,排除鼻咽癌
- **儿童**:评估腺样体

### 影像
- 颞骨 CT:乳突气房密度增高
- 不常规,鉴别诊断

## 治疗

### 观察期
- **单纯 OME 观察 3 月**:
  - 50% 3 月内自愈
  - 适合无听力损害、无症状儿童

### 药物治疗
- **抗生素**(急性发作期):阿莫西林 1-2 周
- **糖皮质激素**:口服 / 鼻用,短期(2 周)
- **抗组胺 / 减充血剂**:伴 AR、URTI
- **黏液促排剂**:桉柠蒽、桃金娘油
- **咽鼓管吹张**(捏鼻鼓气 Valsalva):辅助

### 手术治疗

#### 鼓膜切开 + 置管(grommet)
- **指征**:
  - 观察 3 月未愈 + 听力损害
  - 双侧 OME + 语言发育迟缓
  - 反复急性发作
  - 鼓膜内陷袋形成(胆脂瘤前兆)
  - 自愈困难的高危因素(腭裂、Down)
- **置管类型**:短管(6-18 月)、长管(> 2 年)、T 形管
- **机制**:通气引流,等待咽鼓管功能恢复

#### 腺样体切除术
- **指征**:腺样体肥大伴 OME
- **同期置管**:效果好
- **避免单纯腺样体切除**(不解决 OME)

#### 鼓膜修补
- OME 治愈后遗留穿孔

### 儿童 OME 管理流程
1. **诊断**:耳镜 + 声导抗 + 测听(可配合)
2. **观察 3 月**(轻度、无听力损害)
3. **药物辅助**(急性加重、鼻部疾病)
4. **腺样体评估**(伴肥大)
5. **置管**(无效或听力损害)
6. **取管**(6-18 月后)
7. **复发性 OME**:再次置管或腺样体切除

## 注意事项
- 成人**单侧 OME** 必须鼻咽镜 / MRI 排除鼻咽癌
- 儿童 OME 影响**语言、学习、行为**,不可忽视
- 长期置管可致鼓膜穿孔、鼓室硬化、胆脂瘤
- 置管期间**避免水入耳**(可戴耳塞或淋浴帽)
- 飞行前后使用减充血剂滴鼻
- 鼻部疾病(AR、鼻窦炎)同步治疗
- **疫苗**:肺炎球菌、Hib、流感疫苗可降低发病率
- 二手烟暴露是儿童 OME 可改变危险因素
