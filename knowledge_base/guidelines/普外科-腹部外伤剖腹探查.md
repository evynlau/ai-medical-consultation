# 腹部外伤剖腹探查

## 概述
腹部外伤在创伤中占 7-10%,死亡率 10-30%。分为闭合伤(钝挫伤)和穿透伤(刀刺、枪弹)。剖腹探查指征需综合血流动力学、影像、查体决定,延误手术是死亡主因。

## 损伤机制
- **闭合伤**:交通事故、高坠、撞击、挤压
  - 常见损伤:脾破裂、肝破裂、肠系膜撕裂、空回肠、胰腺、肾、膀胱
- **穿透伤**:刀刺伤、枪弹伤
  - 入口和出口不等同损伤范围,需重视「伤道」

## 评估

### 初步评估(ATLS)
- 气道、呼吸、循环、神经、暴露
- **血流动力学不稳定**(SBP < 90 mmHg,心率 > 120)→ 抢救室剖腹 / 手术室
- **FAST 超声**:床旁重点评估,4 个区(右上腹、左上腹、盆腔、心包)
  - 阳性 → 紧急剖腹
- **胸腹联合伤**:胸片、CT、必要时剖胸

### 进一步评估(稳定者)
- **腹部增强 CT**:金标准
  - 实质脏器损伤分级(AAST Ⅰ-Ⅴ 级)
  - 肠系膜损伤、游离气体、腹膜后血肿
- **诊断性腹腔穿刺(DPL)**:敏感度 90%+
  - 不凝血 > 10 mL、胃肠内容物、胆汁 → 剖腹指征
- **实验室**:血常规、血气、乳酸、肝功、胰酶、淀粉酶、凝血、血型

## 剖腹探查指征

### 绝对指征
- 血流动力学不稳定 + 腹腔积血(FAST 阳性 / DPL 阳性)
- 腹膜炎体征
- 膈下游离气体
- 穿透伤伴腹膜破损
- 腹腔穿刺抽到胃肠内容物、胆汁、血不凝

### 相对指征
- CT 提示活动性出血、肠管损伤
- 腹膜后血肿(穿透伤、扩张性)
- 实质脏器损伤分级高(AAST Ⅳ-Ⅴ 级)

### 非手术管理(NOM)
- **血流动力学稳定** + **无腹膜炎** + **无空腔脏器损伤**
- 适应证:AAST Ⅰ-Ⅲ 级肝脾损伤
- 绝对卧床、ICU 监测、动态复查 CT、限制性液体复苏
- 失败率 10-15%

## 手术原则

### 开腹切口
- 腹部正中切口(快速、暴露好、可向上下延长)

### 探查顺序
- **控制出血**优先:四象限填塞、Pringle 手法(肝门阻断)
- 然后处理污染源
- 系统探查:肝、脾、胃、十二指肠、空回肠、结肠、直肠、膀胱、膈

### 实质脏器处理
- **脾**:
  - 保脾:缝合、修补、脾动脉结扎、生物胶
  - 切脾:无法保脾、严重伤、凝血障碍
  - 儿童优先保脾
- **肝**:
  - 缝合、止血纱、氩气刀、电凝
  - 肝部分切除:严重星芒状伤
  - 肝周填塞:凝血病、循环不稳
- **肾**:尽量保肾(修补、部分切除)
- **胰腺**:引流 + 修补,主胰管损伤行胰肠吻合 / 远端切除

### 空腔脏器处理
- 胃、小肠:**修补 / 切除 + 吻合**
- 结肠:**修补 / 切除 + 造口**(损伤 > 50% 周径、污染重、休克)
- 直肠:修补 + 乙状结肠造口 + 骶前引流
- 膀胱:修补 + 留置导尿 / 耻骨上造瘘

### 腹膜后血肿
- **中央区**(十二指肠、胰腺、肾):穿透伤、扩张性 → 探查
- **盆腔区**:钝挫 → 不打开;穿透 → 选择性
- **侧腹区**:钝挫稳定 → 观察

## 术后管理
- ICU 监测、容量复苏
- 纠正凝血病(输血浆、血小板)
- 抗生素、破伤风免疫
- 营养支持:早期肠内
- 损伤控制(DCO):分阶段手术,ICU 复苏,24-48 h 再手术

## 注意事项
- **三联征**:骨盆骨折 + 腹膜后血肿 + 失血性休克
- 妊娠外伤:母胎评估,辐射尽量避免
- 多发伤评估需多学科
- **并发症**:再出血、腹腔感染、胰瘘、肠瘘、短肠综合征
- 法律证据保留(刀刺、枪伤)
