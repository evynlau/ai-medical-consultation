# 感冒中医辨证

## 概述
感冒是感受触冒风邪或时行病毒,引起肺卫功能失调,出现鼻塞、流涕、喷嚏、咳嗽、头痛、恶寒、发热、全身不适等为主要临床表现的常见外感病。中医分风寒、风热、暑湿、气虚、阴虚、时行感冒,辨证用药各不同。

## 病因病机
- **外因**:六淫(风、寒、暑、湿、燥、火)、时行病毒(流感)
- **内因**:正气不足、卫外不固、劳倦、体虚
- **病位**:肺卫
- **基本病机**:卫表不和、肺失宣肃

## 辨证分型

### 1. 风寒感冒
- **主症**:恶寒重、发热轻、无汗、头痛、肢节酸痛
- **伴随**:鼻塞声重、流清涕、咽痒咳嗽、痰白稀
- **舌脉**:舌苔薄白、脉浮紧
- **治法**:辛温解表、宣肺散寒
- **方药**:**荆防败毒散** / **葱豉汤** / **麻黄汤**(表实)
- **中成药**:感冒清热颗粒、风寒感冒颗粒、午时茶

### 2. 风热感冒
- **主症**:发热重、恶寒轻、有汗、咽喉红肿疼痛
- **伴随**:鼻塞流黄涕、咳嗽痰黄、口干微渴
- **舌脉**:舌尖红苔薄黄、脉浮数
- **治法**:辛凉解表、清肺透热
- **方药**:**银翘散** / **桑菊饮**
- **中成药**:银翘解毒丸/片/颗粒、双黄连、清热解毒口服液、桑菊感冒冲剂

### 3. 暑湿感冒(夏季)
- **主症**:夏季发病、发热、汗出热不解
- **伴随**:头昏重胀痛、身重倦怠、胸闷、呕吐泄泻
- **舌脉**:舌苔厚腻、脉濡数
- **治法**:清暑祛湿解表
- **方药**:**新加香薷饮** / **藿香正气散**(藿香正气为暑湿常用)
- **中成药**:藿香正气水/胶囊/丸、十滴水、保济丸

### 4. 气虚感冒(平素气虚)
- **主症**:恶寒较甚、发热、无汗、身楚倦怠
- **伴随**:咳嗽、咯痰无力、平素易感冒
- **舌脉**:舌淡苔白、脉浮无力
- **治法**:益气解表
- **方药**:**参苏饮** / **玉屏风散**(预防)
- **中成药**:玉屏风颗粒(预防)、参苏丸

### 5. 阴虚感冒
- **主症**:身热、微恶风寒、少汗
- **伴随**:心烦、口干、干咳少痰
- **舌脉**:舌红少苔、脉细数
- **治法**:滋阴解表
- **方药**:**加减葳蕤汤**

### 6. 时行感冒(流感)
- **主症**:高热不退、恶寒、肌肉酸痛、头痛、乏力
- **舌脉**:舌红、脉数
- **治法**:清热解毒、疏风透表
- **方药**:**银翘散合普济消毒饮** / **清瘟败毒饮**
- **中成药**:连花清瘟胶囊/颗粒(卫健委流感推荐)、疏风解毒胶囊、金花清感
- **西药**:神经氨酸酶抑制剂(奥司他韦)

## 鉴别要点(快记)

| 项目 | 风寒 | 风热 | 暑湿 |
|---|---|---|---|
| 发热 | 轻 | 重 | 中,午后重 |
| 恶寒 | 重 | 轻 | 中 |
| 汗 | 无 | 有 | 汗出热不解 |
| 鼻涕 | 清 | 黄 | 浊 |
| 咽痛 | 轻 | 重 | 中 |
| 痰 | 白稀 | 黄稠 | 白腻 |
| 舌苔 | 薄白 | 薄黄 | 厚腻 |
| 脉 | 浮紧 | 浮数 | 濡数 |

## 兼证治疗

### 咳嗽重
- 风寒:**杏苏散**;风热:**桑菊饮**
- 痰热:**清金化痰汤**

### 咽痛重
- 风热:**银翘散 + 山豆根、射干**
- 中成药:蓝芩口服液、蒲地蓝消炎口服液

### 头痛重
- 风寒:**川芎茶调散**
- 风热:**芎芷石膏汤**

### 高热
- **柴胡注射液**(肌注)、**清开灵**(静滴)

## 注意事项

### 治疗
- **解表祛邪为要**,不可早用补益(留邪)
- 不可过用寒凉(冰伏表邪)
- 中病即止,汗出热退即停药

### 调护
- 避风保暖、休息
- 多饮温开水、姜枣茶(风寒)、薄荷茶(风热)
- 清淡饮食
- **饮食禁忌**:油腻、辛辣、生冷(退热后 1-2 日)

### 转归
- 普通感冒 5-7 天自愈
- 流感易传变、肺炎、心肌炎
- **警惕信号**:高热不退、呼吸困难、胸痛、神志改变、咯血
- 老人、儿童、孕妇、慢病者易重症,及时就诊

### 误区
- 感冒就喝板蓝根(适用于风热)
- 感冒就喝姜汤(只对风寒)
- 「感冒7天好」盲目硬扛
- 滥用抗生素(病毒为主)
- 多种感冒药叠加(对乙酰氨基酚过量)
