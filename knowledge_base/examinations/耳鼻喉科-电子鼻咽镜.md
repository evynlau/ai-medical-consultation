# 电子鼻咽镜

## 概述
电子鼻咽镜(电子鼻咽喉镜)是软性纤维镜结合电子成像技术的内镜系统,可清晰观察鼻咽、口咽、喉、下咽、咽鼓管等部位,具有可弯曲、患者耐受好、图像清晰、可录像等优势,是鼻咽癌、喉癌筛查与诊断的首选工具。

## 原理与设备
- **软性纤维镜**(冷光源)+ **CCD/CMOS 摄像头**
- **工作通道**:吸引、活检、喷药
- **辅助**:NBI(窄带成像,内镜)、荧光
- **显示器**:高清成像系统

## 适应证

### 鼻咽部
- **鼻咽癌筛查**(EBV 阳性、单侧分泌性中耳炎、回缩血涕)
- 鼻咽癌随访
- 腺样体评估
- 鼻咽部炎症、良性肿瘤

### 喉部
- **声嘶**检查
- **喉癌筛查**
- **声带息肉 / 小结 / 囊肿 / 白斑**
- 喉外伤、喉狭窄
- 喉返神经麻痹
- 喉部异物

### 咽部
- 慢性咽炎、扁桃体
- 咽部异物
- OSA 评估
- 下咽癌筛查

### 其他
- 吞咽功能评估(FEES)
- **咽鼓管功能评估**
- 鼻咽部活检、脓肿切开
- 取异物(咽、食管入口)

## 禁忌证

### 绝对禁忌
- 急性颅底骨折伴脑脊液漏
- 严重颈椎外伤
- 不能配合检查且无监护人

### 相对禁忌
- 严重心肺疾病
- 鼻腔大出血
- 凝血障碍(取活检)
- 精神异常、不合作儿童

## 操作流程

### 准备
1. **知情同意**
2. **禁食 2-4 h**(防呕吐)
3. **询问**:鼻中隔手术史、出血史、麻药过敏
4. **鼻腔准备**:
   - 减充血剂:1% 麻黄碱 / 羟甲唑啉
   - 表面麻醉:1-2% 丁卡因 / 利多卡因
   - 雾化吸入麻醉
5. **咽部麻醉**:1% 丁卡因喷雾
6. **必要时**:阿托品(抑制分泌)、镇静

### 体位
- 坐位 / 半卧位,头部稳定
- 儿童:家长 / 助手固定

### 检查
1. 选择通畅鼻腔
2. 沿下鼻道进入鼻咽部
3. **系统观察**:
   - 鼻咽:顶后壁、咽隐窝(鼻咽癌好发)、咽鼓管圆枕、咽鼓管咽口
   - 软腭、口咽
   - 舌根、会厌谷
   - 喉:会厌、杓会厌皱襞、杓状软骨、室带、声带(发「衣」声观察)、声门下
   - 下咽:梨状窝(下咽癌)
4. **录像、拍照**
5. **必要时活检**:可疑病灶取组织

### 检查后
- 禁食水 2 h(防呛咳)
- 取活检者:鼻腔填塞 1-2 h、防出血
- 告知:麻醉后短暂咽部麻木

## 异常表现

### 鼻咽部
- **鼻咽癌**:菜花样 / 结节 / 溃疡 / 黏膜下隆起,好发咽隐窝
- **腺样体肥大**:鼻咽顶后壁分叶状
- **鼻咽部囊肿**(潴留)
- **鼻咽纤维血管瘤**(青少年男性)

### 喉部
- **声带息肉 / 小结 / 囊肿**
- **声带白斑**(癌前)
- **喉癌**:菜花样、溃疡、不对称
- **声带麻痹**:固定于中线 / 旁正中
- **Reinke 水肿**

### 下咽
- **下咽癌**:梨状窝黏膜不规则
- 异物

## NBI(窄带成像)
- 蓝光(415 nm)、绿光(540 nm)
- 强调黏膜表层微血管形态
- **早癌**(鼻咽癌、喉癌)更清晰显示
- **鼻咽癌 NBI 分类**:「尾形」血管(敏感度 80%+)

## 临床应用价值
- **早期鼻咽癌诊断**:可发现微小黏膜病变
- **喉癌分期**:声带活动、病变范围
- **活检精准定位**:提高病理阳性率
- **动态观察**:发声、吞咽、咳嗽时变化
- **术中辅助**:鼻内镜手术

## 注意事项
- 鼻腔狭窄:选择合适路径(中鼻道)
- 鼻中隔穿孔、术后:慎入
- 急性鼻出血期:避免
- 儿童需家长陪同、必要时镇静
- 大量活检可致出血,需备止血
- 检查前禁食水(防呕吐)
- 黏膜麻醉过敏(丁卡因):罕见但严重
- 检查后 2 h 勿进食(咽麻木易呛咳)
- 提示鼻咽癌可疑者联合 EBV DNA、MRI
- **单侧分泌性中耳炎**(成人)+ 鼻咽镜 = 排除鼻咽癌
