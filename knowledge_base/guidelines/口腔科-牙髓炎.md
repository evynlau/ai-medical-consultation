# 牙髓炎

## 概述
牙髓炎是牙髓组织的炎症性疾病,多为深龋未及时治疗的进展结果,临床以剧烈疼痛为主要表现。分为可复性牙髓炎、不可复性牙髓炎(急性、慢性)、牙髓坏死、牙髓变性等。

## 病因

### 细菌感染(主要)
- **深龋**(最常见)
- **牙体缺损**:楔状缺损、磨损、牙折
- **牙周袋**(逆行性牙髓炎)
- **血源感染**(罕见)

### 物理因素
- **急性牙外伤**:冠折、牙震荡
- **慢性损伤**:磨牙症、咬合创伤
- **温度**:磨牙产热、窝洞制备
- **电流**:异种金属(流电刺激)
- **气压**:高空飞行(气压性)

### 化学因素
- **充填材料刺激**:硅水门汀、自凝树脂
- **酸蚀**
- **消毒药物**

### 医源性
- 窝洞制备产热
- 牙髓暴露未妥善处理

## 分类与临床表现

### 可复性牙髓炎
- 冷热刺激一过性敏感
- 无自发痛
- 刺激去除即缓解

### 急性牙髓炎(不可复性)
- **自发痛**:阵发、剧烈、夜间加重
- **温度刺激**:冷热痛,**热痛冷缓解**
- **放射痛**:沿三叉神经分布放射,**不能定位**
- **坐卧不安**(夜间痛)
- 晚期:搏动性痛、热加剧
- 体征:深龋、探痛、叩诊早期(-),晚期(+)

### 慢性牙髓炎
- **长期钝痛、咬合痛**
- 冷热敏感
- 食物嵌塞痛
- **慢性溃疡性**(开放性)
- **慢性闭锁性**
- **慢性增生性**(牙髓息肉,青少年)

### 牙髓坏死
- 无痛、牙冠变色(灰黑)
- 探髓无反应

### 牙髓变性
- 牙髓钙化(髓石)
- 牙内吸收(粉红斑点)

## 诊断

### 病史
- 疼痛性质、持续时间、放射
- 冷热刺激
- 夜间痛
- 咬合痛

### 临床检查
- **视诊**:龋坏、充填体、牙冠变色、瘘管
- **探诊**:深龋、探痛
- **叩诊**:早期(-)、晚期(+)
- **松动度**
- **牙髓活力测试**(关键):
  - **冷诊**:冰棒 / 氯乙烷 / 冷气
  - **热诊**:热牙胶
  - **电活力测试**(EPT)
- **X 线**(根尖片):
  - 深龋近髓
  - 根尖周病变(鉴别)
  - 髓石、根管钙化

### 鉴别诊断
- **三叉神经痛**:扳机点、洗脸痛、电击样
- **急性根尖周炎**:定位明确、咬合痛、叩痛
- **龈乳头炎**:定位明确、龈乳头红肿
- **急性上颌窦炎**:多牙痛、头痛、鼻塞

## 治疗

### 治疗原则
- **去除感染、保护活髓**(可复性)
- **去除感染、保存患牙**(不可复性)

### 可复性牙髓炎
- **安抚治疗**:
  - 氧化锌丁香油酚(ZOE)安抚
  - 氢氧化钙间接盖髓
  - **充填修复**

### 不可复性牙髓炎

#### 根管治疗(首选, RCT)
- **原理**:彻底清除感染根管 + 严密充填
- **步骤**:
  1. **开髓揭顶**
  2. **髓腔预备**
  3. **根管预备**:不锈钢 / 镍钛器械
     - 手扩、K 锉
     - 机扩(ProTaper、WaveOne、Reciproc)
  4. **根管消毒**:氢氧化钙、氯己定
  5. **根管充填**:牙胶尖 + 根管封闭剂
  6. **冠方封闭**:复合树脂、GIC
  7. **术后修复**:充填 / 嵌体 / 全冠

#### 活髓保存治疗
- **间接盖髓**(深龋):Ca(OH)₂ + GIC
- **直接盖髓**(意外露髓):
  - Ca(OH)₂、MTA、Biodentine
- **活髓切断**(年轻恒牙):
  - 部分冠髓切除 + Ca(OH)₂ 覆盖
  - 根尖继续发育(apexogenesis)
- **根尖诱导成形术**(年轻恒牙根尖未闭):
  - Ca(OH)₂、MTA 屏障(apexification)

#### 牙髓摘除术(传统)
- 局麻下摘除牙髓
- 已逐步被 RCT 取代

#### 干髓术、塑化术(历史)
- 疗效不确切,已基本淘汰

### 急诊处理
- **开髓引流**:急性牙髓炎剧痛应急
- **牙髓失活**:亚砷酸(48 h) / 多聚甲醛(7-10 d)
- **口服止痛药**:布洛芬、双氯芬酸
- **抗生素**:扩散至根尖周 / 间隙感染

## 注意事项
- 急性期优先**止痛**,不可贸然充填
- **X 线检查**重要(根管情况、根尖周)
- 弯曲根管、钙化根管难度大,需显微根管
- **显微根管治疗**(根管显微镜):提高成功率
- 根管治疗后脆性增加,需**全冠**保护
- **MTA** 是良好根管屏障材料
- 根尖未发育完成的年轻恒牙:活髓切断 / apexification
- 乳牙牙髓炎:根管治疗(乳牙根管) 或 拔除
