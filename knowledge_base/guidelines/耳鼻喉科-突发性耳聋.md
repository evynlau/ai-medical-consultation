# 突发性耳聋

## 概述
突发性耳聋(SSNHL)是指 72 h 内突然发生的、原因不明的感音神经性听力损失,至少在相邻两个频率听力下降 ≥ 20 dB。我国年发病率约 5-20/10 万,近年呈上升趋势,**治疗越早,预后越好**。

## 病因与机制

### 不明原因(占多数),可能机制
- **内耳微循环障碍**:血栓、栓塞、出血(最被接受)
- **病毒感染**:HSV、VZV、流感、腮腺炎
- **自身免疫**:Cogan 综合征、狼疮
- **膜迷路积水**(类似梅尼埃急性发作)
- **蜗窗膜破裂**
- **精神应激、自主神经紊乱**

### 危险因素
- 高血压、糖尿病、高血脂
- 吸烟、酗酒
- 心理压力、疲劳
- 血管病、动脉硬化

## 临床表现
- **突发听力下降**(数分钟-数小时-3 d)
- **耳鸣**(70-90%):可为首发
- **耳闷胀感**
- **眩晕**(30%):提示前庭受累
- **恶心、呕吐**(伴眩晕时)
- **听觉过敏 / 重振**

## 分型(中华医学会指南)
- **低频下降型**:1 kHz 以下受累,预后好(可能膜迷路积水)
- **高频下降型**:4 kHz 以上,预后差
- **平坦型**:全频下降(可能内耳血管)
- **全聋型**:全频重度聋,预后最差

## 诊断

### 核心:纯音测听
- 72 h 内发生
- 至少相邻 2 个频率听力下降 ≥ 20 dB
- 单侧多见(95%)

### 检查
- **耳镜**:鼓膜正常
- **声导抗**:A 型,镫骨肌反射消失
- **听力学**:
  - 纯音测听(确诊)
  - 言语测听
  - ABR(听神经瘤鉴别)
- **前庭功能**(伴眩晕):
  - 视频头脉冲(vHIT)
  - 冷热试验
  - 前庭诱发肌源性电位(VEMP)
- **实验室**:
  - 血常规、血糖、血脂、肝肾功能
  - 凝血
  - 感染:EBV、HSV、HIV、梅毒
  - 自身抗体(ANA、ANCA):鉴别
- **影像**:
  - **颞骨 MRI / 内听道 MRI**(必备):**排除听神经瘤**
  - 颅脑 MRI(怀疑颅内病变)

## 治疗

### 治疗时机
- **越早越好**:发病 1 周内治疗效果最佳
- 1 月后开始治疗,效果差
- **超过 3 月**多形成永久聋

### 一般治疗
- **卧床休息**
- **心理疏导**
- **低盐饮食**
- **避免噪声、劳累**

### 药物治疗
#### 糖皮质激素(基础)
- **口服**:泼尼松 1 mg/kg/d × 7-14 d,渐减量
- 或甲泼尼龙、地塞米松
- **鼓室内注射**(补救 / 重症):
  - 甲泼尼龙、地塞米松
  - 经鼓膜穿刺或圆窗置管
- **机制**:抗炎、消肿、改善微循环

#### 改善微循环
- **银杏叶提取物**(EGb 761):金纳多
- **前列地尔**(脂质体 PGE1)
- **低分子右旋糖酐**
- **丹参注射液**
- **降纤**:巴曲酶(纤维蛋白原高)
- **抗凝**:低分子肝素(争议)

#### 神经营养
- **甲钴胺**(维生素 B12)
- **鼠神经生长因子**(NGF)
- **胞磷胆碱**

#### 高压氧(辅助)
- 发病早期(< 2 周)
- 联合药物,提高疗效

### 治疗方案推荐
- **低频下降型**:利尿剂(氢氯噻嗪) + 激素
- **高频下降型**:扩血管 + 神经营养 + 激素
- **平坦型**:扩血管 + 激素 + 神经营养
- **全聋型**:强化方案 + 鼓室内激素

### 随访
- 治疗 7-14 d 复查听力
- 3 月评估预后
- 未恢复者佩戴助听器或人工耳蜗植入

## 注意事项
- **单侧突发听力下降 = 排除听神经瘤**:MRI 必需
- **治疗越早越好**:延误致永久聋
- **双侧 SSNHL** 警惕全身病(血管炎、自身免疫)
- 儿童 SSNHL 罕见,需全面排查
- **复发型 SSNHL**:5-10%,需长期随访
- 伴眩晕者预后差
- 老年、伴糖尿病、治疗晚者预后差
- 高压氧需在有条件医院、专科会诊后进行
- **梅尼埃病**:低频聋 + 眩晕 + 波动,需鉴别
