# 甲状腺功能亢进

## 概述
甲状腺功能亢进症(甲亢)指甲状腺合成和分泌甲状腺激素过多,导致高代谢和交感兴奋综合征。Graves 病(GD)最常见(60-80%),多见于 20-50 岁女性。其他病因包括毒性多结节性甲状腺肿(TMNG)、毒性腺瘤(TA)、桥本甲亢、亚急性甲状腺炎、药物性等。

## 病因分类
- **自身免疫性**:Graves 病(TSH 受体抗体 TRAb 阳性)
- **甲状腺自主性**:
  - 毒性多结节性甲状腺肿(TMNG)
  - 毒性腺瘤(TA)
- **破坏性甲状腺炎**:
  - 亚急性(亚甲炎)、「无痛性」、「产后」
  - 桥本甲状腺炎「漏出期」
- **外源性**:
  - 甲状腺激素过量
  - 含碘造影剂/药物(胺碘酮)
  - TSH 分泌性垂体瘤(继发性)

## 临床表现
- **高代谢**:怕热、多汗、消瘦、乏力
- **神经**:易激惹、震颤、焦虑、失眠
- **心血管**:心动过速、房颤、收缩压↑、脉压差大、心衰
- **消化**:食欲亢进、腹泻、肝损
- **生殖**:月经稀发、不育
- **Graves 特异**:
  - 弥漫性甲状腺肿、杂音
  - **突眼**(TAO,30%)
  - **胫前黏液水肿**(2%)
  - **杵状指**(罕见)
- **甲状腺危象**(见后)

## 诊断与鉴别
### 实验室
- **TSH** ↓(亚临床期可 < 0.1 mU/L)
- **FT3、FT4** ↑(明确甲亢)
- **TRAb** / TSI:Graves 特异(阳性率 70-95%)
- **TPOAb / TgAb**:桥本、GD 可阳性
- **血沉**:亚甲炎↑ > 50 mm/h

### 影像
- 甲状腺超声:弥漫性肿大、血流「火海征」(GD)、结节
- **摄碘率(RAIU)**:
  - 升高:GD、TMNG、TA
  - 降低:甲状腺炎、外源性、碘负荷
- 必要时甲状腺核素显像

## 治疗

### 1. 抗甲状腺药物(ATD)
**甲巯咪唑(MMI)**:首选,15-30 mg/d × 4-8w → 减量 5-10 mg/d,总疗程 12-18 月
**丙硫氧嘧啶(PTU)**:妊娠 T1、甲状腺危象、严重过敏 MMI 者,150-300 mg tid
- 副作用:粒细胞缺乏(0.3%)、肝损、皮疹、血管炎
- **监测**:前 3 月每 2-4 周查血常规、肝功

### 2. 放射性碘(RAI,¹³¹I)
- **适应证**:ATD 失败/复发、TMNG、术后复发
- **禁忌**:妊娠/哺乳、严重突眼(可加重)
- 治疗前低碘饮食 1-2 周,ATD 停用 1 周
- 通常一次治愈,甲减发生率 50-80%(需终身 L-T4 替代)

### 3. 甲状腺全/近全切除
- 适应:巨大、结节可疑癌、ATD/RAI 禁忌、儿童
- 术前 ATD + Lugol 液 1-2 周

### 4. 对症
- **β 阻滞剂**:普萘洛尔 10-20 mg tid,控制心率
- 房颤:抗凝、控制心率

## 甲状腺危象(Storm)
- 诱因:感染、手术、创伤、RAI、停药
- 诊断:**Burch-Wartofsky ≥ 45** 或日本甲状腺协会标准
- 治疗:PTU 优先 → Lugol 液 → 普萘洛尔 → 糖皮质激素 → 退热、纠正水电
- ICU 监护,死亡率 10-30%

## 注意事项
- MMI 与 PTU 不互换
- 妊娠 T1 用 PTU,T2 改 MMI
- TRAb > 3 倍正常 → 妊娠晚期、新生儿甲亢风险
- 儿童首选 ATD
- 突眼:戒烟、激素、眶减压
- 亚临床甲亢(TSH ↓、FT3/4 正常):老年、房颤、骨质疏松高危需治疗
