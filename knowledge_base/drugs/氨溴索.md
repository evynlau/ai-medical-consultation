# 氨溴索

#### 氨溴索
*## 基本信息*## 
- 分类：黏液溶解剂（祛痰药）
- 常见商品名：沐舒坦、 Ambroxol
- 上市时间：1970年代
- 处方/OTC状态：处方药（部分OTC）
*## 适应症*## 
- 痰液粘稠不易咳出
- 慢性支气管炎、支气管哮喘
- 新生儿呼吸窘迫综合征
*## 药理作用*## 
- 促进呼吸道黏膜纤毛运动
- 增加痰液中唾液酸含量，降低黏度
- 刺激表面活性物质合成
*## 用法用量*## 
- 成人：30mg/次，3次/日（口服）
- 雾化吸入：7.5-15mg/次，2-3次/日
- 静脉注射：用于住院患者
*## 不良反应*## 
- 胃肠道不适（恶心、呕吐）
- 偶见过敏反应
*## 注意事项*## 
- ⚠️ 支气管痉挛患者应先用支气管扩张剂
- ⚠️ 肝肾功能不全者调整剂量
*## 禁忌*## 
- 对氨溴索过敏者
*## 临床应用要点*## 
- 与抗生素联用可提高肺组织药物浓度
- 新生儿呼吸窘迫综合征预防性使用效果确切
- 起效较快，30分钟至2小时见效
