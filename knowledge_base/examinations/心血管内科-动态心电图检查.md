# 动态心电图检查

## 概述
动态心电图(Holter)通过便携式记录盒连续记录 24-72 h(部分可达 7-14 天)心电图,**捕获常规心电图难以发现的一过性心律失常和心肌缺血**。

## 适应证
### Ⅰ 类(明确推荐)
- 评估原因不明的心悸、晕厥、黑矇、头晕
- 评估阵发性 AF / 房扑
- 起搏器 / ICD 功能障碍评估
- MI 后 / 慢性心衰 LVEF 降低者,评估心律失常风险
- 隐源性卒中 / TIA 筛查 AF
- 评估抗心律失常药物疗效
- 评估频率适应性起搏器

### Ⅱ 类
- 评估胸痛原因
- 评估糖尿病神经病变
- 评估肥厚型心肌病
- 评估二尖瓣脱垂
- 评估长 QT 综合征、Brugada 综合征

## 检查前准备
- 胸前皮肤清洁、剃毛(必要时)
- 电极位置:5-7 个
  - 改良 V1(胸骨右缘 4 肋间)
  - V3(V3 位置)
  - V5(V5 位置)
- 男性胸毛多者备皮
- 详细记录日记:**症状 + 时间**(活动、情绪、用药)

## 正常参考值
- 总心搏:约 8-12 万次/24 h
- 室早:< 100 次/24 h(或 < 1%)
- 房早:< 100 次/24 h
- 房颤负荷:< 0.5%(< 23 min/24 h)
- 室速:无
- 长 RR 间期(< 50 bpm):睡眠时常见
- ST 段:水平型 / 下斜型压低 ≥ 0.1 mV 持续 ≥ 1 min 为缺血

## 常见阳性发现及意义

### 心律失常
- **频发室早**:
  - < 1% 良性
  - 1-10% 需进一步评估
  - > 10-20% 警惕室早致心肌病
  - 形态:左束支(LBBB 形态)→ 右室起源;右束支(RBBB 形态)→ 左室起源
- **非持续性室速(NSVT)**:连续 ≥ 3 个室早、< 30 s
  - 在心梗后 / DCM / HCM:猝死风险↑
  - 无器质性心脏病:预后好
- **持续性室速**:需立即治疗
- **房颤 / 房扑阵发**:评估 AF 负荷,决定抗凝
- **长 RR 间期**:
  - 2-3 s:年轻运动员生理性
  - > 3 s:SSS、高度 AVB → 起搏器
- **间歇性束支阻滞** / 预激

### 心肌缺血
- 评估标准:ST 水平/下斜型压低 ≥ 0.1 mV 持续 ≥ 1 min,两次间隔 ≥ 1 min
- 「缺血性 ST 改变」最常见于活动时
- 变异型心绞痛:ST 一过性抬高
- 计算缺血总负荷:ST 段下移面积(综合深度 × 时间)

### 起搏器功能
- 起搏比例(%)
- 起搏夺获情况
- 感知功能
- 起搏器介导性心动过速(PMT)
- 电池电压

## 记录日记
**关键**:患者日记是症状-心电图关联的金标准。常见记录:
- 11:30 开会(紧张)
- 12:00 心慌
- 14:20 上 3 楼(气短)
- 22:00 入睡

## 报告内容
1. **基本信息**:姓名、年龄、ID、检查时间
2. **心率统计**:
  - 最快 / 最慢 / 平均心率
  - 24h 总心搏
  - 白天 / 夜间心率
3. **心律失常**:
  - 房早、室早数量及形态
  - 房速、房颤、房扑发作次数 + 持续时间 + 负荷
  - 室速、室上速
  - 长 RR 间期
4. **ST-T 改变**:
  - 缺血发作次数
  - 与活动 / 症状关系
5. **结论**:有意义的发现 + 建议

## 注意事项
- **不能洗澡**(一般)
- 远离强磁场(高电压、电焊、磁疗)
- 不能用电磁炉
- 保持皮肤干燥
- 记录准确日记
- 24 h 阳性检出率:约 30-40%(发作稀疏者)
- **复发性不明晕厥**:可延长至 7-14 天,或改用事件记录仪 / 植入式记录仪(ILR)

## 衍生检查
- **事件记录仪(External Loop Recorder, ELR)**:症状出现时激活记录
- **植入式心电记录仪(ILR)**:皮下植入,可用 3 年,用于稀少发作
- **移动心脏遥测(MCT)**:实时传送,适合高危
- **心电贴片**:长程(7-14 天),依从性好
