# 重症超声

## 概述
重症超声(Critical Care Ultrasound, CCUS)是床旁即时超声(Point-of-Care Ultrasound, POCUS)在 ICU 的系统应用,涵盖心脏、肺、血管、腹腔、神经等评估。具有无创、实时、可重复特点,改善诊断、引导操作、评估治疗反应。

## 核心应用

### 1. 心脏超声(FOCUS / FoCUS)
- **评估内容**:
  - 心腔大小、室壁运动
  - 心功能:LVEF、RV 扩张 / 衰竭
  - 容量状态:IVC、LV 充盈
  - 心包积液
  - 瓣膜功能(快速评估)
- **方法**:
  - **胸骨旁长轴(PLAX)** / 短轴(PSAX)
  - **心尖四腔(A4C)** / 五腔
  - **剑突下四腔**(SC4C)
  - **肋下 IVC**

### 2. 肺部超声(LUS)
- **正常**:A 线、滑动征(肺点判断气胸)
- **异常征象**:
  - **B 线**(垂直混响):间质综合征、肺水肿、ARDS、肺炎
  - **肺实变**(肝样变):肺炎、严重肺水肿
  - **胸腔积液**:无回声区、脊柱征
  - **气胸**:无 B 线 + 无肺滑动 + 肺点
- **方案**:
  - **BLUE 协议**(急性呼吸衰竭)
  - **LUS 评分**(ARDS):12 区,0-3 分 × 12,> 18 重度
- **膈肌评估**:膈肌增厚分数 DTF、膈肌位移

### 3. 容量评估
- **下腔静脉(IVC)**:
  - 内径 < 2.1 cm + 塌陷 > 50% → 容量不足
  - IVC 内径 / 塌陷指数(CI)
  - **CVP 估计**(敏感性、特异性有限)
- **左室充盈**:E/A、E/e'
- **RUSH 协议**(休克快速超声)

### 4. 血管超声

#### 深静脉血栓(DVT)
- 压迫法:股静脉、腘静脉
- 不能压扁 → DVT

#### 血管通路引导
- **中心静脉**(颈内、锁骨下、股)
- **动脉穿刺**
- **PICC**(经外周植入中心静脉)
- **优势**:减少气胸、动脉误穿

### 5. 腹部超声

#### FAST(eFAST)评估
- **游离液体**:肝肾隐窝、脾肾隐窝、盆腔
- **气胸**(扩展)
- **腹部外伤**(穿透、钝伤)

#### 胆道
- 胆囊壁增厚、胆汁淤积、胆管扩张、结石

#### 肾脏
- 肾积水、肾结石
- 肾灌注(RRI,多普勒)

### 6. 操作引导
- **胸腔穿刺**(避横膈)
- **腹腔穿刺**
- **心包穿刺**
- **腰椎穿刺**
- **神经阻滞**
- **血管通路**
- **气管插管**(喉)

### 7. 神经重症
- **视神经鞘直径(ONSD)**:< 5 mm 颅内压正常
- **经颅多普勒(TCD)**:
  - 大脑中动脉(MCA)
  - 血流速度 → 脑血管痉挛(SAH)
  - 搏动指数(PI)
  - 微栓子监测
- **经颅彩色双功超声**(TCCS):脑实质

## 适应证

### 呼吸困难(急性)
- **BLUE 协议**:
  - A 主导 + 滑动 → COPD / 哮喘
  - A 主导 + 滑动 + 静脉 → 肺栓塞
  - B 主导 → 心源性肺水肿
  - B 主导 + 实变 → 肺炎
  - 0 / A 主导 → 严重 COPD、哮喘、气胸

### 休克评估
- **RUSH 协议**(Rapid Ultrasound for Shock and Hypotension):
  - **心泵功能**(HR、CO)
  - **容量**(IVC)
  - **梗阻**(心包积液、张力性气胸)
  - **血管**(主动脉、腹主动脉瘤、DVT)
  - 快速鉴别休克类型

### AKI
- 肾积水(梗阻性)
- 肾大小、皮质厚度
- 肾阻力指数(RRI,多普勒)
  - > 0.7 提示持续 AKI

### 创伤
- **eFAST**:腹腔、心包、胸腔

## 实施

### 培训
- **基础**:60-100 例
- **进阶**:300-500 例(心脏、肺)
- **认证**:中国重症超声研究组(CCUSG)、WINFOCUS、ACCP/SCCM

### 设备
- 便携式、床旁
- 多探头:相控阵(心脏)、凸阵(腹)、线阵(血管、神经)、微凸(肺)

### 报告
- **图像存档**
- 报告:时间、所见、结论
- 整合临床

## 优势与局限

### 优势
- 无创、实时、可重复
- 床旁、减少转运
- 减少辐射(X 线、CT)
- 引导操作
- 快速评估

### 局限
- **操作者依赖**
- **体型、肺气、敷料影响**
- **声窗有限**(肺气、肥胖)
- 不能完全替代 CT/MRI

## 注意事项

### 临床整合
- **POCUS ≠ 替代**传统检查
- 整合病史、查体、检验
- 多超声联合
- 团队协作

### 质量控制
- 图像存档
- 定期考核
- 同行审阅

### 进阶评估
- TEE(经食管超声):肥胖、肺气、机械通气
- 心脏应变:心肌功能
- 颅内血管:脑血管反应性、压力自动调节

### 特殊场景
- **CPR**:心脏按压评估、ROSC 判断
- **ECMO**:导管位置、心功能
- **神经**:脑血流
- **围术期**:心脏手术

### 教学与认证
- **CCUSG**(中国重症超声研究组):初级、中级、高级培训
- 国际:WINFOCUS、ACCP、SCCM
- 受训后必须保持操作量
