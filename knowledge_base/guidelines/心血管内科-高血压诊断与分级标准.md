# 高血压诊断与分级标准

## 概述
高血压是我国最常见的慢性病,成人患病率约 27%(近 3 亿人),是心脑血管病最主要的可改变危险因素。准确的诊断与分级是治疗决策的基础。

## 诊断标准
依据《中国高血压防治指南 2018 修订版》:
- **诊室血压**:非同日 3 次测量收缩压 ≥ 140 mmHg 和/或舒张压 ≥ 90 mmHg
- **家庭血压**:≥ 135/85 mmHg
- **动态血压**:24h 平均 ≥ 130/80 mmHg,白天 ≥ 135/85 mmHg,夜间 ≥ 120/70 mmHg

## 血压分级
| 分级 | 收缩压(mmHg) | | 舒张压(mmHg) |
|---|---|---|---|
| 正常 | < 120 | 和 | < 80 |
| 正常高值 | 120-139 | 和/或 | 80-89 |
| 1 级(轻度) | 140-159 | 和/或 | 90-99 |
| 2 级(中度) | 160-179 | 和/或 | 100-109 |
| 3 级(重度) | ≥ 180 | 和/或 | ≥ 110 |
| 单纯收缩期 | ≥ 140 | 和 | < 90 |

当 SBP 与 DBP 分属不同级别时,**以较高级别为准**。

## 危险分层
根据血压水平 + 心血管危险因素 + 靶器官损害 + 临床并发症:
- **低危**:1 级 + 无危险因素
- **中危**:1 级 + 1-2 个危险因素,或 2 级 + < 2 个
- **高危**:1-2 级 + ≥ 3 个危险因素或靶器官损害
- **很高危**:3 级,或 1-2 级 + 临床并发症

## 危险因素清单
- 年龄 > 55(男)/ 65(女)
- 吸烟
- 血脂异常:TC ≥ 5.2 或 LDL-C ≥ 3.4 mmol/L
- 早发心血管病家族史(男 < 55 / 女 < 65 一级亲属)
- 腹型肥胖:男腰围 ≥ 90 cm,女 ≥ 85 cm
- 缺乏运动
- 高同型半胱氨酸血症(≥ 15 μmol/L,「H 型高血压」)

## 靶器官损害
- 心脏:左室肥厚(心电图或超声心动图)
- 血管:颈动脉内膜中层厚度 ≥ 0.9 mm 或斑块
- 肾脏:eGFR 30-59 ml/min/1.73m² 或微量白蛋白尿 30-300 mg/24h
- 眼:视网膜动脉狭窄、动静脉交叉压迫

## 临床并发症
- 心脏:心绞痛、心肌梗死、心衰、房颤
- 脑:脑出血、缺血性卒中、TIA
- 肾:肾功能不全 eGFR < 30、蛋白尿 > 300 mg/24h
- 血管:主动脉夹层、外周动脉疾病
- 眼:高血压视网膜病变 III/IV 级

## 注意事项
- 测量前 30 分钟禁烟禁咖啡,排空膀胱,静坐 5 分钟
- 测量双臂,取较高一侧;老年人、糖尿病者需测立位血压
- **白大衣高血压**:诊室高、诊室外正常,需 24h 动态血压确诊
- **隐匿性高血压**:诊室正常、诊室外高,预后更差,不容忽视
- 儿童高血压采用年龄/性别/身高别百分位标准
