# 颌面外科概述与常见疾病

## 概述
颌面外科(口腔颌面外科)是口腔医学的重要分支,主要诊治**面颈部的先天性畸形、炎症、外伤、肿瘤、关节疾病**等。需要口腔颌面外科医师具备普通外科、整形外科、眼科、神经外科、耳鼻喉等多学科知识。

## 业务范围
- 颌面部外伤(颌骨骨折、软组织伤)
- 颌面部肿瘤(良性、恶性)
- 先天性畸形(唇腭裂、颅面畸形)
- 颞下颌关节疾病
- 颌面部感染
- 牙颌面畸形(正颌外科)
- 唾液腺疾病
- 神经疾病(三叉神经痛)
- 口腔颌面种植
- 美容整形

## 常见疾病诊治要点

### 颌面部骨折
- **下颌骨骨折**(最常见)
  - 临床表现:咬合错乱、张口受限、面部畸形
  - 治疗:**切开复位 + 内固定**(钛板/钛钉)
  - 咬合关系恢复是核心
- **颧骨颧弓骨折**
  - 面部塌陷、张口受限
  - 手术复位 + 固定
- **上颌骨骨折**(Le Fort Ⅰ/Ⅱ/Ⅲ)
  - 严重、常伴颅脑损伤
  - 复位 + 颌间固定
  - Le Fort Ⅱ/Ⅲ 需多学科
- **鼻骨骨折**
  - 鼻出血、鼻梁塌陷、歪斜
  - 复位(闭合 / 开放)

### 唇腭裂
- 最常见先天性畸形(我国 1.4/1000)
- 一期修复:3-6 月(唇裂)、1-1.5 岁(腭裂)
- 序列治疗:外科 + 正畸 + 语音
- 多学科(MDT):颌面、儿科、麻醉、语音治疗、心理
- 腭裂术后语音训练

### 牙颌面畸形(正颌外科)
- 骨性错颌(下颌前突/后缩、上颌前突/后缩、双颌前突)
- **正畸-正颌联合治疗**:
  - 术前正畸(去代偿)
  - 正颌手术(Le Fort Ⅰ、BSSRO 等)
  - 术后正畸(精细调整)
- 数字化设计(3D 打印导板、虚拟手术)

### 颞下颌关节疾病
- **TMD**(颞下颌关节紊乱)
  - 关节弹响、疼痛、张口受限
  - 保守治疗为主:咬合板、理疗、药物
  - 关节镜(冲洗、粘连松解)
  - 开放手术(罕见)
- 关节强直:关节成形
- 关节脱位:手法复位

### 唾液腺疾病
- **腮腺多见**
- 腮腺肿瘤(多形性腺瘤 70%):外科切除(面神经解剖)
- 颌下腺、舌下腺肿瘤
- 涎石:取石、腺体切除
- 炎症:导管结石、抗感染

### 颌面肿瘤
- 良性:造釉细胞瘤、骨瘤、神经鞘瘤
- 恶性:**口腔鳞癌**(多见)、唾液腺癌、肉瘤
- 颈部淋巴结清扫
- 重建:游离皮瓣(腓骨、前臂、腹直肌)
- 多学科(肿瘤外科、整形、放疗、化疗)

### 颌面部感染
- 智齿冠周炎(见口腔科)
- 颌骨骨髓炎
- 间隙感染(口底、咽旁、颞下)
- 切开引流 + 抗生素
- 牙源性感染最多见

### 神经疾病
- **三叉神经痛**(外科治疗)
  - 药物(卡马西平)失败
  - 射频热凝
  - 球囊压迫
  - 微血管减压(MVD)
  - 立体定向放射

## 手术特点
- 麻醉:**鼻插管全麻**(口腔内手术)
- 重要标志:面神经、腮腺导管、颈动脉
- 无菌要求高
- 术后饮食:流食、半流
- 口腔卫生维护
- 咬合关系(关键)
- 面部美观(头等大事)

## 注意事项
- **颌面骨折常伴颅脑损伤**:先稳定生命体征
- 颌面骨折咬合恢复是核心
- 唇腭裂:序列治疗,儿童期多次手术
- 肿瘤:多学科、终身随访
- TMJ:首选保守
- 神经痛:MVD 效果最好
- 任何面部畸形:评估心理
