# 头颅 CT 检查

## 概述
头颅 CT 是神经科、急诊科最常用的**神经影像学检查**,利用 X 线对组织密度的高分辨,**快速识别出血、梗死、占位、钙化**等病变。优点:扫描时间短(< 1 min)、急重症首选、急性出血高敏感;缺点:软组织分辨力差、辐射(约 2 mSv)、骨伪影。

## 适应证
- **急诊**:**脑卒中首选**(区分出血 / 缺血)、急性外伤、意识障碍、抽搐、剧烈头痛
- **神经系统定位体征**
- **颅内占位、脑积水**
- **骨性病变**(骨折、Paget)
- **脑疝、颅高压**

## 禁忌证与相对禁忌
- **无绝对禁忌**
- **相对**:**妊娠**(尤其早孕期)、甲状腺功能亢进症(对比剂)、造影剂过敏、肾功能不全

## 检查前准备
- **平扫**:无须特殊准备
- **增强**:禁食 4-6 h,询问过敏史、肾功
- **去除金属**(发夹、耳环、假牙)

## 主要技术
- **平扫(非增强)**:急诊、急性出血、急性外伤
- **增强扫描(CT+C)**:占位、血管、感染、术后
- **CTA(CT 血管成像)**:动脉瘤、动脉狭窄、动静脉畸形
- **CTP(CT 灌注)**:急性缺血性脑卒中半暗带评估
- **多模式 CT**:平扫 + CTA + CTP,一站式卒中评估

## 正常 CT 表现
| 组织 | CT 值(HU) |
|---|---|
| 脑灰质 | 35-45 |
| 脑白质 | 25-35 |
| 脑脊液 | 0-15 |
| 血液(新鲜) | 60-80 |
| 钙化 | > 100 |
| 骨 | > 1000 |
| 脂肪 | -50 ~ -100 |
| 空气 | -1000 |

**脑实质结构**:基底节、丘脑、胼胝体清晰可辨;脑室、脑沟、脑池对称。

## 急性出血(CT 高密度)
- **脑出血**:**高密度影**(新鲜血 60-80 HU,3-5 d 减低,与脑实质呈等密度,1-2 周密度更低,慢性期与 CSF 接近)
- **蛛网膜下腔出血(SAH)**:鞍上池、外侧裂、纵裂池高密度
- **硬膜外 / 硬膜下血肿**:
  - 硬膜外:**双凸透镜形**(动脉性)
  - 硬膜下:**新月形**(静脉性,易跨颅缝)
- **出血量计算(ABC/2)**:
  - A= 长径、B= 短径、C= 层数 × 厚度
  - V= A × B × C / 2

## 急性缺血性脑卒中
- **超急性期(0-6 h)**:**可无明显异常**(< 6 h 难辨)
- **早期征象**(MCA 供血区):
  - **岛带征(insular ribbon sign)**
  - **豆状核模糊**
  - **灰白质分界不清**
  - **脑沟变浅、轻微占位**
  - **大脑中动脉高密度征(HMCAS)**:动脉血栓
- **明确期(24-48 h)**:**低密度区**,符合供血区分布
- **出血转化**:低密度区内出现高密度

## 头颅外伤
- **颅骨骨折**:线性、凹陷、粉碎、颅底
- **脑挫伤**:着力点 / 对冲部位斑片状高密度(出血)、低密度(水肿)
- **硬膜外血肿**:双凸透镜高密度
- **硬膜下血肿**:新月形高密度(急性)、等密度(亚急性)、低密度(慢性)
- **弥漫性轴索损伤(DAI)**:皮髓交界、胼胝体点状出血(MRI SWI 更敏感)

## 占位性病变
- **脑肿瘤**:**等 / 稍高密度 + 周围水肿 + 强化**;**钙化**(脑膜瘤、颅咽管瘤、寡突胶质)
- **脑脓肿**:**环形强化 + 中央低密度**,周围水肿重
- **脑囊虫病**:多发小钙化

## 脑积水
- **脑室扩大**、**脑室周围低密度**(间质水肿、Transependymal CSF)
- **Evans 指数**:**侧脑室前角最大径 / 颅骨内板最大径** > 0.3
- 阻塞性:中脑导水管、第四脑室梗阻

## 缺血缺氧性脑病
- 心肺复苏后
- **双侧基底节 / 大脑皮层**密度减低
- **白质密度相对增高**("反转征")
- **脑沟脑池消失**(脑水肿)

## 注意事项
- **早期缺血(< 6 h)**:**CT 可能阴性**,需 MRI DWI 确诊
- **后颅窝 CT**:骨伪影多,小病灶易漏
- **对比剂过敏**:轻者皮疹、恶心,严重过敏性休克
- **肾功能不全(GFR < 30)**:慎用碘对比剂
- **辐射剂量**:儿童、孕妇注意,必要时选 MRI
- **儿童镇静**:难以配合者可镇静
- **图像窗**:常用脑窗(W 80, C 40)、骨窗(W 2000, C 500)
- **常规三平面重建**:横断面、矢状面、冠状面

## 报告基本结构
1. 临床信息
2. 扫描技术(平扫 / 增强 / CTA)
3. 各脑叶结构、脑室、脑沟
4. 阳性发现(位置、密度、范围)
5. 出血、梗死、占位等关键判断
6. 建议(增强、MRI、随访)
