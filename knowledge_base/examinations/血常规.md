# 血常规(Blood Routine Test)

## 概述
血常规是最基础、最常用的血液检查,通过检测血液中各类细胞的数量、形态和比例,辅助诊断感染、贫血、血液系统疾病等。

## 检查项目

### 红细胞系统
- 红细胞计数(RBC):男 4.0-5.5 ×10¹²/L,女 3.5-5.0
- 血红蛋白(HGB/Hb):男 120-160 g/L,女 110-150
- 红细胞比容(HCT)
- 平均红细胞体积(MCV)
- 平均血红蛋白含量(MCH)
- 平均血红蛋白浓度(MCHC)
- 红细胞分布宽度(RDW)

### 白细胞系统
- 白细胞计数(WBC):4-10 ×10⁹/L
- 分类:中性粒细胞(N%)、淋巴细胞(L%)、单核细胞、嗜酸、嗜碱

### 血小板
- 血小板计数(PLT):100-300 ×10⁹/L
- 平均血小板体积(MPV)
- 血小板分布宽度(PDW)

## 常见异常解读

### 贫血
- Hb 降低 + MCV 降低 → 缺铁性贫血、地中海贫血
- Hb 降低 + MCV 升高 → 巨幼细胞贫血(B12/叶酸缺乏)
- Hb 降低 + MCV 正常 → 急性失血、慢性病贫血

### 感染
- WBC ↑ + N% ↑ → 细菌感染
- WBC 正常/↓ + L% ↑ → 病毒感染
- 嗜酸 ↑ → 过敏、寄生虫

### 血液系统疾病
- 三系减少 → 警惕再障、白血病
- PLT ↓ → 出血倾向、免疫性血小板减少

## 适用场景
- 健康体检
- 发热、感染
- 乏力、头晕(查贫血)
- 出血倾向
- 化疗/放疗监测
- 术前常规

## 注意事项
- 空腹(避免脂血干扰)但非绝对
- 抽血前避免剧烈运动
- 女性避开月经期(可能影响结果)
- 报告需结合临床,由医生解读
