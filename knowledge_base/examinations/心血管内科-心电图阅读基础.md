# 心电图阅读基础

## 概述
心电图(ECG)是心血管病最常用、无创、便宜的检查,10 分钟可完成。本指南按阅读顺序阐述。

## 12 导联
- **肢体导联**:Ⅰ、Ⅱ、Ⅲ、aVR、aVL、aVF
- **胸前导联**:V1-V6
- V1-V2:右室
- V3-V4:室间隔 / 前壁
- V5-V6:左室侧壁
- Ⅱ / V1:看 P 波最清楚

## 正常值
- **心率**:60-100 次/分
- **P 波**:< 0.12 s,振幅 < 0.25 mV,Ⅰ/Ⅱ 直立、aVR 倒置
- **PR 间期**:0.12-0.20 s
- **QRS 波**:< 0.12 s,振幅 + 
- **QT 间期**:0.36-0.44 s(Bazett 校正:QTc)
- **电轴**:-30° 至 +90°

## 系统阅读 8 步
1. **标准**:走速 25 mm/s,定标 1 mV = 10 mm
2. **心率**:RR 间期 / 60
3. **节律**:规则?P 波在每个 QRS 前?
4. **P 波**:形态、振幅、时限
5. **PR 间期**:恒定?延长?
6. **QRS**:电轴、振幅、时限、形态
7. **ST 段**:抬高 / 压低
8. **T 波**:直立 / 倒置 / 高尖

## 重要诊断征象

### 缺血 / 梗死
- **STEMI**:
  - V2-V3:男 ≥ 0.2 mV,女 ≥ 0.15 mV ST 抬高
  - 其他 ≥ 0.1 mV,伴 R 波递增不良
- **NSTEMI**:ST 压低、T 波倒置
- **后壁 MI**:V1-V2 ST 压低 + 高 R 波 + 镜像改变
- **Wellens 综合征**:V2-V3 双向 / 深倒 T 波,提示 LAD 严重狭窄

### 心律失常
- **窦速** / **窦缓** / **窦性心律不齐**
- **房早** / **房速** / **房颤**(P 消失、绝对不齐)/ **房扑**(锯齿状 F 波 250-350)
- **室早**(宽 QRS,前无 P)、**室速**(连续 ≥ 3 个室早)、**室颤**(无 QRS)
- **AVB**:
  - Ⅰ 度:PR > 0.20 s
  - Ⅱ 度 Ⅰ 型(Wenckebach):PR 渐长后脱漏
  - Ⅱ 度 Ⅱ 型(Mobitz Ⅱ):PR 恒定,突然脱漏
  - Ⅲ 度(完全):房室分离,P 与 QRS 无关
- **分支阻滞**:
  - RBBB:V1 兔耳征(rsR')
  - LBBB:V5-V6 宽 R,Ⅰ/aVL 宽 R,电轴偏
- **预激(WPW)**:PR < 0.12 s + QRS > 0.12 s + delta 波

### 电解质
- **高钾**:T 高尖、QRS 增宽、P 低平 → 室颤
- **低钾**:T 低平、U 波、ST 压低 → 尖端扭转型室速
- **低钙**:QT 延长(ST 段长)
- **高钙**:QT 缩短

### 房室肥大
- **左室肥厚**:S(V1) + R(V5/V6) > 男 4.0 / 女 3.5 mV
- **右室肥厚**:V1 R/S > 1,电轴右偏
- **左房大**:P 波时限 > 0.12 s,双峰(Ⅱ)
- **右房大**:P 波高尖(Ⅱ ≥ 0.25 mV),「肺型 P 波」

### 起搏心电图
- 起搏钉样信号 + 宽大畸形 QRS(右室起搏)
- 心房起搏:钉后 P 波
- 双腔:AV 顺序起搏

## 易混淆征象
- **早期复极**:ST 凹面向上抬高 + J 波(年轻人良性)
- **Brugada 综合征**:V1-V3 穹窿型 ST 抬高
- **心包炎**:广泛 ST 抬高 + PR 压低,无对应导联 ST 压低
- **肺栓塞**:SⅠQⅢTⅢ、右束支、T 倒置 V1-V4
- **高钾**:宽 QRS、T 高尖

## 报告规范
- **正常** / **大致正常**
- **临床意义未明** / **临界**
- **异常**:详细描述

## 注意事项
- 急性胸痛 + ST 抬高 = 立即会诊、启动导管室
- 既往 LBBB 干扰 STEMI 判断,使用 Sgarbossa 标准
  - 同向性 ST 抬高 ≥ 1 mm(5 分)
  - V1-V3 ST 压低 ≥ 1 mm(3 分)
  - 不一致 ST 抬高 ≥ 5 mm(2 分)
  - ≥ 3 分诊断急性 MI
- 心电图正常不能排除 ACS(需动态复查)
- 心电图报告 ≠ 临床诊断,需结合症状、心肌酶、影像
