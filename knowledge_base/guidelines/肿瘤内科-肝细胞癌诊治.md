# 肝细胞癌诊治

## 概述
肝细胞癌(HCC)占原发性肝癌的 75-85%,我国年新发约 36 万,死亡约 32 万,均占全球 50% 左右。**多数基于慢性肝病**(HBV、HCV、酒精、代谢相关脂肪性肝病 MAFLD)。其诊治具有**病理诊断非必需**(典型影像可临床诊断)、**分期与治疗一体化**、**多学科综合**的特点。

## 危险因素
- 乙型肝炎(HBV,我国主要)、丙型肝炎(HCV)
- 酒精性肝病、黄曲霉毒素(霉变花生玉米)
- 代谢相关脂肪性肝病(MAFLD/MAASH)、糖尿病
- 肝硬化(任何原因)
- 家族史、男性、年龄

## 筛查
- **高危人群**(HBV/HCV 肝硬化、进展期纤维化):每 6 月**肝脏超声 + AFP**
- MRI/LI-RADS、超声造影(CEUS)用于结节鉴别

## 临床诊断标准
- 慢性肝病/肝硬化基础上,肝脏结节 ≥ 1 cm,典型影像学表现(动脉期强化、门脉期/延迟期廓清) → **可临床诊断 HCC**
- **LI-RADS**(CT/MRI 5 类) LR-5 高度提示 HCC
- 不典型者需**穿刺活检**(注意针道种植)

## 病理
- 分化:Edmondson-Steiner Ⅰ-Ⅳ 级
- 病理分型:细梁型、粗梁型、假腺管型、实性型、硬化型
- **分子特征**:TERT 启动子、TP53、CTNNB1(β-catenin)突变
- 免疫组化:Arg-1、HepPar-1、GPC-3、CD34、HSP70

## BCLC 分期(巴塞罗那,广泛采用)
| 分期 | 体能(PS) | 肝功能 Child-Pugh | 肿瘤特征 | 治疗策略 |
|---|---|---|---|---|
| **0(极早期)** | 0 | A | 单发 ≤ 2 cm | 消融/切除 |
| **A(早期)** | 0 | A-B | 单发或 ≤ 3 个 ≤ 3 cm | 切除/消融/移植 |
| **B(中期)** | 0 | A-B | 多发结节,无血管侵犯 | TACE |
| **C(进展期)** | 1-2 | A-B | 血管侵犯/肝外转移 | 系统治疗(靶向+免疫) |
| **D(终末期)** | 3-4 | C | — | 最佳支持 |

**中国分期(CNLC)**、HKLC、APASL 略有差异。

## 治疗

### 早期(BCLC 0/A)
- **肝切除**:米兰标准外也可考虑
  - 单发、Child A、储备良好
  - 解剖性 vs 非解剖性切除
  - 术后复发 5 年 60-70%
- **肝移植**:米兰标准(单发 ≤ 5 cm 或 ≤ 3 个 ≤ 3 cm,无大血管侵犯/肝外)
- **局部消融**:射频(RFA)、微波(MWA)、冷冻
  - ≤ 3 cm 接近手术效果
  - 邻近大血管、膈顶、胆囊等可考虑

### 中期(BCLC B)
- **TACE**(肝动脉化疗栓塞):**一线**首选
  - cTACE(碘油 + 化疗药) / DEB-TACE(载药微球)
- 联合:索拉非尼/免疫 + TACE 探索中
- 等待移植前桥接

### 进展期(BCLC C)
- **一线**:
  - **阿替利珠单抗 + 贝伐珠单抗**(T+A,IMbrave150):**目前优选**
  - **度伐利尤单抗 + 替西木单抗**(STRIDE,HIMALAYA)
  - **帕博利珠单抗**(KEYNOTE-394,中国研究)
  - 多纳非尼(中国)、阿帕替尼 + 卡瑞利珠单抗
- **二线**:瑞戈非尼、卡博替尼、雷莫西尤单抗(AFP ≥ 400)、帕博利珠单抗(可选)

### 系统治疗
- **靶向**:索拉非尼(2007 一线)、仑伐替尼(REFLECT 一线非劣效)、多纳非尼(中国)
- **免疫**:PD-1/PD-L1 单药或联合
- **联合方案**:阿替利珠 + 贝伐、度伐利尤 + 替西木单抗、信迪利 + 贝伐(中国)

### 放疗
- SBRT(立体定向放疗):寡病灶、桥接
- 门静脉癌栓:放疗 ± TACE

### 伴随治疗
- **抗病毒**:HBV-DNA 阳性恩替卡韦/替诺福韦,贯穿全程
- 保肝、利尿、营养支持
- 腹水:TIPS
- **Child-Pugh C** 谨慎系统治疗,优先姑息

## 注意事项
- **多学科诊疗(MDT)** 全程
- HBV/HCV 需长期抗病毒
- 治疗中动态评估肝功能
- 治疗目标:生存 + 生活质量并重
- 心理支持、营养评估
- 出现骨转移:双膦酸盐
- **Child-Pugh 评分、白蛋白-胆红素(ALBI)分级**辅助评估储备
