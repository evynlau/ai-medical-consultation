# 支气管镜检查

## 概述
支气管镜是经鼻 / 口插入气管、支气管,直视下观察并可活检 / 治疗。是**呼吸道肿瘤、炎症、异物、出血**的关键诊疗工具。

## 适应证

### 诊断
- **不明原因咯血** / 痰血
- **不明原因慢性咳嗽**(影像学阴性)
- **肺不张**原因
- **肺部阴影 / 肿块**(中央型)
- **胸腔积液**病因
- **可疑感染**:TB、真菌、PJP、机会性感染
  - BAL(支气管肺泡灌洗)
  - 保护性毛刷
- **可疑肿瘤**:活检、刷检、灌洗
- **纵隔 / 肺门淋巴结肿大**:EBUS-TBNA
- **气道狭窄 / 阻塞**评估
- 异物取出
- 烧伤 / 吸入伤评估

### 治疗
- **咯血**:止血(冰盐水、肾上腺素、电凝、激光)
- **异物**取出
- **大气道阻塞**:支架、激光、电切
- **痰液潴留**:吸引、灌洗
- **肺脓肿**:灌洗引流
- 气管插管困难
- 引导气管插管

## 禁忌证

### 绝对禁忌
- 严重心肺功能不全
- 严重心律失常
- 主动脉瘤(破裂风险)
- 不能配合 + 无全麻条件
- 凝血严重异常(活检时)

### 相对禁忌
- 近期 MI
- 不稳定心绞痛
- 严重高血压
- 活动性咯血(需备止血)
- 巨大甲状腺 / 主动脉瘤
- 严重颈椎病
- 上腔静脉综合征(脑水肿)
- 妊娠(相对)

## 类型
- **硬质支气管镜**:全麻,用于异物、大出血、介入
- **可弯曲支气管镜(软镜)**:
  - 常规:内径 5-6 mm
  - 细镜:3-4 mm(ICU、困难气道)
  - 治疗型:大通道(吸引、介入)
- **超声支气管镜(EBUS)**:
  - **EBUS-TBNA**:纵隔 / 肺门淋巴结穿刺
  - 凸阵超声(实时)vs 径向(检查周围型)
- **导航支气管镜**:周围型肺结节

## 术前准备
- 知情同意
- 详细病史(心肺、过敏、出血)
- 禁食 **6-8 h**、禁水 2 h
- 心电图、凝血、影像
- 麻醉前评估
- 术前用药(可不用):阿托品(减少分泌)

## 操作流程
### 麻醉
- **局部**:
  - 鼻 / 咽:2% 利多卡因
  - 喉:喷喉
  - 气管:通过支气管镜注入利多卡因
- **全身**:复杂介入、硬镜、儿童
- **监测**:心电、SpO₂、BP

### 进镜路径
- 鼻腔(常用)→ 咽 → 喉(声门)→ 气管 → 隆突 → 主支气管 → 段 / 亚段
- 顺序检查:气管、隆突、双侧主支气管、各叶段
- 重点:病变部位

### 取材技术
- **活检**:可见病变
- **刷检**:细胞学
- **灌洗(BAL)**:远端灌 50-100 mL NS,回收 40-60%
- **保护性毛刷**:定量培养
- **TBLB**(经支气管肺活检):X 线透视下,周围型
- **EBUS-TBNA**:纵隔 / 肺门淋巴结
- **冷冻活检**:ILD、肿瘤(更大标本)

## 术后处理
- 禁食 2-3 h(待咽喉麻醉消退)
- 观察 1-2 h(出血、气胸)
- 痰血:可少量
- 活检后:观察胸痛、呼吸困难
- 驾车、签字:24 h 内避免

## 并发症
- **喉 / 支气管痉挛**:严重低氧
- **出血**(活检后):
  - 少量(< 50 mL):观察
  - 大量:冰盐水、肾上腺素、电凝、BAE
- **气胸**(TBLB):1-5%
  - 大量:胸穿抽气 / 闭式引流
- **低氧血症**:SpO₂ < 90%
- **心律失常**
- **感染**:发热、肺炎(< 1%)
- **麻醉药过敏 / 中毒**
- **喉痛、声嘶**(短期)

## 各类疾病支气管镜表现

### 肺癌
- 菜花样、结节样、浸润
- 管腔狭窄、阻塞
- 黏膜增厚、出血、坏死
- **早期中央型**:黏膜红斑、增厚

### 支气管结核
- 黏膜充血、水肿、溃疡
- 瘢痕狭窄(愈合期)
- 淋巴结瘘、肉芽肿

### 异物
- 多种形态
- 多见右侧(下叶)
- 长期可致肉芽肿、阻塞

### 咯血定位
- 出血点:鲜红、涌出
- 健侧:分泌物
- 必要时双腔插管

### 气道狭窄
- 良性:TB、结节病、淀粉样变、复发性多软骨炎、外伤
- 恶性:肿瘤、转移
- 治疗:扩张、激光、支架

## 治疗性支气管镜

### 气道支架
- 适应:恶性狭窄、外压、气管软化
- 类型:金属(覆膜 / 裸)、硅胶、动力
- 并发症:移位、肉芽、分泌物潴留

### 腔内治疗
- **激光**(Nd:YAG):切除肿瘤
- **电切 / 电凝**(APC)
- **冷冻**:良性、异物
- **光动力**(PDT):早期中央型肺癌
- **近距离放疗**(后装):腔内

### 异物取出
- 钳夹、网篮、球囊
- 硬镜更优

## 注意事项
- 操作前评估,严格指征
- 备急救药品 / 设备
- 出血可能致窒息,备硬镜 / 插管
- 活检部位充分暴露
- 灌洗液送检(细胞、微生物、生化)
- 操作后:严密观察
- 报告含:描述、活检部位、初步诊断
- 「肉眼观察」+「病理」+「微生物」综合诊断
