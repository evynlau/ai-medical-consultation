# 急性白血病

## 概述
急性白血病(AL)是造血干 / 祖细胞克隆性增殖、分化障碍致正常造血受抑的恶性血液病。分急性髓系白血病(AML)和急性淋巴细胞白血病(ALL),我国年发病率约 5-7/10 万。是儿童、成人最常见恶性肿瘤之一。

## 分类(WHO 2016/2022)

### AML
- **伴重现性遗传学异常**:
  - t(8;21)(AML-ETO)
  - inv(16) / t(16;16)(CBFB-MYH11)
  - t(15;17)(PML-RARA,APL)
  - t(6;9)(DEK-NUP214)
  - inv(3) / t(3;3)(GATA2)
  - t(1;22)(RBM15-MKL1)
  - 突变 NPM1、CEBPA、TP53
- **伴骨髓增生异常相关改变**(AML-MR)
- **治疗相关**(AML-TR)
- **非特指(AML-NOS)**(MO-M7)

### ALL
- **B-ALL**:
  - t(9;22)(BCR-ABL1)
  - t(12;21)(ETV6-RUNX1)
  - t(4;11)(KMT2A-AFF1)
  - t(1;19)(TCF3-PBX1)
  - 超二倍体、低二倍体
- **T-ALL**

### 急性未分化白血病(AUL)
- 混合表型急性白血病(MPAL)

## 临床表现

### 骨髓衰竭(主要)
- **贫血**:苍白、乏力、心悸
- **出血**:血小板 ↓(鼻、牙龈、内脏)
- **感染**:粒缺(肺炎、败血症)
- **粒缺发热**(FN)

### 浸润
- **肝脾淋巴结肿大**(尤其 ALL)
- **骨痛**(尤其儿童 ALL)
- **牙龈增生**(AML-M4、M5)
- **皮肤浸润**(AML-M4、M5)
- **CNS**:头痛、颅神经、颈抵抗
- **睾丸**(ALL)
- **纵隔**(T-ALL)

### 高白细胞 / 实验室
- **白细胞 ↑**(50-100 × 10⁹/L)
- **高尿酸**(肿瘤溶解风险)
- **DIC**(APL 特异)

### 代谢
- 高钾、高磷、低钙
- 急性肾损伤
- **肿瘤溶解综合征(TLS)**

## 实验室

### 血常规
- **白细胞 ↑**(大部分,10-100 × 10⁹/L)
- **贫血**(正细胞)
- **血小板 ↓**
- **原始细胞**:可见

### 形态
- **外周血 / 骨髓**:原始细胞 ≥ 20%(WHO)
- Auer 小体(AML)
- 细胞化学(MPO、PAS、ANAE、NSE)

### 骨髓
- **增生明显活跃**(原始 ≥ 20%)
- 形态学(M0-M7)

### 流式免疫分型(关键)
- 区分 AML / ALL
- 谱系标记:
  - **髓系**:MPO、CD13、CD33、CD117、CD15、CD11b
  - **B 系**:CD19、CD22、CD79a、CD10、CD20、cIg、sIg
  - **T 系**:CD2、CD3、CD5、CD7、CD1a、CD4、CD8
- **混合表型**(MPAL)

### 细胞遗传学 / 分子(关键预后)
- **核型**:
  - **预后良好**:t(8;21)、inv(16)、t(15;17)
  - **预后中等**:正常核型、其他
  - **预后不良**:-5/5q-、-7/7q-、复杂核型、t(6;9)、t(v;11q23)
- **FISH**(关键融合)
- **分子突变**:
  - **NPM1**(良好,如不伴 FLT3-ITD)
  - **CEBPA 双突变**(良好)
  - **FLT3-ITD**(不良,靶向药)
  - **TP53**(不良)
  - **KIT**(不良)
  - **IDH1/2**(靶向药)
  - **BCR-ABL1**(Ph+ ALL,TKI)
- **NGS 面板**(28-50 基因)

### 其他
- **腰穿 + CSF**(CNS 评估)
- **凝血**(DIC、APL)
- **肝肾、电解质、尿酸、LDH**
- **HLA 配型**(移植准备)
- **心电图、超声**(化疗前)

## 诊断
- 形态 + 流式 + 遗传 = 精确分型
- MICM 分型
- 危险分层(预后)

## 治疗

### 总体策略

#### AML
- **诱导化疗**:DA(柔红霉素 + 阿糖胞苷)或 IA
- 缓解后:**巩固 + 维持**或**HSCT**
- **靶向治疗**(突变):
  - **FLT3-ITD**:米哚妥林(Midostaurin)、吉瑞替尼(Gilteritinib)(R/R)
  - **IDH1/2**:艾伏尼布(Ivosidenib)、恩西地平(Enasidenib)
  - **BCL2**:维奈托克(Venetoclax)(尤其老年、TP53)
- **老年 / 不耐受**:维奈托克 + 阿扎胞苷(VEN/HMA)

#### ALL
- **诱导**(VDLP):长春新碱 + 蒽环 + L-ASP + 泼尼松
- **巩固 + 强化**:高危多药
- **维持**(2-3 年):6-MP + MTX
- **CNS 预防**:鞘注、放疗
- **Ph+ ALL**:TKI(伊马替尼、达沙替尼)+ 化疗
- **复发**:CAR-T(CD19)、blinatumomab、inotuzumab

#### APL(急性早幼粒)
- **ATRA + 砒霜(ATO)**:**非化疗方案**(可门诊)
- **诱导**:ATRA + ATO
- **缓解后**:ATRA + ATO 巩固
- **高危(WBC > 10)**:加蒽环
- **DIC 处理**:输血、抗凝

### 造血干细胞移植(HSCT)

#### 适应证(AML)
- 高危遗传学
- 复发
- 中危(部分,MRD 持续阳性)

#### 适应证(ALL)
- 高危(Ph+、t(4;11))
- 复发
- MRD 持续(+)

#### 条件
- 年龄、配型、状态
- 同胞 / 无关 / 半相合

### 支持治疗

#### 血液支持
- **血小板**:< 10 × 10⁹/L 或活动性出血(< 20)
- **Hb**:< 60 或症状(输 RBC)
- **辐照血**(HSCT 后)

#### 感染防治
- **粒缺发热**:紧急广谱抗生素 + 抗真菌
- **预防**:TMP-SMX、PCP、氟康唑、阿昔洛韦
- **G-CSF**:短期(< 7 d)
- **环境**:层流病房

#### 肿瘤溶解综合征(TLS)
- **水化**(3 L/m²/d)
- **别嘌醇 / 拉布立酶**(尿酸)
- 监测:K⁺、尿酸、磷、Ca²⁺
- **血液透析**(严重)

#### DIC(APL)
- 输血小板、新鲜冰冻血浆、冷沉淀
- ATRA + ATO 后控制

#### CNS 白血病
- 鞘注(MTX、Ara-C、激素)
- 全身化疗(高剂量 MTX、Ara-C)
- 放疗(部分)

### 特殊类型治疗

#### APL(关键)
- **ATRA + ATO**:低中危(标准)
- 高危:加蒽环
- **分化综合征**(发热、呼吸困难、肺浸润):
  - 激素、地塞米松 10 mg iv q12h
- **不化疗**(ATRA + ATO 治愈率 > 90%)

#### 老年 AML
- 强化化疗风险高
- **VEN/HMA**(维奈托克 + 阿扎胞苷):低强度、有效
- **最佳支持**

#### Ph+ ALL
- **TKI**(达沙替尼 > 伊马替尼):一代、二代、三代
- TKI + 化疗 → 缓解
- TKI 维持(终身)
- HSCT(部分)

## 注意事项

### 监测
- 血常规:每日(诱导)
- 骨髓:诱导后(第 14-28 天)
- MRD(微小残留病):流式 / PCR / NGS
- 巩固后:定期复查(2 年内 3-6 月)

### 复发
- **MRD 监测**(敏感、早期)
- 复发:再诱导、HSCT、CAR-T、临床试验

### 化疗副作用
- **黏膜炎**(化疗)
- **肝毒性**
- **心脏毒性**(蒽环)
- **L-ASP**:过敏、胰腺炎、凝血
- **MTX**:肾、肝、肺

### 感染(主要死因)
- **粒缺**:风险高
- 真菌、病毒、PCP
- **疫苗**:灭活、HSCT 后免疫重建

### CNS 防治
- ALL 必查
- 鞘注 × 4-6 次(诱导期)
- 高危:放疗

### 生育
- 年轻患者:生育力保存
- 化疗后:卵巢 / 睾丸功能 ↓
- HSCT 后:通常不孕

### 长期
- **继发肿瘤**
- **心脏**(蒽环)
- **骨骼**(激素、MTX)
- **心理**
