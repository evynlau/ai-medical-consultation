# 内分泌科-血糖监测

## 概述
血糖（Blood Glucose，GLU）是指血液中的葡萄糖，是机体组织细胞能量代谢的主要供能物质。血糖水平受胰岛素、胰高血糖素、肾上腺素、皮质醇、生长激素等多种激素的精密调控，维持在相对恒定的范围内（空腹静脉血糖 3.9-6.1 mmol/L）。

血糖监测是糖尿病诊断、治疗方案调整、病情控制评价及慢性并发症预防的核心检查，也是低血糖症诊断和疗效监测的重要手段。内分泌科的血糖监测涵盖空腹血糖、餐后血糖、随机血糖、口服葡萄糖耐量试验（OGTT）及糖化血红蛋白（HbA1c）等多种检测项目，是糖尿病及其并发症全程管理的基石。

## 检查方法
### 常用血糖检测方法
1. **葡萄糖氧化酶法（GOD）**
   - 原理：葡萄糖氧化酶（GOD）催化葡萄糖与氧反应生成葡萄糖酸和过氧化氢，后者与色原底物反应产生有色产物
   - 特异性高，只测葡萄糖
   - 临床最常用的方法

2. **己糖激酶法（HK）**
   - 原理：己糖激酶催化葡萄糖与 ATP 反应生成葡萄糖-6-磷酸，后者进一步反应产生 NADPH，测定吸光度变化
   - 准确性更高，是参考方法
   - 自动化生化分析仪广泛采用

3. **葡萄糖脱氢酶法**
   - 原理：葡萄糖脱氢酶催化葡萄糖与 NAD/PAD 反应
   - 特异性较好，但某些药物可能干扰

4. **快速血糖仪法**
   - 原理：采用葡萄糖氧化酶或葡萄糖脱氢酶电极法
   - 操作简便快速，适用于自我血糖监测（SMBG）
   - 末梢血检测，结果供参考

### 口服葡萄糖耐量试验（OGTT）
- **适应证**：糖尿病诊断不明确时、妊娠期糖尿病筛查、糖耐量减低（IGT）评估
- **方法**：
  - 空腹 8-10 小时后采集空腹血
  - 口服 75 g 无水葡萄糖（溶于 250-300 mL 水中，5 分钟内饮完）
  - 采集服糖后 2 小时血标本
  - 可加采 30 分钟、60 分钟、180 分钟血标本（改良 OGTT）
- **注意事项**：试验前 3 天正常饮食（碳水化合物摄入 ≥ 150 g/天）；试验前避免剧烈运动

### 糖化血红蛋白（HbA1c）
- **原理**：血红蛋白与葡萄糖非酶促反应结合形成糖化血红蛋白，反映过去 **2-3 个月**平均血糖水平
- **检测方法**：离子交换高效液相色谱法（HPLC）、免疫法、毛细管电泳法等
- **参考值**：4.0%-6.0%（不同检测系统略有差异）
- **临床意义**：糖尿病诊断标准之一（≥ 6.5%）；血糖控制好坏的评价金标准

### 糖化白蛋白（GA）
- 反映过去 **2-3 周**平均血糖水平
- 优于 HbA1c 用于评价短期血糖控制及药物调整效果

### 持续葡萄糖监测（CGM）
- 通过皮下葡萄糖传感器连续监测组织间液葡萄糖浓度
- 可生成动态葡萄糖曲线（AGP），全面评估血糖波动
- 适用于脆性糖尿病、胰岛素泵调节、妊娠期糖尿病等

## 正常参考值
| 检测项目 | 正常参考范围 | 单位 |
|----------|--------------|------|
| 空腹血糖（FPG） | 3.9-6.1 | mmol/L |
| 餐后 2 小时血糖（2hPG） | < 7.8 | mmol/L |
| 随机血糖 | < 11.1 | mmol/L |
| OGTT 2hPG | < 7.8 | mmol/L |
| 糖化血红蛋白（HbA1c） | 4.0%-6.0% | % |
| 糖化白蛋白（GA） | 11%-17% | % |

### 糖尿病诊断标准（WHO/ADA）
| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|------------|--------|
| 空腹血糖 | < 6.1 | 6.1-7.0 | ≥ 7.0 mmol/L |
| OGTT 2hPG | < 7.8 | 7.8-11.1 | ≥ 11.1 mmol/L |
| HbA1c | < 5.7% | 5.7%-6.4% | ≥ 6.5% |
| 随机血糖 | — | — | ≥ 11.1 mmol/L + 典型症状 |

## 临床意义
### 血糖升高
#### 糖尿病及其分型
- **1 型糖尿病**：以空腹血糖和餐后血糖显著升高为特征，易发生酮症
- **2 型糖尿病**：早期可仅表现为餐后血糖升高，空腹血糖可能正常（IGT 或 IFG）
- **妊娠期糖尿病**：孕期血糖控制目标更严格
- **其他特殊类型糖尿病**：胰腺疾病、内分泌疾病、药物所致等

#### 继发性血糖升高
- **内分泌疾病**：库欣综合征、肢端肥大症、嗜铬细胞瘤、甲状腺功能亢进症等
- **胰腺疾病**：慢性胰腺炎、胰腺切除术后、胰腺肿瘤
- **药物因素**：糖皮质激素、利尿剂、免疫抑制剂等
- **应激状态**：严重感染、创伤、手术、急性心脑血管疾病

### 血糖降低（低血糖症）
- **空腹血糖 < 3.9 mmol/L** 为低血糖预警值
- **血糖 < 2.8 mmol/L** 为临床低血糖症诊断标准
- 常见原因：
  - 胰岛素或降糖药过量
  - 胰岛素瘤（内源性胰岛素过多）
  - 严重肝肾功能不全
  - 营养不良、长期饥饿
  - 剧烈运动后
  - 酒精性低血糖（抑制糖异生）

### 血糖波动与慢性并发症
- 血糖波动增大可加速糖尿病慢性并发症的发生发展
- HbA1c 控制不佳与微血管并发症（视网膜病变、肾病、神经病变）及大血管并发症（冠心病、脑卒中、外周血管病）密切相关
- 糖尿病患者 HbA1c 控制目标一般应 < 7%（个体化调整）

## 注意事项
- **空腹要求**：空腹血糖检测需禁食 8-12 小时，可适量饮水；检测前一天晚餐宜清淡
- **采血后处理**：血糖检测应在采血后及时送检或加入氟化钠抗凝管（抑制糖酵解）
- **OGTT 注意事项**：试验前需停用可能影响血糖的药物（如糖皮质激素、噻嗪类利尿剂）；孕妇采用 75 g OGTT
- **快速血糖仪的局限性**：快速血糖仪检测末梢血，结果受操作技术、环境温度等影响较大，不能替代实验室检测
- **HbA1c 的局限性**：血红蛋白异常（如贫血、溶血、输血后）或妊娠期 HbA1c 结果可能不准确
- **动态监测的意义**：单次血糖只能反映采血瞬间水平，连续监测或 HbA1c 能更好地反映总体控制水平
- **应激状态**：感染、创伤、手术、情绪激动等应激状态可导致血糖暂时性升高，需结合临床判断
- **采血部位**：不同部位（指尖、静脉）血糖值有差异，临床诊断以静脉血浆葡萄糖为准
- **检测时间点选择**：餐后血糖指从吃第一口饭开始计时 2 小时后的血糖，而非餐后任意时间
