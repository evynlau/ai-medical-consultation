# 苯海拉明

#### 苯海拉明
*## 基本信息*## 
- 分类：第一代H1受体拮抗剂
- 常见商品名：苯海拉明片、 Diphenhydramine
- 上市时间：1940年代
- 处方/OTC状态：非处方药（OTC）
*## 适应症*## 
- 过敏性鼻炎、荨麻疹
- 乘晕宁（晕动病）
- 失眠（短期使用）
*## 药理作用*## 
- 阻断H1受体，抗过敏
- 具有较强中枢抑制和镇静作用
- 抗胆碱作用明显
*## 用法用量*## 
- 成人：25mg/次，3次/日
- 睡前50mg用于助眠
- 乘晕宁：50mg于乘车前30分钟服用
*## 不良反应*## 
- 嗜睡、头晕（较常见）
- 口干、视力模糊
- 尿潴留
*## 注意事项*## 
- ⚠️ 禁止驾驶和机械操作
- ⚠️ 青光眼、前列腺增生患者禁用
- ⚠️ 不宜长期用于助眠（可能导致依赖）
*## 禁忌*## 
- 对苯海拉明过敏者
- 新生儿和早产儿
- 正在使用或14天内使用过单胺氧化酶抑制剂者
*## 临床应用要点*## 
- 镇静作用强，常用于睡前服用
- 具有抗晕动作用，是乘晕宁的主要成分
- 抗胆碱副作用明显，老年人慎用
