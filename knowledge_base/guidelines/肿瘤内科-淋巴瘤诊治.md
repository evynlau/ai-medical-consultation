# 淋巴瘤诊治

## 概述
淋巴瘤是起源于淋巴造血系统的恶性肿瘤,分为**霍奇金淋巴瘤(HL)**和**非霍奇金淋巴瘤(NHL)**,后者占 90%。NHL 又分为 B 细胞(80-85%)和 T/NK 细胞(15-20%)。**弥漫大 B 细胞淋巴瘤(DLBCL)**最常见。**病理学**(组织形态 + 免疫组化 + 分子)是诊断金标准。

## 危险因素
- 免疫缺陷:HIV、移植后(PTLD)
- 病毒:EBV(Burkitt、NK/T)、HTLV-1(ATL)、HCV(部分 B)
- 幽门螺杆菌(MALT 淋巴瘤)
- 自身免疫:干燥综合征、桥本甲状腺炎
- 化学/放射线暴露

## 分类(WHO 2022 简版)
- **HL**:经典型(结节硬化、富淋巴细胞、混合细胞、淋巴细胞消减)、结节性淋巴细胞为主型(NLPHL)
- **B 细胞 NHL**:
  - **DLBCL**(包括高级别 B、伯基特、CNS 淋巴瘤)
  - 滤泡性淋巴瘤(FL)
  - 套细胞淋巴瘤(MCL)
  - 边缘区淋巴瘤(MZL、MALT)
  - 慢性淋巴细胞白血病/小淋巴细胞淋巴瘤(CLL/SLL)
  - 伯基特淋巴瘤
- **T/NK NHL**:外周 T(PTCL)、间变性大细胞(ALCL)、NK/T 细胞(鼻型)

## 诊断
- **淋巴结活检**(完整切除优先,避免细针)
- **免疫组化**:
  - **B**:CD20、CD79a、PAX5
  - **T**:CD3、CD4、CD8
  - **HL**:CD15、CD30(RS 细胞)
  - **生发中心**:CD10、BCL6
  - **增殖**:Ki-67
- **FISH / 分子**:MYC、BCL2、BCL6(双/三打击淋巴瘤)、MYC 重排(伯基特)、t(11;14)(MCL)
- **分期**:
  - **PET-CT**(尤其 DLBCL、HL)
  - 骨髓活检 + 穿刺
  - **LDH、β2 微球蛋白**
  - 头颅 MRI(睾丸、CNS 危险)
  - HIV、HBV、HCV

## 分期(Ann Arbor + Lugano)
- Ⅰ:单一淋巴结区
- Ⅱ:膈同侧 ≥ 2 区
- Ⅲ:膈两侧
- Ⅳ:结外器官
- A/B 症状:A 无,B 有(发热、盗汗、消瘦> 10%/6 月)

## 治疗

### DLBCL(最常见)
- **一线**:**R-CHOP**(利妥昔单抗 + 环磷酰胺 + 阿霉素 + 长春新碱 + 泼尼松)6 周期
- 局限期(Ⅰ-II、aaIPI 0、肿块 < 7.5 cm):**R-CHOP × 4 + 受累野放疗**
- 高危、双表达、双/三打击:**R-CHOP + X**(来那度胺、硼替佐米);**R-DA-EPOCH**(高危)
- 老年:剂量调整(R-miniCHOP)
- **CNS 预防**:高危(双/三打击、睾丸、CNS 浸润)
- **复发/难治**:
  - 二线:**R-ICE / R-DHAP** + **ASCT**(自体移植)
  - 三线:**CAR-T**(Axi-cel、Tisa-cel、Liso-cel,CAR-T)
  - **Pola-R-CHP**(Polivy 联合,部分 1L)
  - **Tafasitamab + 来那度胺**
  - **CD30+**:维布妥昔单抗

### 滤泡淋巴瘤(FL)
- Ⅰ-Ⅱ:**放疗 ± R**(可选,不可治愈)
- 进展、Ⅲ-Ⅳ:**利妥昔单抗 + 苯达莫司汀(R-B)**
- **R-CHOP** 另一选择
- **维持**:利妥昔单抗每 8-12 月
- 复发:R-B、Tazemetostat(EZH2 突变)、来那度胺 + R

### 套细胞淋巴瘤(MCL)
- 一线:**R-CHOP / R-DHAP + ASCT + 利妥昔维持**(年轻)
- 老年:R-CHOP + 维持、BR、伊布替尼

### 边缘区淋巴瘤(MALT)
- **Hp 阳性胃 MALT**:根除 Hp(70% 缓解)
- 其他:放疗、R-CVP、R-B

### 霍奇金淋巴瘤(HL)
- **经典型 Ⅰ-Ⅱ(预后良好)**:**ABVD × 2-4 + 受累野放疗**
- **Ⅰ-Ⅱ(预后不良)**:ABVD × 4 + 放疗;或 **eBEACOPP**(高强度)
- **Ⅲ-Ⅳ**:**ABVD × 6**;**A+AVD**(维布妥昔 + 阿霉素 + 长春花碱 + 达卡巴嗪,Echelon-1)
- **难治/复发**:
  - **维布妥昔单抗 + Bendamustine**
  - **PD-1**(帕博利珠单抗、纳武利尤、替雷利珠)
  - **ASCT**
  - **BV + PD-1** 桥接

### 鼻型 NK/T 淋巴瘤
- 局限期(Ⅰ-Ⅱ):**SMILE**(类固醇、甲氨蝶呤、异环磷酰胺、依托泊苷、培门冬酶)/P-GEMOX + 放疗
- 进展期:**P-GEMOX**、含培门冬酶方案、PD-1

### T 细胞淋巴瘤(PTCL)
- **CHOP** 仍是一线,CD30+ 加维布妥昔
- **来那度胺**(AITL、PTCL-NOS)
- 难治:Romidepsin、Belinostat、ALK+ ALCL 克里唑蒂尼

## 注意事项
- **病理诊断**必须由血液病理学家复核
- 活检前勿用激素(影响诊断)
- **Cotswolds/Lugano** 分期 + **aaIPI** 评分
- 利妥昔单抗需筛 HBV
- 化疗前心电图、心超(蒽环)
- **B 症状、LDH、ECOG** 是预后因子
- **CNS 预防**:侵袭性 B、高危、睾丸
- ASCT 适合 ≤ 65 岁、化疗敏感复发
