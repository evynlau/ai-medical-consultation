# 椎管内麻醉

## 概述
椎管内麻醉(Neuraxial Anesthesia)是中枢神经阻滞,通过椎管内注射局麻药,阻滞脊神经传导。包括蛛网膜下隙麻醉(腰麻)、硬膜外腔麻醉(Epidural)、骶管阻滞。广泛用于下腹部、下肢、盆腔、产科及术后镇痛。

## 解剖

### 椎管解剖
- **棘上韧带**(皮肤 → 棘突尖)
- **棘间韧带**(棘突间)
- **黄韧带**(连接椎板,致密)
- **硬膜外腔**(黄韧带 → 硬膜,含脂肪、静脉丛)
- **硬膜**(坚韧纤维膜)
- **蛛网膜**(薄)
- **蛛网膜下腔**(含脑脊液 CSF,成人 25-35 ml)
- **软膜**(覆脊髓)
- **脊髓**:成人 L1 终止(新生儿 L3)

### 椎间隙定位
- **C7**(隆椎,最突出)
- **T7**:肩胛下角连线
- **T4**:乳头连线(男性)
- **L4**:髂嵴最高点连线
- **L2-3**、**L3-4**(常选择)

## 蛛网膜下隙麻醉(腰麻,Spinal Anesthesia)

### 适应证
- 下腹、盆腔、髋关节、下肢手术
- 肛肠、会阴
- 产科(剖宫产)
- 时间 1.5-3 h

### 禁忌
- **绝对**:穿刺部位感染、休克未纠正、凝血障碍、颅内高压、患者拒绝
- **相对**:脊柱侧弯 / 后凸明显、神经系统病(不主张)

### 操作
- **体位**:侧卧位 / 坐位(鞍麻)
- **定位**:L3-4 或 L2-3(成人脊髓止于 L1)
- **消毒、铺巾、局麻**
- **正中入路**:棘突间 → 黄韧带 → 硬膜(突破感) → 蛛网膜 → CSF 流出
- **针**:25G 笔尖式(Whitacre、Sprotte,减少 PDPH)
- **药物**:
  - **0.5% 布比卡因**(等比重):10-15 mg
  - **0.5% 左布比卡因**:10-15 mg
  - **0.5% 罗哌卡因**:15-20 mg
  - **0.5% 布比卡因**(高比重):8-15 mg + 8% 葡萄糖
- **调节平面**:药液比重、体位、注药速度
- 鞍麻:坐位、高比重、小剂量
- **失败**:CSF 不流出、解剖不清

### 平面控制
- **感觉神经平面**:针刺 / 冷觉测试
- **影响**:
  - 比重(最关键):高比重向低处、低比重向高处
  - 体位
  - 药量、浓度
  - 注药速度
  - 注射部位
- **平面与手术**:
  - **T4**:心、乳腺
  - **T10**:下腹
  - **L1**:髋、下肢
  - **S2-4**:会阴

### 并发症
- **低血压**(T1 以上交感阻滞):扩容、麻黄碱、去氧肾上腺素
- **心动过缓**:阿托品
- **术后头痛**(PDPH,1-3%):平卧、补水、咖啡因、硬膜外血补丁
- **腰麻后神经损伤**(罕见):马尾综合征
- **尿潴留**
- **恶心、呕吐**
- **高位脊麻** / **全脊麻**(平面过高,严重)
- **感染**(脑膜炎)
- **出血**(硬膜外血肿)

## 硬膜外麻醉(Epidural Anesthesia)

### 适应证
- 胸、腹部、下肢手术
- 产科分娩镇痛(主要)
- 术后镇痛
- 慢性疼痛
- 多种时间长手术

### 禁忌
- 同腰麻
- **脊柱手术史**(慎)

### 操作
- **体位**:侧卧
- **定位**:依据手术
- **方法**:
  - 穿刺:正中 / 旁正中入路
  - **阻力消失法**(LORT):针尖到达硬膜外腔,阻力消失
  - **悬滴法**(负压法)
- **置管**:留置硬膜外导管(2-3 cm 在内)
- **试验剂量**:1.5% 利多卡因 3-5 ml(含肾上腺素 1:20 万)
  - 误入血管:心率↑、耳鸣、唇麻
  - 误入蛛网膜下:全脊麻
- **追加剂量**:5-10 ml(分次)
- **维持**:持续 / 间断给药

### 药物
- **0.5-0.75% 罗哌卡因**:感觉运动分离,产科首选
- **0.25-0.5% 布比卡因 / 左布比卡因**
- **1-2% 利多卡因**(短效)
- **阿片类辅助**(产科):
  - **舒芬太尼** 0.5-1 μg/ml
  - **芬太尼** 2 μg/ml

### 术中管理
- 分次给药
- 控制平面
- 监测血压(椎管内交感阻滞)

### 产后 / 术后镇痛
- **PCEA**(Patient-Controlled Epidural Analgesia)
  - 背景 4-6 ml/h、Bolus 2-4 ml、锁定 15-20 min
  - **0.1-0.2% 罗哌卡因 + 舒芬太尼 0.5-1 μg/ml**

### 并发症
- **穿破硬膜**(无意识或意外):腰麻
- **硬膜外血肿**(1:150000):紧急 MRI、手术减压(< 8 h)
- **硬膜外脓肿**:发热、神经痛
- **全脊麻**:意外大量进入蛛网膜下腔,呼吸骤停、严重低血压
  - 抢救:插管、复苏
- **低血压**
- **局麻药中毒**(误入血管)
- **神经损伤**(神经根)
- **尿潴留**
- **硬脊膜穿破后头痛(PDPH)**

## 骶管阻滞
- 儿童、成人(肛肠、会阴)
- **骶裂孔**为标志
- 药物:0.25% 布比卡因 0.5-1 ml/kg
- 儿童镇痛、超声引导提高成功率

## 椎管内麻醉 vs 全麻
- 椎管内:应激小、苏醒快、术后镇痛、血栓少、恶心少
- 全麻:气道安全、可控性强、儿童不合作

## 注意事项

### 抗凝
- **低分子肝素预防剂量**:12 h 后 / 拔管 4-12 h 后
- **治疗剂量**:24 h 后
- **华法林**:INR < 1.5
- **新型口服抗凝**(DOAC):停药 24-48 h
- **抗血小板**:阿司匹林 OK、氯吡格雷 7 d
- 拔管后再次等待同样时间

### 休克、低血容量
- 椎管内阻滞加重低血压
- 纠正血容量后再行

### 严重贫血
- 椎管内阻滞可能加重低氧

### 穿刺困难
- 老年人韧带钙化、肥胖、脊柱畸形
- **超声引导**(推荐)
- 改换间隙、旁正中入路

### 监测
- **血压**(连续):椎管内阻滞后每 2-5 min
- 心电图、SpO₂
- 平面监测
- 急救准备(全脊麻、心脏骤停)

### 全脊麻
- 误注入蛛网膜下腔大量局麻药
- 高平面阻滞 → 呼吸、心脏骤停
- **抢救**:气道(插管)、血管活性药、复苏

### 神经损伤预防
- 严格无菌
- 神经刺激器辅助
- 短针、笔尖针
- 轻柔操作
- 避免神经内注射
