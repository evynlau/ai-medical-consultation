# 胃镜检查

## 概述
胃镜(上消化道内镜,EGD)经口进入食管、胃、十二指肠(球部、降段)直接观察黏膜形态、色泽、蠕动,获取组织活检,完成内镜下治疗。我国自 20 世纪 70 年代开展,目前年检查量数千万,是最常用、价值最高的消化道检查之一。无痛胃镜(静脉麻醉)普及显著改善耐受性。

## 适应证

### 诊断性
- **上消化道症状**:反复上腹痛、胀满、嗳气、吞咽困难、烧心
- **不明原因消化道出血**:呕血、黑便、便血(活动期 24-48 h 内)
- **吞咽困难、胸骨后疼痛**
- **贫血、消瘦**(排除上消化道肿瘤)
- **胃手术 / 化疗后随访**
- **Hp 根除后胃癌筛查**
- **肝硬化**:曲张静脉筛查与治疗
- **IBD、CD 上消化道评估**
- **活检**:慢性胃炎、萎缩 / 肠化 / 异型增生、肿瘤分型

### 治疗性
- 消化道出血(止血、套扎)
- 息肉切除(活检、EMR)
- 早癌 / 黏膜下肿瘤(EMR、ESD)
- 食管 / 幽门狭窄扩张、支架
- 胃造瘘(PEG)
- 异物取出
- 食管静脉曲张套扎(EVL)
- 胃底曲张组织胶注射

## 禁忌证

### 绝对禁忌
- 严重心肺疾病不能耐受
- 休克、昏迷
- 主动脉瘤
- 急性冠脉综合征
- 食管 / 胃穿孔
- 重度颈椎病变 / 口腔病变不能进镜

### 相对禁忌
- 严重精神异常不能配合
- 凝血障碍(INR > 1.5、PLT < 50)
- 急性重症咽喉炎、腐蚀性食管炎急性期
- 妊娠早期
- 严重脊柱侧弯

## 术前准备

### 评估
- 病史、用药史(抗凝、抗血小板、麻醉药过敏)
- 心肺功能、年龄、合并症
- 凝血(有创操作)
- 肝功、HBV、HIV(活检前)
- 知情同意

### 饮食与药物
- **禁食 6-8 h**,禁水 2 h(普通胃镜)
- **口服药物**:降压药可少量水服;降糖药、胰岛素视情况
- **抗凝 / 抗血小板**:
  - 阿司匹林:活检无碍,EMR/ESD 停 5-7 d
  - 氯吡格雷:活检可不停,治疗停 5-7 d
  - 华法林:停 5 d,INR 控制在 < 1.5;新型口服抗凝药(NOAC)停 1-2 d
- **胃内残留**:
  - 幽门梗阻:洗胃 / 延长禁食
  - 重度胃下垂:左侧卧位

### 麻醉
- 普通胃镜:咽喉部 1% 利多卡因 / 达克罗宁
- 无痛胃镜:丙泊酚 1-2 mg/kg 静推,监测 SpO₂、BP、ECG

## 操作步骤
1. 患者左侧卧位,头略前倾,咬口垫
2. 进镜至食管、贲门
3. 胃底(反转)、胃体、胃角、胃窦
4. 幽门、十二指肠球部、降段
5. 退镜仔细观察各部位
6. 必要时活检(常 6 块)
7. 操作时间 5-15 min

## 内镜治疗
### 活检与 EMR
- 标准活检钳
- **EMR(内镜下黏膜切除)**:
  - 适应证:< 2 cm 黏膜内癌、腺瘤、癌前病变
  - 步骤:黏膜下注射 → 圈套 → 电切
  - 整块切除
- **ESD(内镜黏膜下剥离)**:
  - 适应证:> 2 cm、广基、黏膜下浅层
  - 步骤:标记 → 黏膜下注射 → 切开 → 剥离
  - 一次性整块切除
  - 难度大、并发症多(出血、穿孔)
  - 适应证:早癌、巨大息肉、黏膜下肿瘤

## 术后注意事项
- 活检 / EMR:禁食 4-6 h,软食 1-3 d
- ESD:禁食 1-2 d,补液,PPI 静推,观察出血 / 穿孔
- 无痛胃镜:24 h 内禁驾、精细操作
- 腹胀、咽痛:1-2 d 自然缓解
- 黑便、剧痛、发热:立即就诊

## 常见并发症
- 咽部擦伤、出血(0.5%)
- 心律失常、低氧、误吸
- 出血:活检、EMR/ESD
- 穿孔:EMR/ESD(0.5-1%)、食管穿孔
- 麻醉相关:丙泊酚呼吸抑制

## 注意事项
- 年龄 > 45 岁首次筛查,有家族史提前
- 早期胃癌常无特异性症状
- 活检阴性不能完全排除肿瘤(取样误差)
- Hp、胃泌素、抗体联合判读
- 萎缩 / 肠化定期随访
