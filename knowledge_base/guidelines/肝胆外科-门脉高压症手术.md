# 门脉高压症手术

## 概述
门脉高压症(portal hypertension)是一组由门静脉系统压力升高引起的临床综合征,主要病因为肝硬化(我国 90% 为肝炎后肝硬化)。当食管胃底曲张静脉破裂出血(EVB)时,病死率高达 20-40%。外科手术是药物和内镜治疗失败、Child-Pugh A/B 级患者的重要选择。

## 病因与分类
- **肝内型**(最常见):肝硬化(乙肝、酒精、胆汁淤积)
- **肝前型**:门静脉血栓、门静脉海绵样变
- **肝后型**:布加综合征、缩窄性心包炎

## 手术适应证
- 食管胃底曲张静脉破裂大出血,药物 + 内镜治疗失败
- 反复出血,不能长期耐受内镜治疗
- Child-Pugh A/B 级(肝功能 C 级者慎选)
- 区域性门脉高压(胰源性)

## 术式分类

### 一、断流术(贲门周围血管离断术)
- **原理**:切断门奇静脉之间的反常血流
- **代表术式**:Hassab 手术、Sugiura 手术
- **优点**:不减少肝脏血流,术后肝性脑病少
- **缺点**:再出血率较高(10-20%)
- **我国最常用**

### 二、分流术
- **非选择性分流**:门腔静脉端侧/侧侧分流(治疗 EVB 有效,但肝性脑病高达 30-50%)
- **选择性分流**:
  - 远端脾肾分流(DSRS,Warren 术)
  - 冠腔分流
- **限制性分流**:限制性门腔侧侧分流(分流量 < 10 mm)
- **优点**:止血彻底、再出血率低
- **缺点**:肝性脑病

### 三、联合术式
- 分流 + 断流(分流断流联合术,我国裘法祖院士倡导)

### 四、肝移植
- 终末期肝病(Child-Pugh C)合并门脉高压、出血
- 是根本性治疗

## 围手术期处理
- 术前:稳定血流动力学、纠正凝血、抗生素预防感染
- 术中:超声多普勒、门静脉测压
- 术后:监测出血、肝功能、肝肾综合征、肝性脑病
- 内镜/药物序贯治疗:β 阻滞剂、生长抑素
- 抗病毒治疗(乙肝相关)

## 注意事项
- 门脉高压手术属高风险手术,严格把握适应证
- Child-Pugh C 级、严重低蛋白血症(ALB < 25 g/L)慎用
- 合并肝癌、重度黄疸(> 50 μmol/L)预后差
- 多数病例可经内镜、介入(TIPS)处理,外科手术作为备选
- 术后长期随访:出血、肝性脑病、肝功能衰竭
- 多学科综合管理
