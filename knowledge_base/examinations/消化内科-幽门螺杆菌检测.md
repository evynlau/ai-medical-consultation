# 幽门螺杆菌检测

## 概述
幽门螺杆菌(Hp)是革兰阴性微需氧菌,定植于胃黏膜,全球感染率约 50%,我国约 50-60%。Hp 是慢性胃炎、消化性溃疡、胃癌、MALT 淋巴瘤的主要病因。IARC Ⅰ 类致癌物。准确诊断与根除对胃癌防控至关重要。检测方法分侵入性(依赖胃镜)和非侵入性(无创)。

## 分类与方法

### 一、侵入性(依赖胃镜 + 活检)

#### 1. 快速尿素酶试验(RUT)
- **原理**:Hp 产生大量尿素酶,分解尿素 → NH₃ + CO₂,试剂 pH 改变显色
- **优势**:快速(几分钟)、廉价、可在胃镜时立即进行
- **活检部位**:胃窦 1 块 + 胃体 1 块(提高敏感性,避免球部异位)
- **敏感性 90-95%**、**特异性 95-100%**
- **假阴性**:出血、PPI、抗生素、铋剂、严重萎缩
- **假阳性**:其他产尿素酶菌(空肠弯曲菌等),罕见

#### 2. 组织学(Warthin-Starry 银染 / Giemsa / 免疫组化)
- **金标准之一**,可同时评估炎症、萎缩、肠化、癌
- 活检:胃窦 2、胃体 2、角切迹 1(OLGA/OLGIM 评估)
- 敏感性 90%+ 特异性 100%
- 费用高、需病理医师

#### 3. Hp 培养
- **唯一能药敏的方法**
- 用于多次治疗失败、耐药评估
- 成功率 70-80%(特殊转运、需微需氧条件)
- 耗时 3-7 d

#### 4. PCR / 分子检测
- 胃液、活检、粪便
- 测耐药基因:23S rRNA(克拉霉素)、gyrA(左氧氟沙星)、rdxA(甲硝唑)
- 指导精准根除

### 二、非侵入性

#### 1. ¹³C 尿素呼气试验(UBT)
- **金标准**非侵入性方法
- **原理**:口服 ¹³C-尿素 → Hp 尿素酶分解 → ¹³CO₂ 呼出
- **操作**:
  - 空腹 6 h、漱口
  - 服用 ¹³C-尿素胶囊 + 橘汁(延缓胃排空)
  - 收集 0 和 30 min 呼气
  - DOB(δ 超过基线) ≥ 4‰ 阳性
- **敏感性和特异性均 > 95%**
- **停药要求**:PPI 停 2 周、抗生素 / 铋剂停 4 周
- **优点**:无创、重复性好、量化
- **缺点**:不适用于胃大部切除
- **¹⁴C 呼气试验**:简便、价格低,孕妇儿童避免(辐射)

#### 2. 粪便抗原试验(SAT)
- **原理**:检测粪便中 Hp 抗原(单克隆抗体)
- **酶联免疫、胶体金**
- 敏感度 90-95%、特异度 95%
- 适用于儿童、不能配合呼气
- 停药要求同 UBT
- **胶体金试剂盒**:快速、但准确度差于 ELISA

#### 3. 血清抗体(IgG)
- 反映既往或现症感染
- 阳性不证明活动感染(治疗后 6-12 月仍可阳性)
- 适用:**流行病学调查、筛查、血小板减少(ITP)、胃癌高发区筛查**
- 治疗评估:不用于根除评估
- 治疗前血清可作为基线

#### 4. 尿液抗体、唾液抗体**
- 准确性较差,临床少用

## 适应证

### 检查(诊断)
- 消化不良、溃疡症状
- Hp 相关疾病确诊
- Hp 感染流行病学调查
- 胃癌家族史筛查
- 儿童 ITP、不明原因贫血
- 长期 PPI / NSAIDs 使用前

### 根除评估
- 首选:UBT、粪便抗原
- **停 PPI ≥ 2 周,停抗生素 / 铋剂 ≥ 4 周**
- 血清抗体不用于评估
- 必要时胃镜复查 + RUT / 组织学

### 筛查(胃癌高发)
- 日本(40 岁起):UBT + 胃镜
- 我国:胃癌高发区、健康体检

## 结果判读
- **UBT DOB ≥ 4‰**:阳性
- **RUT**:30 min-24 h 显色(具体看试剂)
- **SAT**:临界值(ELISA:OD ≥ 临界)
- **血清抗体**:定性 / 定量

## 假阴性 / 假阳性

### 假阴性
- 近期用药(PPI、抗生素、铋、硫糖铝、促动力)
- 出血(中和 pH)
- 萎缩、肠化、Hp 球形变
- 早期感染(< 2 周)
- 胃大部切除

### 假阳性
- 产尿素酶其他细菌(空肠弯曲菌、幽门螺杆菌亚种)
- 口腔卫生差

## 注意事项
- **检查前停药**:PPI 2 周、抗生素 / 铋剂 / 中药 4 周
- **儿童检测**:首选粪便抗原、UBT;血清抗体仅筛查
- **怀孕**:避免 ¹⁴C-UBT、血清抗体
- **明确诊断 = 根除治疗前必须有活动性证据**
- **既往治疗者**血清抗体可保持阳性数年
- 胃镜检查同时活检,提高检出率
- 不同方法联合使用提高准确性
