# AI 影像分析模块方案

> 医生辅助诊断子系统，支持多模态医学影像分析

---

## 一、项目背景

### 1.1 目标
- **场景**：医生辅助诊断工具
- **核心价值**：AI 自动标注影像中可能出现的病灶，辅助医生阅片
- **次要价值**：患者可查看 AI 分析过程，了解影像如何被解读

### 1.2 与现有系统关系
- **独立模块**：不与问诊对话耦合
- **菜单入口**：在管理后台和医生工作台添加"影像分析"入口
- **数据共享**：可关联问诊记录（可选）

## 四、数据与模型

### 4.1 数据集

| 项目 | 内容 |
|------|------|
| **来源** | Kaggle Chest X-Ray Images (Pneumonia) |
| **样本数** | 5,856 张 |
| **类别** | NORMAL / PNEUMONIA |
| **年龄** | 1-5 岁儿童 |
| **格式** | JPEG (不规则分辨率) |
| **许可证** | CC BY 4.0 |

**数据划分**：
- 训练集：5,216 张
- 测试集：624 张
- 验证集：16 张

### 4.2 模型选择

| 模型 | 优势 | 劣势 | 决策 |
|------|------|------|------|
| **ResNet50** | 原项目使用，精度高 | 模型较大（~100MB）| ✅ 选用 |
| EfficientNet-B0 | 更小更快 | 需重新训练 | 备选 |
| DenseNet121 | 医学影像常用 | 需重新训练 | 备选 |

**选择理由**：
- 原项目已验证 ResNet50 达到 95.5% 准确率
- 迁移成本最低（仅需转换权重格式）
- 与 Grad-CAM 集成成熟

### 4.3 训练环境

| 项目 | 配置 |
|------|------|
| GPU | 用户 GPU 环境 |
| 框架 | PyTorch 2.0+ |
| 训练轮数 | 30 epochs |
| Batch Size | 16 |
| 学习率 | 0.0125 |
| 优化器 | SGD (momentum=0.9) |
| 损失函数 | CrossEntropyLoss |

## 五、API 设计

### 5.1 接口列表

```python
# 1. 上传影像并分析（核心接口）
POST /api/v1/imaging/pneumonia/analyze

# 2. 获取分析历史
GET /api/v1/imaging/history

# 3. 获取单个分析详情
GET /api/v1/imaging/{analysis_id}

# 4. 医生提交标注
POST /api/v1/imaging/{analysis_id}/annotate

# 5. 获取模型列表
GET /api/v1/imaging/models

# 6. 上传自定义模型
POST /api/v1/imaging/models/upload
```

### 5.2 核心接口详情

#### POST /imaging/pneumonia/analyze

**Request**：
```
Content-Type: multipart/form-data
- file: 影像文件 (JPEG/PNG, max 10MB)
- patient_id: 患者ID (可选)
- consultation_id: 关联问诊ID (可选)
```

**Response**：
```json
{
  "id": "img_2026_06_10_001",
  "prediction": "PNEUMONIA",
  "prediction_label": "肺炎",
  "probabilities": {
    "normal": 0.045,
    "pneumonia": 0.955
  },
  "confidence": 0.955,
  "model_version": "resnet50_v1.0",
  "inference_time_ms": 234,
  "gradcam": "data:image/png;base64,...",
  "warnings": [
    "本结果仅供医生参考，不作为最终诊断依据",
    "请结合临床症状和其他检查综合判断"
  ],
  "disclaimer": "AI辅助诊断工具，最终诊断需由专业医生确认"
}
```

#### POST /imaging/{analysis_id}/annotate

**Request Body**：
```json
{
  "doctor_id": 1,
  "annotation": "右肺下叶斑片状阴影",
  "agreement": true,
  "correct_label": "PNEUMONIA"
}
```

**Response**：
```json
{
  "success": true,
  "message": "标注已保存"
}
```

## 九、风险与合规

### 9.1 关键风险

| 风险 | 等级 | 应对策略 |
|------|------|----------|
| **数据隐私** | 🔴 高 | 数据脱敏、不存储原始影像 |
| **模型偏差** | 🟡 中 | 仅儿童数据，需扩展成人数据集 |
| **误诊责任** | 🔴 高 | 明确免责声明 + 医生确认流程 |
| **GPU 资源** | 🟡 中 | 支持 CPU 推理（< 2s/张）|
| **数据集单一** | 🟡 中 | 后续可补充成人胸片数据 |

### 9.2 合规要求

1. ✅ 必须显示"AI 辅助"标识
2. ✅ 必须显示免责声明
3. ✅ 不能作为独立诊断依据
4. ✅ 仅供医生查看
5. ✅ 患者查看需医生授权
