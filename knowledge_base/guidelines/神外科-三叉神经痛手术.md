# 三叉神经痛手术

## 概述
三叉神经痛(TN)表现为三叉神经分布区短暂、剧烈、电击样疼痛,好发于中老年。**药物治疗**(卡马西平)是一线,**经皮穿刺手术**与**微血管减压术(MVD)**是外科选择,根据病因、患者状态个体化。

## 分类
- **经典 TN**(原发,80%):神经血管压迫(NVC)
- **继发性 TN**:肿瘤、多发硬化、动脉瘤
- **特发性**:无明确原因

## 诊断
- **临床表现**(主要):
  - 单侧、突发、短暂(< 2 min)电击样痛
  - 触发点(洗脸、刷牙、咀嚼、说话)
  - 三叉神经分布区
  - 间歇期正常
- **MRI**(3D-TOF、CISS/FIESTA、FIESTA):
  - 排除继发
  - 评估血管、神经关系
- **三叉神经反射**:角膜反射、瞬目反射
- 鉴别:牙痛、舌咽神经痛、颞下颌关节病、丛集性头痛、SUNCT

## 治疗

### 药物治疗(一线)
- **卡马西平**(首选):100 mg bid 起,渐增至 200 mg tid
  - 注意白细胞、肝功、皮疹(SJS)
  - 70% 初始有效
- **奥卡西平**:300 mg bid 起,600-1800 mg/d
- **加巴喷丁、普瑞巴林**:辅助
- **巴氯芬**:辅助
- 长期:副作用、耐药

### 外科治疗
- **指征**:
  - 药物失败、不能耐受副作用
  - 影像学发现 NVC
  - 患者要求
- **方式**:
  - **微血管减压术(MVD)**:首选(有明确 NVC)
  - **经皮穿刺手术**:不适合 MVD、复发、高龄
  - **SRS(γ刀)**:不能耐受手术

### 1. 微血管减压术(MVD)
- **Janetta 手术**
- **机制**:解除血管对三叉神经的搏动性压迫
- **疗效**:90% 显著缓解,80% 长期无疼痛
- **步骤**:
  - 枕下乙状窦后入路
  - 释放脑脊液、显露神经
  - 识别责任血管
  - Teflon 棉垫隔
  - 全程神经电生理监测(BAEP、LSR)
- **并发症**:
  - 脑脊液漏(2-5%)
  - 听力下降、面瘫(1-5%)
  - 感染、颅内血肿
  - 死亡率 < 0.5%

### 2. 经皮穿刺手术
- **机制**:破坏三叉神经半月节传导痛觉
- 适合:老年、复发、不愿开颅
- 有效率 90-95%,复发率 20-30%
- 类型:
  - **射频热凝(RF)**:经典、首选
    - 选择性 V2、V3
    - CT 引导或 C 臂
    - 复发可重复
  - **甘油注射**:操作简单
  - **球囊压迫(PBC)**:适合 V1 分布
- 并发症:
  - 面部麻木(预期)
  - 角膜反射消失
  - 咀嚼肌无力
  - 复视、颅内感染(罕见)

### 3. 立体定向放射外科(SRS)
- **γ刀**:三叉神经根部 70-80 Gy
- 适合:药物失败、合并症、复发
- 缓解延迟(数月),长期 60-70%
- 复发率 20-30%(3-5 年)
- 副作用:面部麻木(5-15%)

### 4. 外周神经手术
- 撕脱、神经切断
- 复发率高,不推荐

## 决策与流程
```
确诊 TN
  ↓
一线:卡马西平 / 奥卡西平
  ↓
失败 / 副作用
  ↓
MRI 评估 NVC、继发
  ↓
有 NVC、年轻: MVD (首选)
  ↓
不适合 MVD / 复发: 经皮穿刺 或 SRS
```

## 围术期(MVD)
- 神经电生理监测(BAEP)
- 术中识别血管、神经
- 术后:头痛、颅内血肿、感染
- 多数术后即缓解,部分延迟

## 预后
- **MVD**:80% 长期无疼痛(10 年)
- **RF**:80% 短期、50-60% 长期
- **SRS**:60-70% 5 年缓解
- **复发后** 可再次手术或转换方法

## 注意事项
- **NVC 阳性者 MVD 优于其他**
- 多发硬化性 TN:SRS 较好
- 双侧 TN 罕见,慎用破坏性手术
- 术后残余痛:短期(数月)可观察
- **心理评估**:长期疼痛可伴抑郁
- 老年:RF / SRS 优先
- 复发:分级处理
