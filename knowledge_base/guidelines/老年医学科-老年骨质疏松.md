# 老年骨质疏松

## 概述
骨质疏松症(OP)是老年人最常见的骨骼疾病,**60+ 患病率 30-40%**(女),**80+ 60%**。**脆性骨折**(髋部、椎体、前臂)是其严重后果,**髋部骨折 1 年内死亡 20-30%**。**早筛查(BMD)、防跌倒、规范化治疗**是核心。

## 流行病学
- 我国 60+ OP:男 15%,女 30%
- 髋部骨折 1 年死亡率 20-30%
- 椎体骨折 5 年再发 20%
- 我国 50+ 髋部骨折 2035 预计 60 万+ (国际)

## 危险因素

### 不可改变
- **年龄、性别**(绝经后)
- **种族**(亚洲、白)
- **家族史**(父母髋部骨折)
- **早绝经**(< 45)
- **既往脆性骨折**
- **低体重**(< 57 kg 或 BMI < 19)

### 可改变
- **吸烟、酗酒**
- **Vit D、钙缺乏**
- **缺乏运动**
- **多重用药**(糖皮质、抗癫痫、芳香化酶抑制剂、雄激素剥夺)
- **营养不良**
- **跌倒** 风险

## 诊断

### BMD 测定(DXA)
- **金标准**
- **部位**:腰椎 + 髋部
- **T 值**(白种人女性峰值)
  - **≥ -1.0**:正常
  - **-2.5 < T < -1.0**:骨量减少
  - **≤ -2.5**:骨质疏松
  - **≤ -2.5 + 脆性骨折**:严重
- **Z 值**(< 50 岁)
- **椎体骨折评估(VFA)**:椎体

### 影像
- **椎体骨折**(X 线/MRI 提示)
- 脆性骨折 = 诊断 OP(独立于 BMD)

### FRAX
- **10 年骨折概率**:
  - **髋部 ≥ 3%** 或 **主要骨质疏松性骨折 ≥ 20%** → 治疗
- 含/不含 BMD

### 实验室(排除继发)
- **血钙、磷、ALP、PTH**
- **25-OH Vit D**
- **肝、肾**
- **TSH**
- **CBC、ESR**
- **尿钙**(24 h)
- **PTH(继发性甲旁亢)**
- **免疫固定电泳**(MM)
- **性激素**
- **OGTT、CEA**(男)

## 治疗

### 1. 基础
- **钙**:**1000-1200 mg/d**(饮食 + 补)
- **Vit D**:**800-2000 IU/d**(目标 25-OH Vit D > 30 ng/mL)
- **运动**:抗阻 + 平衡(太极)
- **戒烟限酒**
- **防跌倒**(环境、肌力、视力、停用致跌药)

### 2. 抗骨吸收(首选)
- **双膦酸盐**:
  - **阿仑膦酸钠** 70 mg/周(口服,**空腹水 200 mL、立位 30 min**)
  - **利塞膦酸钠** 35 mg/周
  - **伊班膦酸钠** 3 mg/3 月 IV
  - **唑来膦酸** 5 mg/年 IV(15 min,住院观察)
  - 5 年后可"药物假期"(口服)、3 年(IV)
- **地舒单抗(Denosumab)** 60 mg s.c. q6m
  - 不可"停药"(反弹),需序贯 BP
  - 严重骨折、肾衰用
- **SERMs**:**雷洛昔芬**(女,绝经后,椎体为主)
- **雌激素**(绝经早、围绝经,短期)

### 3. 促骨形成
- **特立帕肽**(TPTD 1-34) 20 μg/d s.c.
  - 严重骨折、严重 OP
  - **2 年** 限
  - 后序贯 BP
- **阿巴洛肽**(Abaloparatatide)
- **Romosozumab**(romos 单抗):促形成 + 抗吸,12 月,后序贯

### 4. 序贯治疗
- **特立帕肽 → 双膦**
- **罗莫单抗 → 双膦**
- **地舒单抗 → 双膦(必须)**
- **BP 用 3-5 年 → 评估**

## 方案选择

| 风险 | 治疗 |
|---|---|
| 轻度 OP(无骨折、骨量减少) | 钙 + Vit D + 运动 |
| 中度 OP(无骨折) | 钙 + Vit D + 双膦酸盐(口服) |
| 严重 OP(脆性骨折、髋/椎) | 双膦酸盐(IV)/地舒/特立帕肽 |
| 极严重 | 特立帕肽/罗莫 + 序贯 |
| 肾衰 (eGFR < 30) | 地舒单抗 / 西那卡塞(继发甲旁亢) |

## 监测
- **BMD**:每 1-2 年(早期)
- **骨代谢标志**(BTM):
  - **PINP**(促形成)、CTX(抗吸)
- **血清钙、25-OH Vit D**
- **髋、肾**(双膦)
- **颚骨、下颌骨坏死(BRONJ)** 风险

## 脆性骨折急性处理
- **髋部**:手术(半髋、全髋) + 早下床
- **椎体**:保守(无神经)、手术(脊髓压迫)
- **椎体成形(PVP/PKP)**:顽固痛
- **康复**(早活动、防血栓)
- **再骨折预防**(基础 + 抗 OP)
- **跌倒预防**

## 注意事项
- **BMD 仅 -1.0 但有骨折 = OP**
- **FRAX** 评估
- **钙 + Vit D** 是基础
- **运动**(有氧 + 抗阻 + 平衡)
- **跌倒** 预防
- **药物副作用**:
  - 双膦酸盐:流感样症状(IV)、食管刺激、颚骨坏死(BRONJ)、非典型股骨骨折
  - 地舒:低钙、感染
  - 特立帕肽:高钙、头晕、肾结石
- **不滥用激素**(糖皮质)
- **肾衰**:地舒、特立帕肽(可用)、双膦减量
- **空腹口服双膦**(水 200 mL,立位 30 min)
- **髋部骨折**:48 h 内手术(条件)
- **二次骨折预防** 1 科
- **健康教育** 重要
