# 带状疱疹

## 概述
带状疱疹是由水痘-带状疱疹病毒(VZV)再次激活引起的急性感染性皮肤病。病毒初次感染时表现为水痘,痊愈后病毒潜伏于脊神经后根或脑神经感觉神经节,当机体免疫力下降时病毒可再次活化,沿神经纤维移动至皮肤,引起带状疱疹。以沿身体一侧周围神经分布的成簇水疱伴疼痛为特征。好发于中老年人,50岁以上人群发病率显著升高。痊愈后可获得较持久免疫,但有复发可能。

## 分类
- 眼带状疱疹(累及三叉神经眼支)
- 耳带状疱疹(面瘫、耳鸣、听力下降 Ramsay Hunt综合征)
- 运动性带状疱疹(肌肉麻痹)
- 泛发性带状疱疹(免疫功能低下者,皮疹泛发)
- 内脏带状疱疹(病毒播散至内脏器官)
- 脑膜脑炎型带状疱疹
- 骶部带状疱疹(累及骶神经)
- 无疹性带状疱疹(仅疼痛无皮疹)
- 顿挫型带状疱疹(皮疹不典型或仅红斑)

## 危险因素
- 年龄>50岁(最重要危险因素)
- 免疫功能低下(HIV感染、恶性肿瘤、免疫抑制治疗)
- 长期使用糖皮质激素
- 器官移植后使用免疫抑制剂
- 过度劳累、精神压力大
- 创伤(手术、外伤)
- 放射治疗
- 合并慢性疾病(糖尿病、肝病、肾病)
- 恶性肿瘤(尤其血液系统肿瘤)
- 以前患过水痘(病毒潜伏)

## 常见症状
- 前驱症状(出疹前3-5天):
  - 患处感觉异常(灼痒感、刺痛、感觉过敏)
  - 轻度乏力、低热、食欲下降
  - 患处神经痛(烧灼样、刀割样、针刺样)
- 皮疹特点:
  - 成簇水疱,绿豆至黄豆大小
  - 沿某一周围神经呈带状排列(单侧,不超过正中线)
  - 常见部位:胸背部、腰腹部、头面部、四肢
  - 躯干为好发部位("缠腰龙")
  - 面部(眼支受累最严重)
  - 水疱初起清亮,后转浑浊,破溃后结痂
- 疼痛(带状疱疹后神经痛PHN):
  - 急性期疼痛(出疹期间)
  - 皮疹消退后疼痛持续>3个月为后遗神经痛
  - 疼痛性质多样:烧灼样、电击样、刀割样、针刺样
  - 疼痛可持续数月至数年
- 局部淋巴结肿大
- 病程:2-3周,老年人可更长

## 并发症
- 带状疱疹后神经痛(PHN,最常见并发症,发生率约10-30%)
- 眼部并发症:
  - 角膜炎、角膜溃疡
  - 结膜炎
  - 虹膜睫状体炎
  - 青光眼
  - 视力下降甚至失明(眼带状疱疹)
- 耳部并发症(Ramsay Hunt综合征):
  - 面瘫(周围性面神经麻痹)
  - 耳鸣、听力下降
  - 眩晕
- 皮肤并发症:
  - 继发细菌感染
  - 瘢痕形成
  - 色素沉着或脱失
- 运动性麻痹(肌肉无力)
- 脑膜脑炎
- 脊髓炎
- 继发细菌感染(肺炎、败血症)
- 内脏播散(免疫功能低下者)

## 治疗原则
- 抗病毒治疗(发病72小时内启动):
  - 首选阿昔洛韦(口服或静脉)
  - 泛昔洛韦(口服,方便)
  - 伐昔洛韦(口服)
  - 疗程7-10天
- 镇痛治疗:
  - 急性期:NSAIDs(布洛芬、萘普生)
  - 后遗神经痛:加巴喷丁、普瑞巴林(一线用药)
  - 三环类抗抑郁药(阿米替林)
  - 弱阿片类药物(曲马多)
  - 局部辣椒素贴膏
- 糖皮质激素(存在争议):
  - 急性期短期使用可减轻神经痛
  - 适用于中老年患者,无禁忌证者
  - 需与抗病毒药同用
- 局部治疗:
  - 炉甘石洗剂(止痒)
  - 抗感染软膏(莫匹罗星)
  - 湿敷(渗出多时)
  - 眼带状疱疹:阿昔洛韦滴眼液、眼膏
- 神经营养药:甲钴胺、维生素B1、B12
- 物理治疗:紫外线照射、激光局部照射
- 后遗神经痛的处理:
  - 多种镇痛药物联合
  - 神经阻滞治疗
  - 脉冲射频神经调制
  - 心理干预

## 何时就医
- 出现典型带状疱疹皮疹(成簇水疱沿神经带状分布)
- 眼周出现水疱(立即就诊,避免眼部损伤)
- 耳部出现水疱伴面瘫、耳鸣(警惕Ramsay Hunt综合征)
- 疼痛剧烈,常规镇痛药无效
- 皮疹泛发,累及范围超过一个神经节段
- 免疫功能低下者出现皮疹
- 出现发热>3天不缓解
- 皮疹破溃后出现脓性渗出、红肿加重(继发感染)
- 出现视力下降、眼球疼痛(眼部并发症)
- 面瘫加重或双侧面瘫
- 出现恶心呕吐、头痛、颈项强直(脑膜炎)
- 出现呼吸困难(内脏播散)

## 预防
- 接种带状疱疹疫苗(最有效预防措施):
  - 重组带状疱疹疫苗(RZV,欣安立适):50岁以上人群接种,保护率>90%
  - 接种2剂,间隔2-6个月
  - 以前患过水痘者更需接种
- 提高免疫力:
  - 适度运动、规律作息
  - 均衡饮食(多摄入蛋白质、维生素)
  - 充足睡眠
  - 减轻精神压力
- 避免过度劳累
- 积极控制慢性疾病(糖尿病等)
- 避免长期使用免疫抑制剂(需权衡利弊)
- 早期发现皮疹,及时启动抗病毒治疗(可缩短病程、减轻疼痛)
- 接触患者后注意洗手(传染性较低,但水痘易感者仍需注意)
