# 老年糖尿病

## 概述
我国 60+ 糖尿病患病率 20%+,80+ 30%+,糖尿病前期 30-40%。老年糖尿病以**2 型为主**,**异质性大、共病多、低血糖风险高、衰弱**。**个体化目标、避免低血糖、关注多药**是核心。

## 特点
- **多 T2DM**(95%+)
- 1 型、长病程
- **肌少性肥胖**(Sarcopenic obesity)
- **认知障碍、抑郁** 共病
- **多重用药**
- **衰弱、跌倒**
- **肾功能不全**
- **低血糖症状不典型**
- **心脑肾** 风险

## 诊断
- **空腹 ≥ 7.0**(禁食 8 h)
- **OGTT 2h ≥ 11.1**
- **HbA1c ≥ 6.5%**
- 随机 ≥ 11.1 + 症状
- 老年**症状不特异**

## 控制目标(中国 2022 指南)

| 情况 | HbA1c |
|---|---|
| **健康老年(> 65 岁)** | < 7.5% |
| **复杂/中等**(多病、轻度认知、轻度功能受限) | < 8.0% |
| **非常复杂/健康差**(终末期、严重认知、长期照护) | < 8.5% |
| **终末期**(预期寿命短) | 避免高血糖、避免低血糖 |

- **HbA1c 8.5%+**:症状严重
- **低血糖阈值**:HbA1c < 6-7%

## 治疗

### 1. 生活方式
- **饮食**:个体化(老年营养、咀嚼)
- **运动**(150 min/周,有氧 + 抗阻)
- **减重**(肥胖)
- 戒烟限酒

### 2. 药物

#### 一线
- **二甲双胍**(eGFR ≥ 30):
  - 500-2000 mg/d
  - **优选**(老年轻度消化)
  - 监测肾、肝、Vit B12
- **DPP-4i**(老年安全、低血糖少):**西格列汀、沙格列汀、维格列汀、利格列汀**
  - **肾功能不全**:西格、维格减量
- **SGLT2i**(心肾保护):
  - **达格列净、恩格列净、卡格列净**
  - eGFR ≥ 20(糖尿病) / 20(心衰) / 20(CKD)
  - 注意:**泌尿、生殖感染**(老年女性)
  - 容量不足、酮症
- **GLP-1RA**:**利拉鲁肽、司美格鲁肽、度拉糖肽**
  - 体重 ↓
  - 恶心、肠道
  - 不可用于 MTC、Men2 史

#### 联合
- **二甲双胍 + SGLT2i / DPP-4i / GLP-1RA**
- **SGLT2i + DPP-4i**(无共同机制、协同)
- **SGLT2i + GLP-1RA**(心肾、肥胖)

#### 老年避免/谨慎
- **磺脲**:低血糖,**慎**(格列美脲、格列齐特缓释风险较低)
- **胰岛素**:低血糖,需操作能力
- **噻唑烷二酮**(吡格列酮):水肿、心衰、骨松
- **α 糖苷酶**(阿卡波糖):胃肠道

#### 胰岛素
- **必要**:T1DM、严重、应急、口服不佳
- **基础胰岛素**(NPH、甘精、地特、德谷):
  - **甘精 U100** 10 qd
  - **德谷 U100**(超长效)
- **预混**(诺和灵 30R 等) 注意低血糖
- **强化**:基础 + 餐时
- **加药** 谨慎(低血糖)

## 低血糖
- **阈值**:老年 < 3.0 < 一般
- **症状不典型**:嗜睡、淡漠、跌倒
- **严重**:昏迷、心脑缺血
- **处理**:**15-20 g 糖** → 15 min 测 → 重复
- **胰高血糖素**(注射、严重)
- **避免**:强化降糖、SGLT2i 致酮症(低血糖样症状)
- **未察觉低血糖**

## 急性并发症
- **DKA**(老年症状不典型)
- **HHS**(高渗):高糖、脱水、昏迷(老年多)
- **乳酸酸中毒**(双胍 + 肾衰)
- **SGLT2i 相关酮症**(正常血糖)

## 慢性并发症
- **视网膜**(年查眼底)
- **肾**(尿蛋白、eGFR)
- **神经**(感觉)
- **血管**(心、脑、外周)

## 多病共病
- **心衰**:**SGLT2i**(优)
- **CKD**:**SGLT2i**(eGFR ≥ 20)
- **ASCVD**:**SGLT2i / GLP-1RA**
- **骨松 + 跌倒**
- **认知**:低血糖避免

## 衰弱老年
- **HbA1c 8-8.5%**
- 简化方案
- 关注跌倒
- **GLP-1RA / DPP-4i**(安全)

## 急性期管理
- **胰岛素**(持续 IV/泵)
- **目标血糖** 140-180 mg/dL(住院)
- **SMBG q4-6h**

## 监测
- **HbA1c** q3 月(可达目标)/ q6 月
- **SMBG**(频度个体化)
- **肾、肝、电解质**
- **Vit B12**(双胍)
- **视网膜**(年)
- **足部**

## 注意事项
- **个体化目标**
- **避免低血糖**(关键)
- **多药精简**
- **不严格降糖**(衰弱、终末期)
- **衰弱、肌少、跌倒** 关注
- **认知障碍**:简化、自我管理支持
- **操作能力**(胰岛素、注射)
- **饮食营养** 平衡(不严格)
- **运动**:有氧 + 抗阻
- **足部护理**
