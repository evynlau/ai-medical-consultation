# 电解质与血气

## 概述
电解质与血气分析是肾脏功能评估的重要补充。肾脏调节体液渗透压、酸碱、电解质平衡,肾功能损害常伴多系统紊乱,血气分析 + 电解质检测是诊治关键。

## 钠(Na⁺)
- **参考值**:135-145 mmol/L
- **临床意义**:
  - **低钠**(< 135):
    - **稀释性**:SIADH、心衰、肝硬化、肾衰
    - **缺钠性**:呕吐、腹泻、利尿、肾上腺皮质功能不全、盐丢失性肾病
  - **高钠**(> 145):
    - **浓缩性**:脱水、尿崩症、渗透性利尿(高血糖、甘露醇)
- **尿钠**(FENa):鉴别肾前性、肾性 AKI

## 钾(K⁺)
- **参考值**:3.5-5.5 mmol/L
- **临床意义**:
  - **低钾**(< 3.5):
    - 摄入不足、丢失(呕吐、腹泻、利尿)
    - 转移(胰岛素、β₂ 激动剂、碱中毒)
    - 肾小管病(Fanconi、RTA、Bartter、Gitelman)
    - 甲亢周期性麻痹
  - **高钾**(> 5.5):
    - 肾排钾障碍(CKD、肾上腺功能不全、ACEI/ARB、螺内酯)
    - 假性高钾(溶血、止血带、PLT ↑)
    - 转移(酸中毒、横纹肌溶解、肿瘤溶解)
- **心电图**:
  - 低钾:U 波、ST ↓、T 低平、室性心律失常
  - 高钾:尖 T 波、QRS 宽、P 消失、室颤

## 氯(Cl⁻)
- **参考值**:98-110 mmol/L
- **随 Na⁺ 平行变化**
- **意义**:
  - **低氯**:呕吐(代谢性碱中毒)、利尿
  - **高氯**:高氯性代谢性酸中毒(腹泻、RTA)
  - 计算阴离子间隙:AG = Na - (Cl + HCO₃)

## 钙(Ca²⁺)
- **总钙**:2.10-2.55 mmol/L(8.5-10.5 mg/dL)
- **离子钙**:1.15-1.35 mmol/L
- **校正钙**:= 测 Ca + 0.02 × (40 - Alb)
- **临床意义**:
  - **低钙**(CKD-MBD):低钙、高磷、PTH ↑
  - **高钙**:原发性甲旁亢、肿瘤、维生素 D 中毒
- **钙磷乘积**:> 55 易转移性钙化

## 磷(P)
- **参考值**:0.85-1.45 mmol/L(2.5-4.5 mg/dL)
- **临床意义**:
  - **高磷**:CKD G3+、甲旁腺功能减退、肿瘤溶解、维生素 D 中毒
  - **低磷**:甲旁腺功能亢进、Fanconi、严重营养、磷结合剂
- **CKD-MBD**:Ca、P、PTH 三联管理

## 镁(Mg²⁺)
- **参考值**:0.7-1.0 mmol/L
- **临床意义**:
  - **低镁**:利尿剂、肠道丢失、CNI、酒精
  - **高镁**:肾衰、含镁抗酸剂
- 与低钾、低钙互相关联

## 碳酸氢根(HCO₃⁻)
- **参考值**:22-27 mmol/L
- **代谢性酸中毒**:
  - HCO₃⁻ ↓(< 22)
  - 代偿 PaCO₂ = 1.5 × HCO₃⁻ + 8
  - **AG 升高**:尿毒症、DKA、乳酸
  - **AG 正常**:腹泻、RTA
- **代谢性碱中毒**:HCO₃⁻ ↑(呕吐、利尿)

## 酸碱度(pH)
- 参考:7.35-7.45
- 详见「动脉血气分析」

## 渗透压(Osm)
- **血浆**:275-295 mOsm/kg
- 计算:2 × Na + 葡萄糖 / 18 + BUN / 2.8
- **尿渗透压**:
  - 等渗 ~ 血:等张尿(肾衰、肾性)
  - 高渗:肾前性、SIADH(不适当浓尿)
  - 低渗:尿崩症、原发性多饮

## 阴离子间隙(AG)
- **公式**:AG = Na⁺ - (Cl⁻ + HCO₃⁻) = 8-16 mmol/L
- **高 AG**:「MUDPILES」(甲醇、尿毒症、DKA、副醛、异烟肼/铁、乳酸、乙二醇、水杨酸)
- **低 AG**:低蛋白血症、多发骨髓瘤、锂中毒、溴中毒、误差

## 阴离子间隙解读
- **尿毒症性 AG ↑**:肾排酸障碍
- **RTA**:AG 正常型 + 高氯
- **DKA**:AG ↑ + 血酮体
- **乳酸酸中毒**:AG ↑ + 乳酸

## 肾脏病典型模式

### 1. CKD 晚期
- **代谢性酸中毒**(高 AG):HCO₃⁻ < 22、pH < 7.35
- **高血钾**(> 5.5)
- **低血钙、高血磷**
- **高 PTH**

### 2. 肾小管酸中毒(RTA)
- **Ⅰ 型(远端)**:AG 正常,低钾、肾结石、磷酸盐结石
- **Ⅱ 型(近端)**:AG 正常,低钾、Fanconi
- **Ⅳ 型**:高钾、醛固酮抵抗

### 3. AKI
- **代谢性酸中毒 + 高钾**
- **呼吸代偿**(Kussmaul)
- **水潴留**(稀释性低钠)

### 4. 透析相关
- 透析后低钾、低钙
- 透析间期高钾、酸中毒
- 失衡综合征

## 监测与处理

### 高钾
- 急:葡萄糖酸钙 + 胰岛素 + 葡萄糖、聚苯乙烯磺酸钙、透析
- 慢:限制摄入、降钾树脂、纠正酸中毒

### 代谢性酸中毒
- HCO₃⁻ < 22:补碱(碳酸氢钠口服 / 静)
- 严重(pH < 7.1、HCO₃⁻ < 12):紧急静滴
- 透析患者:透析液碱基 35-40

### 低钠
- 急性严重(< 120、神经症状):3% NaCl 100 ml × 1-3 次
- 慢纠正:6-10 mmol/L/d(< 8 / d 防脑桥脱髓鞘)
- SIADH:限水(< 800 ml/d)

### 低钙
- 急性:葡萄糖酸钙静推
- 慢:口服钙 + 活性维生素 D

## 注意事项

### 标本
- 血气:动脉肝素化注射器,15 min 送检
- 电解质:血清 / 血浆(避免溶血、长时间止血带)
- 尿电解质:24 h 尿或随机同步血样

### 影响因素
- 高血糖:假性低钠(每 ↑ 5.5 mmol/L 葡萄糖,Na 假性 ↓ 1.6 mmol/L)
- 高蛋白 / 高脂:假性低钠
- 输液:稀释、电解质偏差

### 联合解读
- AG / 渗透压 / 阴离子
- 血气 + 电解质 + 肾功
- 动态观察
